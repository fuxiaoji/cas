# 铁底湾手游内容与 CAS 实时战斗的接线

铁底湾最新可核验交付为 **0.6.11 离线试玩**，构建源 `6601bddde1b4f0817ebbb6864ee80137647e1d88`，APK 哈希 `994debaafb0c98bbbe683fadab72a7982009888febdcf54caa6befbb12acc29a`。相较原迁移基线 0.6.9，新增七日签到和战役结尾演出。0.6.11 离线包关闭排位，联机匹配与排位仍以 0.6.7 的实交付行为对照。CAS 五版及适用想定是战斗数据基线。旧角色和关卡 ID 保持稳定，CAS 账号和存档独立。

| 迁入代码 | CAS 落点与适配 |
| --- | --- |
| `mobile/src/progression/GrowthPort.tsx` 的母港区、`growth.css` | `client/src/GrowthPort.tsx`；沿用原结构、值更舰、海报和底部入口，由独立 CAS 存档提供数据。 |
| `mobile/src/online/AccountPanel.tsx` 的登录区、`account.css` | `client/src/Login.tsx`；本机登录和注册接 `account.ts`。账号之间隔离，首个账号接续本机旧 CAS 离线档。 |
| `mobile/src/prologue/script.ts`、角色立绘及结尾 CG | `client/src/prologue/`；剧情、选择和归港图沿用。开场为 15 艘舰真实交火，镜头推近五舰后，在同一战局上叠加对白，三段实操接续同一战局。原作 96 艘舰的开场编制尚未移植。[序章来源](campaign/prologue-runtime-sources.md) |
| `mobile/src/campaign/` 的海图页面、海岸线和母港底图 | `client/src/campaign-map/`；保留六张区图和海域定位，接入 16 个想定的 32 个中文关位。0.6.11 战役结尾演出仍待移植。 |
| `mobile/src/activities/ActivityCenter.tsx`、`activity.css`、`check-in.ts`，以及 `mobile/src/meta/store.ts` 周奖励 | `client/src/activities/`；已接前六天的奖励、周补给商店和挑战奖励。第七天北卡罗来纳在对应 CAS 舰卡及战列舰能力核验后启用。 |
| `mobile/src/economy/ShipArrival.tsx`、`ship-arrival.css` | `client/src/RecruitArrival.tsx`；复用到港演出。只在实际征募入账后显示当次 CAS 舰娘、兑换勋章和保底结果。 |

| 原手游模块 | 保留的体验 | 接到 CAS 的验收条件 |
| --- | --- | --- |
| 母港、大厅、舰库、编队、征募和邮箱 | 初始舰队、值更舰、双池双券、保底、邮件和已解锁 AI；进港能继续上次进度。 | 已有母港、初始舰队、离线体验池、预设、部分商店和活动。原舰池、指定兑换、三舰礼包、邮箱和正式经济仍需舰卡、货架或账号服务。 |
| 战役与越级挑战 | 同盟／轴心双线、三档难度、评级，历史编制借舰；挑战和竞技使用个人舰队。 | 按[战役原页对照](campaign/source-crosswalk.md)载入 CAS 编制、海域、目标和特例，不能只换海图或舰名；另核周本和首通奖励。没有原书对应的旧作原创关，保持原剧情 ID，以明确标注的 CAS 架空想定承接。 |
| 对战大厅与约战 | 先免费约战与 3000 分非排位，再按旧方案排位；10000 分保留战列舰和护航编制。 | CAS 实战重定舰价、用原生同一内核做权威战局。排位仍由玩家确认服务器 AI 建议。跨端重连、本席回放和结果幂等均实测后再开放。 |
| 日间教学与夜战教学 | 序章训练基础航线与火力。独立夜战课用固定阵位和航线教本舰雷达、目视识别、照明与战情。 | 由状态机依次确认开机回执、本舰直接回波、目视接触和实际起亮。 |
| 开场序章 | 保留舰队演出、五位初始舰娘、对白选择、选领舰、教学和一次性奖励。 | 对照旧 `mobile/src/prologue/script.ts`。玩家在第五驱逐小队执行多航点、同步、拖炮及调角放雷；舰队火力和弹着从 CAS 对局取证。 |
| AI 指挥官 | 保留原作人设、头像和擅长的任务。 | 旧 `tactical.py` 与 `formation_tactics.py` 的搜索、接近、交战、屏护、雷击和撤退条件转为实时状态；旧六角距离不作为 CAS 参数。全程使用本席观察和同一命令校验。 |

指挥官语音事件对照旧 `mobile/src/events.ts`、`mobile/src/sound.ts`。本地试玩版使用十六段旧阵营通用录音，按局、席位及可见事件去重，序章开场也从同盟席可见战报触发。专属指挥官录音仍待迁移。配乐现有五段原创曲目，按序章、机动、交火、胜负切换并为电台让音。铁底湾所用《战舰世界》曲库缺少可供独立 CAS 包分发的授权。阵营录音只在显式本地试玩构建中打包。[原创音频台账](../client/src/audio/score/ledger.json)

舰况立绘以稳定 ID 匹配。圣乔治角与通道行动的 18 艘具名舰使用原手游的对应原图；弗莱彻、克利夫兰、阳炎、川内的通用演习舰另用标明身份的舰型代表。原路径、ID、哈希和本地内测范围见[立绘台账](../client/src/assets/portraits/ledger.json)。

新局使用 `cas-realtime-v8`。舰船按连续弧线机动，炮座状态决定能否开火和何时开火，鱼雷推进和命中由核验的 CAS 武器档和概率表裁决。存档按各自版本重演。[航行、鱼雷和炮座依据](rules/continuous-navigation.md) · [覆盖台账](rules/coverage.md)

独立[免费内测服务](../server/README.md)已有账号、双池双券、保底、邮箱、签到、免费商店和圣乔治角双线权威 PvE。个人编队可用拥有舰船选舰、定领舰并保存云草案，服务校验 3000／10000 分档舰种和数量约束。两档的 CAS 点表、个人舰队出战、匹配和排位仍未开放。离线征募仍是体验池，第七日签到仍处于待启用状态。
