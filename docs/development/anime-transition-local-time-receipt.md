# 全屏动漫转场与现实时间港湾

2026-11-12，按用户纠正后的要求实施。默认转场重新使用全屏动漫遮盖与揭幕，保留约三名放大小人；标题与母港各有晨、昼、昏、夜四套实时光景。只修改界面表现，不触碰原核、经济进度、历史地图、剧情构图和正式用户存档。

## 默认过场

`page_transition.gd` 默认 `full_screen_wipe=true`，0.62秒；三种完整画面切换为云浪横推、圆形开合和错层纸帆斜切。原生 `AnimationPlayer` 在遮满后释放旧页截图，再揭开已建好的新页面；无额外等待。卡片使用动漫云朵、两层海浪、金色太阳、放射短线与小纸片装饰，覆盖窗口全域。

小人默认三名，目标高度为画布26%，独立延时、跳高、节奏、轻摆。之前每次近似相同的原因是只从已拥有角色抽选，而新档仅三名。现在默认从全部已登记、身份准确的SD角色库随机选三个，相邻转场优先避开上一组三个；纯装饰展示不等于获取或解锁角色，不改变账户。Inspector的`Use Registered Cast`可改回仅已有角色库。少量候选时按实际数量显示，不伪造重复身份；已注册本人素材由统一`character_art.gd`解析，后续海伦娜纠正会直接生效。

快速切页和取消会释放截图与输入门。减少动态、关闭页面动效、同页刷新及headless均直接切换。旧轻淡入保留为可选参数，但不是当前默认。

## 现实时间光景

`local_time_backdrop.gd`绑定`Time.get_datetime_dict_from_system(false)`，即运行机器的现实本地时间，每10秒重新读取；保持页面打开也会跨时段改变。可注入独立时钟做验证，未与模拟时钟、航次天气或账户日期混用。

| 本地时段 | 港湾/标题表现 |
| --- | --- |
| 05:00–08:00 晨曦 | 粉紫天空、暖云边、低太阳与暖色水面反射 |
| 08:00–16:30 日间 | 明蓝天空、白云和清透海面；标题旧画中烘焙的橙色晚霞转为日光云色 |
| 16:30–19:00 黄昏 | 紫色高空、橙金地平线、暖色岸壁、太阳光路、初亮的航标 |
| 19:00–05:00 星夜 | 蓝色月光、程序月牙与星点、灯塔和码头暖灯、月色水纹 |

光景并非整页叠加黑色。天空、海水、岸壁、日月、反光、登记灯位分别渲染。材质只附在背景图，秘书舰、标题和按钮不被染暗。每个时段以小时渐变，跨分界无需重建页面、重置选项或改写档案。装饰性水纹与星光可随减少动态停止，现实时间刷新仍保留。

四套光景复用既有原创港湾/标题底画与程序材质，不是新生成的四张不同视角CG，也没有替换战场程序海域或已恢复的历史卫星图。

## Godot编辑入口

- `scenes/ui/page_transition.tscn`及`page_transition_overlay.tscn`：动画Timeline、云海配色、遮罩样式、时长、人数和大小；新增`Use Registered Cast`开关。
- `scripts/title_screen.gd`与`harbor_view.gd`：Inspector的`Preview Hour`为-1时跟随现实时间，0–23时预览指定小时。运行时`LocalTimeBackdrop`节点的`clock`可注入测试时钟。
- `shaders/local_time_backdrop.gdshader`：天空/岸壁/海水配色、日月位置、亮灯登记坐标及光路。

本轮没有修改`main.gd`、`port_presentation.gd`、Rust或军需/竞技/剧情数据；由主代理另行集成其他任务。
