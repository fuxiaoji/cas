# 2026-11-14 驻防互动、陆图镜头与出击编成

本批只调整 Godot 呈现及原有经济服务的只读搭载预览；不改历史战役、舰表、参考资料或 Rust 海战裁决。

## 已实现

- `sortie_formation.tscn` / `sortie_formation.gd`：主编成改为保存舰队、当前舰成员、可用舰库、本次出航四个清楚区域；本人肖像、舰名和舰种不借用同级舰。鼠标拖放、独立触屏拖放、点选均共用 FleetManager。保存编队和成员没有三舰上限，多支随行舰队仍合并成真实唯一身份列表；重复舰由既有服务拒绝。
- 主编成的舰队栏宽、航行摘要宽、卡片尺寸可在 Godot Inspector 调整，编辑器可预览原生 Control 布局。主入口由 Main 加载该场景。
- 弹药、油料、体力、货舱展示来自现有经济服务；出航是否可用取决于 `preview_sortie()`。装载弹窗关闭后重新读取摘要。实际出航仍执行 Main.launch 和原有账户事务。
- `army_loadout.gd`：逐 MCP 查看本人立绘与北约规模军牌，逐真实连队配置载具与搭载舰；只列出本次随行且满足资格的舰艇。容量按整连、实际弹药装载、真实运输表检查，显示人数及舱位，悬停可查各舰装载。关闭只丢弃草稿；保存只保存搭载配置，不扣出航资源。
- `amphibious_expedition_service.prepare_plan()`：原 prepare 的计算提成只读草稿入口，继续校验本人编制、重复连队、载舰、整连运力、身体上限。两栖装甲载具与装甲部队均要求 APV / LHA / CV；空输要求 LHA / CV；普通登陆艇不增加该资格限制。prepare 仍读取已保存计划并调用同一入口。
- 家园海陆出击可以选用真实已存舰队，舰娘肖像随外观变化；显示真实出航弹药。默认战术选择先尝试可由现有舰艇投送的编制。采购与关闭按钮、底部校验文字不再重叠裁切。
- `home_ship_resident.gd`：驻防舰名单对应本人舰娘小人上岸活动，离开驻防即移除，已解锁外观变更立即刷新；与原战术娘采用独立身份层。轻触和相遇使用短暂动作与小光点反馈，不弹出长文字、不改数值或发放奖励。
- `littoral_land.gd`：点击在抬起且未拖动时才下发选择；拖图、滚轮指针锚定缩放、双指缩放及平移、触控板手势、键盘方向 / Home / ±、手柄焦点控制；夹住镜头边界，主副图切换保留镜头，拖部队卡期间不抢地图镜头。缩放沿同一个岛屿投影框连续变化，避免从全图滚一下反而视觉缩小。

## 实际验收

`godot/tests/sortie_home_camera_review.gd` 在独立账号、离屏 NVIDIA OpenGL 窗口执行：**67 / 67**。包含 960×540、1280×720、1920×1080 三种窗口，真实鼠标双向拖舰、独立触屏拖舰、跨编队身份冲突拒绝、两支编队七艘出航、空输不许上普通战列舰、普通海军陆战连可搭载、保存与取消不扣费、驻防本人外观与名单更新、真实地图滚轮 / 拖动 / 双指及镜头保持。最后真实 Main.launch 进入原生海陆搜打撤，分别核对实际扣除的弹药、油料与体力与预览一致。正式用户档及其备份在测试前后逐字节一致。

证据：`artifacts/godot/sortie-home-camera-20261114/receipt.json`、`gpu.log` 与同目录 9 张实际 GPU 截图。

回归：`littoral_v4_component_review.gd` **87 / 87**，`appearance_consumption_review.gd` **48 / 48**。后者只为隔离 B 账号显式进入母港再测秘书舰，以适配新账号从第一章进入的正式行为，没有改变新手流程或外观实现。

## 范围与限制

- 自由舰队 / 海军搜打撤没有恢复旧的三舰上限。家园海陆独立场仍遵守现有服务的 1–6 艘舰、2–5 个 MCP 投送限制；没有伪称它已支持无限海陆兵力。
- 家园小人散步是表现层日常互动；不虚构驻防战斗结果。新驻防表现不改变真实兵力或起锚规则。
- 67 项 GPU 验收中的地图输入使用生产地图控件配合呈现夹具，整套账户与出航使用真实经济服务及原生核心；87 项组件回归仅为呈现验证，不冒充整场海陆战斗证明。
