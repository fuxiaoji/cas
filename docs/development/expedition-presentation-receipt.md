# 冒险海域与俯视实体表现验收

2026-11-12。此记录只登记程序环境、公开实体表现和剧情教学；任务效果、舰队预算、自动指挥与货舱的完整航次由各自原核与集成回执登记。

## 实际改动

- `enemy_animation.gd` 根据已可见接触的航速、攻击状态和血量变化选择待机、游动、蓄力、出击、受击。失联立即清除此实体的动画记忆；新地图复用接触编号也不会继承上场受击。记忆不保留位置。
- 七种原创实体统一为90°正俯视、源图朝北。渊喉改为背部朝镜头的长体海兽，取消侧视龙式投影。新增锈壳采掘蟹和祭潮鳐。每种一张1536×1024透明原图，3×2六姿态，以42个512平方Atlas区域使用；没有重采样、重写或裁改生成图片。7张项目文件与生成原件、台账SHA均一致。
- `monster_renderer.gd` 只投影本席公开接触。怪物朝向按公开航向旋转；海面预警使用原核圆形或胶囊方向、半径和倒计时。敌舰使用正俯视舰体、炮座和航迹，有公开血条和武器就绪灯；未知舰型保持通用轮廓。`down` 仅依赖最近5模拟秒的公开 `defeated_entities`，不以失联推测死亡。
- 任务地图标记常驻只有图形，接取与作业中突出，作业弧来自真实进度，完成勾/放弃叉；名称与状态在悬停时读取。Boss只有 `announced` 且有公开坐标和半径才显示异动海域、刷新倒计时，不制造未出现实体。
- 沉没都市、拜教中继、风暴残骸、热泉矿区、流民堤道均沿用真实种子碰撞岛，增加程序水色、岛面材质和局部地标地表细节。热泉为少植被玄武岩、蒸汽与热口；中继为地表回路；堤道为拼接平台与旗帜；残骸为破损船板。装饰在既有地标屋顶下方，位于公开实心基础范围内，不扩大碰撞或伪造箱子。海浪、云、雨雾、海岸、地表继续程序动画，不用固定地图照片。
- 教学展开时抑制重复自动弹出的实体情报卡，手动点选仍能查精确血量和攻击。新版舰况详情通过公开 `expedition_munitions` 展示弹种、鱼雷型、备雷与各雷座装填秒数；历史舰况文本保留。

## 可编辑入口与边界

原图、完整提示词、来源和SHA：`docs/art/generated-enemies-topdown-v2.json`。SpriteFrames和Atlas资源位于 `godot/assets/enemies/topdown-v2/`，六姿态可直接在Godot资源检查器中编辑。实际运行脚本为 `sea_map.gd`、`anime_environment.gd`、`expedition_scenery.gd`、`monster_renderer.gd`、`enemy_animation.gd`、`expedition_markers.gd`；情报卡仍是可编辑的 `godot/scenes/ui/monster_intel.tscn`。

每个状态采用独立关键姿态配合程序呼吸/蓄力动作，未登记为骨骼动画。程序地标细节是表现，不新增碰撞、伤害或任务奖励。新v2规则只用于明确新建的搜打撤；旧存档、剧情v1和历史规则不自动升级。
