# 新版岛屿编成、布防与无损演习

本轮家园入口使用显式 `cas-island-war-v2`。旧 `home_island_war.gd`、`prepare_island()` 和 littoral v1–v4 的准备/结算路径保留，旧航次仍按原请求继续。遗迹搜索保留原入口；本次不把旧存档换成新载具规则。

## 玩家路径

- 海岛「出航」进入新的图像编成页：选择舰娘、战术人格、投送工具；先点「检查计划」，看到原核通过及真实弹药费用后确认。人机突袭、防守、自家演习三者明确区分。载舰采购保留直接入口。
- 新目录22人包含近卫第88伞降旅（5连×10身体）与第6海上空中突击营（1连×6身体；每身体驾驶一架武装直升机，不额外复制6名步兵）。正常账号不会自动获得新人格；新版招募池等概率22人，重复协议依旧转协议片。
- 驻防可选1–22个已拥有、整备足够的本人，受原核实际身体/连队预算限制。编成显示本名、完整番号、北约类型与规模、实际先遣人数。
- 详情页默认展示立绘、成长与投送/作战分工；数值由「展开战术数据」按需查看。补员和训练使用滑块。
- 岛务「岛屿布防」：在原核同种子地形图上拖动选址，松手后检查合法性；确认才扣材料。取消不扣费。查看模式点已有部署可以撤除，不返材料。

## 数据和账号边界

`island-war-v2.json` 由 Rust 导出，`home_service.v2_profile()` 只读22人实际数值、技能说明、规模、载具选项；`v2_limit()` 同源读取1–6舰、22人格、600身体与96连预算，目录缺失则拒绝新版出击。`tactical-art-v2.json` 仅叠加本人立绘/小人，不覆盖旧核心数值。新 UI 对运输类型做中文显示，不另复制战斗数值表。

`prepare_exercise()` 为纯预览。其养成服务使用只读构造，连首次缺少level/xp字段的旧本人也不会被预览悄悄修改。攻方来自玩家所选本人，守方来自自己的驻防舰娘/战术人格/设施真实HP/成长/布防，未安排驻防时拒绝开始，绝不借NPC充数。

演习由 `main.launch_home_exercise()` 的独立原核会话运行，账号 `begin`/`settle` 都明确拒绝演习。原航次、原原核、余额、身体整备、弹药、设施、奖励、录像账本不进入演习交易；退出返回海岛，直接母港及转场导航也恢复原会话。终局只有演习结果提示，不出正式结算。

真实v2出击仍通过原子账号交易：同配置原核新快照绑定、扣预览弹药、用原核真实战损结算。多连队使用 `recovered_hp_percent`，部分连队失联只损失对应回收份额，不清空已回收连队。防守核对全部原设施HP；实际触发/毁坏的雷阵和阵地移除，不在下局免费补回。回放保留真实版本、初始配置和指令，不重新结算。

## 编成头像与实测性能

编成的舰娘和战术人格两条卡带都按可见范围加预取加载，滚出范围的控件释放头像引用；共享图片缓存保持32项上限。保留全部206艘舰娘与22个战术人格的真实可选控件，不通过删内容节省资源。

独立满图鉴账号、RTX5070/OpenGL、1280×720窗口实测（f8e候选时的UI前后对照，不冒称最终核战场基准）：初始加载8张舰娘头像与6张战术立绘，滚动期间分别最多11/8张。相同场景将战术条也改成可见加载后，首开含8帧就绪时间636→299毫秒，编成纹理计数365,653,707→231,436,043字节（减少约128MiB），稳定帧p95为6.535毫秒。连续开关五次后节点数回到母港84个，跟踪静态堆约109MB，共享缓存32项；逐项检查账号和正式主备未变。

这是桌面满图鉴界面的跟踪堆、渲染器纹理计数和实际帧间隔，不代表总进程内存、移动设备或6000身体战场指标。完整前后报告分别为 `receipt-performance-ui-before-lazy-units.json` 与 `receipt-performance-ui.json`；24次真实指针滚动及22人格条滚动也在测试中覆盖。
