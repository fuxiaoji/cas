# Godot 单人模式与港口经济完整迁移

本轮以仓库中已经实现的单人内容为基线，原始PDF、用户文档和参考项目只读。模式、经济和故事分别使用可追溯的数据来源；动画不承担发奖职责。日期为2026-11-11。

## 来源与口径

`scripts/import-godot-modes.mjs`读取现有TypeScript并生成5关挑战、6个AI目录、原训练课程与雷达子集、5名序章领舰×3个记忆分支×31节点的剧情对话。对话由现有CAS适配的`storyDialogue`输出，避免恢复旧规则或预写命中战果。人物和历史身份仍按稳定ID关联。

征募基础概率沿现有2/8/20/70。常驻与UP分别累计连续普通次数，九次普通后保证至少稀有；保底时20/8/2归一。UP的UR中50%为密苏里，基础单抽概率1%，不承诺不存在的限定必中或歪后保证。UP原画为`res://assets/recruit/missouri-up-v1.png`，完整带背景构图用于卡池，原图Atlas区域用于头部特写，原角色立绘保留。新建Godot试玩档发放10张UP券；旧档不自动补发，可通过签到和序章获得。原本已实现的舰队勋章继续用于AI解锁，重复征募同时沿当前打捞Demo规则转硬币。

挑战奖励严格沿旧`port.receiveChallenge`和`activities/week.ts`：全局首次主目标一次性发2常驻券及雷击AI；每关记录解锁，绝不逐关额外发首奖；其后每周最多3次复战、每次2券；完成3场真实挑战后周补给500硬币和3券。战役奖励与最好星数沿旧`campaign-progress.ts`，只发尚未领取的阈值差额，重演不发奖励。6进化AI的解锁战役和800–1200券原价保留，并继续标为待平衡；基础炮战6勋章、雷击首通与默认协同仍可达。

七日签到沿旧每日500/800/1200硬币及常驻/UP券数量。Godot已有稳定的可战单舰所有权，因此补齐第七日北卡罗来纳的本地领取；已拥有按20勋章转换，不再沿用旧客户端因缺所有权通道而暂停的限制。邮件、签到与周配给均执行账户原子提交，日期使用北京日界；日期回退和重复请求不重复领取。

## 经济可持续性与边界

普通弹药100份售160硬币，满修100%损伤为200硬币，训练80经验售100硬币。废料25、合金60；装备/指挥组可以保留并获得已实现的货舱/搜索效果，也可明确出售。借用基础任务不消耗私人弹药、维修或货币，最多4份废料价值100；以每次满载计，4次基础撤离可覆盖一舰满修与100份弹药，未要求余额恰好为零或先有适航自有舰。

常驻券500硬币，按当前重复硬币补偿，全部重复时的基础期望补偿为81硬币，不能通过买券与重复回收套利；勋章无回售通道。原6进化战术800–1200券仍是遗留暂定价，尚未宣称达到合理取得周期，基础三风格和单人主循环不依赖采购这6项。新手邮件、初始券、签到与首通均有限且幂等；周补给有日历与真实战绩门控。

## 保留边界

不实现服务器支付或多人经济。原始剧情中的四段电影时间和标题保留，原核开场与回放由战斗控制器负责；任何尚未迁移的镜头、课程或编成细节必须在验收中单列。角色原画和归档音频的本地试玩/公开发行范围继续遵守已有素材台账。

四段电影和三段关键课程现已完成真实窗口验证。其余昼间/夜间/雷达课程保留逐步骤提示与证据门控；炮雷拖动、照明、雷达、接管与取消的通用关键路径由战斗迁移验收覆盖，不宣称每一门课程都另行完成一遍完整人工路线。逐舰历史点购、特混分组和旧预设编辑器由并行模块迁入，见`godot-deployment-migration-receipt.md`的68项真实窗口结果；特混标记为架空部署，不计历史星数或历史奖励。当前为Windows单机档，旧浏览器按账号隔离的localStorage不会被自动覆盖或伪装为已导入；Android原核绑定和安装包仍在本轮范围之外。
