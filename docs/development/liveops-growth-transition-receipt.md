# 全屏转场、成长与版本内容交付

2026-11-12。依据本轮用户授权实际修改游戏；独立游戏设计代理负责成长和资源关，剧情、转场及编辑性分别独立实施/审查。原始 PDF、参考工程、既有历史阵位与原书舰表没有修改。

## 可直接体验

双击根目录 `CAS-Godot.cmd`。母港左上“指挥官 Lv.”进入玩家档案；舰娘详情进行训练、突破和舰装改装；“出航 → 资源海域”选择四类、三档资源任务。母港顶栏“活动”进入版本内容；“军需 → 模拟充值”体验本地订单。

Godot 项目是 `godot/project.godot`。在 Godot 项目管理器导入并编辑，F5 运行主场景。也可用 `scripts/start-godot.ps1 -Editor` 启动编辑器。`CAS-Godot.cmd --check` 最终构建/导入通过，退出码 0。

## 本轮结果

1. **全屏转场**：云浪擦除、圆形揭幕、斜向帆片三种短效果，默认 0.56 秒；覆盖期间防止误点，新页面保持同步生成，不影响战斗时钟或原核随机数。保留随机已有 SD 点缀；减少动态、同页刷新和无图形运行直接切换。查阅两个 GitHub MIT 案例后原创实现，链接、源码树及许可证记录见 [转场回执](fullscreen-transition-receipt.md)。
2. **成长**：指挥官 Lv.1–20 只解锁内容；舰娘 Lv.10/20 两次突破，最高 Lv.30。基础/进阶/精研训练记录与三档突破核心共六种素材，可 3→1 合成。银币、训练、舰装、水手四类资源海域，每类三档，共 12 关；Lv.3/6 开放后两档。只有实际带货成功撤离才发对应物资与经验。新深层关采用实际前沿接驳区，避免往返空耗。详见 [成长设计](../design/player-growth-v1.md)。
3. **舰装**：火控测距仪、轮机增压器、复合隔舱、平衡改装套件、弹道计算仪五种类型，影响各自对应属性。总预算沿用约 1% 上限，改装保留物件身份和档次，旧实例与旧航次兼容；历史借用舰不套自有养成。每种均有独立物件美术。
4. **剧情**：增加风暴甲板、维修坞、资料舱三张场景 CG 与五段旁白；标点停顿、说话高亮、短暂上下轻颤、角色动作及分场音景，减少动态时静止。保留 16 节点、原有选择与三场真实战斗门。三次真实首通各发 150 指挥官经验，失败、重放和重复结算不多发。详见 [演出回执](chapter-presentation-v2-receipt.md)。
5. **活动**：潮线档案主视觉、当前版本公告、实际战役开发状态、密苏里 UP 新复杂背景 CG、签到与每周挑战配给。UP入口打开真实当前UP池，概率说明读取实际配置。战役目录当前 11 条，其中可试玩 6 条、完整历史核验 0 条，分别列示，不伪造百分比或上线日期。签到同时展示银币/券等奖励，领后正确显示明日状态并禁用重复按钮。
6. **模拟充值**：六档带独立美术的元词补给，创建订单 → 确认 → 模拟到账，可关闭后从记录继续、取消及查看历史。全程标明本地模拟、不扣真钱；没有支付服务、二维码或银行卡表单。余额和状态同一存档事务提交；重试不重复到账，保存失败回滚。充值不发指挥官经验。

## Godot 编辑入口

| 内容 | 实际运行资源 | 编辑方式 |
|---|---|---|
| 母港 | `scenes/ui/harbor.tscn` | 具名按钮、秘书舰、背景和 SVG 图标可移动/替换。关闭 `use_default_styles` 后保留原生节点字体/颜色/样式覆盖。秘书舰个人位置由存档设置覆盖。 |
| 活动 | `scenes/ui/activity_hub.tscn`、`data/liveops.tres` | 场景编辑分栏、标签和主视觉位置；资源 Inspector 编辑标题、副标题、两张 CG 和公告数组。预览页签可切换，运行时使用同一资源。 |
| 模拟充值 | `scenes/ui/simulated_recharge.tscn`、`simulated_pack_card.tscn` | 六张实际嵌套卡片；修改 `pack_id` 即时预览。`use_default_style` / `use_catalog_content` 可关闭默认覆盖。交易档位由 `data/simulated-store.json` 决定。 |
| 全屏转场 | `scenes/ui/page_transition.tscn`、`page_transition_overlay.tscn` | Inspector 配色/时长/样式/预览进度，AnimationPlayer 曲线；`scenes/demos/transition_gallery.tscn` 可 F6 单独演示。 |
| 剧情 | `scenes/chapter_stage.tscn`、`data/chapter-scenes/*.tres` | 具名背景、演员、旁白及字幕节点；资源编辑台词、表情、动作、CG、音景和字幕布局，详见 [剧情编辑指南](chapter-editor-workflow.md)。 |
| 成长与物件 | `data/player-growth.tres`、`assets/growth/icons/*.tres`、`assets/gear/icons/*.tres` | Inspector 编辑材料、配方、经验、舰装类型；独立 AtlasTexture 可替换贴图/区域。 |

主要新界面是实际运行的 PackedScene，并非另做一套静态样稿。部分活动详情的布局和旧战术 UI 仍由 GDScript 创建；当前逻辑画布 1600×900，超宽窗口延续横向伸展。权威战斗判定仍为可读写的 Rust 源码及其原生/WASM构建；修改 CG、布局、公告、台词和养成配置无需重写战斗原核。审查未宣称所有旧 UI 均已转为 Inspector 场景节点。
