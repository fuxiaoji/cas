# 正史三章、限定UR双形象与活动画面

本版按用户新的神通流浪战帮主线重写并接入Godot。第一章《借来的灯，自己的岸》从信标任务、救起主角、联盟军审，延续到礼物坐标、灯鲨协议、借兵夺岛、建设驻防与乌龟山觉醒；第二章《不许熄灭的码头》讲救助与控制的边界；第三章《把名字留在海上》讲白塔改写人格与拒绝覆盖权限。正文共22753个汉字、107节点、881句，包含互斥分支。每章约一小时是设计预算，不是三小时真人实测结果。

## 游玩入口

关闭旧游戏后，双击仓库根目录 `CAS-Godot.cmd`。从母港进入“出航”→“返航灯”新正史目录→第一章。后两章按新正史通关记录解锁，旧剧情进度和旧入口保留。若已有未结束的海上航次，先继续并正常返港，不会清掉这次行动。

密苏里已经拥有后，在“舰娘”→密苏里→“形象”选择服装：默认“午后休憩”，舰娘自身Lv.20解锁“重拾军令”。立绘和战斗小人同时切换；航次中暂不能换装。军装不是另一艘船，不消耗招募券、不发重复舰或战力奖励。卡池展示是预览，不授予未拥有的角色或服装。

## 本人美术与设定镜头

两套密苏里保持同一张成年面孔、白发龙角、灰青龙尾、短手套、黑色哑光麂皮过膝低跟靴与白丝。日常以软针织、短裙、松披大衣、抱枕与保温杯表现懒散傲娇；军装改海军制服短裙、军帽、海图和白色海军大衣。每套SD有12个姿态，包括行走、开炮、受击与倒地；实际发射/正伤触发相应动作，时限结束回到待机或行走，不改变裁决。

觉醒CG与展开形态CG参照密苏里号1945年照片，突出长而窄的舰体、前二后一的三座三联装主炮、美国式舰桥和双烟囱。参考来源为[美国海军历史档案80-G-316036](https://www.history.navy.mil/our-collections/photography/us-navy-ships/battleships/missouri-bb-63/80-G-316036.html)及[密苏里纪念馆资料](https://ussmissouri.org/files/Battleship-Missouri-Memorial-Fact-Sheet-2023.pdf)。这是风格化叙事图，不作为历史测绘图或海图。

新增 `ship-form.png`、`one-mind-crew.png`、`one-mind-tactical.png`，分别展示舰装展开、同一舰娘意识分担舰上岗位、灯鲨同一战术意识的多身体分工。前两张只在密苏里自报姓名后使用；灯鲨图严格参照MCP-011本人。信浓的投影按已有战列舰本人画像生成，揭晓前名签隐藏身份。

15张选用PNG、两套SD的AtlasTexture及生成来源/SHA见 `godot/assets/story/canon-v2/manifest.json`。每次生成提示、输入参考和拒用理由保存在 `artifacts/canon-v2-art/generation-prompts.json`，三张设定CG见 `lore-cg-generation.json`。旧版本人画像与原始世界观文档保留。

## 画面与Godot编辑

征募页采用大海报、左侧图片池签、低干扰双形象标签与下方单抽/十连。活动页以一张主CG和两张辅助图卡呈现版本内容，公告、开发进度、签到、活动商店与规则仍可访问。抽奖先真实提交，揭幕/跳过/回看只展示已保存结果。

用Godot导入 `godot/project.godot`。可编辑场景是 `scenes/ui/recruit_banner.tscn`、`activity_hub.tscn`、`tactical_recruit.tscn` 与 `canon_story.tscn`；剧情与对应教学动作在 `data/story-canon-v2/chapter-01.json` 至 `chapter-03.json`。作者源与可读稿在 `docs/story/canon-v2/`。故事场景支持章节/节点/行的预览，动态图层和真实账户服务仍由脚本绑定。

新进度保存于 `progression.story_canon_v2`，选装保存于 `appearance_v1`。外观只在所属应用的角色表内替换视觉字段，独立账号、预览与剧情服装互不串用。选择、真实行动、固定协议同步、奖励均有保存边界；动作节点不能靠“跳过对白”通关。

## 真实验收与范围

三章实际行动链在隔离普通账号通过2201项检查，107节点均到达结尾，16次原核行动保留runId、事件与真实成败。另测满级已有MCP-011与可选人机竞技；固定协议始终同一份，测试号已有本人不会再发碎片或硬币。真实防御撤退接失败对白，不伪造胜利。三张新CG和逐字播放/继续按钮通过独立GPU画面检查。

双形象验证覆盖19级锁定、20级解锁、存盘重读、重复选择不写盘、错误形象拒绝、航次禁换、真实写盘失败回滚，以及钱包/舰船数值/物品/进度不变。实际Boot与舰娘档案在1280×720、1920×1080渲染，两套立绘和SD均可见；秘书、编队、舰库、战斗、转场与模式内缓存消费另有检查。最终项目与资源哈希、日志和各回执入口见 `artifacts/story-canon-v2/integration-receipt.json`。

世界观修订DOCX已渲染9页并逐页目检。普通用户主备档本轮只读，测试全部用独立路径；未接管用户游戏窗口。原核仍为 `195322d160a42d32ead2f78cdacbb86ac36e1718ec19cd82f1c9b3059c6c8782`，历史舰表/阵位/参考PDF不改，本轮没有重跑整套历史native/WASM验收。

后两章目前复用已登记的真实任务和两栖训练。四重巡与重巡级怪物增援、密苏里救援齐射属于本版叙事CG；尚未新建完全对应这段演出的独立原核战场。白塔专属海图、逐名难民护送与人格恢复模拟仍是后续制作项。退出时仍有现有ObjectDB资源释放警告，未宣称已经消除。详情见 `docs/story/canon-v2/叙事与教学设计.md`。
