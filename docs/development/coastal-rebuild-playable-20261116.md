# 从认可 Demo 重建的新海岸试玩

2026-11-16。用户明确授权必要时放弃旧地形，从认可的三维 Demo 出发。这次交付把同一套地表、建筑、植被、水面和光照接到实际 Main 家园及海陆战页面；旧离散台地不是新版地形基础。

## 打开

双击仓库根目录 `CAS-Coastal-Rebuild.cmd`，或 `CAS-3D-Play.cmd`。打开后经过可见加载层直接进入新岛。点击设施可查看/操作；滚轮缩放、拖动查看；通过“训练”进入借用编队登陆练习，下方连队卡可拖到合法滩头，海陆主图可互换。普通账号入口 `CAS-Godot.cmd` 仍保留，避免尚未重做的剧情/旧航次静默换图。

新试玩使用独立账号 `artifacts/coastal-rebuild-20261116/player.json`，27 个已发布战术人格、13 类设施和充足建设资源。旧存档不迁移到 36 米的新建设地址，不覆盖正常账号。

## 已接入的部分

- **真实 720×720 米连续样区**：认可 Demo 原程序输出 181×181、4 米格、厘米量化高度，保留草坡、山体、海崖、河谷、沼泽和沙滩。没有把小样区拉伸成 8×10 公里。
- **同一份地理驱动规则与显示**：新核心校验冻结高度、坡度、岸线、地貌和水位，家园/陆战/海图读取该快照；移动、地面视线、合法卸载和建设空间跟随真实地理。视角变化不挪动实体。
- **实际家园**：36 米建设地址，完整设施地形包络校验；13 类设施复用 Demo 建筑模块；21 条真实地表道路；驻民走真实道路，脚底跟地面。默认基地近景与全岛概览分开。
- **实际登陆战**：普通艇在合法岸边卸载，连续地形参与步行和遮挡；坦克、两栖车、自行炮、直升机和登陆艇显示为真 3D，女性身体为本人 2D 动作；保留下方连队卡、拖动、托管、速度和海陆主小地图。
- **轻量观察**：普通帧只传不可变地理标头，首次按哈希请求完整快照；静态地表不随战斗 tick 重建。道路裁剪使用岛内局部坐标，避免远距离世界坐标丢失精度。

独立版本：`cas-island-war-coastal-v1` / `cas-littoral-coastal-v1` / `cas-coastal-geography-v1`。本次地图哈希 `fnv1a64:def8b4272dcb6ef2`。保存与重演保留版本和完整配置。原始 Demo、PDF、正常发布核心及并行 MCP-306 草案不覆盖。

## 尚未完成

这是从 Demo 建立的第一块实际可玩海岸，**不是整部游戏美术重构全部完成**。随机大岛、多岛搜打撤、全剧情地图、完整城镇与废土布景、道路交口细节、建筑/车辆进一步精修、全兵种平衡、手机真机预算仍在后续阶段。当前只有三个实际沙岸卸载槽位，不宣称三处彼此分离的大沙滩。

大舰的连续吃水/搁浅裁决尚未接入；海图外部视觉深海不等于新增原核水深。当前通路未增加假桥、道路未虚构移动增益。旧 NPC 设施在新原创模式中按类型/数量/耐久逐一重新落在合法地块，空间不足会明确阻断；历史想定不经过该适配器。720 米地图上战斗密度、身体重叠和教学节奏仍需逐关重新设计，不能照搬旧大岛的目标间距和战斗强度。

## Godot 可编辑入口

主工程仍为 `godot/project.godot`。新入口场景为 `godot/scenes/coastal_play_v1.tscn`；显示模块在 `godot/scripts/world3d/`，建筑与车辆原始模型/来源记录在 `godot/assets/world3d/`。启动器设置 `CAS_WORLD3D=1`、`CAS_COASTAL_V1=1` 和独立核心路径；在编辑器运行新场景时也需要这些环境配置。原核心/旧关卡不因在编辑器打开项目而被重新编译或替换。
