# Godot 单人搜打撤内核与桥接验收

日期：2026-11-11。新主客户端复用现有 `cas_core::Engine` 和 `cas-sim.exe` 逐行 JSON 接口，不另造一套战斗裁决。原始 PDF、历史想定、历史舰卡及表值均不因打捞模式调整。

## 输入与观察接口

创建航次：`{op:"new_salvage",seed:6106,start:{content:"salvage-v1",fleet:[{id:"IBS-U-USN-FLETCHER",hp:100,ammo:100,level:1,equipment:false,command:false}]}}`。每个 fleet 元素只允许列出的六个字段；`name/type/points` 等客户端展示字段需要先剔除。内核兼容 1–5 舰，Demo 页面按开发文档限制 3 槽。只接受已核验的可出战单舰身份，不用收藏舰替代战斗卡。

响应保持 `{ok:true,data:observation}` 或 `{ok:false,error}`。标准 `route/preview_route/ai/fire/step/observe/save/load/replay` 继续使用同一内核。新增：

| 命令 | 字段 | 作用 |
|---|---|---|
| salvage_collect | ruin | 已发现遗迹 750 米内、8 节以下开始搜集 |
| salvage_extract | exit | 所有仍可航行舰进入同一 1000 米撤离圈后开始 20 秒计时 |
| salvage_cancel | 无 | 取消搜集及撤离，进度归零 |
| salvage_drop | index | 永久弃置当前货舱的一件货物，不退回容器 |
| salvage_abandon | 无 | 主动失败返港，记录为可重演命令 |

`data.salvage` 公开 `score/threat/capacity/searchDuration/cargo/ruins/exits/collecting/extracting/extracted/loot/ships/enemyBudgetHulls/generatorVersion/content`。只给玩家已发现遗迹；敌舰精确状态、任务记忆和未发现遗迹不进入公开观察。`ships` 每行包含稳定身份、剩余百分比 HP/弹药、`protected`、`canNavigate`。经济层只在 `extracted=true` 时转移货物并返回可航行舰剩余弹药；失败不得把 `loot` 当成功奖励。

Godot 数字均按双精度解析。原生 stdio 入口将可精确表示的整数 double（如 `100.0`）转换为整数，保留真实坐标小数。`{op:"save",serialized:true}` 在普通 `data` 外返回顶层 `serialized` 原始 JSON 字符串；Godot 将此字符串原样写入活动航次，恢复时调用 `{op:"load",serialized:raw_string}`。普通 save 协议保持不变，以免影响既有原生/WASM 检查。

## 架空模式登记默认值

下列均为本次游戏玩法设置，不冒充原书历史剧本数值。

| 项目 | 运行值与状态 |
|---|---|
| 海域 | 24000 × 14000 米，2700 秒航次，8 个程序岛屿、10 个遗迹、3 个撤离点 |
| 随机流 | 地形、遗迹布局、掉落、敌舰部署各自固定种子流；战斗仍用原核随机流 |
| 通行 | 西侧、南侧和岛间保留通道；生成后校验出生点至每处遗迹及撤离点的 600 米宽水面通道 |
| 敌方总预算 | 按冻结分数落 4 档，3–6 艘已登记源卡；高档增加轻巡，不改变单舰属性 |
| 编队分 | 登记舰体基础分 + 每成长等级 20 + 每装备 75 + 每指挥组 50；不按残血/缺弹降分 |
| 阈值 | 小于1500、小于3000、小于6000、其余；待平衡实测，非永久正式平衡承诺 |
| 容量 | 8 + 2 × 已装备舰数；全部为共享货舱单位 |
| 搜集 | 向上取整 max(4, 12 − 0.25 × 累计成长等级 − 指挥组数) 秒；受伤、离开范围或超速中断 |
| 守卫 | 4 千米任务区；累计追击 90 秒后返回，途中 3 千米内可自卫 |
| 巡逻与追击 | 开局已存在实体，沿已生成路线；仅用敌席有效接触及友军可知报告；120 秒追击上限/最后接触超时，返回任务区 |
| 保护 | HP 归零或原核最大可航行速度低于4节进入保护状态，停止战斗、不参与撤离到点检查；不永久删除角色资产 |
| 主炮补给 | 仅打捞模式每次实际主炮齐射消耗1个百分点补给，耗尽停止主炮和副炮；主炮伤害/命中/装填沿原核 |
| 鱼雷补给 | 出航百分比约束源卡已装管数与备雷，发射/装填仍走原核，按实际消耗扣除共享补给，未交火时不因离散雷管装载舍入而损失补给，回执不超过出航弹药百分比 |
| 结算时序 | 每秒完成移动与炮雷伤害后检查保护/搜集/撤离；撤离完成即冻结，防止同一结果重复取物或继续消耗 |

本模式使用虚构昼间默认海况，不混入历史想定目录、星数或原书胜负条件。成长效果只改变货舱、搜索效率和敌预算，不给 CAS 主炮表添加伤害倍率。
