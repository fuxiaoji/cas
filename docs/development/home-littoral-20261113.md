# 家园、战术人格与海陆空协同试玩

本轮围绕“舰队把伙伴送上岸，再把她们接回家”实现独立原创模式。世界、玩法和美术取舍见[设计说明](../design/home-littoral-v1.md)，具体裁决见[两栖行动规则](../rules/littoral-v1.md)。历史战役、旧搜打撤与原始资料保持原样；本轮人机岛并非线上玩家。

## 打开与试玩

双击根目录 `CAS-Godot.cmd`。母港顶栏选择「返航灯岛」，首次从遗迹救援支线进入：前篇会面 → 真正登陆、搜索、撤收 → 后篇驻岛委托 → 家园建设。未完成的原航次仍可继续，不会被新家园入口抹掉；开展新行动前需先完成或正常结束原航次。

教学真实胜利一次性授予驻岛权、礁刃和十张协议券。此后点空地建设、点建筑升级/维修、收取生产，选择真实拥有舰娘驻防。家园的「海陆协同」可选三个人机岛进攻、守岛演练或两栖打捞；旧打捞出航页也有「两栖遗迹 · 带队登岛」。岛屿选择为碎波哨岛、旧港仓岛、长云堡礁，采用登记种子和不同实际布防，不只是换名字。

出航选择1–6艘自有舰和最多五支已获得编制。战斗、均衡、运输三档装载分别至多100%、70%、40%弹药；少带的弹药留在原库存，实际舱位增多。日进、千岁使用真实AV运输支援身份，运力大于普通舰；未拥有时可走现有舰娘招募，不伪造运输舰身份或替玩家领取。

左侧海图指挥舰队，右侧陆图指挥已选部队；两张图共用时钟、坐标与结果。载舰接近选定滩头才能投送，空降部队可在真实6000米范围内机降。选择「近岸炮援」再点陆图，舰艇按真实位置、射界、装填与余弹执行待发目标，可取消；直升机需在场、有弹且在射程。点击遗迹搜索，物资随部队实际撤回；不能仅靠关闭窗口领取。所有存活部署部队返舰、存活舰进入出口后完成撤离。菜单可保存暂离，回放为只读。

## 角色与世界

二十个编制各有独立编号、人格、军种、角色立绘和档案；首批云隼、礁刃、冬鸢、汐锚、铁潮可实战，其他十五支仅整编预告，不在当前消费招募里投放。当前五支各20%，单次一券或160元词，二十次保底未收录新核心；重复转协议片而不复制新人格。

MCP为旧文明群体认知协议。部队的每个机器人身体都有女性化人类外表，同一部队的多个身体都是同一个“她”；舰娘的舰桥、炮手、水手人形同理。载具与旋翼机是她操作的装备。编制称谓不代表可在此小地图无限生成一个现实兵团，原核限制活跃身体与运输预算。损耗保留核心、降低真实整备率，缓慢自然恢复，医疗与有限护理加速。

新版立绘按用户纠正采用轻盈小巧的成年动漫女性：柔和脸型、窄肩、轻型战术服饰和适量携具。原重装候选已弃用。参考下载、尺寸与来源放在 `artifacts/home-littoral-20261113/gfl-reference/`，不随发行素材打包。[美术方向](../art/tactical-20261113/style-direction.md)和[完整提示词/来源清单](../art/tactical-20261113/generation-ledger.json)记录20张立绘、2张CG及弃稿。全部使用内置图片生成；正式图片已复制进 `godot/assets/tactical/portraits/` 和 `godot/assets/home/story/`，不是只留在生成缓存。

## 音画与可编辑性

十一首原创BGM约11分45秒，分别覆盖标题、昼夜港口、剧情、紧张探索、海战、登陆、家园、肉鸽及胜负。两播放器交叠、真实循环点、对白/广播压低和原音量设置保留。[音乐与转场说明](../design/original-score-and-parade.md)列出试听、可编辑MIDI/音符/合成源。全屏动漫遮盖保留，约三名随机本人SD错相蹦跳且真实横向穿行；减少动态与关闭动效仍可用。

原生Godot工程为 `godot/project.godot`，导入后F5；新场景位于 `godot/scenes/ui/`：`home_island.tscn`、`tactical_recruit.tscn`、`home_story.tscn`、`littoral_battle.tscn`、`littoral_result.tscn`。界面使用Control/Container与Inspector参数。编制文本在 `godot/data/tactical-units-v1.json`，44页教学文本在 `home-story-v1.json`，原创乐谱/MIDI在 `music/original-v1/`。岛岸、地表、云和海水用程序绘制/材质，两个故事CG只用于演出。
