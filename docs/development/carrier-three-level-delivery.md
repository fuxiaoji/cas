# 三档航母控制交付（2026-11-15）

已将常用操作收敛为“高自动化：航母安排；中自动化：玩家指定目标；低自动化：玩家调度具体编队”。独立入口 [CAS-Carrier-Academy.cmd](../../CAS-Carrier-Academy.cmd) 默认选择高档并暂停，玩家选好档位后继续。使用说明见 [三档航母指南](carrier-three-level-guide.md)。

高、中档只保留每舰一张航空支援卡；低档才展开联队、中队、在空卡。右侧航母按钮显示当前档位，各舰卡显示任务和等待原因。召回后该舰保持停止派遣；重新选高档或为该舰指定目标恢复。中档指定650米支援区域，航母可选择区域内其他合法敌人，非保证点杀。

同一张支援卡可拖到海图和陆图。高档优先有效己方航空标记和威胁岸上友军的公开目标；选机遵守机型限制。友军距投弹点不足350米时暂缓，投放前再次检查。飞机保持真实空速、盘旋和油耗，起飞/投放/回收/整备消耗既有有限资源，切档不补充任何库存。

海陆接线在 `island_war_v2.rs`、`island_war_v3.rs` 中仅增加显式新版航空的公开观察传递、查询路由、航空与陆军控制权分离以及避免双重派机；没有调整陆战部队、武器、载具、地形或其裁决。当前陆战实际目标、可见范围与支援标记传给航空层，避免使用旧练习岛的目标。陆军托管不因航空操作关闭；总撤收期间不再派机。

独立 agent 完全未读源码，仅凭指南完成高档出击、中档区域支援及真实命中、低档出击与在空改令、全员返舰和存读。累计实际推进306模拟秒。其指出的入口差异、区域含义、接令反馈、全损原因和缺失示例均已修订并复核。证据见 [最终独立复核](../../artifacts/carrier-v3/blind-play/final-review.md)，不把这项逐行JSON试玩冒称独立UI盲测。
