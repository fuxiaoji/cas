# 人机海岛攻防与表现整合 v1

2026-11-14，本轮开发已接入正常 Godot 入口。游戏仍从 `CAS-Godot.cmd` 启动；同目录 `CAS-Godot.lnk` 使用新的弗莱彻眨眼比枪图标。Godot 可直接编辑 `godot/project.godot`，新增录像栏为独立 `.tscn` 场景。

## 体验入口

- 母港进入返航灯岛，顶栏「岛务」选择六个人机岛并侦察、编队、出击；「手动开启防御模拟」使用已保存的海军和战术驻防。当前为本地人机模拟，没有自动离线入侵。
- 「岛务 → 仓储与扩区」查看岛屿等级、真实可建格、保护量和本场风险量。升级联络中枢扩大实际建造区；新战斗的原核地理也随岛级扩大。
- 岛上「战术人格」打开本人档案，进行训练、突破、专精和滑块补员。二十人格各自保存进度、实际先遣身体和战损；整备与升级分开，不免费治疗。
- 「岛务 → 攻防录像」回看最近八场完整本地记录。独立原核进程承担播放、暂停、1/2/4/8倍与滑块定位；退出恢复原行动。总记录上限8MB，记录不完整时明确不可回放。
- 「岛务 → 作战图鉴」可浏览二十张独立失败CG；返回回到岛务。真实失败结算中，缺失、失能或整备低于35%的本人显示对应CG入口。插画是叙事美术，不冒作本场真实伤亡截图。

## 攻防、成长与边界

新显式 `cas-island-war-v1` 复用真实 World 海军及v4海陆空，并增加六个人机布局、八类设施、驻舰起锚、有限炮塔/航空消耗、实际来袭登陆艇、指挥所与仓库占领、攻防专用托管。新增机枪、加农、迫击、防空、岸炮和维修节点；各自射程、通视、最小射程和库存不同。当前部分新设施复用已有精细建筑图，不声称八套全新建筑立绘。

保护量外20%构成本场风险池，并设上限；账户只扣原核实际失去的库存，奖励、战损与补员均原子结算和去重。核心验证有306秒十连突袭真实获胜、60秒舰队拦截真实防御获胜、416.8秒真实敌军登陆并掠夺失守。账户自己的弱防御布局在406.1秒失守，实际扣浮材375、合金375、补给375、协议片7；两者是不同夹具。

二十战术人格Lv1–30、10/20级突破；满级约5%耐久/火力增益只进入新岛屿核。身体损失缓慢恢复，可付费补到滑块公示目标。世界观1000–6000完整编制上限与本次有限先遣人数分开。部分专精共用成长，未实现独立技能树。详情及原创数值见 `docs/rules/island-war-v1-source-notes.md` 与 `island-war-home-v1-20261114.md`。

## 美术与手感

二十部队各自使用本人立绘作为身份参考，独立生成1672×941密集失败场景；混合仰卧、侧卧、俯卧、闭眼、空望和少量吐舌，加入衣物弹痕、擦伤、焦痕、合成表面损伤与散落装备。数量目标28–36仅是构图提示，不能充当精确人数裁决。完整提示、来源、SHA与逐图目检在 `docs/art/tactical-defeat-cg-20261114/ledger.json`；可点击总览在 `artifacts/tactical-defeat-cg-20261114/qa-overview.html`。

运输载具以真实连续位置差求运动方向；陆图先经过斜俯视投影再确定屏幕朝向，平滑转向不改变命令或物理坐标。海图插值按真实观测，来袭登陆艇显示实际位置和血量；海图载具缩到合理可读尺度。原有步兵、旋翼与装卸姿态继续绑定本人素材。

程序海岸提高采样、湿干沙过渡、低频地色与细颗粒，种子散布小石/漂木；城镇不再把空街区整片铺成不透明水泥。海图静态地形仅在镜头或实际地图变化时重绘，海浪与云层继续独立动态。没有用固定地图照片替代程序地理。

舰炮支援消费真实公开发射记录，按原核飞行时间显示弧线/拖尾、闪光、爆炸、尘浪和烟雾；近同时同地点的画面爆炸合并，炮弹轨迹仍各自保留，伤害不合并或新增。仅地图视觉震动，HUD不动，零震幅可关。透明特效图集来源及提示见 `docs/art/naval-support-v1.json`。

弗莱彻图标采用本人金发、白帽、星形发饰、青绿围巾和单手比枪，Windows ICO及五密度Android传统/圆形/自适应资源已接配置。Android目前交付图标和可编辑打包预设，不是可玩的完整APK，原生桥仍需移植。
