## 启动与两段转场

1. 轻量首屏只依赖程序云、水波、罗盘和系统字体；项目初始清屏色与首屏一致，不需要先读完大字体、角色目录和整套 Main 才能绘制。
2. 先等实际第一帧绘制，再在线程中准备 Main 场景、标题图和中文字体；进度来自 ResourceLoader，档案、服务、页面准备分阶段报告实际完成状态。没有按时间制造百分比。
3. 账号失败时停在可读错误页，重试/退出可用，不继续初始化空账号。读取失败不会自动重置存档。
4. 切页顺序是旧页 → 全屏动漫遮幕 → 素材准备 → 新页稳定绘制 → 揭幕。慢准备持续显示真实进度；约三名原本人 SD 循环横向蹦跳并落地。缓存命中后只完成正常遮幕/揭幕，不额外添加假等待。
5. 未知进度使用循环指示，减少动态仍保留静态加载屏障；加载期间拦截鼠标/键盘，重复路由按最新请求处理，旧回调不能揭开新遮幕。
6. 启动资源/页面等待有超时与可读失败。动画不推进模拟时间，不发奖励，不扣资源。战斗控制器在页面完成后才被调用；进入全屏也放在遮幕之下。
7. 保留直接实例化 `main.tscn` 的同步接口，已有编辑场景与工具可继续使用。正式 boot 显式启用 `deferred_startup` / `staged_navigation`。

同时修复异步切页引入的后续动作时机：保存返航后提示、整理物资后打开仓库弹窗、跨页招募展示、家园剧情最后一句启动训练均等待实际目标页。家园剧情使用当前版本登记的贷款编队，不沿用旧单连训练参数。
