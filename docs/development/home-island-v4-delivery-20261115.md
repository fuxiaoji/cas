# 家园、27部队与离线图鉴 v4 交付

本轮新增使用显式 `cas-island-war-v4`。正常招募、养成、编成、驻防、出击与家园详情读取原核导出的 `godot/data/island-war-v4-published.json`：27名本人、54个具体武器型号、18个武器类别。既有 v1/v2/v3 航次、录像和服务仍按各自版本处理，不升级旧航次；历史战役不使用这些改编数值。

## 家园的尺度与交互

`island_home_preview` 与新海岛战斗共用岛屿生成数据。HQ 1至5级分别扩展实际宽高，1级约3200×4400米，5级8000×10000米；建设网格为120米，原点固定为 `(13880,12460)`。升级扩展可建格地址，包括负格，不移动原有设施；旧12×9只保留在旧版画面后备路径。

家园使用原核的岛屿轮廓、河流、道路、高地、坡口与逐设施位置。地形高度按1倍米制投影，建设预览和确认前都检查原核合法性。设施位置没有为了构图而重新排列。默认镜头从真实HQ附近的设施中心取景，24倍近景便于看清基地；顶栏按钮可切换全岛，再回基地，滚轮、拖动和双指缩放均可用。

主设施按65米的显示宽度投影；居民SD使用14米的可读性表现尺度，近景实拍约18–24像素高，与约70–90像素宽的主设施协调。这是SD的可读性处理，不能理解为人类真实身高。设施的建设占格、战斗碰撞和战场米制不因此变大。灰色铺装及设施之间的细步道仅作接地装饰，沿实际设施点位和高度绘制，水域、沼泽及离岸段不画连接；不会增加原核桥梁、道路、可通行区或碰撞。

静态原生地表和庭院保留在独立CanvasItem中，只在地形、镜头或实际设施变化时重建；海水shader、轻量海岸线、云、收取反馈与居民继续更新。Windows独立离屏1280×720、每视角120帧的暖镜头测量中，近景帧间隔p95由132.8降至6.7毫秒，全岛由357.3降至6.6毫秒。该记录不是Android性能或冷启动预算；镜头变化仍需重建地面。详细测量方法和原始来源见 `home-performance-comparison.json`。

## 本人日常动作与资料馆

`home_daily_art.gd` 只消费已批准的本人帧；实际帧可来自多个图集，逐帧读取裁框、脚底锚点与参考高度。没有本人SD时不会把立绘当小人，也不会借用另一个角色。家园驻舰和战术部队按独立相位行走、停留、眨眼、招手、伸懒腰和坐下；某本人没有对应姿态时保持其本人待机帧，不声称该动作已经绘制。

本轮日常清单33名：27战术部队及6名实际驻舰身份。6舰的新12帧动作，以及301–305的新生活/倒地帧已批准；原22部队复用其已有真实动作，部分新增日常姿态仍为后续素材工作。北卡罗来纳 `IBS-U-USN-UNNAMED-T01-R03` 与密苏里为不同身份，绑定分别保留。

岛务中的舰艇资料馆独立展示7名 `source_only` 航空舰身份及其本人立绘、小人和原始资料页。它们没有加入正常拥有列表、招募池、历史战役或可出击阵容；资料馆不会为尚未完成的舰艇造战斗数值。

## 27部队与图鉴

301–305已接入正常招募、养成、编成、驻防与详情。共享开发目录中的306/28人草案属于另一个进行中的请求，本轮运行和打包通过独立published绑定固定为已验收的27人，未删除草案或借入未交付本人。正常账号不自动赠送新增本人；测试fixture中的授予只存在于隔离账号。身体HP统一读取本轮原核的4倍基准数值，车辆耐久、乘员、有限弹药和维修独立处理。304轮式两栖步战车、305履带两栖突击炮使用各自真实四向装备图，不以旧通用两栖车缩图冒充。

独立离线入口：`output/tactical-codex-v4-20261115/index.html`。页面包含本人立绘、SD、编制、分工、主副武器型号、固定投送方式、独立作战载具、伤害类别和距离精度曲线。具体型号与类别明确分开；类别插图标明为类别示意。点射/连射的发间间隔、组间停顿、弹匣、弹匣换弹和总备弹分别显示，兼容字段 `reload_s` 不冒充换弹时长。

图鉴使用本地素材、字体和数值，不需要联网。滑块调整的是方案副本，可导出JSON或CSV；它不会写正式游戏目录、运行中的原核数值或账号。旧版v3离线交付继续保留。
