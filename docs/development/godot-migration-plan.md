# CAS Godot 单人 Demo 总体规划

## 2026-11-11 用户视觉纠正

用户明确要求以迁移前的母港、舰库编队、战役航图截图为基础，不接受迁移初稿的等重面板和缩小角色。保留原海军蓝/旧金/纸白、宋体标题、大立绘、不对称功能层级；参考明日方舟的编队信息层次和碧蓝航线的角色/舰位识别。卡池参考原神实际祈愿截图的插画主视觉、底部抽取操作、稀有度分色竖卡结果，不复制其角色、美术文件或抽卡概率。进入战斗自动全屏，海图铺满窗口，只保留紧凑 HUD 与可收起的交互，不显示母港资源和导航。

实际查看的研究截图：`artifacts/design-references/genshin-wish.jpg`、`arknights-formation.png`、`azurlane-formation.jpg`。它们只作设计研究，不进入游戏素材。原创云海背景为内置图片生成结果，存入 `godot/assets/backgrounds/recruit-sky.png`。旧稿保留在前次验收凭证中，不再作为最终视觉验收。

2026-11-11。用户本次要求优先于旧企划中的商业化、多人和剧情安排。依据一期开发规格制作可反复玩的单人搜打撤；世界观是创作参考，其中的候选设定与文末 Agent 提示不是独立执行指令。原始四份文档只读。

## 技术与产品决策

- Godot 是新主客户端，Rust CAS 保持唯一战斗裁决来源。以本机 JSON 桥接保留种子、观察、命令、存档与重演；不另写简化战斗。
- 历史战役、架空打捞、经济资产各有清楚边界。地形与敌人随机化仅用于架空打捞；历史舰卡、阵位、目标与表值保持原来源。
- 一期单人使用三舰位、一个卡池、一条成长线、程序海域、多撤离点、手动出售。多人仅占位，付费、社交、完整剧情后置。
- 新 UI 采用海港实景与角色主视觉、清楚的侧向作战入口、底部六项导航；编队强调舰位和威胁预览，避免满屏同尺寸卡片和无意义装饰。
- 立绘和小人按稳定 identity 对应。小人仅改变投影，碰撞与瞄准继续使用战舰长度线；原版舰影可切换。没有逐舰生成证据的图不得标为已生成。
- 语音只订阅本席实际观察事件。用户提供的录音与 BGM 用于本地测试，许可状态逐文件记录，不能因此声称可公开发行。

## 分阶段任务与验收

|阶段|任务|完成证据|
|---|---|---|
|T01 现状与契约|阅读治理/开发文档，梳理已有资产与未提交改动，确定桥接/存档接口|本规划、接口文档、来源台账|
|T02 工具链|验证本地 Godot、构建 MCP、安装 GitHub 前端与游戏设计技能|实际版本、启动与 MCP 探测记录|
|T03 港口 UI|大厅、征募、舰库、编队、商店、仓库、战役/设置|真实窗口点击、截图与无错误日志|
|T04 经济|原子存档、购买、抽卡、重复补偿、修理、成长、装配、出售、锁航次|不足额、重复结算、退出恢复测试|
|T05 海域|独立随机流、岛礁、遗迹、三撤离点、可航路径验证|同种子一致、多种子连通验证|
|T06 战斗|守备/巡逻/追击、观察公平、CAS 原核命令|真实接敌/命中/失去接触记录|
|T07 闭环|搜集、容量、弃货、全可航舰撤离、失败、保存暂离、续局|成功→卖货→补给→成长→第二次出航及失败/续局|
|T08 美术音频|逐舰立绘/小人、原舰影开关、八首 BGM、事件语音、交互音|覆盖清单、来源与哈希、实际播放|
|T09 历史回归|接通原核测试战役、保持旧版作为核验基线|原生/WASM 重演、旧浏览器回归|
|T10 交付清理|统一启动脚本/说明、可重建过程文件清单|可运行包、清理记录、剩余 blockers|

## 文件职责

主集成负责 `godot/project.godot`、场景、UI 与桥接客户端、总规划、交付与真实窗口验收。内核线负责 `src/salvage.rs` 与原生桥接；经济音频线负责 `godot/scripts/economy.gd`、音频调度与配置；工具美术线负责 `tools`、技能、导入工具和美术台账。所有线保留当前已存在改动，不操作原始 PDF 与参考工程。

## 清理与迁移边界

先形成 Godot 可运行替代再清理。仅清理本次产生且可重建的缓存、临时日志/中间产物；保留旧客户端、旧构建、源码、素材、验证凭证及用户未提交文件，直到对应功能迁移与回归完成。引擎/原生桥接与 Godot 导入日志通过不能代替真实窗口验收，也不能代替历史想定的原页和 WASM 验收。

## 开发中待核项目

- 当前 Godot 目录有 210 份已登记立绘和经济模块基础，尚无主场景；Godot 可执行文件路径实际可能是包含解压文件的目录，必须实测。
- 既有搜打撤草稿需审查路径、敌观察、撤离与战利品边界后才可标完成。
- 210 名角色的小人需要逐舰生成/对应验证，不能以缩小立绘冒充全部完成。
- 装备、指挥组与成长只展示真实接入效果；未接入项留在 blockers，不作为已完成战斗加成。
