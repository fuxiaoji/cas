# 第一章演出打磨与 Godot 编辑验收

2026-11-12 在既有《返航灯》16 节点、两处选择、三场真实行动基础上完成演出更新。原章节 ID、任务版本、目标、关卡顺序、历史 CAS 舰表和战役均未改动。

## 成果

新增风暴甲板、港内维修坞、修复资料舱三张背景，用于不同段落。甲板表现脱困前的清晨；维修坞表现淡水设施、旧装备与返港生活；资料舱用于阅读刚打捞回的档案，台词明确是港内修复资料舱，没有引入潜水玩法。原有救援、异常接触、听证、沉没信标四张 CG 保留。背景只参与剧情，不代替程序海图。

五处新旁白为返港、维修、档案、异频信号和命名提供呼吸段。对白总数由 51 增至 56；原分支回声和表情所在行号保留。独立环境提示与地点标记采用浅色、较小字号，让人物和场景保有主体面积。正文改成可编辑 RichTextLabel，使用正确 OpenType tag 的 Noto Sans SC 400，避免变量字体回退为过细字重。

普通对白不抖动；寒冷或断续信号才有低幅上下波动，整句显示后 0.35 秒停下。句号、问号、逗号等加入短停顿。第一次点击/空格/Enter 完整显示并停止波动，第二次推进。目录和回顾弹出时暂停阅读。减少动态时关闭文字波动、入场位移、呼吸、镜头慢推和信号闪光。角色动作仍为程序化静态立绘演出，没有新增全角色 Live2D 或整章配音。

各段落明确选择现有母港、整备或航行音景，避免章节每换一句对白就被主路由重置为母港音乐。没有另外生成叙事语音。

## Godot 可编辑性

游戏实际实例化 `godot/scenes/chapter_stage.tscn`。`Speaker`、`Body`、`Environment`、`Cast`、`Backdrop` 等命名节点可直接改字体、位置、色彩和锚点。根节点提供预览场景、预览行和“刷新场景预览”。

`godot/data/chapter-scenes/` 下 16 个 `.tres` 资源可直接在 Inspector 编辑对白、语气、镜头、轻颤、动作、背景、同框角色、地点和音景。表现资源只允许覆盖视觉字段，不能覆盖任务、目标、奖励、下一节点或玩家选择。逻辑仍在 `chapter-one.json`，章节存档兼容原节点 ID。详见 [编辑说明](chapter-editor-workflow.md)。

Godot 4.7.2 成功导入，并以 `--editor res://scenes/chapter_stage.tscn` 实际加载此场景，无解析、资源或工具脚本错误。
