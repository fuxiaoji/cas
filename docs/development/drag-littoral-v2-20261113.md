# 2026-11-13 两栖拖卡指挥与二十编制

本轮按最新反馈把两栖操作收敛为拖卡。海陆图交换主图与右上同步小图；底部同一排本人部队卡可登陆、移动、攻击和搜索。海图真实舰艇指向陆地后显示一张对应舰炮卡；所选部队显示一张情境专长/撤收卡。详细数字保留在详情页，战斗保留当前状态和必要冷却。

## 玩家入口

重新打开根目录 `CAS-Godot.cmd`。母港→返航灯岛，未解锁时先进入新岛登陆；已有岛屿可点“开始拖动教学”，或部队页“重学拖动指挥”。战斗菜单内有“拖动指挥帮助”。已有未完航次先继续或正常结算，不静默清掉存档。

1. 部队卡拖到岛上，实际载舰先靠岸、登陆艇随后送她们上岸。
2. 点右上小地图换到陆图，队卡拖空地移动、拖敌人攻击、拖遗迹搜索。
3. 回海图拖实际舰艇指向岛屿，再回陆图拖舰炮卡指定落点；炮位/弹药/射程/装填仍真实裁决。
4. 撤收卡拖到本人位置，等真实回舰；切海图把返航卡拖入撤离圈。全舰驶入后再拖一次，产生实际结算。

教学有循环手势、源卡/目的地聚光和一条短指令，没有点“下一步”假过关。17阶段带到真正的撤离结算。靠岸/命中/搜索/回收都由实际公开战况验证；提示可关闭和重学，保存恢复保留主图、选择与帮助状态。提前清场/已搜索/无可用炮弹会如实解释并调整练习，不补弹、不伪造目标。旧航次不会被新教学误遮盖。

追加要求已经接入底部部队卡：本人头像右下显示对应类型兵牌，海陆共用；符号不接收鼠标事件，不改变拖卡命令。军牌采用原创简化军事类型语法，配中文兵种提示，不宣称完整APP-6标准。

## 二十编制和真实约束

全部20支开放招募和实战；普通等概率各5%，保留既有新核心保底/重复转片与交易去重。每队不同身体编成、耐久、弹药、射程、装填、移动、运输占用和有限主动技能，原核导出 `godot/data/tactical-profiles-v2.json` 是界面唯一数值源。详细表见[设计说明](../design/littoral-drag-v2.md)，能力与指令见[版本合同](../rules/littoral-v2.md)。

每航次最多六支先遣队、六艘已拥有舰娘，仍须满足真实载舰空间和整备要求。世界观1000–6000是完整协议上限，本次派遣3–4身体，不能自动得到千人储备。前五名沿用本人12姿态SD；新增十五名目前使用本人肖像与类型兵牌，不冒借另一名人物的SD，也不声称已补齐十五套专属动作素材。

新版只用显式 `cas-littoral-v2`，旧v1与历史战役保留原版。新队列沿合法水路接近真实插入范围；接受命令不会瞬移。舰炮实际转向到射界、扣真实炮弹并发弹。医疗不复活、不超过初始整备；后勤使用有限120发地面储备，不能制造舰炮弹药。教学结束标志只影响帮助入口，不负责授岛/授人/奖励。
