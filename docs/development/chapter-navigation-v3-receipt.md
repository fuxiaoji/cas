## 消除逐句闪烁

同一 `chapter` 页现在调用 `Chapter.refresh()`；保留 `ChapterStage`、`Backdrop`、同框且仍在场的演员节点。对白换句只替换本句阅读器和按钮，高亮说话者；演员不再每句从零透明度淡入，也不再无限呼吸。背景资源改变时仅做约 0.45 秒交叉淡出，同背景完全不淡出。相机只在镜头标签变化时短移。“自动”开关不重置已经显出的本句；“减少动态”使当前文字和角色静止。信号标签不再触发全屏闪光。

`chapter_route_test.gd` 对真实页面、舞台、背景、纹理与演员的实例 ID 逐项检查，确认换句保留身份；还检查同背景不存在 `BackgroundBlend`。演出素材的文字和标签继续由 16 份 `.tres` 编辑。

## 以新玩家操作三场真实关卡

`chapter_novice_playthrough.gd` 使用独立新账户，真实窗口中以鼠标输入选择章节、舰队卡、海面航点、确认航线、开始/暂停、炮标拖拽、打捞及撤离按钮。航速通过玩家可见的编队 SpinBox 设置。阅读段使用合法的跳过/选择推进，不篡改解锁数据。为确定性验收，时间使用真实原核 `step` 分批加速，未伪造胜负、耐久、掉落或任务事件。

## 新玩家试玩发现并修复

1. **不知道画线不等于命令。** 教学依次观察选中舰艇、草稿航点、已接受航令、时钟开始，金框只指向当前需要点击的实际按钮。草稿不改舰队位置。
2. **找不到残骸操作。** 关内教学只定位本席已发现的档案；靠近750米且不超过8节后，提示选择和“打捞残骸”；读条和攻击中断都跟随实际状态。
3. **到了出口却不结束。** 明确提示所有可航行舰艇集结，并由玩家点击“开始撤离”推进12秒。出口定位读取公开 `x/y`，修复误读 `p` 导致镜头移到原点。
4. **手动炮击后其余火力不继续。** 真核会将编队炮击授权交给玩家。若只教拖拽，等待到900秒仍不能稳定过关。现教学说明授权，并提供明确的“恢复舰队自动炮击”命令，保留移动、鱼雷与战术配置；相同玩家路径恢复462秒真实胜利。首发教学提前到暂停的0秒，避免自动炮击先装填导致新手此时无法操作。
5. **返回后仍看见旧关。** 页面历史保留旧选择，但任务进度前进时，路线会优先选中新节点；同一进度去设置再返回仍保留玩家所选回看片段。
6. **截图空白而按钮仍能点。** 主框架先有背景与遮罩，章节场景必须放在这两层之后、通用返回/设置之前。修复层序后重新检查真实截图，没有用静态假图代替界面。

教学卡可随时收起、再打开，不阻止任何操作，不访问未发现敌人，不自行开火、移动、打捞、撤离或写入胜利。失败结果不会显示完成目标。
