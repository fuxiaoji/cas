# 海岸样区人物与载具表现修正

本轮只修改显示适配，不改历史舰卡、原核碰撞、移动路线、伤害或载具米制尺寸。原始 PDF、参考工程与正常存档不写入。

- 已实际逐张目检本人步行图集：已发布身份均朝图像右侧。显示朝向改为比较实际两次坐标在当前相机中的投影方向；海图镜像由最终画布同时作用于运动和图像。
- 位置只在两次真实观察点之间按原生时间/倍速插值，不外推。重复 tick 不清除行走、不重置插值；暂停、回放倒退、上下车、重新部署与死亡直接对齐该次实际位置。沿途高度查询同一权威三角地面。圈与点击使用同一可视锚点。
- 装填倒计时不再视为持续开火；本人移动保留行走动作。人物脚底继续使用各帧登记 pivot，不移动实际身体。站姿显示高度改为2.2米，原约9米坦克不改缩放，近景可读且体量明显大于步兵。
- 倒地本人使用其自己的已登记倒姿，以12×12细分透明纹理网格贴合原生坡面。保留真实深度测试，可被建筑/围墙/前方山坡遮住；不强制置顶。敌方使用自己的安保图集。
- 独立载具收到真实 `shots.operator_id` 后才产生炮口火光、炮塔瞄准和炮座后坐；重复观察不会再次触发。后坐只改枪炮子节点，不移动车体锚点。火光至少保留一个实际绘制帧，避免低帧率完全跳过。

验证入口：`res://scripts/coastal_motion_review_v1.gd`。它复制单独测试账号，通过真实 Main 的训练按钮与拖卡进入原生战斗，持续GPU播放并采样；之后另外标记的显示测试才注入观察样本，绝不向原核或正常账号提交伪造状态。显示测试覆盖八方向、匀速、同tick、暂停、回放倒退、上下船、九个不同坡面倒姿和真实shot字段契约。最后一次实际核心路径与哈希写入报告。

活动输出位于 `artifacts/coastal-rebuild-20261116/motion-review/`，交付时复制冻结。`renderer-fixture-*` 仅是显示测试，不能当作真实原核战果；`actual-main-*` 与 `live-*` 来自真正 Main 窗口。
