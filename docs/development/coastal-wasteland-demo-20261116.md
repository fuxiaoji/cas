# 海岸废土样区第二轮交付

日期：2026-11-16。运行工程：`demos/land-art-3d`。本轮只扩展隔离三维美术样区，不发布新的原核、正式家园经济或战斗规则。

## 打开与观看

- 双击根目录 `CAS-Land-Art-Demo.cmd` 运行Godot样区。
- 双击 `CAS-Coast-Review.cmd`，查看大图及可播放/暂停的海浪采样。图册离线运行。
- 样区底栏“更多景观”或数字5–9可看湿地、海崖、废土工业、海图预览与围墙。1–4保留海湾、港镇、山林和家园样板。拖动、滚轮、天气切换、Tab隐藏、F11全屏、Esc退出沿用。
- 编辑器导入 `demos/land-art-3d/project.godot`。动态源位于scripts/shaders；`scenes/editable_coast.scn`可直接选择调整模型与材质。快照在保存前恢复近景可见性，避免海图简化把模型隐藏状态存入。

## 实际修正与证据

实际Windows/Godot4.7.2 Compatibility/RTX5070捕获11张1600×900图片，位置在 `artifacts/coast-v2-20261116/screenshots/`。图片来自游戏运行，没有使用生成概念图或固定地图照片。海浪帧在 `waves/`；评审页仅做格式转换和序列播放。

独立目检和几何检查促成的修正：沼泽从圆坑变成接入河谷的低地；防线先做连续缓坡土方再放工事；工业平整范围避开旧工坊；十字路口标记修正三角朝向；普通艇/重型艇避开礁岸；陆地载具展示路线避开办公楼基座；沉没断楼拆开顶层连续楼板，让原镜头能看到断层和窗洞；宽相机后移，消除前景海面被近裁面切掉；保存静态场景前恢复近景模型。

可复跑检查和结果：

- `demos/land-art-3d/tools/check_coast_v2.gd`：直接调用真实地理和建筑工厂，检查3种种子重复/逆序采样、五类地貌、有限登陆、全场设施实际足迹、8GLB及SHA、快照地形顶点、所有权与关键模型可见性。报告 `artifacts/coast-v2-20261116/geography-validation.json`。
- `assets/vehicles3d/vehicle-water-route-verification.json`：默认seed714完整艇体与原地面/渲染三角地面，133,200个相位/艇体采样。只证明展示路线的净空，不代替正式航路和碰撞。
- 载具源目录中的地面路线检查核实际港镇地台包围盒与炮管伸出范围。检查的是固定样区展示环，不宣称通用寻路。
- `artifacts/coast-v2-20261116/desktop-render-samples.json`：近景和远景各180帧，报告包含帧等待、绘制次数、图元和Godot静态分配。静态分配不是进程RSS，图元包含渲染通道。桌面帧率不等于中端手机通过。
- `artifacts/coast-v2-20261116/runtime.log`：最终实际GPU截图/保存。最终捕获用Dummy音频避免电脑音频设备热切换；无音频能力验收。早先鼠标交互日志保留了一次WASAPI设备失效，不能说全部历史日志无错误；它没有产生脚本/着色器错误。
- `scripts/package-coast-v2-review.py --check`：离线本地链接、显示文件和原图哈希；浏览器检查图册播放/暂停和窄屏布局。图册不能证明Godot触摸/手机性能。

本轮真实鼠标检查更多菜单、湿地镜头、海图预览返回港镇、滚轮缩放、拖图、Tab隐藏与Esc退出。Android双指和实体机未测。静态SCN须另行实际GPU加载/绘制/释放，不只读取文件存在。

最终检查：地理/设施/模型/快照57项通过，交付时效/源文件SHA/艇车路线报告/截图/静态GPU加载/图册等38项通过。最终静态场景另载绘制和释放退出0，未发现嵌套实例或孤立节点。最终桌面近景/远景绘制次数中位为426/62，180帧等待p95约6.35/6.35ms，Godot静态分配约131.3MB；仅这台RTX5070的样区数据，仍不表示中端手机预算已过门。

最终目检图片和报告已独立复制冻结到 `artifacts/coast-v2-20261116/final-20261116-132456/`，不依赖后续会被截图命令覆盖的活动文件。该目录内`delivery-validation.json`登记每份证据SHA；当前总回执在上级同名文件。新复核脚本是 `scripts/verify-coast-v2-delivery.py`，它在验证源文件和报告仍对应当前场景后创建新的时间戳冻结目录。

## 素材与性能边界

8件载具共40,280三角、18表面、约2.71MB GLB；原三件GLB保留原SHA。运输直升机使用登记的CC0免费底模适配，其余新增艇车/武直为Blender原创；现有坦克的CC0来源和修改记录保留。所有来源、米制尺寸、轴向、源文件和材质在 `assets/vehicles3d/vehicle-manifest.json`。自然模型沿用已登记免费库。Tripo调用为0。

新增工事按设施内部共享材质，但尚未完成手机级整场合批和近远LOD资产。海图预览现为隐藏细节模型，未完成正式海图地标和战术符号替代。阴影、透明水面、地形/碰撞网格和完整战斗仍需手机预算实测。当前720×720m仅美术样区，不能放大后声称是满级家园岛。

按照[正式接入审计](../design/coastal-wasteland-followup-20261116.md)和[总计划](../design/land-scene-3d-reconstruction-plan-20261115.md)继续：先冻结权威地理和旧档边界，统一高度/岸型/合法卸载/通路/设施ID，再接家园、海陆主小地图和搜打撤消费者。海图按米和公里换算并减少渲染细节，同一点切图不漂移，不缩岛、不放大设施。随后才是实际登卸载、反甲/反步兵制衡、建造账本、有限驻防、攻防恢复、回放和Android发布门。
