# 两栖连队、专属载具与家园操作 v3

2026-11-14。本轮内容接入 Godot 正常启动路径，新行动使用 `cas-littoral-v3`；已有 v1/v2 行动按保存时的版本继续。历史战役的舰表、航速、武器与裁决不套用本轮地面提速。

## 从哪里开始

双击项目根目录的 `CAS-Godot.cmd`，进入「返航灯岛」。尚未获得岛屿的普通账户先完成训练；已经拥有岛屿的账户也能从训练入口重学。三课分别是「制海权」「登陆与炮援」「协同作战」，用真实拖放、战斗和撤离推进，关闭帮助不算完成。

- 海图：拖部队卡到岛上，载舰先靠近，再投送本人运输载具；拖战舰进入海域移动，指向陆地准备炮援。
- 陆图：拖部队卡到地面移动、敌人攻击、遗迹搜索；拖舰炮卡指定实际炮援落点。点击右上角小地图交换海陆主图。
- 顶栏：暂停和 1/2/4/8 倍速。撤收各连后，让舰艇驶入返航圈，完成真实撤离。
- 家园：分别设置舰艇驻防、战术驻防；新派遣选择 2–5 连和本人支持的运输方式。返回退一层，母港直接回港；未确认的建设不扣费，在途行动先保存。

## 本轮变化

每连有 6–10 个真实女性机器人身体，每场最多五连五十人。新 v3 地面基础移动速度为前版 2.5 倍，普通地面装填间隔除以 1.8；1/2/4/8 倍速推进真实模拟时钟。人数、伤亡、运输、弹药与撤收都参与结算。

二十个战术人格分别绑定二十种专属默认载具，四张透明图集共四十帧。包含不同登陆艇、两栖战车、侦察气垫艇、抢修艇、电子战艇、医疗艇、导弹艇、火箭艇、补给艇、潜入艇、河口艇、破障艇、指挥艇，以及轻型突击直升机、倾转旋翼机、武装直升机和搜救直升机。艇、车、直升机在运兵人数、速度、装甲和耐久上有实际取舍。

MCP-027 的赤隼武装直升机在运输阶段使用独立的有限武器：十二发、1.2 秒装填、1400 米目标距离。返程保留剩余弹药，耗尽后停止射击，运输被击毁也会造成真实损失。它不是仅播放攻击特效的运输标记。

人物动画保持实体实例与脚点对齐，同 tick 刷新和交换主图不再重置行走或重复受击。五连密集时，选中连显示大 SD，其余连以各自类型的逐体兵牌分簇显示；所有身体仍分别存在且可命中选择。切换连队后显示该连人物。

家园战术驻防独立保存，实际防御行动使用这份选择。已拥有的本人小人在合法陆地区域水平蹦跳、相遇互动。战术招募增加寻频、握手、头部近景、全身揭示、下一位、跳过和回看；十次结果用五列两行显示。动画只呈现已经提交的招募结果，中断、回看或跳过不会再扣费。

## 编辑位置

- `godot/data/tactical-profiles-v3.json`：从原核导出的二十编制与合法运输选项、人数、属性。
- `godot/data/transport-variants-v3.json`、`godot/assets/tactical/transport/`：专属载具、图集区域和固定尺度锚点。
- `godot/scripts/tactical_transport_art.gd`：载具解析与程序旋翼、水迹；`godot/scenes/ui/tactical_transport_preview.tscn` 可在 Godot Inspector 中调整并预览。
- `godot/scenes/ui/protocol_reveal.tscn`、`godot/scripts/protocol_reveal.gd`：可编辑招募演出场景。
- `godot/scripts/littoral_progressive_tutorial.gd`：三课真实状态引导；`home_island.gd`、`home_service.gd`：家园与账户接线。
- 美术来源及生成记录：`docs/art/transport-v3-20261114/generation-ledger.json`。新图由内置图片生成工具生成，未对生成图作程序修补；图集裁切与脚点仅是显示元数据。

## 验收与边界

最终汇总及源文件指纹见 `artifacts/littoral-v3-integration/integration-receipt.json`。包含正式默认原生核、新旧规则逐字节对照、真实 Windows Godot 输入、三课实际胜利和撤离、暂停与倍速、五连五十人、家园导航/账户、招募去重与存取重演。

原核 Rust 300 项通过；原生/WASM 的 22 组 12,377 次请求完全一致，旧 v1/v2 的 14 组 8,729 次请求与原核完全一致。七次真实原核航次记录六胜一负，失败不发成功奖励；不以保证每局胜利来验收。

三课窗口测试用真实输入完成全部操作，等待区间用真实原核 0.1 秒步进快速推进，不能当作完整 1 倍墙钟游玩时长。性能记录来自本机 Windows / RTX 5070，输入注入通过不等于手机实机验收。家园攻防继续本地人机，未新增联网。

二十款独有素材对应默认载具；切换其他合法运输家族使用明确标注本人的通用备用载具，未声称有六十套独有图。已有五个战术人格使用本人 SD，其余使用本人肖像或类型兵牌，不借他人小人。固定尺度运输动画和密集连队排布只影响显示，不移动原核实体或改变命中坐标。

设计与规则分别见 `docs/design/littoral-companies-v3-20261114.md`、`docs/rules/littoral-v3.md`。正常用户主备档未用于本轮写入测试，所有账户操作在隔离档中验证。
