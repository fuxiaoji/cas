# 2026-11-12 货舱拖放交付

用户反馈的主要问题是缺少直接搬动物资和落位预判。现在列表物件、物件缩略图和舱内已装物资都可按住拖动；拾取第二格不会突然把第一格吸到鼠标上。完整积木和原物件插画跟随指针，原位置保留淡色轮廓。合法位置显示绿色轮廓及「✓」，重叠、越界和超重用红色、交叉及文字共同说明。R旋转同时保留抓取的格点。拖出格库、右键或Escape只取消本次搬动，不丢弃物品，Escape不同时关闭货舱。

保留单击选择后落格的原操作；增加双击或「快速装入」寻找第一个合法空位。快速装入只处理选中物件，不重排其他物件，也不搜索或创建物资。真正弃置仍有独立确认。列表减少重复说明，物件配插画和占格缩略图。母港十列格库的右两列原本被窄滚动容器裁剪，已扩宽格区并重新安排列表及操作。

拖动和几何预览是显示层。成功松手才调用现有 `cargo_place` / 仓库事务，原核继续验证范围、速度、形状、重叠、边界和载重；UI不修改真态或发放奖励。整理时暂停、确认中暂停、取消/确认后的恢复、母港交易锁与既有撤离结算保持原语义。

- `godot/tests/cargo_drag_review.gd`：Windows/NVIDIA真实窗口，旧v4 **83/83**，15次按住拖放和11次普通点击。包括列表到格、格内搬动、第二格抓点、拖中R旋转、重叠、出界、ESC、右键、双击、960×540/1280×720/1600×720、真正搜索/中途保存重启/撤离/失败/暂停确认、母港右端列落位与兑换。
- 同一用例加 `-- --adventure`，使用新的 `cas-adventure-v1`，**86/86**。实际遇到实体攻击打断搜索后重新搜索，保留此前已发现物资且没有重复；新的移动速度缩短到达时间，搜索时钟与8秒时长没有改动。危险预警优先于低优先级物资文字，原核公开事件仍含实际搜索完成和入舱。
- 原兼容用例 `cargo_v4_integration_test.gd` 现显式移除新玩法profile，继续测试旧v4而不把新冒险默认出航误当旧规则。原核路径环境变量可指定运行副本，避免覆盖用户在用的程序。
