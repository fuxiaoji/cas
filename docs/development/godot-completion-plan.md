# Godot 全量迁移续作

2026-11-11。本轮依据用户提供的海图指挥台截图继续迁移已有功能。用户本次明确要求原版战斗界面与操作逻辑；此前“全屏海图”指窗口全屏，不表示去掉编队、舰况、战术AI和战情。保留原版顶栏时钟、开始/暂停、单步和1/2/4/8/20倍，海图与可收侧栏同屏。

## 迁移顺序

1. 逐项对照旧客户端：模式与导航、教程/序章、战役/挑战、港口资源与舰库、海图手势/指令预览/撤销、炮雷/雷达照明/烟幕、舰况炮座、AI建议/权限、战报、存档及只读重演。原版缺失或源规则阻断项目保留显式说明，不新增伪功能。
2. 已迁移的单人搜打撤和真实经济继续回归：程序海域、有限敌预算、观察公平、搜集/弃货/撤离、失败/中断恢复、幂等结算、仓库卖货与采购、维修成长、唯一配装、借用恢复。
3. 对照原有母港与用户截图，保持海军蓝金、宋体标题、大角色、编队层级和战争航图；已安装的GitHub前端/游戏设计/Godot技能复用，不重复下载同名副本。
4. 搜打撤使用独立风格化海面与岛屿：深青与群青海水、手绘波纹、浅水色带、沙岸/岩层/植被分面。原核岛屿边界不变，视觉纹理不进入碰撞或视线判定；历史战役保留清晰战术海图。
5. UP池采用有背景的复杂舰娘原画；抽取包含可跳过航海信号演出、稀有度反馈、头部/半身特写和完整结果。扣券、确定角色、重复补偿和保存先完成，动画不发奖。UP概率从配置真实读取，普通池规则不被静默改变。
6. 逐舰小人持续制作：210个稳定identity，已存在6张原创候选，剩余204张。每张基于自身CAS立绘、参考网站SD比例，透明图、短肢平涂、来源哈希、提示词与目视质量检查齐备后才接入。候选不冒称用户逐张签收；无需把等待用户签收作为开发停工门。保留原舰影开关，投影不修改原核长度/阵位。
7. 语音、8首指定BGM和CC0交互音在新界面中复核；只订阅本席观察事件，防重复播报/未知方位猜测，音量与暂停/让音设置仍持久化。

## 设计取舍

风险与带回物资是单人循环中心，战斗操作服务于观察、航路、接战与撤离。港口保持旧版本有辨识度的海军美术；打捞海域增加手绘自然层次，同时让舰位、航路、炮弹与鱼雷保持高对比。卡池将复杂原画和角色特写作为视觉重心，详情、概率和记录移入可达的次级页面。风格化不借机改历史舰卡或裁决概率。

## 验收

模式/操作迁移矩阵逐项对应旧文件与新入口；Godot语法及独立事务测试、真实窗口手势/侧栏/全屏、原核实战与原生/WASM重演、旧浏览器历史回归、原创美术覆盖检查。只有实际完成的项登记完成，最终未完成项保留具体原因及可复验清单。

本轮并行素材归属：美术线0–69；战斗线70–111及161–170；集成线112–160；经济线171–209。已有原创候选逐ID跳过，参考网站同名模型不计入原创覆盖。四种打捞物资插画由集成线生成并接入仓库/货舱。旧单人编辑器与序章电影以真实迁移矩阵继续核对。
