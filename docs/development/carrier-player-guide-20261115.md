# 航母使用详解

新版操作、持续盘旋与八步实操教学详见[航母拖动指挥详解](carrier-command-v2-guide.md)。下文保留首轮操作说明；新独立练习入口现启用v2，在空改令、联队卡和各舰姿态按新版指南。

双击项目根目录CAS-Carrier-Academy.cmd进入独立练习。启动后暂停并打开航母指挥菜单；关闭菜单、按右上“暂停”恢复时间。借用企业、翔鹤与护航舰，不消耗正常账号资产。菜单里的“详细教学”可随时回看；本轮新录舰船、飞机在“原书资料图鉴”查看，未开放出战的条目有明确说明。

## 先看中队卡

底部每张航空卡标题先写母舰名，再写机型。企业的野猫/无畏/蹂躏者与翔鹤的零战/九九舰爆/九七舰攻分别归属各自甲板。横向拖动底栏可查看后排卡片，拖卡离开底栏再移到海图才下作战命令。可出击是已在甲板的飞机，在空是正在起飞/飞行/巡逻/返航的飞机，损失不会通过等待自动补齐。

同一母舰的不同中队共用一条串行甲板；两艘航母有两条独立甲板。可以一边让企业出击，一边让翔鹤准备另一波。同舰飞机逐架起飞和回收，不能把多张卡同时拖下就当作同步升空。

## 第一次警戒与打击

1. 先拖企业野猫卡到母舰附近、距离母舰超过600米的海面；松手前确认落点有效。新版会登记任务并在下一个调度点开始出击。
2. 看飞机逐架离开甲板，飞抵指定点后进入patrolling警戒，继续实际耗油。发现3000米内敌机后会转向拦截，武器用尽后返航。
3. 将翔鹤轰炸机卡拖到已发现敌舰；敌舰接触是合法目标，不能把海水任意点当敌舰。也可拖到真实岛内地点对地打击。
4. 鱼雷机只能拖到敌舰，不能炸岛。战斗机拦截敌机时拖到真实敌机图标。非法目标、超程或已失效接触会拒绝并解释，拒绝不应消耗飞机或武器。
5. 飞行需要时间，攻击效果来自飞机真正抵达并使用武器；松手并不是立即伤害。母舰还需自己保持安全航线。

## 排队、修改和召回

甲板忙碌、飞机在空或整备中时，仍可拖卡安排下一次任务。每个中队只保留一个待命，新拖动替换旧落点。待命不会预先扣武器，实际出击才装载。原地反复拖卡不会复制飞机。

把同一中队卡拖回所属母舰的位置（当前母舰600米内的召回捕获区），会取消该队待命并召回实际在空飞机。召回后飞机自己飞回，不会瞬移。母舰移动，返航终点也跟着真实母舰移动。正常完成回收不是战损；受损飞机不会自动满血。

返航机进入母舰附近1500米后，自动调度优先保留甲板回收，避免无限起飞压住回收。飞机需要依次着舰，再整备20秒。只有看到available回升、airborne下降，才说明回收完成。原有撤离命令会检查仍在空的本方飞机，不能用撤离静默删除飞机。

## 多航母分工

第一艘派战斗机警戒，第二艘优先派攻击机；留下一批飞机与弹药作为第二波。攻击机接敌时可调第一艘的轰炸机接力，随后留甲板给返航机。不要只盯着可出击架数，还要看武器库存、损失和下一轮整备。

开启航空托管后，只改变航空安排：轮换各舰各中队，战斗机优先拦截/警戒，攻击机从本席敌舰接触里选择目标，并按已有在途任务分散攻击。每方航空托管预算12架，双方活动总数24架。它不会凭空补机补弹，也不保证所有波次同时抵达。手动待命中队不被托管改写。关闭托管停止后续自动安排，已经起飞的飞机继续执行真实任务；需要它们回来时再召回。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 拖了没有立刻起飞 | 看待命、甲板忙、整备、返航优先和活动飞机预算；已有队列不需要重复点击 |
| 飞机在海面转圈/停留 | 警戒任务在指定点保持，继续耗油，可遇敌拦截或手动召回 |
| 鱼雷机拒绝目标 | 只接受真实敌舰接触，不接受地面或敌机 |
| 母舰沉没后还有飞机 | 在空飞机不会被瞬间删除；当前没有其他航母备降，需要真实燃油/损失结算 |
| 没有武器了 | 库存有限；等待只能整备，不能凭空生产武器。未发射的武器随实际返舰归库 |
| 新舰无法加入舰队 | 图鉴source_only是核表录入状态；完整战斗消费者及验收未完成前不会发放出战资格 |

## 自测操作清单

实际完成一次海面警戒、一次空中拦截、两舰各自出击、忙甲板待命、更换待命目标、主动召回、着舰后第二波。每个中队始终应满足“甲板可用 + 在空 + 已损失 = 初始飞机总数”。菜单阅读不算通过这些实际操作。

当前是近场玩法，不能将2秒起飞/3秒着舰/20秒整备当原版CAS。原规则直甲板起飞3架/分钟、着舰1架/45秒，还包括风、海况、高度、挂载和事故。原书巡航总航程也不能直接当单程攻击半径。完整边界和页码见carrier-ops-v1-source-notes.md。
