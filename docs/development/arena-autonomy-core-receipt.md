# 本地人机竞技与新版全自动打捞原核

2026-11-12。新增玩法属于独立架空模式，不改历史CAS舰表、阵位、环境、原始PDF或参考工程。竞技没有联网或真人匹配服务。

## 竞技接口与裁决

- `arena_catalogue`给出当前实际可加载的舰娘ID、CAS点数与24个人机名称；没有核准出战卡的身份不会出现在选择表中。
- `new_arena`请求：`{op, arena_version:"cas-local-arena-v1", seed, mode:"ranked"|"team3", groups:[{id,name,ships:[角色ID]}]}`。只接受此版本字段，内部使用`cas-realtime-v10`、`open-intel-v1`；不能混入历史或双席主机存档。
- 排位：玩家1–4个编队，身份不能重复，单席最多32舰，总点数不超过10000；对手按种子随机生成2–4个人机编队，预算总计不超过10000。编队单组最多16舰，点数不是必须花满。
- 3v3：玩家为一席、可控制1–4个编队、总预算3400；两名人机队友各3300，三名人机对手总预算10000。各自独立AI。双方席位不受舰籍阵营限制，镜像身份可以在双方出现，同一方身份不重复。
- 稳定64位随机源在取模后转索引，Windows与WASM同seed阵容一致。舰体、火炮、鱼雷、射界、装填和伤害沿用真实已加载卡及即时v10，不伪造命中。
- 原核拒绝玩家向人机队友或对手的舰船/编队下令；自己分舰后仍可操作，运行中也最多四个玩家编队。AI内部导航、炮雷和损管不受手动权限限制。
- 15分钟模拟时间后等真实在途炮弹落定，或一方全灭，按击沉CAS点数结算，返回`winner:allies|axis|draw`。此模式`result.allies/axis`表示击沉点数，不能按历史的“艘数”标签显示。
- `view.arena`提供模式、种子、`match_id`、预算、玩家编队ID、完整阵容、bot身份和终局原因。完整`roster`包含所有初始舰艇，击沉不删除身份；玩家分舰会改变所属fleet。账户可绑定seed、请求与实际终局，防重复发奖，账户实现由主线负责。
- `save/load/replay`保存初始编成和真实玩家命令，由种子重建人机并逐秒重演。新可选`Saved.arena`缺省不序列化，旧存档字节保持。

## 新版自动打捞

`{op:"extraction_autopilot",enabled:true,policy:"balanced",version:"cas-extraction-pilot-v2"}`显式启用新版；默认启用和开航由Godot主线接线。旧日志未带version继续旧行为，不在加载时升级。

新版自动接受可承受任务；根据本方舰体余量、炮雷、承载、已公布威胁和返航油量取舍挑战。可就近完成任务，再实际搜索与装载；远任务先确保附近货物。使用原核任务接受/交互、搜索揭示、积木摆放/整理、真实等待接驳命令，不凭空创建战利品。炮雷自动授权，导航由专属规划器负责。低血、缺弹、低油、满载或时间临近时带货退出；合法手动命令立即接管。

真实三舰纵队测出旧策略的尾舰未入接驳区问题：领舰停在区边缘，尾舰在外而不再重下航路。新版按完整队列深度设入区目标；队列长到接驳矩形无法容纳时，临时分舰各自入区，保留全部舰艇与物资。旧pilot行为不改。

## 即时鱼雷审查

新`new_salvage`使用v10，合法鱼雷命令当秒发射；不是等180秒窗口。自动射向暂未落入发射管射界时持令，合法即发，最多90秒；显式指定炮座/数量非法会拒绝，不扣弹。标准/疾行备雷20秒、重型30秒，仅有限储备可装填。已有旧v9航次和刻意冻结v9的挑战天梯保留原窗口时序；界面应标明规则版本与“射界等待/装填”，不能全局重写旧航次。
