# 全程序动漫海域与 v2 天气验收

最终交付为 `artifacts/godot/weather-motion/CAS-程序云海-v2真实天气航次.mp4`。真实 Godot 画面，1280×720、30 fps、840 帧、28 秒，文件 6,119,028 字节，SHA-256 `9b53e7eb0e4034185d8f553064b10aad15a2d78635d0a3a626d3146eb2d19ced`。没有合成画面、插帧或地图照片。

## 全程序场景

- 水面由世界坐标噪声、推进碎浪、浅水与日光碎光生成；两列错相岸浪朝原岸线推进并消散。
- 云由三维密度、14 层光学积分和光衰减生成；云影共用密度场。零云量对象不绘制，云影跳过不需要的光照计算。
- 陆地从权威岸线扫描生成内存距离场，程序噪声生成海滩、岩壁、高地和疏密林地；斜视高度投影形成受光大岩面。原岸线多边形负责最终裁切。
- 运行代码不再引用 `anime-cloud-v2.png`、`anime-island-v2.png`。旧素材仅作为早期美术归档保留。
- 航迹只读取当前已知单位的真实历史位置；失去接触即清除相应尾迹，模拟时钟回退清空旧迹。
- 环境图层位于可见舰艇、鱼雷、弹道和选中标记下面。云在已知单位周围额外软化，没有查询隐藏敌人。

## 权威天气与暂停

Godot 读取原核 `observation.weather` 的当前种类、下一种类、过渡比例、云量、雨量、雾量和视觉风。环境仍由原核 `environment` 决定有效能见度、降水、海况与昼夜。客户端没有随机天气时钟；历史战役及无 weather 字段的旧档使用原来的固定环境。

`weather_paused` 冻结天气缓冲，海浪、云和雨滴动画仍继续；不会发出模拟 step。视觉风只用于绘画流向和美术漂移，不代表新增舰艇、烟幕或射击风力规则。

## 最终原核录像

使用新的 `target/release/cas-sim.exe`，显式 `content=salvage-v2`、种子 6109。600 次原核步进，每帧 2 模拟秒。前 20 秒以 60×验收速度展示真实 20 分钟航次：晴→多云→雨→阴→雾→多云；后 8 秒停止步进，推近岸边检查持续波动。

每个渲染帧检查观察数据未被修改；暂停段验证观察和天气均固定，海面时钟继续推进。固定取景区域平均 RGB 绝对变化 0.02467，61.71% 像素变化超过阈值。`native-render-test.json` 明确保存 `content_version=salvage-v2` 与所有真实天气切换 tick；`animation-pixel-proof.json` 保存像素变化和视频校验。

v2 当前沿用原核已种子化的 `archipelago-1` 岸线生成器，本轮不把玩法布局升级宣称为新的海岸算法。渲染端不会自行搬动或随机重摆岛屿。先前 v1 视频保留作版本归档，最终交付使用带 `v2` 的视频文件。

## 边界

这是 2D / 2.5D 程序美术，没有新增海浪浮力、舰艇风力物理或任意暴风海况。海况遵守原核数值，原舰长线、位置、碰撞、探测与伤害不变。小人生成继续暂停。60×只用于录像验收，不代表默认游戏速度。

最终录像已在 500 米纵队及矩形集合撤离区修复后的核心重拍。原核 SHA-256 `ee1cd72221b551c6ae91a59844abea13ee8f2a7f0016f3aa047addc4c338e517`；两舰初始坐标为 (2200, 2200)、(1700, 2200)，均朝 90°、初速 0。完整部署与核心校验随 `native-render-test.json` 保存；仍为 840 帧、600 步、五种天气和暂停检查全部零失败。

## 矩形集合撤离区最终接线

`sea_map.gd` 只读取公开的 `salvage.exits[0].shape=rectangle` 与 `bounds={min_x,min_y,max_x,max_y}`，绘制淡薄荷色集合海域、中心“集结撤离”标记及同边界小地图。没有从实时舰位推算或扩展区域。`exit_tooltip(index)` 说明全体可航行舰艇须进入标示矩形，以区域边界为准。中心悬停可见说明；交互仍限定中心标记，矩形空海面不拦截选择或绘制航路。原 v1 不生成矩形，东侧与另一撤离点仍为原圆区。

`extraction_region_review.gd` 实际窗口 **43/43**：15 艘真实舰艇分为 8+7 两队，公开区域 x=700..5200、y=1700..3700，中心 (2950,2700)。逐舰验证均在区，屏幕边界反投影与原核 bounds 完全一致；实际收取 5 碎片并在 12 秒内带货完整撤离。中心点选、区域内空点不误选、区域内正常绘航路、观察不变、v1 原字段均通过。凭证 `artifacts/godot/extraction-region/receipt.json`；截图 `01-fifteen-ships-two-fleets-region.png` 与 `02-native-extracted-fifteen-ships.png`。最终同名 v2 视频已使用包含该区域的发布核心再次捕帧，未改海面 shader。
