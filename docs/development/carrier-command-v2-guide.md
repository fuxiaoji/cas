# 航母拖动指挥详解

本轮在独立航母核心中启用新版航空操作。双击根目录`CAS-Carrier-Academy.cmd`进入隔离练习，现有企业、翔鹤和护航舰不消耗正式账号资产。打开右侧“航母指挥 / 教学”，可查说明、实操引导和各舰姿态。其他核心尚未装入新版时会拒绝启用，不影响旧航次。

## 先分清三种卡

| 卡片 | 拖动行为 | 点一下 |
|---|---|---|
| 航空联队 | 拖回所属母舰，取消这艘母舰所有待命并召回其在空飞机 | 筛选该母舰的中队，再点一次恢复全部 |
| 中队（机型名） | 布置下一波：战斗机拖海面盘旋警戒、拖敌机拦截；俯冲机拖敌舰/岛内地点；鱼雷机只拖敌舰 | 查看中队详情 |
| 在空（带“在空”字样） | 改变当前编队的警戒点或兼容攻击目标；拖回母舰召回 | 查看在空改令规则 |

底栏可左右拖动滚动；要下达作战命令，先把卡向上拖离底栏，再移动到海图。拖到小地图会提示先切换主图。松手前查看合法性反馈；按Esc或失去窗口焦点取消，不会下令。

同一母舰的各中队共用串行甲板，不同母舰各有独立甲板。联队卡显示该舰在空数、甲板剩余忙碌时间、近舰待回收飞机数。中队卡显示可用与在空数；已排队时显示具体等待原因。在空卡显示真实阶段与剩余航程量，不能把它当成剩余分钟。

## 飞机持续飞行

飞机在甲板排队起飞时可暂不移动，离开甲板后按真实航速持续运动。警戒落点是盘旋空域的中心，不是停车点。近场新版以约600米盘旋半径和30度/秒盘旋转向上限跟踪指定空域；实际位置连续变化，航向、油量同步裁决。

返航时母舰甲板忙，飞机进入附近约650米的等待盘旋；甲板可用后实际进场，依次回收。盘旋也消耗燃油，不会通过等待补油。返航预留3000米航程量供近舰等待，不能保证母舰已沉没或长期无法回收时仍能安全落舰。母舰移动会改变实际返航位置；没有瞬移着舰或异舰备降。

这些半径、转向上限与燃油预留属于已登记的原创近场控制参数，不是CAS原书航空表值。原版风、航线高度、甲板事故和满额空群仍有未实现项，见规则源笔记。

## 排下一波、修改和取消

中队在空时仍能拖中队卡排下一波；每队最多一个待命，再拖就替换原落点。队列不会预扣飞机和武器，真正起飞时才装载。它可等待飞机返舰、整备、甲板、活动名额或返航机优先回收。

要修改正在飞行的这一波，请拖“在空”卡。全部离开甲板后才允许改令，改令前逐架核验真实燃油、武器、目标资格和返程预留。任何一架不满足就整体拒绝；飞机身份、HP、武器和燃油不会重置。已经返航的编队不能再次派出去，须真实着舰整备。

拖中队卡回所属母舰600米内，可取消该队下一波并召回该队；拖联队卡回所属母舰则处理全舰中队。召回后仍需观察飞机飞回、在忙甲板旁盘旋、依次回收。母舰沉没、目标失效或武器耗尽导致待命取消时，卡上会显示原因；重新下达合法待命会清除旧提示。

己方飞机图标不会把海面警戒落点误判成敌机目标。攻击敌机仍需要实际存在的敌方飞机；战斗机负责警戒/拦截，不能用轰炸机替代空战机。

## 两艘及更多航母怎么用

先从一艘母舰派战斗机建立警戒，另一艘优先出攻击机；留出回收和第二波空间。并行的是两条真实甲板，同舰仍逐架起降。通过点联队卡筛选单舰，避免混淆相似机型；再点一次可恢复多舰总览。

自动调度先处理防空，再分配攻击；附近航母可共享一组警戒，避免所有航母一律先把预算花在重复CAP上。各舰按存活航空甲板数分得活动份额，中队轮换遍历；攻击机根据本席公开接触、距离和已有在途攻击分配目标。每方最多12架、双方活动总数24架；名额不足时等待，不复制飞机。三甲板及敌方航母的真实调度有单独测试，测试夹具不表示新增历史舰已开放。

| 姿态 | 自动行为 |
|---|---|
| 均衡 | 防空优先，兼顾可用敌舰打击 |
| 防空 | 警戒/拦截，停止新打击派遣 |
| 打击 | 优先可用敌舰打击，仍可拦截已接近的敌机；不主动补无威胁CAP |
| 停止派遣 | 不安排新的自动出击，已有飞机继续实际任务 |

手动拖过的中队由玩家接管，AI不会在回收后立刻反向重新派出。选择该舰的姿态按钮会把它的中队交回AI。全局关闭航空托管同样只停止未来安排；要回收已有飞机还需拖动召回。AI没有合法目标时等待或维持已有警戒，不应为了看起来忙碌而虚构敌舰、伤害或起飞。

## 八步实操引导

从菜单选择“跟随实际操作的航母教学”。引导给当前需要的卡和落点画出标记；卡不在屏内时先横拖底栏。没有“下一步”完成按钮：只认玩家实际下令与权威飞机状态。

1. 拖第一艘战斗机到指定海面，等新飞机实际起飞并开始盘旋。
2. 拖第二艘战斗机出击，观察两舰各自的在空飞机。
3. 再拖第一艘中队卡，排下一波，保留当前警戒。
4. 再拖到不同落点，确认只有一个待命且目标改变。
5. 拖第一艘“在空”卡，实际改变当前盘旋空域，飞机/燃油/武器不增加。
6. 拖第一艘联队卡回母舰，等实际回收结束，确认本舰待命已清空。
7. 再拖中队卡出击，等待整备后的新飞机开始第二波盘旋。
8. 开启航空托管，并在各舰姿态分别点“均衡”交回玩家接管的中队；观察原核确认两舰已交回托管。

完成只代表上述操作，既不发账号奖励，也不代表通过完整空中拦截、鱼雷/俯冲攻击或历史航母战役考核。没有敌机时不会用计时器冒造拦截成功。

## 常见问题

- 没起飞：看是否正等飞机、整备、甲板、回收优先或活动名额。反复拖卡只会改待命目标。
- 盘旋很久：当前是持续警戒，或返航等待甲板；看燃油和母舰回收状态，不要把盘旋当卡死。
- 在空卡拒绝：检查是否尚有飞机在起飞、已经返航、弹药用尽，或新航线没有足够返程燃油。
- AI不派某队：看它是否被手动接管、所选姿态、份额、回收优先和合法敌舰接触；到姿态面板交回托管。
- 召回后还有飞机：回收有真实进场与逐架着舰时间，甲板忙时会盘旋；等待在空数归零再撤离。
- 新录舰机不能选：资料条目仍为source_only，不能跳过原版规则和历史验收直接开放。
