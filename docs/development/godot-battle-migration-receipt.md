# Godot 旧海图指挥台迁移验收

2026-11-11。根据用户指定的旧海图指挥台截图及 `client/src/BattlePresentation.tsx`、`BattleMap.tsx`、原主客户端命令面板，将战斗入口恢复为顶部时钟/开始/单步/1、2、4、8、20倍，左侧海图，右侧可收起的编队、舰况、战术AI、战情四页。保持原生全屏，历史战场使用原战术海图，不改变舰卡、舰序、阵位或任何表值。

## 文件与接口

- `godot/scripts/legacy_battle.gd`：原生指挥台、真实舰况、命令、雷达/照明、AI、报告、进度及重演控制器。
- `godot/scripts/battle_map.gd`：继承 `sea_map.gd`，保留其海面、投影、小人与船长线；追加原手势、预览、炮弹/鱼雷轨迹、射程/雷达圈与方位刻度。未修改基础渲染器。
- `main.gd` 保留现有公共入口，战斗委托控制器。`start_local_mode(request,context)` 与 `start_replay(record)` 接模式/档案；`checkpoint`、`finish_battle`、`abandon` 按私人打捞和借用模式分流。经济及教程服务负责冻结航次、验证实操与幂等发奖。

控制器只读本席观察，不读取权威隐藏世界。命令调用与旧客户端相同的 Rust JSON 接口；所有航行/武器预览由原核返回。雷达接触需通过本舰授权，未知敌舰不因UI身份图而泄密。无精确身份的舰型代表图明确标记代表；没有来源则保留舰影。

## 实际运行

命令：`Godot_v4.7.2-stable_win64_console.exe --path godot --script tests/battle_migration_test.gd`。

真实 Windows/OpenGL 可见窗口 **115/115**，124个应用内部 `Input.parse_input_event` 输入事件，10张3840×2160截图，控制台无脚本/运行时错误，正常退出。明确不是OS鼠标自动化。使用独立 `user://tests/battle-ui-<pid>.json`，结束只删除本测试档，不改试玩存档。失败凭证独立写入，不覆盖通过凭证。

`artifacts/godot/battle-migration/receipt.json`：

- `01-command-desk`、`02-route-preview`：旧结构、真实航线草稿与原核路径。
- `03-ship-schematic`、`04-tactical-ai`：舰体/炮座及真正AI建议。
- `05-native-replay`：只读原核重演，末端严格相等、权威save不变、经济不变。
- `07-gun-aim`、`08-torpedo-aim`：原序章合法近距开局，不移动敌舰；鼠标实际下令，随后原核确实发射本舰炮/雷。命中率无null后缀，鱼雷扇区与友舰风险显示为原核结果。
- `06-night-radar`、`09-night-light-smoke`：真实雷达设备、夜间航行330秒获得接触、照明弹起亮、探照灯与烟幕。
- `10-live-training`：未完成实操的当前指令/禁用完成，真实单步证据、原样保存、无奖励退出、档案回放。

完整客户端再回归：`tests/client_integration_test.gd` **106/106**，81个内部鼠标事件，10张截图；征募→两次真实私人航次→保存跨进程恢复→撤离/失败→卖货/补给/养成→借用历史战役至3287秒全部通过。回执没有手工制造；个人舰艇不受借用战役影响，钱包只增加真实登记奖励。凭证 `artifacts/godot/client-integration/receipt.json`。

## 边界

本轮只改客户端接线/可视化，没有修改原核表值或历史想定。此前147内核+1stdio及3组新搜打撤、24组原有原生/WASM重演证据仍分别保存在PVE记录。本原生UI验收不能替代历史原页核对，也没有将source_only目录变为可玩。

静态小人沿身份表渐进补齐，方向动画尚未实现；显示可切原舰影。舰体线长度仍按本席权威 `hullLengthM`，未核实实舰长度不得冒称实测。模式模块的原序章204秒自动开场电影尚未在本控制器单独验收；本轮真实序章战斗仅用于合法开局炮雷操作。Android、多人、支付和未曾开发的后续剧情不在本次完成范围。
