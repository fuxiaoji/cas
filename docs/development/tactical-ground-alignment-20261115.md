# 陆战实体对齐与步坦协同

用户反馈：小人图像与实体位置分离，坦克偏小；希望装甲部队托管能随车掩护、出侧翼开火、受压回撤。

## 已定位的显示问题

`tactical_art_v2.gd` 与旧备用绘制路径将负宽度翻转当成了负方向绘制。Godot 的纹理矩形负宽度用于翻转，矩形落点仍需明确计算；原先在翻转时额外加一个图框宽度，导致图像横向漂移。修正为以动作帧脚底 pivot 为轴反射图框。站立、行走、射击、受击、搜索、倒地均使用同一地面锚点；不改变原图片、帧裁切或实际身体坐标。敌方和旧静态伤亡图的同类翻转错误一起修正。

另一个问题是暂停后单步推进：观察已更新但绘制插值等待播放，图像可停在旧点。暂停时立即重投影到实际公开坐标；播放时保留有限时间的连续插值，镜头移动和缩放不被当成身体运动。新车辆初次显示或原地停留时，从实际公开航向投影朝向。

接口依据：[Godot CanvasItem.draw_texture_rect_region](https://docs.godotengine.org/en/stable/classes/class_canvasitem.html#class-canvasitem-method-draw-texture-rect-region)。实际 GPU 镜像像素检查用于核实本项目的绘制结果，不以公式推导代替画面验证。

## 比例与选择

新 v3 陆图坦克的显示长度至少为同镜头选中 SD 身高的 3.6 倍，其他车辆按各自层次放大；海图继续实际米制。放大不修改武器射程、物理半径和航速。载具中心与角色脚底仍为各自实际中心，不通过屏幕散开制造假队形。准确落在载具中心的拖放优先识别载具，避免附近放大的 SD 头部截走上下车操作。

## 真实协同

新 v3 的步坦规则及限制见 [协同设计](../design/tactical-v3-armor-infantry.md)。022坦克与103两栖战车都执行真实随车后掩护、至多两名侧探射击及受压回撤；103只对已下车身体执行，上车后原身体隐藏并停止地面射击。087自行炮保持远程炮援。掩护取决于射线、真实车辆和身体位置；不会因编入装甲队而获得常驻减伤。直射可被车体截获，己方不能穿车射击，范围与高抛火力仍可威胁车后人员。每个身体保留独立碰撞、武器、弹药与伤亡，车步撤收仍须完成真实接驳。

射击动作亦按真实弹道的 `operator_id` 触发。原记录的 `source` 是连队编号，不能拿它代替实际射手；否则同一连里某人的动作会缺失或绑给别人。回放重建只恢复短时间内实际发生的射击，不凭播放计时额外发射。
