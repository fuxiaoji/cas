# 潮汐回响：流畅战斗与局内舰队

用户本轮要求：肉鸽卡顿、不够割草，并希望后期加入更多舰娘组成编队。新局采用独立 `cas-event-tide-v2`；旧活动航次继续按v1恢复，历史战役、搜打撤、竞技、永久舰表与养成参数保持原有规则。

## 问题与测量口径

正式旧核 `c4c2a09b…` 已归档的seed42/43完整原生对局，前30秒只有8/7击退，三分钟90/93击退。战斗每秒更新一次权威位置，60节乘活动位移后一次跳约309米。连续WASD每0.35秒提交一次航线，随后同步保存整个账户。原核推进并非主要卡感来源；新版增加实体及10Hz，不宣称原核单次请求比旧版更快。归档对照见`artifacts/tide-v2-core/bench-comparison.json`。

真实43舰隔离账户的GPU基线：移动操作含保存P50/P95为31.318/32.026毫秒；单独保存25.283/27.837毫秒。RTX 5070、1280×720与1920×1080，23只怪物时纯渲染帧P95约6.2毫秒，但有约475次绘制调用、7478个渲染对象。测量说明主要卡感来自跳位与同步保存，不能把该显卡的纯渲染结果描述成已经低帧。证据：`artifacts/godot/tide-performance/baseline.json`。

## 新版体验

- 保持三分钟短局。开场已有能快速清除杂兵的火力，连续小批敌潮提供密度；精英与核心承担读招和集中火力的目标。成长增加真实炮雷、范围与能力，敌人死亡、经验拾取、强化、招募都来自原核。
- 一名舰娘出发，出航前从已拥有舰娘中选择后备；局内成长出现援军批次，由玩家选择本人加入，逐步扩到六舰。全队围绕首舰航行并分别开火，共享本局共鸣强化和队伍耐久；后备与队员身份记录进可重演命令，不临时借同名立绘。
- 援军选择采用本人图片列表，普通强化保留三张选择卡。战场主要显示海域、威胁、经验与队伍，不堆全局资源表。局内强化不带出活动，不扣港口油弹，不增加账号所有权或永久成长。

## 流畅度处理

- 新版原核采用固定10Hz微步，观察与界面时钟仍按真实秒；快慢设备采用同样的微步和带种子随机序列，不以全局10倍时间伪装流畅。
- 客户端每0.1秒消费新观察，连续移动保留在原生命令日志中；每5模拟秒批量保存，升级/招募、主动保存、离开、关闭及结算仍保存。保存失败暂停战斗并保留上次成功的档案。
- 新活动观察已经包含实际炮弹/鱼雷，跳过每次更新额外索取空炮击表现的往返；历史模式仍用原有表现流。
- 潮汐专用绘制负责有限实体、裁剪、缓存和视觉插值，程序海面继续动态。视觉位置和震动不写入原核航行、命中或预警范围。具体实体预算、舰种火力、成长与奖励见 `docs/rules/tide-event-v2.md`。

## 保存与账户边界

v2保存含 `frame` 与秒单位 `tick`，二者必须满足 `frame=tick×10`，命令记录微步。活动账户严格核对版本、种子、首舰和后备名单；拒绝未拥有、重复及将首舰再次放入后备。最终结算独立重演原生命令，对比真实队员、终局和奖励，防止伪造入队或奖励；同一航次不重复入账。

活动币、商店进度和首通沿用原活动账户记录，不通过升级规则重置兑换额度或重发首通。测试只用隔离副本，用户主档与备份只核对SHA。

## 性能结果与实际边界

RTX5070、Godot Compatibility、关闭垂直同步及帧率上限，同一真实旧局23敌/9掉落：1280/1920绘制帧P95由6.232/6.083ms降至1.340/1.322ms，绘制调用约475降至180左右。新版六舰91弹48掉落实战，1280/1920绘制帧P95为1.374/1.384ms。实际8墙钟秒生产主循环推进7.9模拟秒，每次0.1秒，帧P95为1.695ms。

完整正常移动操作P95由32.026ms降至18.810ms；新六舰样本桥接往返P95为15.906ms，其后界面更新2.166ms。这些数值包含不同范围，不能以1.38ms绘制时间代替整条操作延迟，也不能将桥接差额未经测量归因于解析或管道。同步周期保存仍保留，观察到最大48.330ms帧；本轮减少保存频率，尚未消除所有峰值，不保证所有机器零卡顿。详细口径与阶段失败记录在`artifacts/godot/tide-performance/review-notes.md`。

援军批次包含「暂不招募、改选强化」，界面逐条读取kind，不能把该普通强化误当舰娘。强构筑允许站桩清场；本轮站桩样本胜利但只招到四名，未伪报六人。普通怪的不同外观目前共用追击锁定攻击。原浏览器白天标题与权威夜战环境不符的既有表现差异继续保留登记。
