# 标题入口、章节路线与新版货舱交付

2026-11-12。本轮是用户授权的 Godot 实装，采用随后提供的两张《重返未来：1999》风格参考修订章节页面；不以此前白底网格为最终方案。原始 PDF、参考工程和历史 CAS 表值未修改。

## 试玩入口

双击根目录 `CAS-Godot.cmd`。普通启动先显示“CAS / 归航”标题页；开始游戏进入母港，有未完成航次时可从标题继续。设置返回标题，母港“剧情章节”进入深色竖幅封面目录，再进入本章的不规则叙事航线，最后选择已解锁片段或作战简报。第二、三卷是明确禁用的未公开记录。

母港“出航”→“打捞远征”选择近海巡航、交锋航路、深渊禁区，以及四种地貌、起航天气。随后编队；“装载与货舱”可调整炮弹计划量，拥有鱼雷的舰艇可卸下鱼雷换载货空间。先搜索、再选择物件并旋转摆放，实际入舱且撤离成功的货物才能带回。成功结算“整理带回物资”直接打开母港物资格库；以后从仓库的“打捞货物”再次进入。

## 主要变化

- 实际开屏场景 `godot/scenes/ui/title_screen.tscn`，原画、游戏名、按钮、设置和退出均为独立节点。开屏与三档远征新增四张原创 CG，完整提示词、原文件和 SHA256 登记在 `docs/art/generated-assets-2026-11-12-v5.json`。这些图只用于菜单；实际战场继续以程序生成水面、云、岛岸和设施。
- 章节采用深色封面陈列、沉城 CG 与不规则叙事航线；未来点不重复堆放“未抵达”。原有 16 节点、两处分支、三场实战和奖励条件保留。对白逐句保留舞台、背景及仍在场的角色，不再反复整屏淡入；换景才交叉淡出。
- 三场剧情实战提供可收起的情境教学，指向真实的编队选择、航点确认、炮击授权、搜索、集结撤离及首领预警。手动炮击后的授权变化也有具体引导。教学不代打，不跳过战斗解锁。
- 返回按钮、Escape 与结果页遵循上一层。列表筛选、滚动和焦点随历史恢复，剧情结果回到新解锁的路线节点。模态窗口优先关闭；战斗中的 Escape 仍先取消当前操作，再打开暂停菜单。
- 新建自有舰打捞使用独立 `salvage-v4`。货舱同时受占格形状和负重约束；容量随指挥官等级、舰船吨位预算、实际部署的运输角色以及武器装载变化。已核吨位与未核舰型预算明确区分，APD 加成只对应已登记身份，原舰卡舰种不改。母港格库按指挥官等级扩大；溢出物件留在待整理区，原有货币和材料库存保留。
- 搜索用权威模拟时钟逐件揭示，支持中途保存重启、取消和受损中断。物件可以选择、旋转、重新放置、整理或弃置，重叠、越界、超重均拒绝。仓库拆包/兑换和结算继续用原账户事务，失败不给未撤出的物资。
- 远征提供三档风险、四种程序地貌与可选择的起航天气。首遗迹和前向撤离区缩短基础循环；风险改变敌压与收益类别。独立设计见 `docs/design/extraction-playability-v4.md`。命中、受损、鱼雷、搜索和入舱使用克制的图标与短反馈，危险提示优先，表现刷新不改变权威状态。
- 独立验收发现 Godot 历史战斗误用“白昼接敌·5对5”通用标题，现改为读取真实 `campaign.missionLabel`；埃斯佩兰斯角正确显示“14舰夜战”。没有改变其舰队、环境或裁决。

## 编辑与边界

Godot 工程入口是 `godot/project.godot`，按 F5 运行。新增标题、章节目录、章节路线、教学卡、远征卡、战斗反馈、货舱、搜索和装载场景均可直接打开编辑。章内文字/CG与镜头资源说明在 `docs/development/chapter-editor-workflow.md`；风险卡内容在 `godot/data/expedition-design.tres`。

第一章仍是现有完成内容；未公开章节没有伪装成可玩关卡。三档为可玩的首版平衡，后续应采集带出率、首次搜索耗时与单位体力收益再调整。旧 v1–v3 航次、资源副本和借用历史兵力保留其既有版本。未核吨位仅作新玩法载货预算，不作为历史参数。旧网页历史海图的通用标题问题仍按既有 blocker 登记，本轮 Godot 标题修复与浏览器兼容通过不构成历史内容重新认证。
