# 本轮用户原始需求与落实边界

以下九项是2026-11-14最新用户要求，覆盖旧“每MCP专属特殊载具”约定；旧已保存/历史规则仍冻结。相关原书和参考文件只读。

1. 关于战术部队，每个战术部队都要画小人和小人动作动画。
2. 不用每个战术部队都安排特殊载具，战术部队的载具分为登陆载具和作战载具。绝大部分步兵只有登陆载具，登陆载具可以有容量、速度和防御差异。普通装甲部队最笨重，但上岸伤害高；两栖装甲部队登陆载具和作战载具是同一个。伞降部队登陆载具是飞机；武装直升机空中突击登陆载具和作战载具同一个；运输直升机部队只有登陆载具。
3. 有作战载具的，作战载具可以和地面部队协同作战。
4. 新增近卫第88伞降旅：直接伞降，运输艇只用于撤离，伞降动画，落地途中很脆弱。白裤袜、短裙、披肩、贝雷帽、长靴、白毛猫娘少女外观；编制5连×10身体。新增第6海上空中突击营：1连×6身体，但有6架武装直升机协同；白紧身裤、短裙、披风、船型帽、黑发狐耳狐尾女孩。医疗技能部队外观偏护士修女。
5. 每个战术部队设计数值和技能。
6. 突出不同舰炮威力差异，战列舰炮援要有压倒性的力量感。
7. 爆炸有真实范围，可将步兵炸飞。
8. 岛屿加入沙滩、悬崖、沼泽、登陆场、河流、森林、灌木；影响不同类型单位移动与可见度。防御可以布置地雷、滩头阵地、水雷。
9. 本地家园攻防演习，可用自己的攻击部队打自己的岛，不损坏账号内设施、不需要修复。

## 实施约束

### 同轮美术追加（以最后一句为准）

三位新/重设计角色需更明确战术装备，仍保持小巧轻盈、对应本人。006最新为白裤袜、长筒马丁靴与护膝，保留黑发狐耳尾、短裙披风船型帽；088最新明确要求过膝长靴（覆盖过程中“膝下跳靴”的解释），保留白裤袜/短裙披肩贝雷帽白毛猫娘，加伞具/胸挂。052为野战护士修女装，救护工具与护士修女元素融合。新画都戴手套，立绘/小人动作保持一致。

倒地身体姿势与表情多样：仰躺/侧卧/俯卧/蜷身等真实独立画姿，配睁眼未闭、白眼、目光向上、吐舌、少量口水/白沫等变化。每身体以稳定种子选择一种并保持，不能不断切换尸姿或仅用镜像充数。画面完整衣装、非血腥；实际爆炸击退后再落地保留。

### 同轮伞兵显示与寻路追加

用户反馈088显示问号，以及队形过于整齐，要求学习红色警戒自动寻路、每身体独立碰撞体积。新v2移除客户端旧五列屏幕排队，始终投影每身体真实中心；核内给出独立物理半径、稳定散开目标、局部避让与狭口依次通行，静态建筑/地形与动态单位均参与占位，空地分层。碰撞不靠视觉挪位模拟，不因同属一个人格就能重叠穿行。全员SD必须完成本人素材绑定及实际导入，新增人格在旧目录缺失时亦不误认他人。

研究参考为[OpenRA Move](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/Activities/Move/Move.cs)的动态障碍等待/让路/重新找路流程，以及[Locomotor配置](https://docs.openra.net/en/playtest/traits/#locomotor)的移动占位分工。仅学习机制，CAS代码独立编写；不导入或改动参考项目，也不声称当前实现等同原版红警或完整多智能体最优寻路。

新增显式版本，旧cas-island-war-v1/littoral-v1..v4/历史原始响应不变。新人格编号MCP-088、MCP-006；MCP-052护士修女外观另存新版。所有女性化身体是对应同一人格，画面采用明确成年年轻女性设定与原认可两头身SD美术；不把载具当成另一人格，也不把1000–6000编制上限当作免费身体。

演习复制完整己方岛屿和所选驻防作为守方，攻击方使用玩家所选自己队伍；隔离模拟真实裁决，但账户不扣弹药/油料/体力/整备、设施HP不变、不发战利品。活跃航次不能被演习覆盖，退出回到原状态。

单一数值目录由Rust导出，Godot只读本人配置。新地形必须有原核通行/遮蔽数据、同种子重现，不靠背景贴图假装生效。新炮击范围/击退属于原创陆战，不修改历史炮表；爆炸与人物抛飞根据实际事件驱动。
