# 炮击表现、受击手感与剧情近景

2026-11-12。用户本轮明确要求炮击口径差异、受击震动、实际管数的多发炮弹和副炮，并用新截图指定剧情半身构图。本记录只涉及本轮表现改动，不是历史战役重新认证。

## 表现与边界

- 共享海图的 `projectile_renderer.gd` 按每条公开 shell 的实际 `barrels` 逐发绘制；三管是三发，多座同秒合并则画实际合计管数，不猜测未公开的炮座归属。独立炮弹有屏幕空间横向间隔、弹头、渐弱尾迹、弹道切线与地面投影，落点水圈/水柱随口径变化。
- 主炮使用较粗的暖金色弹体和较高弧线；副炮使用较细、短尾迹、低弧线的浅青弹体和较小水花。共享渲染也接入活动已有单弹观察；活动没有公开管数，不编造多管参数。敌方只画原有授权弹体，不透露其身份或口径。
- 新增显式只读 `op:presentation` / `projectile-fx-v1`。主炮以本席 `shell_id` 精确关联口径；副炮每次实际发射（包括真实未命中）登记本席起点、当时Contact坐标、口径和管数。没有额外随机数、命中投骰、弹药或伤害。副炮原本为同秒裁决，约0.34秒的飞行仅为视觉，不改变伤害时序。
- 默认原核观察/命令回包/保存内容不增加字段。Godot桥接单独请求表现API，只丰富本地复制的观察；旧核运行时不支持API时回退既有主炮。读取API不推进世界或消耗随机数。新建/加载/回退/只读复盘建立基线，不重播旧副炮效果。
- `combat_impact.gd` 根据本席真实口径区分轻、中、重和战列舰开火，受击读取真实HP减少；终击移除与剧情保护退出仍消费本席真实受击事件。只偏移海图的短暂像素，HUD、持久相机位置、投影反算、命令及模拟时钟保持稳定。密集反馈限幅并归零，设置与战斗菜单有0–100%震动滑块，0关闭镜头移动并保留局部炮口/命中表现。
- 剧情改为用户新参考的宽银幕半身近景；双人/三人统一头肩尺度、下缘渐隐、对白顶部羽化，非说话人压暗RGB而非透明。长对白扩阅读区，角色不再为了露脚而缩小。Atlas取景不改立绘原像素，换表情与眨眼保持稳定。详细窗口与全部台词验收见[剧情回执](story-portrait-safety-receipt.md)。
