# Godot 港口与编队界面复原验收

2026-11-11。用户明确要求以此前母港、编队、战役截图为基础调整，保留海军蓝、旧金、宋体、大角色与不同区域的权重。本次不以统一表格或等宽卡片替代原作构图。

## 实现范围

`godot/scripts/port_presentation.gd` 独立负责四个静态入口：`render_harbor(app)`、`render_roster(app)`、`render_formation(app)`、`render_campaign(app)`。`main.gd` 由主客户端委托调用。模块只读取经济/目录数据并调用既有交易、编队、角色详情、出航与原核接口，不直接改钱包、角色状态或战果。

- 母港恢复左侧欢迎、中央弗莱彻大立绘、右侧不同权重的打捞/战役/借用舰入口，底部沿用公共导航。已拥有数、三舰位、活动航次均为真实状态，不添加虚构教程进度或领奖红点。
- 编队左侧为大角色档案；中央三舰位与两列可滚动舰卡，金框与文字共同标注已编入；右侧固定显示冻结前真实编队分、威胁、货舱、搜索时间、计划弹药和库存，保留强出航按钮与借用恢复入口。
- 舰库为大角色档案和三列可滚动舰卡；点击切换档案，查看与整备继续打开已有真实服务对话框。
- 战役航图读取现有原核11条历史目录，保留资料核验中/本地试玩的差异。旧Natural Earth投影海岸线与标注只读复制到Godot数据，支持总览、铁底湾、中/北所罗门切换，打开真实简报。已有运行时的目录项按自身 `CAMP-ALLIES-*` 编号调用原核，未就绪项不启动。个人舰艇损伤与弹药不变；结算按真实模式回执发放登记的首通奖励。

颜色沿用港口藏蓝 `#0b2636`、港湾蓝 `#173e52`、纸白 `#f0ead8`、旧金 `#e5c88c`。宋体仅用于舰名、欢迎语与作战标题；状态和操作文字保留清晰无衬线。容器管理可滚卡片，其余布局沿主客户端1600×900参照锚点，不改变坐标、阵位或舰卡。
