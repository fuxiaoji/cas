# Godot 单人经济与音频验收记录

日期：2026-11-11。工作范围为 `godot/scripts/economy.gd`、`godot/scripts/audio_director.gd`、`godot/data/economy.json`、`godot/data/audio.json`、音频副本及独立验收。原始 PDF、用户文档、微信归档、MP4 与参考项目未改写。

## 已实现的经济行为

账户服务提供征募、仓库、买弹、计划装载、维修、训练、装配、编队、出航、航次快照和结算。主要资源为硬币（内部 `credits`）和征募券；旧 `medals/materials` 字段为兼容保留，默认不生成，不再出售材料包。一个舰娘身份只保留一个可出航实例，重复征募按配置转为硬币。概率从配置读取，九次普通后下一次保证稀有或以上；十连一次提交扣券、结果、补偿和历史记录。

编队最多三舰。补弹修改装载计划，确认出航时一次从仓库转入部署弹药；成功撤离只返还能航行返港舰的剩余弹药，失败与保护舰剩余部署弹药损失。角色与出航前配装保留，失能舰保留原核损伤与保护标记回港待修；耐久仍为正数但已受保护/无法航行的舰，同样不返还余弹且必须维修后才可再次出航。所有港口交易、征募、装配与编队变更在活动航次期间由服务层拒绝。普通货物成功撤出只入库，必须主动出售才获得硬币；一键出售只处理废料与合金。

装备和指挥组成功撤出后建立独立实例 ID，位置只能在仓库或单舰槽位；卸装与再次装配不复制实例。配装与训练只作用于独立架空打捞模式：构筑分为原核基础点数加每级成长20、装备75、指挥组50；每件装备增加2格公共货舱；搜索秒数为 `ceil(max(4,12-0.25×成长级差之和-指挥组数))`。Rust 打捞模式与经济预览使用相同公式，历史舰卡、炮表与战役数值不变。

基础打捞使用独立借用舰与弹药，占用唯一活动航次，不要求自有舰适航或余额恰好为零。借用资产不进入个人库存、不修改自有舰状态，成功最多带回四份废料，必须实际完成海上航行与撤离。该任务没有按钮直接领币的路径。

存档先写临时文件并验证，再轮换备份并提交；提交失败回滚内存。可选交易 `request_id` 支持买卖、维修、成长、征募、装配和装载计划的幂等重放，相同编号改参数会拒绝。结算按航次 ID 幂等。`save_sortie` 优先保存原核的 `serialized` 字符串，避免 Godot JSON 浮点解析损失原核 64 位随机状态；征募随机状态也存为十进制文本。损坏的主档可读取备份，主档及备份都损坏时保留原文件并明确报错。

战果回执同时保存每舰出航与返港耐久、损伤、实际剩余弹药、实际耗弹、返库与遗失弹药、保护/可航行标记及维修报价。汇总含个人部署和返库数量，借用弹药单列；失败时保留未撤出货物清单但不发货。`latest_receipt()` 通过原子保存的 `last_receipt_id` 重新打开末次战果；旧版本存档按航次编号内的递增序号回溯，不受 JSON 键名排序影响。

## 音频与来源

八首用户指定 `D:/downloads/*.mp4` 已全部提取 Ogg Vorbis 音频，44100 Hz 双声道，统一到 -19 LUFS、-1.5 dBTP，原 MP4 保持只读。八个编号分别接到母港、编队、征募、海上、战斗、商店、胜利与失败场景；场景分配为可调整的开发默认，不推断原曲曲名。两段长音源约为1782秒与1831秒，其余为78至138秒，保留完整音轨。

从已有微信归档台账选择56段已核对的阵营语音并转码，接发现目标、鱼雷来袭、命中、战损、友军误伤、敌舰沉没与开战等本席事件。所有输入为玩家观察，不查询隐藏真态。事件 ID 去重，同一 cue 12秒节流，队列最多三条；鱼雷方位只从本席可见事件位置与本舰航向推导，无法判断时不猜方向。语音播放时音乐降至26%，结束后恢复；音乐、语音、界面音量与静音可持久化，暂停同步暂停音乐和播报。

界面点按、确认、选择和错误音使用 [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds) 的 [CC0](https://creativecommons.org/publicdomain/zero/1.0/) 文件，授权文本在 `godot/assets/audio/ui/Kenney-LICENSE.txt`。用户提供的音乐与第三方战场录音按既有台账仅用于本地私人试玩，公开发行许可未登记；公开导出需排除 `local_music` 与 `local_voice`，或补齐许可。所有源路径、转换后大小与 SHA-256 均登记于 `godot/data/audio.json`。

## 实际验证

- `Godot_v4.7.2-stable_win64_console.exe --headless --path godot --script tests/economy_audio_test.gd`：56项通过，0失败，退出无音频资源泄漏。包含详细战果持久化、失败货物遗失不发货、借用弹药隔离和旧存档末次战果恢复。
- 覆盖概率保底、十连扣券一次、相同请求重放与参数冲突、交易锁、三舰装载与返弹、正耐久保护舰的返弹与再出航门控、原核64位快照文本逐字恢复、唯一配装归属、实际打捞成长、手动卖货及不能二次出售、少量正余额且全舰失能时的借用恢复、失败提交不改变账户。
- 音频验证覆盖8首音乐/56段语音/4个CC0界面音，共68个资产，逐个 FFprobe 成功读取且 SHA-256 与台账一致。68个转码资产合计59,174,122字节。
- 音频运行验证实际载入母港音乐与发现目标录音，检查事件去重、未知方向不捏造警告、暂停恢复以及界面确认音。验收使用独立测试存档，未写玩家正式档案。
- `tests/audio_settings_ui_test.gd` 的6项检查通过：实例化真实主场景并进入设置页，操作三个 HSlider 的实际 `value_changed` 回调，核对音量文件，再重建音频管理器确认恢复。测试结束恢复原音量配置。
- 主场景 `--headless --quit-after 2 --verbose` 的快速退出通过，正在播放的母港 BGM 不再残留 Vorbis 对象。`shutdown()` 和 `_exit_tree()` 幂等停止所有播放器、清空音轨与队列、终止淡入淡出，关闭时留100毫秒给混音线程释放缓存。
- 凭证为 `artifacts/godot-economy-audio.json`、`artifacts/godot-audio-assets.json`。测试脚本仅验证账户与音频模块；真实窗口全流程、原核完整存档重演与历史战役回归由主集成验收另行提供。

## 边界

本次为单机本地资产服务，不构成在线可信经济。所有价格、掉落价值、构筑分增量与威胁阈值都是配置中的 Demo 参数，未宣称已做长期经济平衡。打捞补给采用模式专用的百分比补给抽象，尚未按舰种拆成独立炮弹 SKU；装配只使用已实现的货舱/搜索效果，不虚构命中率加成。未增设商业支付、付费货币或联机经济。

启动器验收：`scripts/start-godot.ps1 -SkipBuild -SkipImport -RunTests -NoLaunch` 实际通过。`godot/README.md` 明确Windows本机进程桥接与Android未交付；导出配置排除私人音轨、语音、角色和背景资产，本次未生成公开或私人独立安装包。
