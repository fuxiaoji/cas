# 自由舰队、程序海域与成长经济交付

日期：2026-11-11。对应用户最新逐项开发请求。本机 Godot Windows 单人版本，继续使用 Rust 权威战斗进程。

## 已接入的内容

| 用户需求 | 实际入口和行为 |
| --- | --- |
| 程序海域 | 水波、岸浪、云/云影、岩岸、高地和植被均为程序生成；相同种子可复现，不同种子改变海域。战场无云岛 PNG 依赖。天气按原核模拟时钟变化。 |
| 自由编队与多编队 | 编队页可保存不限数量舰队，用管理成员增删任意数量自有舰；左侧勾选多个出航队。同一身份一航次只出现一次。实际原核每组生成独立纵队，按规模扩展自定义海域。 |
| 母港导航 | 活动在顶栏；邮件独立右上；仓库在底栏。仓库有物资和舰装/水手实例页。 |
| 军需迁移 | 舰娘直购、补给、礼包、元词兑换和战术五类；迁移旧礼包及指定舰娘经济商品，真实扣账发货，已拥有或限购状态有反馈。 |
| 打捞可发现性 | 左下常驻残骸搜索，只列本席已发现残骸；点选定位，靠近减速后打捞，已打捞状态同步禁用。 |
| 原射程 | 选舰默认显示炮击、鱼雷、目视与实际雷达范围；常驻射程按钮和视图设置同步。实际雷达按原设备开启/失能状态工作。 |
| 资源 | 元词兑换常驻/UP券或物资；银币用于日常；体力120上限、每8分钟恢复1点。剧情、战役和副本奖励统一事务与防重。 |
| 等级与熟练度 | 0–30级的船体/航速/火力差约5%；0–1000熟练度让基础炮击命中项相对提升最多10%，不是命中概率加10个百分点。参战积累，付费训练不增加熟练度；250/500/750/1000各有5元词和50银币一次性小奖。 |
| 舰装和水手 | 舰装提升最多约1%；舵手、火炮、损管、指挥四槽有主副词条，四槽总预算约1%。实例和词条在获得时固定，装卸不复制物件。 |
| 秘书舰 | 更换已拥有舰娘、缩放0.6–1.5倍，实时预览与保存，重启保持。 |
| PvE与天梯 | 资源海域定向刷取；天梯包含3000对4500等精确预算，击败全部敌舰才胜，每周前3次胜利给元词，此后可重复打。打捞普通任务40元词/650银币/12材料，另有实际带回物资；定向副本首箱1件，普通打捞首箱5件。空船即撤不发任务奖励。 |
| 战役与详情 | 202个已登记单舰身份有原始CAS舰表、成长、舰装和水手页；自有舰战役演练为故事难度独立入口，消费成长但不计历史星。历史借用编制、标准/挑战及原始资料保留。 |
| 节奏 | 新打捞首处残骸更近，基础搜索6秒，默认4×可改速率；守卫/巡逻由旧3–6艘增加到与威胁及自有舰数量相适应的密度。没有偷改原始舰卡航速。 |

新的成长、天气和打捞均冻结版本；旧打捞存档仍沿用原始 v1 行为。多编队不能用克隆身份重复出航，成长不回写CAS舰表。同步移动在新自有舰打捞中使用独立架空规则：基础35%，指挥词条小幅提高，失败保留原航线并冷却20模拟秒；此概率不冒称史实。跟随移动和历史同步保持各自既有行为。

新版西侧撤离区按初始舰队真实足迹生成矩形并缓冲500米，所有可航行舰仍须实际进入区域并完成12秒撤离。东侧、南侧保留1000米圆区。这样大纵队不必为了旧圆圈尺寸被强制拆队，也不会把一个巨圆扩到东侧敌战区；公开bounds同时供原核校验、海面和小地图绘制。

## 原创物件与字体

新增内置 Noto Sans SC，保留 SIL OFL 许可、上游元数据和哈希：`godot/assets/fonts/`。所有UI使用同套黑体及明确字重，小圆角和轻量控件代替混合宋体、大标题与胶囊。

新增五张原创透明物件插画：`ammo-crate-v1.png` 和 `crew-{helmsman,gunnery,damage_control,command}-v1.png`，均在 `godot/assets/items/`，同名JSON记录来源、提示词和哈希。不用于战场地形；小人制作仍暂停。

## 使用与边界

双击根目录 `CAS-Godot.cmd`；编辑器导入 `godot/project.godot`。开发工程优先使用最新 `target/release/cas-sim.exe`，导出环境无此文件时再用打包的bin核心。首次进入的新打捞才使用v2，旧在途航次不会静默改天气或玩法。

本轮是Windows单机功能。支付与PvP来源界面明确未开放，没有实际充值/线上账户；Android、多人和小人动画没有冒充完成。程序水云地形采用2.5D表现，不宣称完整流体、侵蚀或三维地理模拟；风只影响表现，原核海况与历史环境仍按登记值。自有舰战役演练为满状态练习，不扣港口舰况弹药，历史星数独立。
