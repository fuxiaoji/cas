“未定位”和“无对应”的范围是当前本地 CAS 剧本集；如要保留原关位，可给这五关单独规划适合 CAS 规则的原创移植，或明确选择一个替代想定。不要用近似的日期、舰名或同名战区自动配对。后续移植使用旧关卡 ID 对照奖励和剧情；战斗内核使用自己的 CAS 想定 ID 和冻结内容版本。

圣乔治角适合先做夜战历史关。源页是开阔水面、共十艘驱逐舰、不需海岸图。美方两列 000°/23 节，日方屏护、运输两列 280°/25 节；保留三个相对阵位约束。日方决定胜利要求全队逃脱且每舰损伤严格低于 25%，美方决定胜利要求击沉三艘且本方各舰损伤至多 25%；恰好 25% 对两边是不同结果。队内距离、13,000 码的屏护参考舰、逃脱边界、裁决终点和并发胜利政策尚未定；原页所列行动运送／撤离人数也不能当作逐舰初载。五艘弗莱彻以及日方舰艇的[雷达候选与版本冲突](../rules/radar-source.md)已登记，夕云级、改装吹雪级、睦月级另需完整的时期配置。没有采用旧作的雷达限制或离图特例。

库拉湾原页已核对两边任务、编制和初始纵队，正文与图上的美军最后两舰顺序相反，留待裁决。霍腊纽原页已有小艇、护送、抵达目标和双方胜利阈值；近似相对几何无法精确闭合，未替原书虚构阵位。这三个独立数据文件均为 `source_transcribed`，引擎和战役页面不得把它们当成已开放关卡。

韦拉拉韦拉录入北方和南方美军、日军两支护航与两支运输编队、侦察机、初始已知目标及双方撤离／拦截条件。Ralph Talbot 在本页印为 Gridley，而书中科隆班加拉页明确记为 Bagley；原写法与待裁决项分别保存。该文件位于 `next/`，在 v2 试玩包冻结后完成，不影响已验包的战役档案。
