**设备边界。** J/K 艉炮按《Home Fleet》原装正后方 20° 盲区保守实现（在 CAS 通用 A 扇区中扣除相对舰艏 170°–190°）；该页只说战争初期修正，逐舰日期未证实。A-36 右栏舰卡注记规定 J/K 共用轮机舱，工程临界引起的减速加倍。仅 J/K 的时期舰卡写入 `engineering_speed_multiplier: 2`：普通临界扣两个航速档，锅炉爆炸扣四档，爆炸概率与直接 DP 不变。该页只给 N 级 Type 291，J/K 的 Type 285 与 286M 记于 1941；本局不开这些设备。德国合表列 FuMO 21 及 1944 年更换记录，没有本交战可用的逐舰实装确认，本局不启用德方雷达。舰体长度、历史初装雷数、实际弹种与 11 月引信异常率未补值。德国两种舰卡都有备雷，本变体暂不实现再装。八舰开局各用 Annex A 在管满配（英 5+5、德 4+4）及 HE 是变体设定，G7a 也没有套用另一本书针对纳尔维克 1940 年 4 月的特例。

**任务与地图。** 旧中文想定书 PDF 3（印刷 4）原页明载四回合、能见度四格。德舰依次在 O14、P13、R12，航向 4；英舰 R16、S16、T15、U15、V14，航向 5；八舰均以旧速度 5 开局。用原版规则 §1.2（PDF 3，印刷 3）的 600 码及 180 秒换算：航向 240°／300°、速度 29.62419 节、时限 720 秒。两旗舰在原书分别为 Z20、Javelin；身份只说明旧开局，不赋予未核的火控能力。开局不重排舰位，不强行等距（德舰一段一格、一段两格），也不把旧后记中的标枪两枚中雷变成脚本事件。旧 2-2-2 对应 11.85 节，按结束时受损后的最大可用航速裁决，主动减油门不算被打瘫。同盟打瘫或击沉一艘德舰为战术、两艘以上为战略胜利；轴心全部保全为战术胜利，再击沉至少两艘英舰为小战略胜利。

**RTS 环境与时序选取。** 四格原为 2,400 码；不硬截断 CAS 目视。变体选夜间基础能见度 5%、海况 2、无降水。CAS 五版 §5.4.1、SS1／SS2 中，快速 C 级目标对 C 级观察者从 5% 升至 10%，基础 3,000 码；未受其他修正的常见检定为 2,500 码，具体为 1,500–3,000 码。这是接近原情境的换算，海况、降水以及百分比没有来自旧想定。按 CAS 五版主规则 PDF 13–14（2-1–2-2）、22–24（3-1–3-3）给基本炮位和 C 级运动；逐秒射击沿用[独立 RTS 炮战方案](../rules/realtime-gunnery-sources.md)。英炮装填 8 模拟秒、横转每秒 10°，德炮装填 9 模拟秒、横转每秒 9°，是 RTS 调度参数；五版只以整个火力窗合并炮击裁决，不提供这些逐炮机械值。
