# 未明的海

序章为虚构对局。玩家接管原剧情中的弗莱彻、帕金斯、莫里、德雷顿、拉姆森。编队使用 [具名记录](../../data/campaign/period/prologue-us-destroyers.json) 中各舰经复核的 Form 10 和 CAS 舰炮、鱼雷行。具名记录时期跨 1941 至 1942，序章沿用各有出处的时期配置，没有指定为历史上同一日的舰队。任务改编使用真实海图和权威引擎事件推进。

开场 15 艘舰分五队。北卡罗来纳、华盛顿以《American Fleets》PDF 8（A-5）和 109（C-3）录入，913 DP，16 英寸炮用 Mk6 穿甲行。大和、武藏以《The Emperor’s Fleet》PDF 7（A-4）和 98（C-2）录入，1365 DP，九四式 46 厘米炮用穿甲行。原序章的信浓在 CAS 舰表是航母改装案，本次战列线用同级真实战列舰大和。战列舰二级火炮、炮控雷达、鱼雷防护系统与舰载机未在此想定开放。两方掩护驱逐队在原舰卡范围内发射浅航直航雷。

脚本用合法航路和射击命令让双方战列舰互射，预录和交接使用相同的种子、出场位置与命令。开场留在同盟视角。玩家仅有第五驱逐小队的指挥权限，后续过场叠在当前海图。现用弗莱彻全身图与铁底湾 0.6.11 舰库成品的 SHA-256 一致。配乐为 [CAS 原创配乐](../../client/src/audio/score/ledger.json)，本地试玩语音仍由旧电台素材和明确的本地构建选项控制。
