# CAS 正史三章：叙事、演出与教学设计

这套内容按用户新的第五驱逐舰小队主线重新创作，使用 `story-canon-v2` 独立数据和进度。旧三章、历史战役及其裁决不改。完整正文见本目录三份“剧本”文件；对应游戏数据在 `godot/data/story-canon-v2/`，不是只有剧情提纲。

## 三章各自要解决的问题

| 章节 | 人物的具体愿望 | 阻碍与代价 | 本章结果 | 不在本章揭开的事 |
| --- | --- | --- | --- | --- |
| 第一章《借来的灯，自己的岸》 | 神通要把四十五名受庇护人类带回港；小队想要不再借泊位的家 | 信标引敌、身份审查、协议征收、借兵条件、岛屿风暴 | 主角被接纳为领袖；取得岛屿；同一份灯鲨协议解封；密苏里承担有限守家责任 | 主角来历、信浓为何特别担保、憎恶目标异常原因 |
| 第二章《不许熄灭的码头》 | 修好净水设施，接回被“保护”条款困住的人 | 物资与舱位有限，白塔把救助变成接管；留下证据与救人需要取舍 | 南汀渡口保住接应航线，取回有限记录，给被救者保留自己的名字和决定 | 白塔最终操纵者，接口与旧信标是否真指向同一个人 |
| 第三章《把名字留在海上》 | 到旧档案区查证，并让仍能回应的舰娘自己决定去留 | 人格被当成可替换配置；救援窗口、回收能力和证据都不完整 | 拒绝覆盖人格的高权限；救出能救的人，保全足以追问的原始记录 | 主角身份全貌、拜AI教组织全貌、全部受害者结局 |

人物不会轮流站出来讲解世界观。神通先算回程、油料和饭，再谈原则；弗莱彻愿意先替同伴高兴，也会直接生气；帕金斯盯编号、合同和原件；阿禾通过滤芯、空桶和妹妹发问；灯鲨安静而有边界，轻声不等于无条件同意；密苏里把照顾藏在油料账和让出的门道里。

## 新号开场与连续性

未来实际新建档案写入 `progression.first_voyage_canon` 显式标记，再直接进入第一章 `v2c1-drifting`。第一人称的冷水、门板和抓空的救生索先建立感受，来源不明的声音反复说“不要打开星门”，接上神通救起和信标突围。幻听与稍后自报身份的状态机 AI 分开登记、分开名牌。短暂回声文字尊重减少动态效果设置，不以闪屏或强制慢字表现失忆。

退出再开时保留原句位置，不回到第一句。主线完成后回正常标题；已有海陆航次优先恢复该航次。旧号缺少这个标记时，不按资源多少、出击次数为零或旧剧情进度判断为“新号”，不把旧版第一章或现有活动清掉。以后新剧情入口仍使用独立 canon-v2 保存，旧版可从旧版入口继续。

第一章在影像室听见港口口述“引爆太阳”和“水淹三军”；第二章从相反版本的洪水回忆与“第二次日出”残片识别叙述差异；第三章取得“星门／中继隔离”索引，同时保留“保持封闭”和“保留撤离窗口”两种缺时间的要求。三段都由眼前的人和取得的物件推动，不用百科页宣布终局因果，也不把个人幻听算作实际收到的命令。

## 第一章的递进教学

| 顺序 | 先通过人物形成动机 | 玩家接着做什么 | 完成证据 |
| --- | --- | --- | --- |
| 突围 | 人船不能再挤在被堵的出口 | 选舰娘卡、画航线并确认、看预警回避；三编队分路接驳 | 真实突破战胜利战报；神通、5DD与避难船全体进入同一撤离区 |
| 母港导览 | 大家终于有地方吃饭与修船 | 逐个认识编队、训练战役、竞技、养成、军需和仓库 | 实际访问记录；不要求消费 |
| 战网 | 联盟训练系统允许试错 | 可选排位及3v3人机练习，也可稍后 | 实际演练战报或明确延期，不假称联网排位 |
| 第一次搜打撤 | 找滤芯，也去看看礼物坐标 | 搜索标记遗迹、收回档案、整理有限货舱、评估撤离 | 真实搜索目标与撤离成功后推进协议保管 |
| 制海 | 地上有人要等航路安全 | 先指挥海军清理海域，再谈投送 | 已登记制海训练真实胜利 |
| 登陆 | 礁刃需要船；云隼快却载量有限 | 拖动军牌、合法搭载、近岸投送、切换海陆视图 | 已登记登陆训练真实胜利 |
| 协同 | 舰炮不是无条件从天空落下 | 摆好支援舰、确认射程弹药、拖炮援卡、联动行动连 | 已登记协同训练真实胜利 |
| 建设与驻防 | 屋子要能住，也要有人守 | 检查或建设设施，安排舰队和战术驻防 | 真实建筑、至少一位驻防舰娘，礁刃与灯鲨已保存为战术驻防 |
| 风暴防御 | 通讯不通，自己先把人和路线守住 | 完成本轮岛屿防御 | 真实终局；胜败都记账，分别接不同后续对白 |

现有满级测试号已经有的设施可以检查确认，不制造重复消费。查看成长不要求为了过教程升级；PVP不是强制卡点。离开剧情页也不会抹掉未完成的操作任务。

## 分支与回响

| 选择节点 | 选项与即时反馈 | 合流及后续回响 |
| --- | --- | --- |
| `v2c1-protocol-choice` | `keep`：先替还没醒来的灯鲨留位置；`exchange`：先写明借兵换岛与返还条件 | 均遇到联盟征收。各有独立对话；第二章、第三章按已保存立场播放不同回应，不假称玩家能凭一次选项阻止征收 |
| `v2c1-defense` | 实际守住首轮，或实际防线退却 | 胜利线肯定已完成的守备；失败线承认退却、优先救人。共同遇到四重巡与重巡级怪物的新一波增援，密苏里解决的是新威胁，不抹掉之前的战果 |
| `v2c2-choice` | `people`：先送人；`record`：保全可验证部分，放弃“全部取回” | 各有独立取舍对白，随后共同进入协同任务；不捏造选择产生了不同原核战利品 |
| `v2c3-listen-choice` | `ask_name`：明确回应；`keep_channel`：保持频道与安静 | 同伴分别谈询问与等候的边界，之后共同护航 |
| `v2c3-evidence-choice` | `people_first`：优先撤人；`window_only`：安全撤离后才尝试多转存 | 各有独立行动安排，均不把没带走的资料写成已掌握 |
| `v2c3-permission-choice` | `refuse`：拒绝覆盖人格；`ask`：只给对方自行回应的窗口 | 都不替他人签署人格覆盖。分别呈现明确拒绝与询问等待两种态度，随后合流；不通过选项获得全海域控制能力 |

分支不是相同句子换个按钮，也不通过虚构资源奖励夸大影响。它们改变同伴听到的话、玩家留下的立场和后续回应。实际敌舰、战利品和战斗结果仍由真实模式结算。

## 灯鲨协议：一份对象，四次保管变化

`未发现 → 实际搜索胜利后回收 → 读完征收段转联盟保管 → 读完信浓归还段返还 → 固定同步灯鲨`

对应事件为 `v2c1-salvage`、`v2c1-confiscation`、`v2c1-return-protocol`、`v2c1-fixed-recruit`。编号一直是 **MCP-011／灯鲨／第11夜航突击队**；她是一个女性人格，完整编制上限1800。一次任务实际投送的行动连与全编制上限分开。

首个家园训练本来就会授予 **MCP-034／礁刃**，因此剧本明说联盟留下基础驻防授权；空突001与装甲022仍为借用，不能冒称全部归还后玩家却莫名多出礁刃。固定同步011不扣随机招募资源，测试号已拥有她也不重复发人格或副产币。第二三章搜索不再产生或重置这份协议。

## 伏笔与善意的限度

| 埋设 | 当下可见的事实 | 本阶段保持的边界 |
| --- | --- | --- |
| 憎恶绕开漂浮位置 | 一次可见目标异常，AI建议保留记录 | 不宣告所有怪物永久不攻击主角，不允许拿异常当护身符 |
| 信浓承担担保 | 须签观察责任、接受后续复核 | 法庭没有被官威取消；主角仍不知黑影身份，离场后只向玩家揭示 |
| 礼物坐标与协议 | 到达坐标并完成搜索才接到发现演出 | 不用对白替代搜索胜利，不暗示信浓能远控所有遗迹 |
| 乌龟山 | 建设时就有奇怪礁体、当地称呼和空间伏笔 | 觉醒前不在舰娘名签中提前显示密苏里；救援后她仍有维护、油料与责任边界 |
| 年长守航舰娘 | 让灯、给合手的干手套、保留小姑娘的扳手 | 没有加入远征、没有确认主角前世；善意不是集体迷恋或无条件服从 |
| 老接口的回应 | 资料里出现似曾相识的格式与欢迎信息 | 兼容记录不等于身份证据；AI不断区分观察与猜测 |
| 白塔的“保护” | 供水确实救过人，手续却没有离开选项 | 不责备受助者当时的妥协；问题落在利用依赖夺走决定的人 |

## 演出与美术锚点

剧情页以人物和背景为主，不在常驻画面摆全局钱包或长表。普通对话稳定大半身同框，不逐句重建人物；CG段落由完整画面承担视觉，不再叠一排人物遮住构图。旁白负责手和物件的动作，人物台词负责当下要说的话。已有弗莱彻、德雷顿表情与眨眼资源可用；其他角色没有专属表情时保持本人立绘，不拿别的角色代替。

## 真实玩法与当前边界

新发动的海上剧情行动明确请求 `chapter_profile: canon-missions-v3`。旧航次仍按已有快照继续，不从新版入口重新创建。新请求使用当前 `salvage-v4` 搜索、逐件发现、真实货舱放置和全舰撤离链；指南从 `view.chapter.tutorialSteps` 第一个尚未完成的动作显示下一步，定位、关提示或打开仓库均不能把原核动作标成完成。

| 数据节点 | 明确登记的真实任务 |
| --- | --- |
| 第一章突围／搜打撤 | `c1-breakout`／`c1-salvage`，后者要求带回旧信标档案并撤离 |
| 第二章搜索／中继 | `c2-relay`，均要求档案与撤离；新增净水材料和广播细节在演出层 |
| 第二章护航／守卫 | `c2-convoy`／`c2-warden` |
| 第三章档案／穿越／Boss | `c3-core`／`c3-crossing`／`c3-breaker` |
| 夺岛与后续两栖段落 | 已登记的v4制海、登陆、协同训练 |
| 风暴本轮防御 | 真实家园防御终局；胜败各自记录 |

新海上任务把神通、五艘驱逐舰和需要护送的人类避难船分别登记为真实编队；新关卡的地形与目标以对应原核验收为准。本章字幕里的四艘重巡、新一波重巡级怪物和密苏里几炮重创仍属于CG与叙事范围，不能从这轮导引推定已经加入防守兵力。人格恢复模拟与每个对白选择对应的全新敌人阵容仍是制作边界。实现说明放在作者文件和元数据，玩家操作页只展示眼前要做的事。

新海上指南按 `move → evade/search → cargo_place → rally → extract` 或首领火力阶段推进。教程第一次搜索由玩家实际操作，不在对白里许诺默认托管；后续常规搜打撤、海陆协同可自行选择当前托管功能。驻防步骤同时核对舰队与034／011，母港参观用“下一站”直接进入下一处，避免反复退回故事页。首领被击败后仍须按新海上任务的实际归航目标集结撤离，不把击杀即时当成返港。

实际原核命令 `route` 按步骤身份区分起航、护送与集结；`search_salvage`、`cargo_place`、`gun`、`salvage_extract` 分别映射到当前搜索、装格、火力和撤离指引。危险停航、受损航速和队列未对齐优先显示可执行的恢复路径：暂停并选择停航队；按真实可用航速重新预览；先预览、再确认重整纵队；重整不合法或共同航速不足4节时查看受损／离列舰并手动脱队，分别带回所有可航行舰。指引不瞬移重排，不改真实航迹物理。雷击明确是拖动、短停瞄准和松手确认，已知友舰可能进入雷迹时优先提示取消或换射向。
