# 海陆空托管 v1（原创 v4 显式开关）

适用范围仅为 `cas-littoral-v4`，不是历史战役规则。原 PDF、历史数据、原 v1–v4 无开关存档和配置保持冻结。

## 控制与重演

- 开启：`{"op":"littoral_autonomy","version":"combined-autonomy-v1","enabled":true}`。
- 接管：同命令 `enabled:false`；任何**成功**的手动战术指令也立即停止后续自动决策，已发航线仍由真实引擎执行。被拒绝的指令不改变控制权。
- 安全撤收：同命令增加 `posture:"withdraw"`。界面的一键托管默认执行任务，玩家仍可直接拖动接管。
- 只有显式开关后的观察增加 `littoral.autonomy`；未开启的旧观察、配置和保存结构不新增字段。
- 保存使用原有命令日志记录开关与人工指令。托管在每个已完成的两秒边界依据本席观察确定性重建；最近 48 条决策包含实际命令、理由、是否被真实校验接受及错误。自动终局在保存帧内完成，重演该帧可直接得到相同结果。

## 本轮原创策略参数

| 项目 | 采用值与边界 |
| --- | --- |
| 决策间隔 | 2 秒；不在每次画面刷新重建路径 |
| 舰队危险阈值 | 存活本方舰艇总耐久不足 25% 时请求撤收 |
| 连队危险阈值 | 进攻/搜索中本连耐久不足 32% 或真实弹药耗尽且无补给储备时独立撤收；防卫连优先保卫 HQ |
| 总体撤收 | 主目标与可安全完成的搜索结束、登陆兵力全部已回收/损失、无存活兵力，或开启后 1,350 秒仍未完成时撤收 |
| 打捞分工 | 每个未搜索遗迹只由一个连认领，真实搜索完成后释放目标，不因动画或命令接受就增加战果 |
| 岸援 | 同舰只保留一条真实待发炮援，余弹保留 8%，友军实体距目标 450 米内不新排队；实际射界、炮座、弹药与海战共用 |
| 航空 | 单舰串行调度甲板。战斗机优先公开敌机，轰炸机/支援直升机优先本方地面部队附近威胁，鱼雷机只攻击公开敌舰；沿用有限飞机、武器、实际飞行及返航整备 |
| 撤收 | 存活连走回本人真实滩头；载舰驶近并停车等待，兼容类别/剩余舱位仍由原核心选择；飞机必须真实返舰，随后全部存活舰进入公开返航圈 |

托管不是自动胜利。兵力伤重、弹药耗尽或主目标未达成时，完成实际撤收后按原规则失败结算。兼容载舰全部损失且岸上仍有幸存连时，显示明确的撤收阻塞；不能把她们传送回港、变更载舰资格或发放胜利奖励，玩家可接管，原行动时限仍有效。

## 验收

Rust 专项覆盖：无开关旧观察不变；成功/失败手动指令的控制权；10 连真实投送、搜索 3 座遗迹和全员实际回收；零舰炮弹药的航母制海课；受损/缺弹撤收；载舰损失与不兼容回收；提前撤离的失败结算；突袭/防卫/搜索三种模式真实结局；中途与终局精确保存重演。

界面测试使用独立账号和指定本地核心，验收开关点击、换主地图后按钮仍可用、手动接管和保存恢复，不触及正式账号。
