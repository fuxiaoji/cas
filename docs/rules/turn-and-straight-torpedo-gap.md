# 水面转向与直航鱼雷差额

核对 `Command_at_Sea_5th_edition.pdf` 的英文原页，页码从 1 起算。以下按已发行的 v7 运行行为记录，供下一版裁决和旧档兼容检查。

| 原页 | 现行差额与验证边界 |
| --- | --- |
| §3.1.4，PDF 22–24（3-1–3-3） | 每个最多 45° 的转向先沿原航向走足进距，逐段转向。B／C 战舰标准舵 300 码，分别损速 2／1 节。满舵 200 码，分别损速 3／2 节。满舵 D100≤5 卡舵后保持同向满舵运动直到修复。每回合不超过 10° 的微调可忽略进距。一个战术回合只有前四次计转向损速，达到 45° 时全回合加速减半。弗莱彻的单舵按舰卡注记使用 A 级转向，仍按 C 级加减速。 |
| `movement.rs` 的航线预览和执行 | 预览把转角拆段数乘以进距，但航迹仍在一个点完成整个转角。运动仅看领舰是否转向来扣全队航速，没有逐舰和逐窗记账。4° 航线阈值、5° 损速阈值与 80 米最短航段是当前实现口径。卡舵时停止编队，没有同向强制运动。改动需同时更新预览、实时轨迹与旧版本分支。原页算例中 A 级舰 5 节、拟转 90°，本窗走 400 码转 45° 后只再走 100 码。下一窗沿新航向再走 300 码才可完成第二次 45°。领舰、后舰与同步各自转弯的预览应能显示这一差别。 |
| §6.3、§6.3.1，PDF 66（6-10） | 需有已探测目标或盲态火控解算。直航雷发射后不改向，鱼雷可设在所属雷架扇区内偏转。浅航可命中 A–E，浅雷遇 A/B 使用侧带防护。深航可避开 A/B 侧带，从 C/D 船底通过，可攻潜望镜深度的潜艇。F/G 均不是鱼雷目标。发射回合只能在开始依普通限制转一次，之后直航且不能规避。每座独立齐射，由玩家选择该座发数。 |
| `combat.rs` 的命令与在途雷 | 当前用已核的浅航、最快速度档，按一次一个雷架的可用管数自动发射，场景另有禁雷。待发过程中仍可换航路，没有发射回合的转向与规避约束。对实时新增 F/G 的首道门，应使这两级既不可作为合法雷击目标，也不能拦截或消耗射向别舰的雷。预览只能据本席已识别的尺寸说明原因。在途命中使用扫掠横过线判断，应为靠近危险半径但未越过横线的切入、航程末端擦边和同秒多舰先后保留可重演算例。 |
| §6.3.2，PDF 66–67、69–76（6-10–6-11、6-13–6-20） | 默认轨迹两侧各 500 码，按目标尺寸和来向找表。图和尺寸表在 PDF 69（6-13），正文指向 6-15 是印页误指。A 的宽／斜／窄向用 I／II／IV，B 用 II／III／V，C–E 用 III／IV／VI。实际航程选最近行，等距选较远行，静止靶上移两行。首个目标全失时下个仍按完整齐射。首次中雷后，余雷分别以单枚判。引擎已有后四项及 II–VI，A 舰还需录入 I 和装甲防护。可选变危险区位于 PDF 68（6-12）。 |
| §6.3.7，PDF 77（6-21） | F/G 发射端另有规则。每枚独立判，舷侧或朝前装具按印刷射程向下 3 行，艉部装具按向下 4 行。未被射击且发射点距离目标不超过 2,000 码的鱼雷艇，命中率加 5 个百分点。书上 1,000 码的侧发算例查 2,500 码行。T.14 型是否适用霍腊纽仍待舰卡和年代核对。 |

下一批须把启用范围与已验想定一同提交。重点样例包括 10°、45°、45°以上及窗边界的进距和损速，领舰损伤后替换航路、F/G 穿越在途雷、A/B 深浅带防护，以及鱼雷预览、执行和敌情日志的一致性。
