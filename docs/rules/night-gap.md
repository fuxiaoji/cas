# 夜战裁决差额账本

口径：英文五版 `Command_at_Sea_5th_edition.pdf` 的 PDF 页从 1 起计，括号内为印刷页。v2 夜航、`cas-radar-v3` 雷达演习和 `cas-illumination-v3` 照明教学的旧存档独立重演；`cas-realtime-v4` 的相应演习还有逐秒主炮。功能在一种想定可用，不代表其他想定同样可用；历史关还须核时期与特例。全书其他范围见[覆盖台账](coverage.md)。

[圣乔治角即时版](../campaign/cape-runtime-sources.md)现有可执行舰卡、已验证的有限夜战能力和独立撤离边界。运输载荷、尚未核准的时期装具、实际雨阵与完整规则仍待补。独立夜战教学另按实际照明、炮雷操作及可重演事件验收。局部函数、对照档案和教练演示都不作“已覆盖全书”的证据。
