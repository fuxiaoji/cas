## 证据与教学

- `chapter.tutorialSteps` 由实际公开状态计算；定位、关闭提示或打开货舱都不产生完成记录。
- 揭露物资不等于携带。搜索可被攻击中断；只有 `archive` 实物具有合法格位才通过撤离门禁。三关档案目标都用当前 v4 格位、旋转和载重裁决。
- 护送船真实失能即失败；失去其他战舰不冒充“人类避难船沉没”。所有可航行幸存舰仍须在同一归航区域等候实际撤离读条。
- 首领被击败后仍需集结撤离；阶段、攻击预警、命中及胜负来自原核，不由剧本写死。
- 动态安全停航、损伤降速与队形不整分别引导重新规划、查看受损舰、预览重整或脱队。原书航迹规则保持原值。
- 新账号开场标记只在真实 `new_profile` 写入；已有账号不根据零进度被判为新号，未完成航次优先恢复。
