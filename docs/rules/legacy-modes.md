# 铁底湾 0.6.9 到 CAS 的实战内容依赖

铁底湾基线为 `F:/Codex/worktrees/android-mobile/铁底湾` 的 Git 快照 `48385c8`。战役关位及对应原页另见[关卡对照](../campaign/source-crosswalk.md)。本表区分已有离线预览和要达到旧作体验所需的实战证据。

| 功能 | 旧版可复核证据 | CAS 落地依赖 |
| --- | --- | --- |
| 序章「未明的海」 | `docs/mobile-prologue-plan-20261105.md`、`mobile/src/prologue/script.ts`、`mobile/public/story/prologue-battle.json`。旧作有 31 个步骤的进度编号，前段是 96 舰（各 48 艘）真实结算录制，从同盟席观察回放；再切到 15 舰近景、可选领舰、实操、剧情选择和一次性见面礼。 | 剧情文本、选择、立绘对照和奖励可独立接线。正式大舰队回放必须由 CAS 合法命令和版本化裁决生成，至少查齐编制中各舰时期与炮雷，需要战列舰时先通重炮、穿甲和临界；验证单一席位、规模性能和可见信息。不能用固定动画、两条边各几艘舰或旧六角格录像作为 CAS 裁决证据。 |
| 初始五驱逐舰与选领舰 | `mobile/src/prologue/script.ts` 固定 ID `IBS-U-USN-{FLETCHER,PERKINS,MAURY,DRAYTON,LAMSON}`；`resources/derived/structured/ships/catalog.yaml` 核对身份与级次。 | 《American Fleets》Annex A PDF 20–22（A-17–A-19）分别提供弗莱彻、格里德利（明确列莫里）和马汉（DD364–379，覆盖德雷顿 DD366、拉姆森 DD367、帕金斯 DD377）。格里德利与马汉按独立舰卡导入；马汉晚 1942 年去中部炮，拉姆森晚 1945 年独有改装。先定演习时期，再将五个角色 ID 绑定到三种实装记录；当前初始舰队可测试流程，仍待这组三型实装与跨启动恢复。 |
| 实战夜战教学 | `mobile/src/tutorial/night-steps.ts` 的 `CAMP-NIGHT-01` 有 10 项实操；用引擎确认编队、计划、尾随、鱼雷、脉冲、发现、照明、炮击和完整指挥循环。炮击成功下令并进入结算即可，不要求命中。 | CAS 教学改按领舰／同步、多航点、1 秒时钟和 CAS 战术窗口；下令、取消、接管与合法发射采用真实事件判定。v2 的夜间目视和暗光炮战可用于预备课。照明弹和探照灯仍须实装，才能替代该原课程中实际照明动作；不得照搬旧 MF、八脉冲和照明数据。 |
| 音乐、舰娘语音与旁白 | `mobile/public/audio/manifest.json` 区分战舰世界原声、联动声音包、事件句；`mobile/src/prologue/script.ts` 保存对白和立绘，脚本不声明对白 TTS。`docs/mobile-development-plan-20261104.md` §5.5 对商业使用范围未确认的素材不列为可发行。 | 先保留战斗开始、发现、受击、炮击和雷击等声音事件与静音控制；按座席过滤，避免声音揭示未探测敌方。原声与联动语音单独审来源和使用范围，或者换原创／有授权音轨；不能把旧客户端资源路径当作新游戏发行许可。序章对白配音可单独录制与回归。 |
| 线上竞技、组队与商店 | 旧基线有独立账号、钱包、活动池、挑战和编制入口。 | 战斗模式先有可核舰卡和 CAS 点表，3000 分档验证免费队伍与上限；10000 分须战列舰和护航规则。联机先完成席位观测、命令权威、重连和幂等发奖；商店和概率外显与实付权限分开验。 |

这些缺口不阻止虚构昼战和夜战演习，但影响序章、旧夜战教学、历史关和竞技的正式开放条件。
