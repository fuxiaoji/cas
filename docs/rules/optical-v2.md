# CAS 五版水面光学与照明 v2

数据包 [optical-v2.json](../../data/rules/optical-v2.json) 保存已核页的原表数值，坐标量统一为码；[night.rs](../../src/night.rs) 为无随机副作用的计算层，权威方传入 D10 / D100 以及允许使用的真实状态。来源文件、PDF 页码和 SHA-256 一并登记，原 PDF 未写入工程发行包。

v2 夜间虚构演习已接上目视发现、丢失和低能见度炮击，昼夜对局均可发现敌方发射迹象及可见尾迹。[sighting.rs](../../src/sighting.rs) 独立维护本方观察；[world.rs](../../src/world.rs) 向敌方观察只发送已见尾迹的本方编号、位置和方向。现版没有雷达、逐步辨识开关或照明指令；探照灯与照明弹仅完成数据和计算验证。

## 数据采用与界面边界

- D100 尾迹以英文主规则为优先；海况表选普通潜望镜列作为基础，避免先用潜望镜“羽迹”概率再叠加鱼雷推进修正。`Steel_Typhoon_5th_ed_Std_1_Oct_25.pdf` PDF 31–32（30–31）记录阳炎级舞风发雷及该交战中被目视发现的尾迹；现有舰表并未给出推进字段，不能套成所有九三式都完全无迹。
- 目视主规则 PDF 52 与玩家手册 PDF 15 的高分辨率原页均核得 28／29 千码末栏 **17.0／17.5**；先前低分辨率读作缺小数。v2 重录准确数值；不改变旧版存档规则包。
- 照明弹散布保留原图灰格标志，显示的偏移取图上每格中心（2,000 码一格）。正文对“在目标后 1–2 千码”的描述与示意图中心格距不完全相同；剪影判定使用明确涂色的格，界面不要把示意散布当成精密测距。
- 试验关固定设置夜间 20%、海况 2、无降水、无雷达；这是演习假设，不是史实。任何夜航测试须分清待命令、已发射、己方弹体和敌方有限尾迹。每个战术窗至多一次敌雷尾迹骰；成功后限在目视范围内跟踪，失去条件即移除，重新发现用本方编号。敌方尾迹不发送发射点、实际余雷数量或剩余航程；原书见雷后次窗自由改航在 RTS 沿用可随时改命令的流程。
