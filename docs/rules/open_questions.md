# 阶段 0 待确认和范围边界

- **CAS-Q-001：舰表适用范围。** 本地美日舰表称其舰表适用于 CAS 四版；本阶段对照五版 §2.2、§3.1、§6.1、§6.3、§8 的字段和表义后，仅用台账列明的四种配置。后续同名舰、改装、航速、二级武器及其他国家不以此次对照为自动批准。
- **CAS-Q-002（v2 已复核）：目视表 28/29 千码第五档。** 英文主规则 PDF 52 和玩家手册 PDF 15 的高分辨率原页均可读为 `17.0`／`17.5`；旧包缺行保留给旧存档，v2 光学表录入正确值。
- **CAS-Q-003：高低档和方位边界。** 航速表印作 0–75% 与 76–100%，未给连续航速的 75–76% 间隙，使用连续数值必须在 RTS 规则中说明边界。靶向图没有规定恰好在刻线上的归属。
- **CAS-Q-004：损伤细目。** Annex A 特殊修正作为原注保存，不对已印 DP 再乘一次。扩展关键损伤各舰种子表、无光或雷达火控、偏航中开雷、雷装填期间受限、受损舰的迫停或漂移，以及不同炮弹选择要逐项登记实际消费者后才可对外宣称支持。
- **CAS-Q-005：阶段 0 损管范围。** 尚未模拟轮机断电、舵卡死后的持续回旋及分轮抢修、舰桥失能、邻舰受弹药库爆炸波及、次要炮和其他武器关键损伤、搁浅／沉没过程、消防转向迎风、跨舰援助、可选国籍修正、倾覆和大火蔓延至弹药库。主规则与扩展损伤表的处理有差异（例如大型水面舰的起火与锅炉结果）；当前明确采用主规则，后续按想定锁定适用版本。
