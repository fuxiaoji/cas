# 原创海岛攻防 cas-island-war-v1

2026-11-14。此规则属于用户授权的架空家园／人机入侵模式，所有新地理、塔防和成长数值均为原创设计，不是 CAS 原书表值。历史战役、舰表及 cas-littoral-v1–v4（包括 combined-autonomy-v1）不升级、不改写；新局须显式调用 `new_island_battle` 并声明 `cas-island-war-v1`。

## 原核与版本边界

- `src/island_war.rs` 包裹既有 v4 海陆空核。海军仍使用原 World 的航行、炮击、装甲、系统损伤与公开观察；敌我舰不是在陆图上伪造的静态模型。新增敌舰后重新初始化实时电池，避免“有舰无炮座”。
- 顶层观察／保存版本为 `cas-island-war-v1`；`littoral.version` 保持 `cas-littoral-v4`，便于已有控制器消费真实多连、搭载、登陆、舰炮与中队数据。新增信息位于 `island_war`，不会进入旧 v4 响应。
- 原 `src/littoral.rs` 仅在内部 `island_geometry: Some(...)` 时使用新岸线、路径范围、地形掩护、结构装甲和终局；旧模式为 None。旧响应已通过逐字冻结门，不能用此可选路径修改历史数据。
- 固定 0.1 秒步长，模拟上限 900 秒。海／陆实际坐标单位均为米；陆军沿既有游戏性加速尺度移动，不能把这个速度表套回历史舰队。

## 岛屿与实际尺度

岛屿等级 1–10 的陆地包围范围为宽 `2500 + 330×(等级−1)` 米、高 `3300 + 350×(等级−1)` 米；即一级约 2.5×3.3 公里，十级约 5.47×6.45 公里。海军世界不缩放岸线或设施。三个西岸登陆场、近岸等待点与撤离海域由同一几何计算，路径网格 40 米。地形自西向东上升至 80 米，当前实际作用为最高 20% 掩护减伤；未声称实现三维高程弹道遮挡。

程序城镇建筑实际占地约 30–75 米，道路宽 20–22 米；保留岸滩、部署区、设施和道路走廊。建筑布局由种子确定。六个人机岛各有不同的防御布局、守舰、守军规模与配色，岸形使用同一组规范化轮廓随等级真实扩大。

设施等级 1–10，每级提高基础 HP／效果 12%。机枪、加农炮须经过实际地面通视；迫击炮可越过城镇障碍但存在最小射程。维修只修在射程内仍存活的设施，每次消耗一个备件，不复活设施。

轻武器攻击 reinforced 结构乘 0.32、medium 乘 0.65；反坦克／坦克／榴弹炮／加农炮／真实舰炮及航空攻击对结构乘 1.15。岸炮对实际舰体的原创装甲衰减为 `max(0.22,1/(1+舷侧装甲×0.10))`，随后扣真实 World HP；不改原舰炮穿甲表。所有炮塔消耗真实弹药，炮弹实际飞行、到达落点后才计算伤害。

## 驻舰、登陆与指挥

- 守岛时己方驻舰、突袭时敌方驻舰初始锚泊，依公开接触触发六秒起锚。起锚未完的移动／开火请求明确拒绝，不先显示成功再清除路线。完成后沿真实 World 行动。
- 防御来袭舰必须实际到达近岸范围（距等待点 900 米内）才发出有限登陆艇。艇以 75 米／秒游戏性速度实际接岸，具有 360HP、有限人员。岸防火力和部队能实际击伤艇；入岸人员继承艇的损伤百分比，沉艇不生成满血部队。
- 普通舰只下放轻步兵；载具登陆仅由现有 CV／LHA／APV 合法类别承载。玩家多连继续使用既有 v4 的本人、载舰、插入、回收和兼容限制。
- 托管通过本席公开观察和同一套合法指令选择登陆、占点、火力、航空中队、能力、撤收与撤离。守岛另有专门的守备指令，舰队缺弹不会让全部地面部队自动弃守。真实支持次数、炮弹和航空库存保持有限。成功手动命令可立即停止自动指挥；被拒绝的命令不取消托管。
- 来袭舰观察侧为敌方本席；地面防御／入侵计划只读该公开信息模式已公示的实体与地图。动画不生成战果。

## 胜负、战损与仓储

仓库须由实际非航空、非登陆艇人员在 300 米内控制，500 米内无敌方地面人员，累计六秒方可夺取。完整仓库给出其真实分配的暴露库存；已毁仓库只能取四分之一，整数向下取整。多个仓库的分配总量严格等于传入库存。

突袭须实际占领指挥部十秒、控制全部仓库并消灭真实守舰，再将部队／飞机实际撤回、舰队驶到撤离海域方能成功。只有实际回收的持有人可带回其库存；放弃／失败不发奖励。

防御至少进行 60 秒，并且所有真实来袭舰、登陆艇和已展开敌人均已被消灭或失去可登陆的载舰，才确认成功。旧版的“等180秒自动获胜”不适用于新规则。指挥部被实际摧毁／占领或到达 900 秒判负。胜利奖励与玩家自身仓库库存分开，不能将保留的库存再次作为奖励加回账户。

防御 `outcome.plundered` 表示仓库被实际占领后失去的暴露库存（包括失去控制后的物资损失），当前版本不要求敌方再次航海撤离、不实现随后夺回库存。账户层只扣原先冻结的暴露库存上限，受保护库存保留；实际本人单位与舰体损伤从原核终局读取。此处是明确的原创简化，不能宣称是完整敌方物流模拟。

## 成长、录像与当前边界

战术部队 1–30 级、两次突破，共同 HP 上限 +5%、火力上限 +5%；额外专精效用预算 ≤1%。当前落实精确射程、机动和后勤弹量的小幅效用，其他专精保留选择、共用成长，未声称每个选项均有独立技能树。所有增益只施加新规则中的本人实际身体一次，不改原舰表或旧 v4 战斗。

保存包含 `{version,seed,config,frame,tick,commands}`。命令流只记通过验证的手动操作和托管开关；自动指挥由相同种子和公开观察确定重演。只读 replay 游标保留完整未来命令，向前按差值推进、向后重建，与 live battle 分离；观看／拖动不会结算或修改账户。

当前为本地人机岛屿攻防，未开放真实在线玩家入侵。没有修改正常主存档、原始PDF、参考项目或正式旧WASM；候选由根任务完成安装。验证清单和原始回执保留于 `artifacts/island-war-v1/`，其中独立浏览器验证只证明旧 Web 战役／竞技兼容，新家园界面由 Godot 实际窗口验证。
