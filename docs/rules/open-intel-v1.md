# 非历史模式开放敌情 v1

用户新授权历史战役之外的游戏性模式公开敌人位置和详细数据。新请求显式携带 `intel_profile:"open-intel-v1"`，保存该版本，旧保存没有字段就继续原先战争迷雾；观察层不能临时猜测开关或根据界面所在页面升级规则。

允许新本地白昼/夜间演习、雷达/照明教学、架空序章、挑战、资源行动、搜打撤和全部架空章节。`new` 顶层字段用于演习/教学/挑战/序章，`new_chapter` 顶层字段用于章节，`new_salvage` 使用 Start 字段。历史 `new_campaign`、历史 Empress 固定想定和权威双席不允许此扩展；未知版本和错误类型拒绝。`cas-event-tide-v1` 是独立公开敌情活动，活动配置同样保存明确版本。

只有启用扩展时，探测/接触更新登记所有存活敌人、真实位置/航向/速度和识别身份；召唤的敌人也在实际出现后公开。死亡目标从活动接触移除。此时信息是规则明确公开，并非客户端读取隐藏权威保存。历史和旧档仍按本席可见接触更新，表现/AI不可越权查询。

新 `contacts` 含 `identified/health/max_health/health_fraction/classId/characterId`；`intelligence` 给最大/实际速度、攻击伤害/距离/周期、装甲、弱点、船体长度、炮管/炮伤表/射程表、已装与备用鱼雷、火控损伤、着火和进水。怪物另给实际阶段读招、预警窗口；海军舰炮则给公开装填状态。数据来自本局实际状态与登记表，没有让界面另造敌人能力。

公开预警保留真实几何、开始/落下时刻、攻击名称和反制短句。憎恶的主角豁免通过 `exempt_ship_id` 公布；看见预警不等于所有友舰都会受击。新规则没有改变历史表值、炮雷命中、伤害、地理位置或历史胜负条件。

原核单测覆盖全部七类本地非历史教学/演习/挑战/序章的开放与精确保存重放，历史覆盖拒绝；新六场章节、普通出航、旧迷雾与新数据进行了 native/WASM 及35组749旧请求逐字节对照。证据见 `artifacts/tide-core/receipt.json` 和 `artifacts/chapter-two-three-core/receipt.json`。
