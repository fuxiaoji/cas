# CAS 五版规则覆盖台账

页码以本地英文 `Command_at_Sea_5th_edition.pdf` 为准，PDF 从 1 起计；括号内为印刷页。章节定位按目录 PDF 6–8 核对，已转录部分另核规则原页。**运行**指已接入指定范围；**局部**指只接入表列的子集；**函数**指已核页的计算，尚缺世界状态或对局消费者；**缺失**指未运行。不要把表格、演算函数或目录定位计作完整实现。

各独立规则版本可用的夜间能力及差额，见[夜战裁决差额账本](night-gap.md)。

v8 将标准舵转向接入连续弧线，并用昼间完整尺寸表支持序章战列舰目标。直航鱼雷新增 A 级命中表、A/B 浅雷减伤与 F/G 排除。序章是 15 艘具名或核准舰型的虚构水面交战。详细源页和缺项见[连续航迹与直航雷](continuous-navigation.md)。

`cas-campaign-v5` 增加 [圣乔治角十舰](../campaign/cape-runtime-sources.md) 和 [通道行动八舰](../campaign/channel-runtime-sources.md) 的冻结时期包。圣乔治角使用本舰连续雷达位置解算直航雷，不能使用共享点或探知未观测航向；通道行动使用原布置和四回合目标，并启用 J/K 工程临界特例。两份均只覆盖已登记的水面能力。

[F/G 小艇原页数据](../../data/rules/small-craft-source.json)已为霍腊纽整理，尚未接入舰炮和损伤实战。单战术回合累加至两倍额定 DP 的沉没门槛，与逐阶段按原始 DP 检定临界伤的门槛是两条裁决。

## 历史夜战落地顺序

《Rising Sun》五版 PDF 71–72（70–71）“First Battle of Guadalcanal”已目视核对：双方名册、相对部署、时间、2%／5% 雨阵与 10% 基准环境、海况 3、SC/SG 装备、日舰初始三式弹、损伤比例与亨德森机场胜利条件均出现在原页。现有弗莱彻、阳炎可作为对照，历史关仍缺其余舰型和对应设施，另外要先完成雷达、降雨、岸轰、历史阵位和胜利条件。只有双方部署与局末判定都遵从原页，才能称为该历史关；早期同类夜战演习须标明虚构。

完成某一行还要补齐对应舰卡或表、规则编号与 PDF 页、运行入口、正反边界与可重演对局。核验通过后才更新状态；工程路线无需依赖一次性移植全书。
