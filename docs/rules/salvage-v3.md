# 水世界 PvE v3：原创规则与冻结边界

`salvage-v3` 是独立虚构单人内容，不能作为 CAS 原书舰表、历史阵位或海怪史料引用。原始 PDF、历史战役、教程、`salvage-v1` / `salvage-v2` 初始条件与重演均不升级。旧在途存档按原 `Start.content` 恢复。

## 海域与单位

- 权威海域生成器 `archipelago-3` 使用独立种子流。四类真实多边形：有开口与可航泻湖的分段环礁、主岛与碎礁簇、锯齿岸形成的峡湾、分散高地与淹城街区。岛岸是唯一陆地碰撞面；地标建筑基底全部在对应岛内。原主航路及三出口通过 300 米侧向通行校验。水面、云与地标细节由表现层程序绘制。
- `data/salvage/creatures-v3.json` 是原创数值的唯一来源。拾骸兽 / 骨帆水母 / 礁脊守卫 / 渊喉 / 憎恶巡游者的耐久为 90 / 140 / 260 / 720 / 180。速度为 16 / 10 / 8 / 6 / 20 节。它们没有舰炮、鱼雷或历史单舰身份。
- `CAS-FICTION-*` 是供现有玩家炮弹、鱼雷与长度线段命中使用的目标适配卡。长度、尺寸档与无装甲是原创适配参数，不是经 CAS 手册验证的生物物理模型。玩家舰卡及命中/伤害表未改。
- 生物攻击独立按 `CAS-FICTION-SEA-01` 处理：读取敌方席位可见接触，锁定公开的圆形预警区域，在模拟时钟到期时对区域内真实存活玩家单位扣除 8 / 12 / 18 / 24 / 10 耐久。伤害不伪称 CAS 舰炮裁决。常规预警 40–60 模拟秒，足以按真实航速避让；攻击不会在落下时追随玩家重新瞄准。
- 渊喉在剩余耐久 65% / 30% 进入二 / 三阶段；二阶段控制环过载并在合法海面召唤拾骸兽，三阶段并列三个固定冲击区域。后两阶段预警 40 秒、间隔 75 秒。击杀源怪物取消尚未命中的预警。
- 阶段没有强制锁血；集中炮雷火力可以在下一次观察前击杀或越过一段。验收分别覆盖快速实际击杀，以及完整观察到三阶段和三个同时存在的权威冲击圈，不能把快速击杀录像冒称完整三阶段展示。
- 怪物信息只附加到当前席位真实接触，预警仅当源接触可见时公开；不向客户端提供敌方真实坐标数组或隐藏生物状态。

## 第一章实战

`new_chapter` 接受 `c1-breakout` / `c1-salvage` / `c1-boss` 和种子。存档锁 `chapter_version: chapter-01-v1`；固定借用弗莱彻、帕金斯、莫里、德雷顿、拉姆森五舰，不写个人舰娘战损或成长。角色名字沿用现有单舰登记；“第五驱逐小队”是水世界剧情小队，不声称历史编成。

1. 突破：实际进入信标 650 米，再把可航小队带入公开集结区并持续撤离 12 秒。憎恶巡游者的目标选择及范围伤害明确排除搭载主角的 1 号舰；其他敌人照常可攻击主角，其他队员仍会受憎恶攻击。
2. 档案：实际靠近搜集 1 号旧信标档案，伤害会中断搜集；携带档案、全队集结撤离才获胜。直接点撤离不能跳过目标。
3. 首领：以真实炮 / 雷击杀开门派控制的渊喉才获胜；放弃、全队失能或超时均失败。

公开事件 `aversion_spared_flagship` / `beacon_reached` / `archive_recovered` / `boss_defeated` / `gatekeepers_control_link` 都由模拟状态产生，不能由跳过对白触发。章节首次奖励与对白推进由独立账户事务核对原核版本、stage、实际终局后发放，不计历史星数。

## 整备与掉落

- `prepare_service(ids, ammo_target, service)` 只读预览；`service_all(ids, ammo_target, request_id, service)` 原子提交，可选 `repair` / `ammo` / `both`。维修每缺 1% 耐久 2 银币，保护/失能状态至少按 1% 修复。弹药不足按登记价 100 份 / 160 银币整包补购到仓库；本次只设出航装载计划，确认出航再扣库存，避免双扣。航次中交易锁定；余额不足、重复舰娘、写盘失败均不部分成交。
- 新 `gear-v2` 六档制式、改良、精良、稀有、史诗、典藏权重分别 550 / 250 / 120 / 60 / 18 / 2（总 1000）。舰装词条 20 / 40 / 60 / 80 / 95 / 100 基点；每组水手主副词条合计 9 / 13 / 17 / 21 / 24 / 25 基点。装备上限仍 1%，四水手组合计上限仍 1%。更高品质不扩大战斗成长上限。
- 已有实例不洗品质、槽位或主副词条；旧 v1/v2 在途航次新结算掉落继续用 `gear-v1`。新 v3 物品保存抽表版本与实例词条，重开页面不重新抽样。

## 验证入口

`cargo test --lib salvage_v3` 覆盖多种子合法几何、固定预警空间与躲避、憎恶特定目标排除、隐藏信息和章节载荷校验。`scripts/verify-salvage-v3.mjs` 跑四地形真实搜集撤离、三个章节真实胜利、Boss 真实失败、中途保存/最终重演、原生/WASM逐请求一致及改动前 v1/v2 冻结快照。`godot/tests/service_rarity_test.gd` 覆盖原子整备、拆分服务、事务重放、航次锁、写盘回滚、六档分布与旧实例保持。
