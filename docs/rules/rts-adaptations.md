# CAS 裁决、即时化与战斗演出

原页以英文五版 `Command_at_Sea_5th_edition.pdf` 为准；PDF 从 1 起计，括号内为印刷页。应把规则差异写入内容版本，不能把动画时长、画面插值或演示关的摆位当成 CAS 数据。

| ID | 原页约束 | CAS 项目处理 |
| --- | --- | --- |
| `RTS-CLOCK-01` | §2.3.4，PDF 17（2-5）：战术回合包含三分钟的移动，计划炮击在其阶段立即、同时裁决；探测在计划炮击之后，反应炮击立即裁决、伤害减半。 | 每模拟秒推进航迹；渲染可插值，暂停和倍速仅改变现实时间。计划和反应仍按相应窗口决定命中与伤害量。v2 对局的伤害实际生效时点另见 `RTS-SHELL-01`。 |
| `RTS-ROUTE-01` | §3.1，PDF 22–24（3-1–3-3）：舰艇受最大航速、加减速、转向前进距离及转向减速限制。 | 航点和两种编队航路是下令与执行方式。后舰的尾随线、同步平移线和预览都受舰卡与规则约束；显示图层不能代替单舰碰撞或搁浅裁决。 |
| `RTS-TURRET-01` | §2.2.1–.2，PDF 13–14（2-1–2-2）：炮座仅可对本座射界内的目标开炮；`&` 分隔同座可用的多个射界，`/` 分隔不同座。§6.1.1–.3，PDF 57、61（6-1、6-5）：受指挥仪或局地控制约束，命中与伤害使用实际射向可用的炮管。未在该主规则、玩家表和首批舰卡找到可执行的舰炮炮塔转速、越界转动路径或额外转炮时延。 | 炮塔转向可作为战术图的反馈，依据本席可见瞄准数据或已裁决的开火方向。旋转动画只驱动外观；无炮座因动画尚未到位而无法开火，也无炮座因画面已转到位而越过射界开火。 |
| `RTS-DRAG-01` | §2.3.4 及 §6.1、§6.3，PDF 17、57–63、66–77（2-5、6-1–6-7、6-10–6-21）：火力有权威时点、可用炮位／雷管、观察和射界限制。 | 拖拽以提交目标／射向为止；取消不提交命令。鱼雷发射后直行，推荐瞄线不是跟踪目标的能力；预览只用本席信息。 |
| `RTS-SHELL-01` | §2.3.4，PDF 17（2-5）；§6 引言，PDF 57（6-1）：一次炮击骰和伤害代表此前三分钟内多发炮弹的效果。 | v2 每轮炮击生成八模拟秒的实体；弹道是表现，飞行时长不是实测弹道值。命中和伤害量仍按 CAS 窗口决定，DP／临界在到达时按同批记账。这与书上即时记账不同，可能影响紧随其后的反应、探测或损管；不得当成等价规则。v1 重演保留原瞬时炮击。 |
| `RTS-GUN-04` | §2.2.2、§2.3.4、§6.1，PDF 13–14、17、57–63；Annex C：只给每炮座射界和每阶段合并炮击裁决、射程、命中、穿深及伤害。 | v4 独立使用逐秒炮座横转、装填、炮击和弹着。同舰每战术窗共用命中骰、按实际炮管份额与装填时长分摊 CAS 伤害，飞行由极远射程及参考仰角推导。没有按原书阶段划分主炮计划／反应火力，保留旧版本原行为。详见[实时主炮原页和改编参数](realtime-gunnery-sources.md)。 |
