# 潮汐突围活动 v2

显式版本 `cas-event-tide-v2`，是原创活动的独立规则。目标是开局即可清扫普通敌群、持续拾取经验构筑，并逐步召集玩家所选的自有舰娘。战斗参数只属于本局，不读取账户等级、装备或 CAS 历史舰表作为伤害参数，不回写永久成长。历史战役、竞技、搜打撤和 `cas-event-tide-v1` 均不改规则或重演。

## 时钟与输入

一局 180 模拟秒，每秒 10 次确定性微步。权威 `frame` 是整数，`tick=frame/10` 是实际模拟秒；暂停选择期间两者均不前进。`step.seconds` 只接受 0–2700 范围内 0.1 秒的非负倍数，0.15、负数、字符串等拒绝，失败不改变当前会话。旧版和历史模式仍使用各自原来的整秒协议。

活动海域 24000×14000 米，合法航点边界 x=300..23700、y=300..13700。首舰初始位置 (12000,7000)、航向 90°、38 节；活动位移为节转米每秒再乘 10，这是本活动明示的尺度。`route {fleet:1,points,speed}` 设置最多 10 个航点及 4–60 节，`speed {fleet:1,speed:0..60}` 调速，0 可立即停住首舰。跟随成员仍会实际驶入队形。操作不瞬移，速度强化按真实秒数缩放。

## 自选后备与实际成员

`new_tide {version:"cas-event-tide-v2",seed,character_id,roster,difficulty:"normal"|"hard",intel_profile:"open-intel-v1"}`。

`character_id` 是首舰，`roster` 是玩家本次选择的后备身份列表，最多 64 名；首舰和后备不得重复，必须是登记的 IBS 单舰身份。原核只识别注册身份，账户服务在创建前验证所有身份实际拥有。未提供后备等价空列表，不凭空替补其他舰娘。

开局只有首舰，最多 6 名同时参战。当前已有 n 名时，等级至少 `3+(n-1)×2` 且时间至少 `25×n` 秒，下一次真实经验升级会给援军选择，故最早加入时间是 25/50/75/100/125 秒。不会由计时器自动赠送成员。援军批次提供所有尚未加入的自选后备，另附一项普通强化，可选择暂不招募；该普通项 `kind:"upgrade"`，不能把整个批次所有选项都当援军。

提交 `tide_choose {offer_id,upgrade:"reinforce:<identity>"}`，必须精确匹配当前真实选项；未知、过期、重复选择拒绝。加入后从后备移除，稳定实体 ID 与 `joined_sequence` 为 1..6，公开本人 `characterId`，真实开火、运动和被敌人选为目标。每次加入使全队耐久上限 +80、实际修复 120。初始全队耐久 500；所有成员共享一条耐久池，每次敌人命中最多扣一次，不按队员数重复扣伤害。界面读取 `tide.team_hp/team_max_hp`，不得将各 `ships.hp` 相加。

首舰由玩家控制，其他成员在首舰后方双列跟随，侧向 ±330 米、每行后距 400 米；第 2/3 名第一行、第 4/5 名第二行、第 6 名第三行。新成员从首舰后方 650 米处进入，按实际运动驶入站位。跟随加速用于维持本活动编队；画面使用真实观察坐标。

## 三类真实攻击

只从已登记身份读取舰名、舰种和主炮口径用于身份与表现。根据实际舰种派生活动角色，所有角色共享本局强化；下表是未强化基础数值，弹体、伤害、射速和爆炸都真实使用这些值。

| 角色 | 舰种 | 每轮炮束 | 每束伤害 | 炮击周期 | 爆炸半径 | 初始雷击 |
|---|---|---:|---:|---:|---:|---|
| torpedo 雷击扇面 | DD/DE/DL | 3 | 44 | 0.8 秒 | 260 米 | 3 枚/2.5 秒 |
| barrage 密集炮幕 | CL/CA 及其他登记类型 | 4 | 40 | 0.7 秒 | 260 米 | 1 枚/3 秒 |
| heavy 重炮轰击 | BB/BC | 2 | 90 | 1.2 秒 | 420 米 | 初始无；雷阵强化后获得 |

每舰独立从本人坐标瞄准 4200 米内最近活敌，自动发射。炮弹 2400 米/秒、寿命 3 秒，鱼雷 1250 米/秒、寿命 5.5 秒；鱼雷基础伤害 100、爆炸半径 480 米。炮束之间 5°、鱼雷之间 12° 展开。每微步用弹体扫过线段检查 100 米碰撞范围，命中后对爆炸内活敌实际扣血；不是按演出定时授予击杀。历史舰表没有由这些活动炮雷参数反向修改。

## 连续敌群、经验与强化

开局 16 名普通敌人在首舰周围 700–1450 米生成，此后每 2 秒补充 `8+floor(时间/30)×2` 名，位置距首舰 1050–2050 米。到 180 秒停止。30/60/90/120 秒各有一名精英，150 秒出现唯一核心 Boss；满预算时优先敌人会替换一名普通敌人，替换不授予击杀或经验。

普通基础生命 `22+floor(时间/60)×4`，精英 `260+时间×2`，Boss 4200；困难生命和伤害 ×1.35。普通追击速度 190 米/秒，精英和 Boss 205。普通/精英/Boss 伤害 9/28/62，命中范围 180/280/500 米。攻击先公开锁定点，1.2 秒后按所有成员真实位置判定；普通攻击距离 1050 米、Boss 2800 米，冷却 3/2.8 秒。三个普通外观种类目前共享普通敌人的追击与锁定攻击规则。

真实死亡生成普通 3、精英 15、Boss 50 经验。基础牵引半径 1200 米，范围内经验以 1500 米/秒接近首舰，150 米内才计入；350 米内掉落合并，满预算并到最近节点，经验总额不丢失。每级需要 `20+当前等级×8` 经验，升级暂停时钟，普通批次提供最多三个不同未满级选项，最初三次至少含一个攻击构筑项。各项最高四级：

| ID | 每级实际效果 |
|---|---|
| damage | 所有队员每束炮击 +16 伤害 |
| haste | 各舰炮击周期 -0.1 秒，下限 0.3 秒 |
| multishot | 每舰每轮多一束真实炮击 |
| torpedo | 每轮多一枚鱼雷，周期 -0.4 秒、下限 1.2 秒；雷击伤害 +20 |
| magnet | 经验牵引范围 +450 米 |
| shield | 全队耐久上限 +100，并修复 140 |
| maneuver | 活动位移 +12% |
| blast | 炮击爆炸半径 +100 米，雷击爆炸半径 +70 米 |
| repair | 全队每秒恢复 2 耐久 |
| chain | 每次炮雷命中后多 2 次附近真实连锁，伤害为该次命中的 65%、范围 100 米，每跳寻找 750 米内活敌 |
| orbit | 每半秒围绕首舰脉冲，半径 `500+等级×180` 米、伤害 `16+等级×12` |

所有强化满级后可重复选择修复 140 耐久。强构筑允许站桩清场；没有为了强制制造失败而削弱已经形成的组合。经验仍需实际拾取，站桩加入成员的速度可能更慢。

## 胜负与奖励

耐久归零即时失败；存活到 180 秒且已击败核心才胜利，绕开核心直到结束也是真实失败。自然终局活动币为：

`min(1000, (胜利?100:15) + floor(min(击退数,2000)/10) + min(精英击退数,20)×5 + (核心已败?40:0))`。

分数为 `min(999999, 击退数×10 + 精英数×100 + (核心已败?1000:0))`，与货币分开。主动 `tide_abandon` 始终 0 币，真实终局带 `abandoned:true`。账户服务重建原核终局证明后只结算一次，继续使用原活动进度与活动商店；局内等级、武器与耐久不带出活动。

## 预算、观察与保存重演

活敌最多 96，炮雷弹体合计最多 192，经验节点最多 48。事件、发射、命中、死亡记录各最多 64，死亡表现另在 2 秒后过期，观察只提供最近 40 条事件。超预算发射不生成弹体，也不会发布假发射条目。远于首舰 6500 米且已存在 20 秒的普通敌人可退出模拟，不授予战绩；精英和 Boss 不因此移除。常规微步不遍历历史指令或历史事件，实体循环有固定上限。

`ships` 包含每名真实成员、`tide_role` 和实际 `attack_profile`。`tide.members/reserves` 带身份、舰种、`role/attack_profile`；成员另有 `ship_id/joined_frame/joined_tick/joined_sequence`。`tide.slots` 提供 used/max/available。`choices` 每条自带 kind，援军还带 character_id/role/attack_profile。`shells/torpedoes` 带 own_ship。`tide.shots/impacts` 带唯一递增 ID、frame/tick、实际 ship_id、位置、种类、半径；命中另有 damage/hits/kills，均来自实际扣血，不以渲染特效反推伤害。恢复时表现层以 ID 游标接续，不重新播放旧命中或旧入队。

保存结构为 `{version,seed,config,frame,tick,commands:[{frame,request}]}`，frame 必须是整数且不超过 1800，tick 必须精确对应 frame/10，同帧指令保留先后顺序。最多 10000 条命令；未知字段、未来命令、乱序、不匹配时钟和重演越过未处理选择或终局均拒绝。存档只保存种子、配置和真实命令，不接受客户端直接填充 HP、击杀、升级、成员或奖励。读取失败不替换当前会话。

新活动必须显式指定 v2。省略版本仍为原 v1，v1 保存继续由原实现加载重演；不将旧活动静默升级。切换世界和活动时清除另一个会话，避免残留状态。

## 实测证据

`scripts/verify-tide-v2.mjs` 驱动真实原核微步、合法航路与选择，九场完整 180 秒航次包括普通 42/43/6106、困难 42、无后备、站桩、BB 首舰、拒绝援军，以及主动绕开核心的真实失败。移动六人构筑首杀 0.3 秒，首升级 3.7–4.6 秒，第一次援军约 26–30 秒，约 126–131 秒达到六人；真实 DD/CA/BB 各自开火。首 30 秒约 120 击退，普通完整局 1183 击退、278 活动币。站桩样本真实胜利但只加入到四人，不误报六人；避核心样本 180 秒仍存活、核心未败，按规则失败。

同机逐请求观测的 step 包含原核、JSON 和进程往返：完整移动样本 p95 约 1.2–1.4 毫秒，末存档约 26KB，完整 load/replay 约 60–80 毫秒。它们与 10Hz 渲染节奏是不同指标。原 v1 基线普通 42/43/6106 首杀 5–6 秒、首强化 19–25 秒、30 秒 7–8 击退、全局 85–93 击退；此前卡感主要还包括 1Hz 画面更新与连续操作反复写盘，表现和账户层分别修复。

边界夹具覆盖错误小数、负秒、非法身份/后备、错误编队、伪造未来帧、停止、退出、v1/v2/世界切换及读取原子性。原核 Rust 测试直接检查真实登记 DD/CA/BB 的 Bolt 伤害、射速、数量和范围与公开 profile 一致，并检查实际受击归零、经验合并守恒、预算和 Boss 入场。证据位于 `artifacts/tide-v2-core/`；`scripts/verify-tide-v2-parity.mjs` 对新夹具和五局旧 v1 逐响应比对 native/WASM 原始字节，旧局另对 `c4c2a09b58d80b5b` 核冻结比较。
