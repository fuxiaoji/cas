# 舰队油料与实物带货 v1

这是架空出航的独立扩展，不是 CAS 原书油耗表。只有新航次显式携带配置才生效。缺少字段的所有旧保存、原历史想定、原舰卡和 v1–v4 行动保持原路径。港口扣款、货物归属锁、退款和奖励防重由账户事务负责；海上消耗、格位、载重和胜负由原核负责。

## 油料

`Start.fuel_v1={version:"fleet-fuel-v1",initial:u32}`。`fuel_preview {start}` 可在创建行动前调用，返回容量、建议量及逐舰吨位和费率。吨位复用 `data/salvage/cargo-tonnage-v1.json` 的登记；未登记项使用与货舱一致的舰型预算，并明确标为 `fictional_budget_fallback`，不回填历史卡。

每舰20节基准每分钟油耗为 `ceil(吨位/1000)`，每秒消耗按实际基础节数乘 `0.2+0.8×(航速/20)²`，内部存千分之一单位并对舰队每秒总量向上取整。怠速20%，沉没舰不继续耗油。冒险10倍位移不再额外乘10倍油耗。油舱容量为舰队基准每分钟耗油×12，建议装载×8；装载超容量、未知版本拒绝。

公开 `view.fuel` 含 loaded、remaining、refundable、consumed、capacity、fraction、state、rate_per_minute、estimated_seconds、return_seconds、return_required、rescue_in 和逐舰账。返航估算取距离最近撤离点的最远存活舰，按20节实际位移计算并加20秒，耗油预算另留1.5倍余量。此估算帮助玩家和自动指挥决策，不替代海图合法航路。

剩余量≤容量20%发一次低油事件；自动指挥在低油或低于返航预算时停止搜索并回港。耗尽时编队目标速度归零，现有加减速继续裁决；禁止新的推进/恢复航行指令，允许明确停船、开火、搜索和附近撤离。不会把舰体最大航速改成零来假装舰船损失。耗尽持续60模拟秒仍未撤离，实际拖救失败，不发未撤物资。

终局才有 `fuel_receipt={version:"fleet-fuel-v1",loaded,remaining,consumed}`，均为整数，始终 `loaded=remaining+consumed`。remaining向下取整，消耗向上取整；港口只对成功撤离的同一行动一次性退还剩余量，失败或主动放弃的海上余油不回库。无海上凭空补油指令。

## 双仓库带货

`Start.cargo_transfer_v1={version:"fleet-cargo-v1",pickup_namespace:"唯一行动命名域",items:[完整物资]}`，仅新的 `salvage-v4 + cas-adventure-v2` 允许。16种v2目录物资可带出；旧无 `loot_id` 的通用四类库存保留旧流程，不伪装成新目录物件。

每件保留 `id/kind/name/shape/kg/value/ruin/placement/loot_id`。原核核验唯一ID、已登记目录、精确形状重量、原三档售价之一、非空格位、真实可用格、重叠和载重，最多96件。任何一件不合法，整次创建失败且不会替换当前行动。带入物实际计入货舱、载重和携带种类；弃置会实际移除。

新搜出的物件ID前加本次 `pickup_namespace + "/"`，带入物ID原样保存，解决不同航次遗迹编号重复。成功撤离返回实际仍在货舱的物件；失败不返回战利品。账户必须锁定带出物原归属、按原ID识别已有物，不能把带出又带回的物资重复发奖/自动换银币。原核提供实物与终局，账户原子移交并防重，两边不各造一份库存。

## 实测

见 `artifacts/tide-core/receipt.json`：同20节十秒航行驱逐耗0.350、战列3.480；1油自动13秒空载撤离；0油61秒实际拖救失败；原物真实占格和重量、新搜物命名域不同、非法导入不改当前保存。所有新观察/保存/重放已进行 native/WASM 对照，旧35组749请求逐字节冻结。
