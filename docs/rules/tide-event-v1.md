# 潮汐回响活动 v1

独立原创短局割草肉鸽，版本 `cas-event-tide-v1`。这是旧世信号引发的共鸣演练，舰娘在本局叠加强化、移动拾取经验并平息核心；不用 CAS 舰表、历史伤害公式、账户船等级或装备当战斗参数，强化绝不回写这些系统。战场为程序动态海面上的开放演练区，不使用固定地图照片。

## 真实单局

180模拟秒，普通/困难两档。0/30/60/90/120/150秒六次有限怪潮；每潮普通10+潮序×2、困难16+潮序×2，困难生命和伤害1.35倍。60/120秒各一个精英，150秒唯一核心Boss；不会无限召唤或反复刷Boss。

舰娘初始耐久300、35节，活动位移10倍、独立航线速度0–60。普通/精英/Boss基础生命45/180/560；普通105、精英95、Boss65米每秒追击。攻击先锁定公开圆形落点，3秒后才按真实位置伤害；离开预警就是防守动作，停止移动会实际受击。Boss伤害42/范围600，其他12或24/范围300，困难再乘1.35。

炮击和雷击自动瞄准，但弹体实际移动、扫掠碰撞并爆炸，不是定时凭空扣敌人HP。炮击初始30伤害/3秒、1300米每秒、3300射程；鱼雷65伤害/8秒、700米每秒、400爆炸范围。每个敌人真实死亡才生成实体经验，普通3、精英10、Boss25。拾取基础半径650米，靠近才计入经验；敌人未死亡/经验未拾取没有虚假成长。

## 三选强化

每级经验门槛 `8+等级×4`。升级后暂停模拟时钟，给三个不同且未满级的候选，提交当前 `offer_id` 与候选ID才生效；旧批次、未知项、数值溢出和重复提交拒绝。九种强化各最多四级：

| ID | 实际效果 |
|---|---|
| damage | 每级舰炮伤害+15 |
| haste | 每级炮击间隔-1秒，最低1秒 |
| multishot | 每级多一束伴随炮弹 |
| torpedo | 每级多一枚鱼雷，周期-1秒，最低3秒 |
| magnet | 每级拾取半径+400米 |
| shield | 每级耐久上限+50并实际修复80 |
| maneuver | 每级活动位移+15% |
| blast | 每级炮弹爆炸半径+120米 |
| repair | 每级每秒恢复1耐久 |

有限升级机会、随机候选与等级上限构成本局组合选择；没有付费抽取强化。150秒后需靠近核心集火，单纯绕开所有敌人存活不能算胜利。

## 胜负、奖励和退出

存活至180秒并击败核心才成功。耐久归零即时失败；180秒核心未死也失败。自然失败保留少量实际战绩奖励：成功基础80、自然失败基础10，加 `min(击杀,120)/3` 整数除法、每精英8、核心击败30。所有奖励由真实终局计算，账户校验同一冻结活动并一次性到账。

**主动 `tide_abandon` 始终0奖励**，终局带 `abandoned:true`，不能通过进入/退出刷币。分数保留用于记录实际表现，不等于奖励货币。活动奖励只进入独立活动商店，不将本局伤害、等级或生命强化带出活动。

## 协议和保存

`new_tide {seed,character_id,difficulty:"normal"|"hard",intel_profile:"open-intel-v1"}`；角色须是登记IBS单舰身份。`route/speed/preview_route` 控制本活动独立航行，`tide_choose {offer_id,upgrade}` 选择，`tide_abandon` 实际退出。

`view.tide` 包含 version/duration/wave/kills/elite_kills/boss_defeated/boss_spawned/level/xp/xp_required/drops/upgrades/choices/offer_id/paused/outcome；时间使用顶层tick。contact health、动作读招、实体弹体、公开死亡确认和XP位置均来自实际裁决。终局outcome含 success/event_tokens/score/kills/elite_kills/boss_defeated/duration；顶层result则沿用普通界面winner/primary。

保存 `{version,seed,config,tick,commands}`，命令按tick记录，只能重演登记活动操作。未知版本/难度/敌情、非登记角色、乱序或超出保存时刻的命令拒绝；读取失败不替换当前会话。保存重建从种子和实际命令恢复，不接受客户端直接填HP、等级、击杀或奖励。

## 实际验收

真实玩家策略：前150秒靠近XP并避开锁定点，核心出现后进入3300米炮程绕行集火；所有移动、强化和射击都实际推进。普通seed42/43及困难44完整180秒成功，90/93/107击杀、9/8/10次真实强化；另一次只追XP不围攻核心的seed43在180秒满耐久仍判失败，站桩seed45在54秒耐久归零失败。五局load/replay完全恢复且逐响应native/WASM相同。主动退出0币、未知配置/重复选择/伪造未来日志拒绝，见 `artifacts/tide-play/` 与 `artifacts/tide-core/receipt.json`。
