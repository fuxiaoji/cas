# 五版水面雷达录入与圣乔治角实装证据

[雷达数据](../../data/rules/radar-source.json)是冻结的来源转录和裁决算例。`cas-radar-v3` 的虚构雷达演习已启用其中核准的水面搜索部分；v1、v2 存档和既有发行包保持不变。原页均已目视核对；PDF 页码从 1 起计，括号内为印刷页。按主规则 §5.2.1 优先取想定实装特例，再取 Annex A 的舰型与日期记录，查 Annex J1 的雷达性能。旧版逐舰 Form 10 只用于交叉核对。

`src/radar.rs` 按舰、装置和目标建立私有跟踪；搜索每窗口用独立 D100，保持不重掷。通过来源舰装置持续观测的目标可以更新本舰位置；下一窗口转发上个窗口冻结的位置，不向受转发舰更新实时航迹。`radarContacts` 只含本席接触代号、可观测位置、观测时点、直接探测舰和迟到报告，不公开敌舰 ID、舰型、航向、航速或战果。正在工作的本舰直接接触可按 §6.1.3 以 −2 做雷达炮击；权限与瞄准在开火时复核，无真态弹道显示；反应火力仍受 CAS 窗口约束。迟到报告可供 AI 导航，不足以直接指挥此版炮雷。鱼雷仍须原光学接触，待核完雷达射击解算；独立航迹失去只留下已知报告，不继续追踪。`radar_set` 是本方装置开关，会写入重演命令。主规则 PDF 108（8-9）的传感器／通信 D6 子判定和随机传感器失能仅对完整实装核对的弗莱彻启用，通信损伤效果未启用；Mk4 与早期 QC 是受损候选，尚无其主动玩法。

`src/radar/mk4.rs` 已写不读世界真态的指向火控计算：中小舰前指挥仪 F 射界按 PDF 14、61 为距艏 ±150°，C／D 目标 8 nmi，再受地平线和遮挡限制。接受有效光学接触或炮口闪光；原版 Mk4 不具盲射能力，单有搜索回波不能得 Mk4 修正。邻岸判定用该目标尺寸的标称距离，按 PDF 58 的 ±5° 和 −2；这是明确保留的原文解读。此函数已测试但没有接进开火。

下一步用已核布阵、舰况和任务接入圣乔治角；继续核对 Mk4 火控和夕雾 Type 22 的安装状态。Mk4 搜索模式该用哪栏杂波未由上述表直接判定，未启用。海岸遮挡已接入实际搜索，杂波区域要求想定提供真实类别与范围；原页只写“零星雨阵”时不会凭空增加区域或强度。核验：`python data/rules/check_radar_source.py` 查原件与算例，`cargo test --locked radar::` 查运行规则、实际雷达炮击、双盲、重演及未接线的 Mk4 边界。其他待做见[夜战裁决差额账本](night-gap.md)。
