# 舰载航空操作扩展 · 来源与边界

## 后续显式v2追加（2026-11-15）

`cas-carrier-ops-v2`增加在空改令、整舰联队召回、待命取消、母舰筛选、各舰航空姿态与手动接管保护。v1命令/重演与未启用航空操作的新旧v4均不自动升级。物理增加用户明确要求的持续飞行：离开甲板后不能静止，盘旋中心是指定航点；警戒半径600m、进入区800m、忙甲板等待半径650m/进入区900m、盘旋航向变化上限30°/s、近舰燃油预留3000m，均在carrier_ops_v2.rs全局单点登记并通过公开flight_policy导出。逐帧真实位置按航速推进，按位移1.1倍扣航程量；这是既有近场油耗公式的真实运动消费，不是仅旋转图标/静止扣油。着舰前实际飞行，空中改令不能重置燃油、弹药或HP。

这些控制值与既有2秒起飞/3秒着舰/20秒整备均属原创近场玩法，不是原书表值。新录原书数据与历史消费者不受影响。多航母AI共享近邻CAP、每舰活动份额、轮换调度、避免在途攻击过度集中；战斗机按公开敌机HP/已分配有限武器分配拦截，目标消失时实际返航而非打击幽灵目标。玩家手动接管后须显式交回托管。完整CAS风、高度、甲板事故、满额空群、同步波次与异舰备降仍未实现。

新操作版本cas-carrier-ops-v1通过独立carrier_ops命令显式启用，旧v4不自动升级。保存记录此命令，回放重建队列/轮换；观察仅启用后多出carrier_ops。新版队列不扣武器，真正launch_air才从真实飞机/弹库扣除。每中队最多一个待命，重复拖动替换，不叠加飞机。中队召回取消待命且真实返航。母舰毁坏/无飞机/弹库耗尽时取消待命并公示原因。

沿用fictional-air-v1近场架构：每中队3架、每中队18武器、活动总数24、起飞2秒/架、回收3秒/架、整备20秒；它们是已有原创近场参数，不是原表。新增AI每方最多12架属于资源调度预算，不改命中概率/伤害。轮换中队遍历、队列优先、返航机1500米内暂停调度起飞；警戒机保留真实油耗，3000米内转拦截。舰艇移动/受击/沉没与飞机飞行/回收仍调用原有真实海战与航空循环。

本轮未实现：完整远程会合/同步抵达波次、不同母舰备降、风向自动迎风、全高度CAP/拦截、舰型真实满额空群、原版航空完整表。教学不得把这些称为已实装。独立试玩不发奖励，读完教学不登记实战毕业；CAS-Carrier-Academy.cmd使用隔离练习档和target-carrier核心，不替换正常运行核或陆战agent成果。
# 三档控制追加：cas-carrier-ops-v3（2026-11-15）

用户要求收敛复杂操作：高自动化由航母选公开目标并安排防空/对舰/对陆；中自动化玩家只指定各舰目标，选机、甲板、飞行、回收由航母完成；低自动化保留v2具体中队和在空编队拖动。新版本以 `carrier_automation` 显式启用，v1/v2和未开启的历史行为冻结。启用/切换不补资源；高、中档清理旧待命和手动接管；中档更换目标召回本舰旧对舰/对陆波次。

原创控制参数全局登记：中档对陆区域半径650米，友军安全间距350米；一方自动调度最多12架、双方活动最多24架；多航母每舰份额至少容纳6架，以免防空占满本舰而永久不能打击，总数限制仍有效，并轮换母舰分配。机型、航程、逐架甲板、航空武器/剩油与真实伤害沿用已登记近场航空续作，不改变原书舰表或历史阵位。v2盘旋参数继续适用。

海陆衔接只增加航空接线：`island_war_v2` / `island_war_v3` 向航母传当前公开陆图，v3包含实际存活效果/支援标记。高档优先有效己方航空标记、接近岸上友军的公开敌人；中档区域内自动选合法目标，非保证点杀。投放前再检查友军间距；过近则保留武器返航。既有陆战负责身体/载具/建筑和实际伤害，不新增一套地面裁决。陆战总托管在新版不再另派同一批舰载机；航空命令保留陆军托管，总撤收时召回并停止新派遣。

界面高/中档每舰一张支援卡，可在海图或陆图拖动；低档展开具体卡牌。公开 `automation` 包含职责、下一步、各舰状态、当前目标和命令契约。详细入口和独立agent说明见 `docs/development/carrier-three-level-guide.md`。完整CAS迎风/高度/事故/实际航空队/备用母舰等旧缺口不因本层自动化而宣称完成。
