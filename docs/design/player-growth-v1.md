# 指挥官、突破与资源海域 v1

2026-11-12，独立游戏系统设计与实施交付。适用于自有舰 PvE，不调整 CAS 原始舰卡、历史阵位或历史借用舰。

## 设计目的

把「获得舰娘 → 编成 → 实战 → 回港整备」串成可理解的循环。玩家等级负责开放内容；舰娘成长提供小幅、长期的投入回报。界面按当前动作展示材料、图标与进度，具体舰表保留在单独页签。

参考的是官方展示的组织方式：

- [原神官方「Training Guide」说明](https://www.hoyolab.com/article/25874981)：把等级、武器、天赋、圣遗物等提升路径分别呈现；突破材料不足时指向来源。
- [明日方舟官方活动及晋升材料说明](https://www.arknights.global/news/2926)：阶段晋升与对应养成物资的分层。

以下数值均为 CAS 自有设计，不照搬参考游戏。保留既有舰娘 Lv.30 上限与约 5% 舰体、航速、火力增益，满熟练度提供约 10% 相对基础炮击命中增益，单舰一个舰装槽、四个水手槽。

## 实际规则

| 项目 | 当前实现 |
|---|---|
| 指挥官 | Lv.1–20；升到下一等级需要 `60+当前等级×30` XP；不直接增加战斗属性 |
| 开放条件 | Lv.1 基础海域；Lv.3 进阶海域、一阶突破；Lv.6 深层海域、二阶突破 |
| 舰娘成长 | Lv.0–10 → 突破到 20 → 突破到 30；在突破上限处保留超额经验 |
| 一阶突破 | 舰娘达到 Lv.10、指挥官 Lv.3、银币400、锈蚀核心4 |
| 二阶突破 | 舰娘达到 Lv.20、指挥官 Lv.6、银币900、精密核心3、共鸣核心1 |
| 训练记录 | 基础 / 进阶 / 精研，每份40 / 160 / 640 XP，消耗银币50 / 200 / 800 |
| 材料合成 | 基础记录3→进阶1；进阶3→精研1；同样适用于两次核心升级；无逆向拆解 |
| 初始核心 | 首次迁移或新建档案赠锈蚀核心2；迁移标记确保不会重复加仓 |

舰娘训练只增加等级经验，实战熟练度必须真实参战积累。指挥官经验来自实际成功行动：资源海域每次60/90/120，既有其他海上行动默认60；第一章三个实战首通各150；历史战役首次成功120；教学或挑战的唯一成功标识首次90。同一结算回执和同一首通标识不会再次发放。

## 三档资源海域

每档包含银币、训练、舰装、水手四类，共12关。原有四个基础任务 ID 和原生遭遇保持原样；新 ID 使用 `silver/training/equipment/crew-t2` 与 `-t3`。

| 等级 | 基础 | 进阶 | 深层 |
|---|---:|---:|---:|
| 指挥官要求 | 1 | 3 | 6 |
| 银币/训练关体力 | 8 | 16 | 22 |
| 舰装/水手关体力 | 10 | 16 | 22 |
| 指挥官经验 | 60 | 90 | 120 |
| 银币关固定银币 | 700 | 1400 | 2100 |
| 训练关记录 | 基础12 | 基础4、进阶5 | 基础4、精研3 |
| 训练关突破核心 | 锈蚀2 | 精密2 | 精密2、共鸣1 |
| 物件最低品级 | 制式 | 改良 | 精良 |
| v3 海怪数量（单舰） | 7 | 9 | 11 |
| 首处物资横坐标（基础生成偏移前） | 原配置 | 4800m | 5800m |

普通资源关固定元词10；实际带回的残骸与物件在此基础上结算。抽卡资源的主要收益仍来自剧情/首通/周挑战与远征，资源本偏向定向养成物资。

高档资源关把接驳撤离区设在前沿物资周边，必须先实际装载货物。这样保留深入海怪海域的风险，减少遵守 CAS 加速与转向规则时重复回航造成的拖延。旧资源关、普通打捞远征、历史战役均保持原撤离规则。更高档增加的是原创海怪、距离和补给报酬，未改写历史军舰参数。

成功条件使用原生战斗结果、实际货舱与返航舰艇；失败不发资源包或指挥官经验，出航体力不会返还。只有成功且货舱非空才发普通资源关奖励。结算和返港资产提交在同一存档事务内完成。

新的舰装/水手掉落仍用制式55%、改良25%、精良12%、稀有6%、史诗1.8%、典藏0.2%的原基础表。进阶将低于改良的结果提升到改良；深层将低于精良的结果提升到精良。高档不额外抬高典藏概率。

## 舰装是选择，不是五个同名加成

新物件为 `gear-v3`；同品级共享既有20/40/60/80/95/100基点预算（100基点=1%）。仅一件舰装可装备到同一舰娘。

| 类型 | 实际原核效果 |
|---|---|
| 火控测距仪 `fire_control` | 全部预算投入相对基础炮击命中 |
| 轮机增压器 `propulsion` | 全部投入航速 |
| 复合隔舱 `bulkhead` | 全部投入耐久 |
| 平衡改装套件 `balanced` | 耐久34%、航速33%、火力33%预算 |
| 弹道计算仪 `ballistics` | 全部投入火力 |

装配后 UI 的加成和原生战斗快照使用同一选择。装备页可付银币200、锈蚀核心2改装类型，保留原物件 ID、品级与总预算。装卸、改装、训练和突破均在航次中锁定。

既有 `gear-v1/v2` 物件不重新抽取、不转换类型，保留旧综合加成。新航次登记 `typed_gear` 标记；之前已经出航的 v3 航次保持原 `gear-v2` 物件掉落，返航不会被本次更新改表。

水手仍沿用四类主、副词条，每组最多25基点、四组合计最多100基点。指挥组继续只影响搜打撤同步机动成功率；未扩大到历史战役命令。

## 存档与版本

- 旧档只缺新字段时补全，不重置舰娘、物件、钱包或航次。
- 旧舰娘实际等级超过10自动保留一阶，超过20保留二阶；已获得等级不回落。
- 旧最高等级达到10/20时，指挥官迁移到3/6，避免已经养成的舰队重新被内容锁挡住。
- `equipment_profile` 是原生快照可选字段；空值不序列化，旧 v1/v2/v3 逐字段回放一致。
- 每次训练、突破、合成和改装先验证，原子写入，写入失败回滚资产与物件；带 request_id 的动作支持相同请求重试。
- 充值由独立模拟服务处理；该模块不会凭玩家等级创建元词余额。

## Godot 编辑位置

- `res://data/player-growth.tres`：原生 `CasPlayerGrowthRules` 资源。Inspector 内可调整指挥官经验、材料 XP、突破配方、改装费用和舰装类型名称/图标等数据。五个战斗类型 ID 与预算由原核校验，增加第六种战斗效果需要同时实现其原核规则。
- `res://scripts/player_growth_rules.gd`：资源类型及导出属性。
- `res://data/meta-economy.json`：各资源关体力、开放等级、固定奖励、最低掉落档。
- `res://assets/growth/icons/*.tres` 与 `res://assets/gear/icons/*.tres`：单个材料/舰装的原生 AtlasTexture，均可独立打开与替换。
- `player_presentation.gd`、`ship_detail_presentation.gd`、`mission_presentation.gd`：指挥官材料仓、舰娘成长/舰装、资源海域的真实交互页面。

原生战斗仍校验 Lv.30、舰装100基点及水手槽预算，设计资源不能绕过战斗安全上限。
