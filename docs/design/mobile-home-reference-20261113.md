# 家园移动端交互参考与落地审查（2026-11-13）

## 范围与结论

本轮只做参考研究和可执行审查。已阅读 agent.md、plan.md、havedone.md，以及 game-design、game-ui-ux、frontend-design 的相关指导；不改变历史战役、原始资料、经济规则或账号存档。

旧版家园的问题首先是操作模型：岛屿像控制面板中的示意图，真正的操作集中在常驻侧栏。用户需要阅读按钮和说明，无法凭岛上的建筑判断下一步。重构应让“看见建筑→点它→做一件事”成为主路径，并让建设、编成、出航逐步展开。

下面的尺寸和布局数字是 CAS 的设计建议，不是引用作品的原始规格。参考只学习交互组织与画面层级，不将官方角色、界面贴图或建筑图片放进发行素材。

## 九条落地建议

### 1. 主屏让岛屿成为可操作的主角

移除常驻建设说明列；岛屿使用可平移缩放的主画布。顶部只保留返回、岛名和三种当前建设资源。底栏最多五个短入口：建设、招募、部队、驻防、出航；仅出航使用最强强调色。建设库、人员清单和详细生产数据在点选后出现。

验收：进入家园后，不读说明也能发现岛、建筑和出航按钮；没有两个大标题复述页名；非选中状态没有大面积白色表单遮挡海岛。参考：海岛奇兵官方实机图、皇室战争官方 Deck Menu。

### 2. 点建筑本身，出现一张就地操作卡

建筑的轮廓、底座和阴影应比地面细节更清楚。点击建筑将它轻微提亮、显示占地和名称；旁边一张卡只放名称/等级、最关键状态以及一个主要动作（升级、维修或收取）。防御射程仅在选中防御建筑时出现。点空地关闭，点击其他建筑就切换。

验收：不用先进入管理模式就能点太阳能板、HQ 和码头；卡片不覆盖选中物，靠边时自动换侧；鼠标滚轮、双指和地图拖动不落建。直接操作物件的参考：[海岛奇兵官方 2024 更新](https://boombeach.supercell.com/en/news/updates/the-calm-before-the-storm/)。

### 3. 建造必须经过预览、摆放和确认

底栏建设打开图形化卡片托盘。点卡片进入幽灵建筑预览；手指/鼠标移动位置，网格仅在摆放时显示。可建用柔和绿底和勾，非法用红底与短原因；不能只靠红绿区分。确认前不扣资源、不保存；底部两个大目标“取消 / 确认建造”。

验收：拖地图放手不能误建；在海里、已占用格、未解锁或资源不足时都能看见原因，确认按钮禁用；取消完全不改存档；成功后返回选中新建筑，而非重新打开整个清单。这是 CAS 的防误触方案，不声称照搬参考作品具体流程。

### 4. 触摸大小按最终屏幕验收

主要按钮和独立点选目标最终至少 48 屏幕像素，紧邻目标留约 8 像素间隔。建筑画面可以有小细节，但点选区域至少是独立的大轮廓或圆形；相邻建筑命中时优先选择点下的可见建筑，不把整片大圆互相覆盖。

1600 宽设计视口缩至 960 时，52 设计像素只有约 31 屏幕像素，不够作为触控目标；需要用最终窗口转换后的尺寸检查。长按提示、悬浮提示只能补充，不能承担手机端唯一说明。

验收：960×540、1280×720、1600×900 中均可区分点击、拖动、滚轮和双指；最小窗口没有被裁去的确认按钮，也不会把卡片点选穿透给地图。

### 5. 生产反馈指向真实物资，不铺满统计

有待收取物资时，设施上出现一个物资图标气泡；点选后收取给出短促飞入资源栏的反馈。无产出时不闪烁、不制造假红点。若现有服务只提供“全部收取”，气泡也必须明确表示总收取，不能暗示只收当前建筑。没有必要把每小时产量、总容量和所有资源永久贴在每栋建筑上。

验收：生产气泡、顶部可领取数量和真实到账值一致；满容量或无待领时有准确状态。状态驱动高亮参考：[皇室战争 3 月中旬更新](https://supercell.com/en/games/clashroyale/blog/news/mid-march-update/)。

### 6. 出航先选任务，再选带谁，最后一键出发

建议两步：第一屏用少量目标岛/行动卡确定“攻岛、遗迹、守岛”；第二屏展开本行动需要的舰娘肖像和战术部队，保留最近选择。底部只保留一个明确的“出发”。运输取舍使用可视货舱条：弹药、登陆部队、剩余货舱，让玩家拖滑块便能看见变化。运输舰的真实肖像和装载能力比 AV 等缩写更有解释力。

验收：确认前有一条简洁汇总（所选舰数、运输席位、弹药、目标），缺部队/载力不足明确指出去哪补；不能因为已有舰娘清单加载顺序而静默重选；取消返回原岛屿视角。入口聚合参考：[皇室战争官方 June Update](https://supercell.com/en/games/clashroyale/blog/release-notes/june-update-2025/)。

### 7. 未解锁时，只给一条可执行的下一步

新岛未解锁时主屏保留岛屿预览，但只出现“接通归航信标 / 开始登陆”的引导卡，不铺八个灰色按钮。已解锁后，第一次建设、第一次驻防、第一次装载部队分别在玩家需要时提示一句，并指向相关物件。完成即收起，允许回看。

验收：新账号从锁定岛进入教学、返回家园、建首个设施、选择运输舰和首次登陆有连贯路径；重返玩家不会被强制重播。参考：[Boomiversary 的按需解锁](https://supercell.com/en/games/boombeach/blog/blog/boomiversary/)、[任务 Go 定位](https://boombeach.supercell.com/en/news/updates/the-calm-before-the-storm/)。

### 8. 图像表达功能，字体负责少量关键信息

图标优先使用有建筑轮廓的功能图，而不是每格一个抽象线符号配说明段。生产、仓储、港务、防御应有可辨认的轮廓、材质和主色；同一家园保持统一透视、光源、阴影和接地尺度。中文正文与按钮选同一套清晰字体，以字号和字重建立层级，不用多套花字。画面中地形、建筑和人物承担美术主体，白色面板只在当前操作时出现。

验收：缩小到最终手机横屏尺度仍能分清码头、工厂、HQ 与炮塔；主要按钮文字四字左右；一张操作卡不再塞全量属性。原作素材只作参考，CAS 继续用原生程序地形和原创建筑美术。

### 9. 记住玩家上下文，反馈短而明确

关闭建设库、出航配置、招募和详情后，恢复岛屿镜头与选择；返回上一层和直接回母港各有明确入口。普通按钮使用约 120–200ms 的弹压/淡入，成功建设可有轻微落地、扬尘和短音效，但不为每个点按全屏转场。确认后出现实际结果而不是长说明弹窗。

验收：连做“拖视角→建造→取消→点设施→出航配置→取消”不会丢失上下文；收取、资源不足、非法建设和切换选择各有不同反馈；不会连续弹多个互相遮挡的气泡。参考：[皇室战争战后保留上下文](https://supercell.com/en/games/clashroyale/blog/news/mid-march-update/)、[海岛奇兵滚动与气泡改进](https://supercell.com/en/games/boombeach/blog/blog/frontline-improvements/)。

## 本轮最小验收路线

1. 新账号锁定岛 → 开始登陆引导 → 返回已解锁岛。
2. 建设托盘 → 选择建筑 → 在海里预览失败 → 在合法格预览 → 取消；资源与存档不变。
3. 再次预览 → 确认 → 点选新建筑 → 查看/升级 → 关卡片。
4. 拖拽/缩放穿过建筑 → 放手不选格、不落建；点顶部/底部 UI 不穿透。
5. 收取真实生产 → 看到到账 → 再次收取为无产出状态。
6. 出航 → 换目标、舰娘、运输比例和部队 → 容量反馈 → 取消保留视角；重新出航仍保留上次编成。
7. 用 960×540 与 1600×900 实际渲染截图，检查触摸目标、上下文卡、托盘和确认区。
