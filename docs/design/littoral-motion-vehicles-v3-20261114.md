# 两栖连队表现、时钟与载具（2026-11-14）

本轮只改变两栖战斗表现和显式10Hz模式的播放速度；不修改原始舰表、身体位置、射界、运输速度、伤害、弹药或历史规则。v3仍读取公开观察。原核与账户版本、三课胜负及原生/WASM相等门由对应负责人独立验收。

## 玩家操作

右上原生按钮切换1/2/4/8倍速，暂停文字显示当前倍率。每次推进仍是原核0.1秒整数微步；一次慢帧最多处理16步，其余时间保留到下一帧。没有跳过裁决、丢弃积欠或把动画时间当成命中。倍率进入本航次UI存档，恢复时保留。

海图拖舰到合法水面会以真实水路驶近；原核纯读`ship_move`预览给出可行路径和拒绝原因。拖向岛屿仍是炮向指令。海陆切换、相机缩放、同tick界面刷新只改变投影，不创建新身体或重播旧射击。

## 人物脚点与密集队形

旧真实raid基线中，24名行走者在同tick刷新后全部回到待机，海陆往返重新创建24个演员。本轮只在新原核时间、真实移动或真实伤害时改变动作状态；布局变化使用`reproject`，不重置动作。原有5位本人SD与敌方独立图集使用逐格透明轮廓测量的脚点和固定站立尺度，源PNG不改像素。不同姿态的透明留白不再拉动脚底；倒地仍以原核伤亡和阶段识别，正常回舰不当作死亡。

超过20名友方时，选中连保留本人完整SD；其他连以逐体类型兵牌显示并分连摆放，各自有短名称。所有50个真实身体都有独立可点击位置，点兵牌可以选择其本人连队；选中后恢复她自己的SD/本人肖像。没有为缺SD的15位借用别人的脸。分簇和细连线属于有限屏幕偏移，命令、碰撞、炮程和世界坐标仍以原核中心为准。远观兵牌不是新增身体或独立人格。

## 载具

`transport-variants-v3.json`登记20个本人专属默认型号，透明图集以Atlas区域读取，保留源图与可编辑元数据。登陆艇、两栖车、直升机分别使用实际公开family；改用非默认family时，用通用family装备加本人兵种牌，不借其他连的专属车。运输体按真实路线向量旋转，相邻同航道运输体有限散开并画回真实中心的细线。

运输中接近公开落点才使用投送图。每个型号各帧共用intact的`scale_reference`，舱门展开不会把整辆车缩小。直升机始终使用无白旋翼盘的完整机身，旋翼为程序动态；这些是静态机身姿态，不宣称多帧行走。低HP的变色和轻烟只读真实HP。027运输炮口闪光消费真实`transport_gunship`记录；本人空中身体也使用027自己的武直。保存恢复不会重放近期记录或补回弹药。

## 可编辑入口

- `res://scenes/ui/littoral_battle.tscn`：原生倍速、主/小地图与拖卡布局。
- `res://scenes/ui/tactical_sprite_preview.tscn`：F6/Inspector查看原5位本人12姿态，脚点由`data/tactical-sprite-anchors-v1.json`编辑。
- `res://scenes/ui/tactical_transport_preview.tscn`：F6查看20型号；Inspector的`preview_deploying`、`preview_damaged`只控制预览。
- `tools/build-tactical-sprite-anchors.py`只测量RGBA轮廓，重新生成脚点JSON，不修改美术像素。
