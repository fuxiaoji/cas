# 两栖拖动指挥 v2

玩家只需先学一个动作：把底部的卡拖到想处理的位置。海军运送、岸上作战、搜索和撤收延续同一个动作。海陆地图始终是同一场战斗的两个观察尺度，点击右上小地图交换，不暂停另一侧、不重新开图。

## 界面与操作

- 海图占主画面时，底部显示本航次部队。把本人部队卡拖到岛上，显示真实载舰路线与合法滩头；松手后载舰先靠岸，再发登陆艇。卡片显示“接近中”“运输中”“已上岸”，不把接受航令当登陆成功。
- 陆图占主画面时，底部同一排卡继续使用。拖到空地移动，拖到敌人攻击，拖到遗迹搜索。部队自动处理射程内交战，玩家指挥整队，不逐个身体点选。
- 在海图把实际舰艇拖向岛屿，调整真实炮位。陆图随后出现这一艘的舰炮卡；拖到落点，等实际射界、装填和弹药允许后开火。范围外、无弹和不能靠岸都先给落点反馈。
- 陆图只展示所选队伍的一张情境专长卡，详情与二次点选菜单承接低频操作。撤收卡拖回本人位置，存活身体真正回载舰后再显示返航操作。
- 海图返航卡拖到撤离圈，所有存活舰艇真实驶入后，再拖一次完成行动。中途可保存暂离；放弃行动保留实际损耗。

常驻只留主要目标、时钟、暂停、菜单、右上小地图与底部一排卡。钱包、全部详细数值、重复舰炮卡和多排工具面板不放回战斗画面。卡片有头像与类型兵牌，状态同时用文字说明，不能只靠颜色。

## 手把手教学

一条短指令、来源卡聚光、目的地聚光、循环手指拖动演示。玩家可以正常操作未高亮区域，也可收起帮助。没有“下一步”代替实际动作。

顺序是拖卡登陆→等待真实靠岸与上岸→点小地图→拖卡移动/攻击→回海图指向岛屿→陆图实际炮援→真实搜索→撤收回舰→海图返航→进入撤离区→真实结算。保存同时保留当前主图、选择与教学进度；恢复时以当前真实战况校验引导，不信任单独一个“已完成”字段。

若敌人提前被清除、遗迹已经真实搜完、所有舰炮确实耗尽，解释现状并调整相应练习，不要求攻击尸体、搜索空遗迹或凭空补弹。教学关闭/完成本身不发资源、不修船、不授岛权；解锁依旧要求原核真实成功。

## 二十编制与数值

`godot/data/tactical-profiles-v2.json` 从实际原核 `littoral_catalogue` 导出，供卡片和详情使用。每支部队有身体组成、HP、伤害、射程、装填、弹药、移动、运输占用，以及有限次数/冷却的专长。最多六支先遣队和六艘随行舰，仍受真实运输空间限制。

1000–6000是世界观下完整协议的身体上限。本航次派出3–4个先遣身体及操作装备，不能把协议上限显示成已免费获得的千人兵力。所有身体是同一女性人格的实例。

兵牌借鉴军事符号的类型语法，自绘并配中文名，不宣称APP-6合规。前五名有本人十二姿态SD；其余十五名用本人立绘肖像与类型兵牌，身份优先，不借另一名角色的小人。

新规则仅显式 `cas-littoral-v2`。旧v1航次恢复原版本与原数值，历史战役和原资料不变。数据与有限专长定义见 `docs/rules/littoral-v2.md`；最终实测、边界和证据登记在本轮开发记录。
