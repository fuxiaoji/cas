# 冒险海域与实体读招

本轮目标是让玩家从海面判断“该往哪里走、正在躲什么、何时可以还击”。仅在公开观察含 `salvage.adventure` 的新冒险航次使用这套信息层；历史战役、旧航次不获得新血量或实体情报。主舰、舰长与鱼雷仍落在原核坐标，界面不产生伤害或替玩家下令。

## 海面主次

- 海面、岛岸、地表、水波、云和天气均由程序绘制。主题使用原核种子生成的真实碰撞岛，不把固定CG当地图。
- 环礁使用明亮青绿浅海；雾礁水道偏蓝；峡湾为冷深蓝；沉城为青灰绿。天气、风和海况继续驱动原有云、雨和波纹。
- 主岛、长岬、弧礁与小碎岛形成体量差。遗迹和建筑基座仍在原核公布的岛内；标识不扩大可碰撞陆地。
- 新生成器 `archipelago-adventure-1` 的地标沿用公开 `landmarks` 接口，禁止因版本名变化而丢失沉城物件。

## 威胁信息层

每只已看见的异种只有一条短血条，蓄力时增加三角提醒。玩家点选后，情报卡才显示血量、招式、蓄力/恢复时间和一句反制。确实威胁己舰的公开预警可自动展开情报；远处预警继续显示在海上，不反复打断当前目标。既看不见的实体，也不能通过旧选中ID或残留预警恢复情报卡。

冲刺预警按原核 `origin→destination` 胶囊段绘制，有方向箭头与结束倒计时；脉冲、喷吐和弹幕沿用各自原核圆心、半径和实际时刻，进度环表示即将命中。免疫旗舰由公开 `exempt_ship_id` 排除，范围内的其他护航舰仍需要回避。

## 第一章教学节奏

1. 雾礁突围：选舰、画线、确认、开始时间；接敌时介绍憎恶不攻击旗舰的例外，并引导护航成员侧向闪避。抵达信标后仍需玩家明确集结撤离。
2. 半淹城市：介绍沿运河接近档案、进入750米搜索范围、减速，再实际打捞。喷吐和脉冲沿观察逐步介绍，不提前泄露未看见实体。
3. 渊喉峡湾：手动炮击与明确交还炮击授权；读公开落点、暂停调整航路、保持移动，观察阶段与弱点。受损舰拉低可用航速时，给出“按可用航速重新预览”操作，只调整草稿，确认下达仍由玩家完成。

教学可随时收起。每次只呈现一个当前步骤，已介绍的实体在本次战斗内不重复弹出介绍。危险提示优先，但不会替玩家移动舰队、开炮或撤离。

## 编辑入口与验证

`godot/scenes/ui/monster_intel.tscn` 为真实可编辑容器、标签与血条；位置、间距和字号可在编辑器调整。`monster_renderer.gd` 只读公开接触和预警；`chapter_battle_guide.gd` 只从命令证据、公开目标和实际终局推进教学。

玩家链测试为 `godot/tests/adventure_presentation_review.gd`：隔离新账户，从剧情推进到三个实战，指针画线/炮击/重新规划、实际搜索与撤离、真实胜利结算与奖励幂等。种子环境测试为 `godot/tests/adventure_environment_review.gd`：四个主题各三种子，原核重复性、实际不同碰撞几何、建筑完整、相同视觉时刻像素相同、波云随时间变化和观察不变。最终运行结果记录在对应 `artifacts/godot/adventure-presentation/receipt.json` 与 `adventure-environment/receipt.json`。

最终v1窗口412/412，三场真实胜利为68秒/65秒/109秒；环境120/120。俯视多姿态实体与v2五场景的后续实现、原图台账和200项真实窗口验收见 [表现验收](../development/expedition-presentation-receipt.md)。
