# 岛屿经济建设与自主布防详细计划

日期：2026年11月15日。状态：设计与后续实施计划，尚未实施。适用范围：原创家园、原创海岛攻防、自家无损演习及相应的新教学。

本计划将家园生产、角色养成、地形建设、驻军和两栖作战连成一套有实际取舍的系统。玩家决定把防守重心放在哪里，也决定牺牲多少经济空间换取防御。装甲保持突破能力；登陆条件、专业反装甲设施和步兵清剿共同限制装甲包办所有任务。

2026年11月15日追加场景风格要求：根据用户五张参考截图，岛屿地形与环境改进为斜俯视、连续地表、有真实空间关系及明确光影的战术场景。第十九节明确当前截图问题、参考拆解、自然海岸与地貌生成、街区和植被组织、素材与渲染路线，以及逐阶段视觉验收；并纳入P0至P6交付。

本轮只交付计划，不修改运行代码、游戏数值或账户。本文的起始参数、公式和版本名是后续原型的建议基线，不是已经生效的规则。历史CAS想定、原始PDF、参考项目、已发布规则和已有航次继续按各自版本运行。

## 一 用户已明确的设计要求

| 要求 | 必须形成的实际行为 |
| --- | --- |
| 装甲和两栖部队目前过强 | 同预算下，纯装甲不能在各种地形与防守配置上都占优 |
| 可卸载的登陆沙滩通常只有几处 | 根据真实岸线、坡度、滩宽和装备条件确定登陆区，禁止任意岸线卸载 |
| 滩头可能有反装甲炮 | 单发反甲伤害高、爆炸范围小，对分散步兵效率低 |
| 多人数海军陆战队承担清剿 | 分组接近、持续作战、占据阵地有价值，不以大量伤亡耗尽岸炮作为唯一解法 |
| 丰富防御设施且可以升级 | 不同目标、射界、射程和升级专精形成组合 |
| 军营可以驻扎防守部队 | 使用真实有限的驻军、预备队和反击行动，不无限刷兵 |
| 有战壕 | 实际影响人员占位、直射掩护、侧翼和阵地争夺 |
| 可以自定义岛屿 | 家园建设结果进入战场，改变实际路线、建设条件和防守布局 |
| 防御有发展代价 | 山地、工事、军营与港口、农田、工厂争夺土地和投入 |
| 防守重心由玩家决定 | 岸防、纵深、核心区、机动防守均可选择，没有强制固定防线 |
| 家园经济需要更重要 | 稳定产出基础建设资源、养成物资和通用货币，支持实际消费 |
| 岛屿达到所提供图片的场景质感 | 改进生硬岸线、等宽沙滩、平台状山地、重复草地和零散摆件，形成连续、自然、有组织的战术环境 |

后文有关升级层级、离线时长、掠夺比例和施工费用的建议，不等于用户已确认这些具体数值。实施时先在隔离演习中校准，再登记最终配置。

## 二 当前基础与改造边界

当前项目已有家园建设、浮材/合金/能源生产、仓库、船坞、岸炮、近防机枪、迫击阵地、防空、海防导弹、整备节点、驻防与无损演习。新系统应先核实这些设施在最终安装版本中的真实效果，再决定扩展或替换，不能再做一套名字相同但不参与战斗的建筑。

当前 `home_service.gd` 的家园基础生产采用按小时产出、最多累计8小时和资源容量上限；家园 `resources.credits` 的显示名为“岛屿补给”，账户 `wallet.credits` 才是通用银币。两者必须分别迁移，禁止因为字段同名就相互覆盖或自动兑换。

当前显式 `cas-island-war-v4` 已登记27本人、独立人车、固定投送工具、普通艇近岸卸载、两栖水陆速度差异、真实车后掩护，以及家园与战场共用地理。新计划沿用这些已登记身份与编制，不把“平衡”当作重做人物设定的理由。

现有v4建设地址使用120米格，实际建筑与道路另有米制尺寸。精细农田、战壕与多格建筑不能直接当成一座占满120米的巨型建筑；后续需要新增更细的建设占地校验，同时保留旧地址映射。

建议为本次组合规则预留 `cas-home-economy-v2` 与 `cas-island-war-v5`；开工时先检查版本占用，正式名称以实际合同登记为准。不得直接给现有v4换数值。

## 三 家园与作战的完整循环

家园生产提供银币、建设资源和养成材料；玩家选择建设、训练、维修或储备；舰队和陆军携带有限补给远征；战斗通过实际夺点、搜索、装载和撤收取得额外收益；收益回到家园支持下一轮建设。驻军、工事和地形改造保护生产，同时占用发展条件。

玩家每次回家至少能作出一种有意义的决定：扩建生产、调整生产任务、训练某支部队、补充战损、改造一处地形、强化一个方向的防御，或者保留资源准备远征。

家园承担可预期的日常成长，远征提供额外收益与稀缺资源。常用养成不能完全依赖抽取；高阶材料也不应通过无上限离线生产迅速取代探索。

建设不强制照着固定顺序完成。教学只要求玩家实际建成、生产和安排一次驻防，后续可自由选择发展方向。

## 四 经济资源与消费关系

### 通用货币与资源分类

| 类别 | 主要来源 | 主要消费 | 约束 |
| --- | --- | --- | --- |
| 银币 | 商港贸易、生产订单、既有任务与远征 | 既有养成支出，以及新建设、维修和研究的货币部分 | 统一进入既有通用钱包，不创建第二种同名银币 |
| 浮材与合金 | 既有回收站/工坊、工厂、带回物资 | 建筑、工事、地形工程与维修 | 复用现有资源，控制新增材料数量 |
| 能源 | 既有能源设施及后续扩建 | 生产配方、设施整备、部分研究 | 不新增一套逐秒电网作为首版前置 |
| 农业物资 | 农田、贸易 | 民生订单、后勤配方和指定整备任务 | 农产品服务居民、贸易和后勤，不写成机器人必须吃饭才能行动 |
| 训练记录 | 训练场定向生产、既有资源海域 | 对应对象的等级经验与训练 | 映射既有合法物品，不凭空增加第二套同名训练经验 |
| 装备与维修材料 | 工厂生产、回收、远征 | 实际可用的装备强化、车辆维修 | 逐项核对已有消费者，未接入的配方不开放生产 |
| 突破及研究材料 | 研究设施加工、远征稀缺原料 | 已有突破和新专精解锁 | 高阶产出受原料和加工能力限制 |

家园不稳定生产元词、招募券或其他高价值抽取资源；若未来增加，需要另行设计，不能隐含在“通用货币”里。本计划中的通用货币明确为银币。

### 生产流程

经济设施使用“生产任务—经过时间—得到库存”的统一流程。单一设施同时执行一个任务；增加设施或升级可提高吞吐量，不能一座工厂同时满效率生产所有材料。

基础回收、电站和农田可选择持续生产；工厂、训练场和研究设施使用可持续排队的配方。玩家可以保存生产安排，并在返港时批量领取，避免反复点击每一块农田。

建议首版保留现有8小时离线上限作为对照，另测12小时与24小时候选。最终应支持每天一次至两次自然回家节奏。容量满后暂停新增产出，不销毁已有库存，也不因离线扣除驻军生命或导致欠费破产。

每种产物建立独立容量或明确共享容量；界面显示实际受限原因。生产预览按输入物资、有效时间、设施状态、配方效率和剩余容量计算，带小数的产出保留余量，不能反复领取刷取舍入差额。

改配方、升级、迁移、断路、受损或改变加成前，先按旧状态结算到变更时刻，再应用新状态。禁止先升级再用新产率回算过去几小时。

### 收支与恢复底线

先用现有银币消费、部队维修和训练成本建立普通新号、中期、满级三档收支表。分别计算维持日常远征的成本、一次常规建设的积累时间和一次失败后的恢复时间，再倒推产率。

首轮调参以“同发展阶段，一次完整离线积累能够支持至少一项可见的基础投入”为目标；具体投入可以是小规模补员、基础训练或低阶建设，不能要求一天同时完成全部升级。

军事设施的建设、升级、维修和出战补给构成主要代价。首版不采用会持续扣成负数的离线军费；若需要补给消耗，在实际装填、整备或出战时扣取，并设明确上限。

保留一条低收益、低门槛的基础恢复来源，确保受袭后仍能获得维修与基础生产所需资源。不能所有收入都依赖已经停产、又需要收入才能修好的工厂。

## 五 经济设施设计

| 设施 | 核心功能 | 选址与布局取舍 | 升级方向建议 |
| --- | --- | --- | --- |
| 商用港口 | 银币贸易与农业/工业订单交付 | 占用适合靠泊的岸线，必须有真实可达海路和连接内陆的道路 | 贸易吞吐、库存与订单种类 |
| 农田 | 农业物资与基础贸易原料 | 需要连续缓坡或平地，占地大；无法与完整工事重叠 | 单位面积产量、储存与加工配套 |
| 工厂 | 建材、维修件、装备材料 | 需要连续平地与运输接入；与防线、道路和农田争夺土地 | 生产效率、配方种类，专精分支 |
| 训练场 | 定向训练记录 | 占据平整用地，承担后方保护需求 | 队列容量、训练专精，不能无限复制训练收益 |
| 研究设施 | 突破原料加工与设施专精研究 | 造价高、价值集中，适合保护但占用纵深空间 | 加工效率与解锁选项 |
| 仓库 | 保存本岛物资与待转运产品 | 集中便于运输，分散降低一次失守损失 | 容量、保护额度或装卸效率 |
| 能源设施 | 提供既有能源资源 | 依具体类型要求地形，仍需保护 | 产量与储能 |
| 维修设施 | 建筑和载具的恢复服务 | 消耗材料并占用建设空间 | 恢复效率或服务容量 |

保留现有停泊船坞的驻防舰职能。商港与军用船坞可以同处港区，但使用独立泊位/设施容量；不能建一个商港就免费获得无限驻防舰与无限贸易。

经济建筑不是自动给予全岛防御惩罚的开关。农田形成开阔地，既可能利于装甲通过，也可能利于守军射击；厂房能遮挡视线和提供局部掩护，也可能让敌人接近。实际优势来自地理、结构与布置。

升级以提高已有设施用途为主。早期开放港口、农田、工厂和仓库的基本版本；研究与高阶加工逐步开放，避免家园刚解锁就必须理解完整工业链。

## 六 土地 地形与建设约束

### 自由布局的范围

玩家可移动合法建筑、修路、修建阵地，并通过工程改造局部地形。岛屿扩展继续扩大真实可用范围；不能只放大画面或把原设施挤小。

山地减少工业可建平地并影响通路、视线和车辆机动。保留山地通常有利于形成障碍，但也会妨碍己方调动，不能让每块山地同时获得高产出、完美射界与无代价通行。

首版支持局部削坡、平整土地、修建坡道和道路。大规模造山、填海与海岸改线列为后续工程项，只有在导航、海路和登陆合法性都能同步更新时开放。

### 建设校验

每次放置检查完整占地、高差、与现有建筑及道路的冲突、合法通路和资源费用。工厂要求整个占地符合平整条件，不能只检查中心点。农田、战壕和道路使用各自占地区域，不按一个通用圆圈判断。

现有120米格保留为旧地址映射；建议新建设校验以10米子格试验，建筑保留真实米制占地。10米仅为待测的全局原创工程默认值，开工时登记精度、性能和小设施的适用边界；不得每座岛临时改比例。

放置预览应显示占地、合法与否、道路连接，以及预计产出变化。移动和改造前先预览，取消不扣费；确认后提交一次事务。

### 防止无解岛与瞬间换阵

生成地形和每次工程完成后，都检查海上接近、合法登陆、登陆后到任务目标的可达路径，以及部队撤收条件。使用按装备类型区分的通行图，不能以步兵能走证明坦克也能走。

山体不能被攻击方清除时，必须保留合法绕行路线；可破坏工事可以封锁道路，但应当有可被对应武器打通的突破方式。军营、农田和仓库也不能成为不可摧毁的寻路堵口工具。

大规模地形工程和建筑迁移有时间、资源或施工期间停产的代价；战斗中不能瞬间换成另一套布局。保存多套蓝图只保存设计，应用蓝图仍计算实际工程费用与工期。

本地防御战开始时固定布局与经济状态版本。战斗和施工的时间关系在账本中明确登记，不能同一工厂被打毁后仍按完好状态补发相同时间段产出。

## 七 登陆区与各类投送

登陆区由海深、岸坡、滩宽、障碍、载具外形和上岸后可达性共同生成，并以岸线区段呈现。普通岛先以2至3处主要登陆区为原型目标；岛级增大可增加，但最终数量服从实际几何，不能强制所有岛长得一样。

| 岸线条件 | 主要可用方式 | 战术作用 |
| --- | --- | --- |
| 宽阔缓坡沙滩 | 重型登陆艇、普通艇、两栖车 | 可大量投入重装备，也容易成为守军重点方向 |
| 较窄沙滩或部分浅滩 | 满足型号条件的轻型艇/两栖车 | 绕行与分散登陆，卸载与展开容量较小 |
| 陡岸和悬崖 | 默认禁止普通海上投送 | 形成地形边界，不虚构现有部队攀崖能力 |
| 合法内陆空输区 | 现有合法航空投送 | 可越过部分海岸阻碍，受航程、防空、下降与撤离约束 |

是否允许某型两栖车利用狭岸，必须按真实注册的原创型号条件确定。保留两栖车比普通坦克更灵活的上岸选择，但不允许穿崖、忽略高差或直接在内陆生成。

重型装备卸载受滩宽、艇位、坡道和车辆占位约束。多个连队不能同时重叠落在同一点；队列等待、改换登陆区和取消投送都应可理解、可操作。

登陆区不是永久安全区：守军可以布防、射击和反击。系统也不强制守军把炮全放到海滩。进攻者查看规则允许公开的登陆条件和已知威胁，再决定正面突破、分兵、空输或先用支援火力。

## 八 战术部队制衡

| 部队类型 | 需要保留的优势 | 对应代价与克制 | 主要协同对象 |
| --- | --- | --- | --- |
| 普通装甲 | 稳定直射火力、防护、突破设施 | 重型投送与道路要求高，怕专业反甲阵地 | 陆战步兵、工兵、侦察 |
| 两栖装甲 | 同体渡海、上岸选择较灵活、持续支援 | 受反甲火力、岸坡、展开空间与载具损失限制 | 清剿步兵、火力压制 |
| 大编制海军陆战队 | 分组展开、持续清剿、占领阵地 | 暴露时怕机枪与范围火力，需要掩护和补给 | 装甲、工兵、迫击与舰炮 |
| 工兵 | 开辟可破坏障碍、近距工事爆破 | 必须实际接近，炸药与行动次数有限 | 步兵护卫、压制火力 |
| 侦察与标记部队 | 获得目标信息、提高支援利用效率 | 自身攻坚能力有限，必须在规则允许条件下观察 | 舰炮、航空、远程火力 |
| 炮兵 | 压制密集阵地、处理部分遮挡后的目标 | 有限弹药、需要合适阵地，怕近身和绕袭 | 侦察、步兵屏护 |
| 空降与空突 | 选择纵深落点、牵制后方 | 怕防空，投送与撤离有风险，不能无限补员 | 地面突破与防空压制 |
| 保障部队 | 提高既有真实整备/战斗效率 | 本体火力有限，效果受现有能力定义约束 | 多兵种持续行动 |

先处理登陆自由度、岸炮专长和作战目标，再决定是否需要改装甲数值。不能同时砍装甲耐久、伤害、速度与装甲倍率，导致无法判断哪项改动有效。

022/103等既有随行步兵可以处理孤立、缺乏掩护的炮位。专业陆战队的价值体现在多方向攻击、清理有机枪和战壕保护的完整阵地、占领多个目标，以及保持战斗持续性。不得让任何一支现有部队自动拥有新的工程或反甲能力。

维持最新27本人目录中敌我对称的身体HP与既有车后掩护定义；若后续需要调整，另列原因和版本化数值差异，不在设施改造中隐含撤回。

## 九 防御设施与升级

### 首版防御组合

| 设施 | 主要任务 | 明确弱点 | 升级专精建议 |
| --- | --- | --- | --- |
| 近防机枪阵地 | 压制暴露步兵、保护炮位 | 对装甲效率低，射界和掩体朝向有限 | 远程压制 / 近距离持续火力 |
| 反坦克炮阵地 | 高单发穿甲、小范围杀伤 | 装填慢、转向慢，怕多方向步兵与近距突入 | 重穿甲 / 快速反应 |
| 迫击炮阵地 | 对付集结部队与部分遮挡后目标 | 近距盲区、散布、有限弹药 | 远程压制 / 更快响应 |
| 喷火或同类近程阵地 | 防止步兵贴近关键设施 | 射程短，怕远程打击和装甲 | 更宽覆盖 / 更强短时阻拦 |
| 防空阵地 | 限制航空支援与空中投送 | 地面火力有限或没有，占建设空间 | 近程快反 / 中距拦截 |
| 军营驻地 | 驻扎、派出真实部队与预备队 | 固定驻扎容量与有限兵力 | 快速出动 / 阵地整备 |
| 战地整备节点 | 支持有限维修与持续防御 | 服务范围、储备和总恢复量有限 | 服务容量 / 恢复效率 |

现有通用岸防炮、海防导弹、地雷/水雷和其他设施逐项保留或显式登记映射。首版不把原有设施静默删掉，也不为凑新类型而制造功能重复的塔。

反坦克炮命中步兵仍然可以造成严重伤害，但小爆炸范围、慢装填和有限射界降低其清剿分散步兵的效率。守军优先攻击装甲目标；改变目标需要真实转向与装填状态，不允许瞬间全向点杀。

### 升级结构

建议采用基础级、强化级、专精级三层结构。进入专精时二选一，展示收益、费用和仍存在的弱点。先验证少量清楚的分支，再考虑更多等级。

一座反坦克炮不能同时升成高穿甲、高射速、大范围、全向反步兵炮。较高数值要付出更高建设、占地或补给代价；设施专精主要拓展用途，不与角色养成叠出无上限倍率。

首版不另设复杂电网、十余种炮弹物流和逐发人工补给。武器射击仍受注册弹药、装填、射程和目标规则约束；阵地战前补充与战后恢复以统一预览呈现。

## 十 军营 驻防与战壕

军营管理真实驻防连队。玩家可以分配守卫区域、巡逻路线、预备队待命点和反击触发条件；连队按真实位置行动，不在警报发生后传送到目标。

以稳定 `company_id` 分配身体和载具，允许同一人格的不同合法连队承担不同任务。同一连队不能同时出征与驻防；不能因此把整个MCP人格所有连队一律锁死，也不能超过既有编制和整备库存。

军营升级增加容量、整备服务或出动效率，不生成免费身体。战斗中的增援只能来自实际未投入的预备队；补员、医疗与车辆维修按真实损失结算。

战壕按入口、容纳位置、朝向和分段连接形成设施。人员必须实际进入合法位置才能获得对应掩护；从前方受直射、从侧后受击、遭受曲射或近距离攻坚的效果分别登记。

空战壕不提供火力，也不自动减少区域内所有伤害。敌方清剿后可占用仍完好的战壕；战壕之间有真实通路，不能把连续动画当成瞬移。

掩护效果先对齐现有车体遮挡与地形系统，明确哪些属于实际遮挡，哪些属于注册的概率/伤害修正。未实现完整三维弹道时，不宣称战壕能按现实剖面逐发防护。

## 十一 自主布防与多样进攻目标

玩家可以把防御集中在滩头、工厂区、仓库、指挥中枢或机动路线。编辑器不要求每座岛必须有三道防线，也不因外围设施缺少炮位判为非法。

原型至少制作四种同发展预算的示范布局：贸易农业型、工业纵深型、岸防要塞型、驻军机动型。这些是验证和参考蓝图，不是给玩家绑定的职业或不可更改的发展路线。

攻击任务分为有限掠夺、设施破袭和核心夺控三类。每场战前说明哪些目标产生收益、是否需要装载带走、何时允许撤离。只打外围仓库可以获得有限战果，但不自动算作攻陷全岛。

摧毁工厂主要影响产能和维修费用；占领仓库才能按规则取得其中可掠库存。不能每炸毁一座设施就凭空产生一份与实际库存无关的资源。

舰炮与航空支援保留价值，仍受实际舰艇、航程、观察、弹药、散布和支援时机限制。通过分散布置、掩护与目标选择形成取舍，不给所有陆地建筑增加任意“免疫舰炮”属性。

## 十二 掠夺 战败与经济恢复

建议只把本岛可掠库存和未转运产品纳入掠夺。已经进入通用钱包的银币、角色、协议、已投入养成、母港实物和建筑等级不直接扣除。商港待结算贸易款在入账前可按明确规则承担风险；入账动作采用固定周期或统一转运条件，避免靠点击速度规避所有风险。

可掠数量建议采用“实际可掠库存乘任务比例，并受本场上限、货舱和实际带离数量约束”。比例与上限由发展阶段和任务类型登记，不在本计划中假定已定值。攻击方到账与防守方扣除使用同一结算凭证。

本地NPC岛可按公开规则恢复库存，但同一战斗不能反复领取。不得为了展示奖励而写入正常玩家账户，也不把本地人机入侵描述成联网袭击。

设施受损后按状态降低或暂停生产；维修恢复功能，保留建筑等级和原有研究。反复受袭的损失间隔、累计损失上限和恢复期在原型中测试，不能让一次失败引出无限连续掠夺。

仓储保护与恢复来源在资源规划中始终可见。自家演习复制布局、库存和双方部队，只产生演习报告，不改变真实经济、整备、施工、奖励或活跃航次。

## 十三 家园操作与信息呈现

继续使用岛上直接操作、图片和拖动。点击建筑显示当前生产、库存、升级与迁移；点击军营显示驻军和预备队；选中工事显示真实射界、覆盖和朝向。

建设过程为选择设施、在岛上预览、查看费用与影响、确认施工。数值输入使用滑块，名称和搜索保留文本。新增设施不把家园改回常驻表格控制台。

提供可切换的建设覆盖层：可建平地、道路连接、登陆区、设施射界和受保护库存。每次只突出当前操作需要的信息，不把所有热力图同时叠满海岛。

升级或改地形时，预览至少说明占地、总费用、停产时间、产出变化和通路变化。非法操作解释具体原因，例如“工厂东侧占地超过坡度要求”或“此工程会切断最后一条合法上岸通路”。

生产支持统一领取、安排持续任务、显示预计满仓时间。战后报告说明哪些设施受损、多少库存被带离、维修需要什么，提供一键查看恢复方案。

岛屿地形与环境按第十九节的新参考方向制作：采用更有材质、体积和空间组织的战术场景，人物身份、已认可SD与界面保持既有约定。港口、农田、工厂和工事以可复用建筑/地表散件构成；设施朝向、施工和受损表现跟随真实状态，不使用固定整岛照片替代自定义地图。

## 十六 平衡验证与验收门

### 同预算对照

测试使用相同发展阶段与明确的部署、载运、弹药和整备预算，比较纯装甲、纯步兵、步坦混合、步兵工兵、空地协同等配置。每种方案按其合法容量配置，不用相同人数伪装成相同成本。

分别在宽滩、狭滩、多坡地和工业区布局上作战，覆盖反甲偏重、反步兵偏重、防空偏重和混合守军。记录任务成功、实际带离收益、身体与载具损失、消耗、耗时、改换登陆区次数及关键目标摧毁顺序。

先用固定种子与同命令对比定位改动效果，再以不同种子和人工操作检查适应性。样本数量与结论可信度随报告公开，不用少数演示局宣称所有兵种已经平衡。

判定方向：反甲岸炮应提高纯装甲正面进攻的代价；缺少反步兵掩护的岸炮应能被合适步兵清剿；混合阵地需要协同但至少存在可执行的突破方案；两栖车在部分合法岸线仍有独特价值。

经济布局比较同投资的净产出、受袭损失与恢复时间。堡垒布局可以更难攻，但正常产能必须付出代价；经济布局可以收益更高，但需要承担更长运输线、重要目标暴露或较少工事覆盖的实际风险。

### 必须通过的边界场景

| 场景 | 通过条件 |
| --- | --- |
| 非法登陆与拥堵 | 不穿崖、不内陆刷兵、不叠车卸载；可等待、改派与撤回 |
| 仅剩一个合法入口 | 改地形不能消除最后通路；可破坏障碍仍能被实际清除 |
| 驻军出征冲突 | 同一连队与载具不能重复使用，不凭空增员 |
| 反甲炮遭步兵侧袭 | 转向、装填、射界和小范围杀伤真实生效 |
| 战壕与掩护 | 只有真实入位人员受对应保护，侧袭/曲射按登记规则处理 |
| 港口或道路受损 | 对应运输和生产效果改变，原因可见，修复可恢复 |
| 升级或切配方后领取 | 变更前后分段结算，不按新产率追溯过去 |
| 满仓与离线 | 不超容量，余量明确，暂停不销毁已有库存 |
| 时间回拨与加速战斗 | 不刷取产出，不因模拟倍速提高经济收益 |
| 重复结算与中途关闭 | 不重复扣费、发银币、生产或领取掠夺奖励 |
| 战败恢复 | 不失去角色/建筑等级，存在可执行的低成本恢复路线 |
| 自家演习与录像 | 不影响正常账户、施工、库存、体力、战损和奖励 |
| 旧档与旧航次 | 无静默升级；历史阵位、表值、地标与旧回放保持冻结 |

原核新增规则必须完成原生与WASM相同输入重演；浏览器真实点击/拖动及Godot实际窗口验证覆盖放置、生产、驻防、出击和战后恢复。教学成功绑定真实行动结果，不能读完说明就通过。

最终报告分清实际完整对局、构造边界测试、纯展示截图和未实现能力。所有仍影响玩法的近似、简化与缺失写入版本源笔记和blockers。

## 十七 主要风险与处理顺序

| 风险 | 处理方式 |
| --- | --- |
| 少数登陆点形成无解火力口 | 验证投送容量、多方向路线与支援窗口；保留地理合法的替代打法 |
| 陆战队变成纯人数消耗品 | 让分组、掩护、侧袭和占领产生价值，限制单目标炮的清剿效率 |
| 装甲自带步兵仍包办所有任务 | 比较同预算的目标处理效率与持续作战能力，完整阵地需要多方向处理 |
| 舰炮一键清空所有防御 | 保留实际弹药、观察和支援条件，以布局分散迫使目标取舍 |
| 经济最优解挤掉其他布局 | 同时检验产能、运输、防御、损失与恢复，不只比较每小时银币 |
| 发展优势滚成无限军事优势 | 土地、驻防编制、运输与专精限制不能被单纯货币消除 |
| 战败造成长期破产 | 保护既有成长、限定可掠范围、保留基础恢复来源 |
| 材料与生产链过多 | 优先复用已有材料和养成消费者，先跑通少量配方 |
| 旧格网损坏地理尺度 | 保留旧地址映射，新占地用米制，家园战场同源核验 |
| 建设预览与战场不一致 | 同一权威几何/设施目录校验，客户端只显示结果 |

先解决决定兵种是否有用、土地是否有取舍、账本是否守恒的问题，再扩大升级树与美术数量。

### 自然岸线与沙滩

先确定岛屿的大尺度形状、海湾、岬角、山脊和低地，再生成局部岸线细节。轮廓应有长短变化和曲率变化，不能只对规则多边形边缘增加密集小锯齿；各处也不应都呈相同圆弧。

海岸至少区分缓坡沙滩、砾石/岩岸、陡崖与人工码头。沙滩集中在合适地形和海湾中，岩岬、崖岸与码头自然打断沙滩，不再让一圈等宽黄色带承担所有岸型。

沙滩按局部高度、坡度和距海距离生成变化：浅水、湿沙、干沙、背滩碎石/低矮植被、内陆地表逐步衔接。带宽沿岸变化，湿沙颜色和细节与干沙区别明确；局部可有冲沟、漂积物和退潮痕迹，避免重复平行条纹铺满整岛。

浅海颜色随登记的水深与底质变化，浪沫沿真实海陆交界组织，海湾与岬角表现有所区别。水波动画不能使视觉海岸游离于真实登陆和碰撞边界；地图实际没有潮汐机制时，不用移动水位改变可通行范围。

可登陆沙滩与不可登陆岩岸必须在正常操作距离有可辨外观，选中投送时再显示精确区段。美术不能画成缓坡沙滩而原核判悬崖，也不能靠美化岸线扩大或缩小旧版陆地。

### 连续地貌与地表材质

山地从山脊、坡面、沟谷和坡脚整体生成。保留需要的高地/低地和坡道，但减少相同高度、相同侧壁、孤立摆放的规则台子。陡崖应有侧面结构、材质变化和坡脚堆积；缓坡应有连续高差，不能全部用垂直切面连接。

河道根据低地与下游方向组织，汇入海湾或登记的出水口。河岸两侧有湿润带、局部裸土和植被变化；不要求首版实现实时水文，但禁止河流视觉上爬坡、悬空穿山或无解释地在平地截断。

地表分为大尺度色调、中尺度区域变化和近景微细节。草地有干湿、疏密、裸土与磨损；沙地有细颗粒和低幅起伏；岩面有方向与层次。材质混合参考高度、坡度、湿度、道路与使用状态，避免无规则噪点铺满所有区域。

纹理按世界米制设定密度，远近镜头保持一致，不随缩放把草叶变成巨斑。采用多种变体、受控旋转与混合遮罩减少重复，同时保留地形方向信息。远景降低微细节，避免闪烁、网纹和过度锐化。

允许生成时执行有界的平滑与侵蚀近似，以去除尖刺和不合理小盆地；具体算法由原型决定。形状自然并不等于每次随机：所有改变地理的处理必须版本化并可重演。

### 道路 街区 港区与农业空间

先规划岛上功能分区与主要交通联系，再生成道路和可用地块。主路连接港口、工业区、居住/服务区与驻防节点；支路接入建筑入口和工作场地，土路进入农田与乡野。道路能有规则街区，也能有顺应地形的曲线，不把全岛套进同一斜格网。

道路需要路缘、路口、桥头、坡道连接和清楚的终点。桥梁跨越真实河道，两端道路实际接通；道路遇到崖壁应转向、设合法坡道或止于明确设施，不能在崖上、崖下各画一条却假装连通。

建筑按街区和地块组成小群体：沿路的朝向、合理的退界、院落、围墙、装卸区和绿化共同确定空间。建筑外观可以有不同用途和高度，但透视、地面锚点、比例、材质精度和光照方向须一致，减少“独立插画贴在大草坪上”的感觉。

港口有连续岸壁/栈桥、泊位、仓库和装卸场，并与道路连接；农田有成片地块、田埂、农路及按需设置的排水沟；工厂有厂房、料场和服务道路。装饰细节不能挤占玩家已经安排的真实占地或凭空附送经济容量。

道路、围墙、树木与建筑之间保留适合当前单位尺寸的实际间隙。环境细节要支持经济建设和军事布防的空间取舍，不能用大片背景摆件让可建土地只剩视觉上的空地。

### 植被与地面散件

植被采用“区域密度—小群落—群内变化”的组织方式：林地内部有疏密和空隙，林缘由乔木向灌木/草地过渡，孤树只占少量。道路行道树和人工绿化可以整齐，野外树木不能按固定间距撒满全岛。

植被与高度、湿度、土壤、坡度和功能分区相关；碎石沿岩岸、坡脚或冲沟出现，草丛沿未铺装边缘生长。避开道路中心、建筑内部、港口水道、必要的卸载空间和出入口。

每种地物设置变体、朝向、尺度范围和最低间距，兼顾局部聚集，避免“每棵树都一样”和随机散点噪声。不能仅把现有小树放大来弥补空旷；应同时检查真实尺寸、群落范围与镜头。

影响碰撞、掩护和视线的树木/岩石进入权威地物目录；纯装饰草叶不获得战斗效果。装饰的随机流与战斗随机流隔离，增加一片草不能改变同局命中结果或登陆区。

### 光影 投影与可读性

地形、建筑、树木和载具使用同一场景光照方向与统一的冷暖关系，表现接地阴影、楼体立面和地形侧面。可采用适合现有渲染方式的阴影与环境遮蔽近似，但不能把黑边和深色滤镜当成立体感。

镜头目标为参考中的斜俯视空间感，同时保留现有海图真实比例与陆图局部镜头。不得为了匹配参考图透视而改变真实坐标、碰撞、射程或移动路径；地形投影、选中圈、建筑入口、人物脚底与弹道继续对齐。

建筑和树冠遮住可操作单位时，采用轮廓、局部淡化或适合现有架构的遮挡处理；不永久移除建筑侧面来获得可读性。单位选中与敌我识别要在草地、沙地、阴影中清楚，环境细节不应盖住弹道和命令标记。

阴影首先是视觉表现。若未来加入阴影影响观察/隐蔽，必须另列战斗规则并由原核计算，不能客户端画面变暗就自动获得减伤。雪地、沙漠和温带可使用各自整体材质方案，不在同一小岛随意拼出几种互不相干的气候。

### 生成与渲染路线

先将工作拆成地理生成、场景组织、渲染三层。地理层保存岸线、高程、河流、坡道和可达性；组织层保存路网、地块、建筑和有战术效果的地物；渲染层据同一数据生成材质混合、细部、阴影和视觉层级。

生成次序建议为：功能与地貌骨架、岛形与高差、岸型/水系、道路与地块、玩家建设/工程变更、地物组织、细节与光照，最后验证建设和全类别通行。道路或工程改变地表后，局部重算相关地块和地物；不能修改一条路就随机重排所有建筑与森林。

先制作一个海岸到街区的局部可运行样区，验证现有斜俯视绘制、材质与高度投影能否达到目标。可使用原创模块、贴图、网格和程序绘制组合。若现有方式无法支撑参考质感，由P0提交两种可比较的渲染原型及性能/改造范围，再决定是否引入更多三维场景能力；本计划不直接承诺整套引擎重写。

家园、陆战与海图共用地理及设施ID，不同镜头使用对应细节层级。全岛远景突出轮廓、地貌和功能区，中景表现道路/街区/植被群，近景显示材料和小物件。远景合批、分块缓存和按需细节应保持确定性，不能靠减少模拟推进量改善帧率。

生成结果保存内容版本与必要的地理快照；跨平台涉及浮点噪声差异时，以权威导出/稳定表示核对。不能只保存一个种子并假定更换算法后还会自动生成同一座岛。

### 视觉验收与证据

固定保存地图种子、岛级、布局、相机位置/缩放、时间与天气设置。使用家园全岛、滩头中景、湿沙近景、山坡/崖壁、河桥、港区、工厂/农田、城区及部队同框作为成套截图；前后对比使用相同尺度，不能用拉远掩盖细节，也不能只截最漂亮的一角。

原型建议覆盖至少3个固定种子，以及新增种子抽查；包含低等级起步岛与高等级扩建岛。检查不同岸向、山坡、桥头和施工改地形后的结果。具体抽样数在P0登记，缺陷数量和抽查范围随报告说明。

必须逐项通过以下标准：

- 全岛轮廓不呈少数粗直边拼成的规则饼状；细节不是统一频率锯齿。
- 沙滩宽窄和岸型有合理变化，浅海—湿沙—干沙—内陆连续，普通镜头看不到拼接线。
- 正常沙滩、岩岸与悬崖的视觉分别符合真实通行规则；显示岸线与碰撞边界对齐。
- 高地与河谷有连续地貌关系；桥头/坡道可达，路面不悬空、不穿过崖壁。
- 草地等大面积材质不出现显著重复棋盘、拉伸、接缝和远景闪烁。
