# 五部队进攻失败与战后清理CG

用户指定所贴溪口失败图为密度参考，要求稍增倒地数量、再提高俯角，为五名新部队各制作一张进攻失败CG；另各制作一张敌方战后清理CG，遗体整齐排成一排，约半数取下外套与鞋靴，物资集中摆放。共10张，另存新目录，不覆盖此前中等数量CG。

- 303栗遥：蓝飞行夹克、浅蓝衬衣、棕马尾，溪口与沙丘双火点；取下外层后保留浅蓝衬衣/格裙/不透明灰袜。
- 304雾棠：棕背带长裙、奶油衬衣、梅紫低髻，轮式两栖战车受阻；主裙保留，仅去外层护具/战术腰带与鞋靴，腿脚仍由不透明袜装覆盖。
- 305霜岑：白立领外套、灰蓝双辫，履带两栖突击炮车与破损海滩道路；取下外层后保留灰衬衣/格裙/不透明灰袜。

两名战车人格使用本人海陆同体装备自行上岸，不凭画面更改为普通艇投送。每张伤亡人物仅本人同意识的多个成年女性化身体，敌方清理队另以灰蓝军服/头盔区分。

## 最新反馈与构图约定

用户看到第一批后认为镜头太高太远，要求靠近，随后追加表情/伤痕差异与周边仍未整理的遗体。最终版本按此反馈重绘十张：约40–45度中等俯角、明显拉近，前景身体占画面高度约三至五成、背景逐渐缩小，优先看清面部、发丝、服装与装备；不再要求俯拍收纳整个场地。表情使用闭眼、半睁/睁眼失神、微张口及个别轻微露舌尖，伤痕由不同位置的衣装磨损、弹孔与少量血迹表达，不描画开放伤口。

进攻图以用户提供图的密度稍加倒地人物，初始提示词约35–40倒地、6–8继续行动，最终近景版本保留中等密度与自然重叠、继续进攻者和后方机枪阵地。画外延伸与近大远小服务细节，图像人数是构图目标，不能当作精确统计。身体完整，衣装有磨损和局部血迹，无开放伤口、肢解或血喷溅。

清理图以单列平行排列为主，头脚同向，队列由近景向背景延伸，允许延伸画外；约半数保留外套/鞋靴，另一部分已取下外层装备，内层衬衣、裙装、不透明袜装保留。周围另散布尚未搬运整理的遗体，姿势/朝向与整齐队列形成区别。移除后的衣物/鞋靴、护具、步枪弹匣、背包电台与物资箱在一侧分类；敌方士兵执行中性回收、登记、搬运，不描画脱衣动作或暴露。约半数是视觉要求，不冒称逐人物件守恒核验。
