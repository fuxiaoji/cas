# 家园导航、战术驻防与训练资产隔离

本轮只改变家园入口、显示与独立海陆行动账户适配。历史战役及 v1/v2 的舰队、规则与快照格式保持原有路径。

## 已复现的问题与修复

- 驻防等弹窗的全屏遮罩拦住原页返回：弹窗提供自己的「返回」「母港」，80逻辑像素高，深色不透明底保证白字对比；切页主动关闭旧遮罩。
- 战术招募的全屏根 Control 吞掉顶栏：Main 在页面边界使其根忽略鼠标，实际按钮、滚动和招募演出继续接收输入。
- 部队详情的「返回」回到部队档案，再返回家园；「母港」始终直接退出到母港。
- 建设预览先取消当前落位，再离开页面；选位及取消不收费。出航预览取消不收费，原核拒绝装载时保留配置弹窗。
- 活跃行动从家园出航入口提示继续同一航次；保存返回母港不新建航次、不重复装弹。

## 驻防与运输

旧 `home_v1.garrison` / `set_garrison()` 仍是舰娘停泊，最多六艘。新增 `tactical_garrison` / `set_tactical_garrison()` 为二至五连；允许明确清空，但不能以空编队发起防御。身份须已拥有、开放、不重复且整备至少10%。行动期间不能修改驻防。

v3 防御只使用保存的战术驻防，真实驻岸，不消耗投送舱位。begin 固定身份及整备率，settle 采用原核真实战损。

新行动默认 `cas-littoral-v3`，二至五连。运输选项来自 `tactical-profiles-v3.json` 的本人 `transport_options`；重装队没有直升机选项时不会凭空增加。逐连传完整 `company_transports`，卡片显示本人型号、人数和舱位。默认图来自本人 `transport-variants-v3.json`；其他合法 family 用通用载具图加本人类型牌，绝不借用另一编制专属图。

总容量读取原核导出的舰艇 `slots_combat / slots_balanced / slots_transport`。界面总量预警之外，每艘实际装载仍由原核最终校验。v1/v2 显式入口保持旧人数上限、无新运输/课程字段。

## 三课与借用

常驻 `Layout/Top/Training` 打开 `TrainingLessons`，按钮为 `Lesson-sea_control`、`Lesson-landing`、`Lesson-combined`。

`prepare_littoral(mode,seed,units,ships,preset,ruleset,lesson,company_transports)` 默认课程 landing。v3 tutorial 三课借用 Iowa、日进；制海权/登陆炮援借034、001，协同作战增加022。借用 ID 明确冻结为 `home_frozen.loan_units / loan_ships`。

训练不永久赠送借用单位，不修复或损伤玩家同 ID 单位，不扣真实弹药，也不把借弹返还到真实钱包。只有第一次实际胜利沿原 once 流程获得岛屿、034、十券和初始资源；重复课程胜利不重复奖励。放弃不解锁；重复结算幂等。

## 家园居民

显示已选战术驻防，未安排时显示至多三个本人已拥有单位。沿合法陆地行横向往返并独立蹦跳，巡逻范围检查四邻陆地留出海岸边距。点击回应仅为视觉交互，不改账户、不生产资源。

有本人 SD 则使用本人图；未制作 SD 时用本人头像与类型牌。旧 Canvas 的岛外舰娘泊位人物投影停用，驻舰账户与防御功能保留，驻防页查看舰娘。
