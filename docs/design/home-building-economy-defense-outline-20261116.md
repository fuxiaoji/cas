# 归航：把避难港建成自己的海上据点

2026-11-16，大纲与建筑风格预览。海岸美术方向已获认可；本稿确定经营和攻防关系，具体产率、价格、工期与掠夺比例留待原型对照。配图为本轮实际Godot三维样板，尚不表示新经济和炮塔规则已安装。

## 1. 玩家每天回家做什么

**收取生产 → 整备舰队与战术部队 → 出海获得稀缺物资 → 带回、交易或加工 → 扩建与布防 → 用演习检查防线。**

家园是有生活气息的战帮据点，也是会进入战斗的真实岛屿。小人可以散步、搬运、训练；设施的朝向、道路、滩头、高地和有限驻军决定攻防。最核心的取舍是：把好地段用于生产，还是留给防线与机动。不会依靠堆十几种货币制造复杂度。

## 2. 建造与岛屿成长

岛上直接拖动建造。底部只在建造时展开图卡：拖入出现占地、入口、坡度和道路预览，旋转后确认；取消不扣费。普通看岛不常驻网格、射程圈或说明墙。数量选择用滑块，设施点开最多先给三个常用动作。

同一座程序岛随指挥所等级解锁可经营范围、废墟清理、道路修复及新的泊位，而不是升级时重抽岛形、移动已有建筑。HQ1先有安身港，HQ2建立后勤，HQ3可经营多区并布置反甲/防空，HQ4形成高地和预备队纵深，HQ5完成多港区协同。正式岛现有真实8×10km空间保持；本轮几百米样区只用于看建筑。

建设要检查完整占地、平整度、入口和道路；港口需要实际海路，农田需要连续缓坡，重设施需要运输通道。普通登陆艇只能近岸卸载；两栖和空输保留各自地形、航程与防空代价。工程不能封死最后一条登陆、夺点、撤离路线。

升级先做三个看得见的阶段：临时拼装、稳定生产、加固专精。表现为加建工作棚、储罐、装卸台或掩体，而非单纯把整栋模型放大。后续专精允许贸易农业、工业生产、岸防要塞、机动驻军等不同布局。

## 3. 建筑与外观

延续浅墙、陶红瓦、青灰机械、温暖石材和碧青海水。民用有窗檐与庭院；工业通过分拣架、采光顶、储罐和堆场识别；防御低矮、厚实、炮口方向清楚。普通树和房不因有Tripo额度就重新付费生成。

## 4. 经济：少资源，真实流转

| 资源/物资 | 来源 | 用途 |
| --- | --- | --- |
| 浮材、合金、能源 | 回收、生产、远征 | 建造、维修、加工和既有养成消费者 |
| 银币 | 港口贸易、订单及既有玩法 | 通用钱包消费，不另造第二套银币 |
| 岛屿补给 | 现有库存与明确的后勤订单 | 保留当前训练、补员、建筑升级消费者 |
| 农产、维修件、训练/突破物品 | 农场/工坊/研究配方、资源海域 | 作为仓库实物或既有物品，只开放已接入真实消费者的配方 |
| 元词、招募券、燃油、弹药、体力 | 沿现有经济来源 | 不用家园无限生产抽卡资源；能源不代替燃油，出航成本仍实际扣取 |

现有 `home.resources.credits` 是岛屿补给，`wallet.credits` 才是银币，保持独立。不能因为名字相同直接合并余额；若以后简化货币，需要明确迁移规则。

持续设施支持统一收取，工坊支持配方队列。保留现有8小时累计作为首轮基线，再比较12/24小时，使每天自然回港一两次也能经营。满仓暂停新增产出；离线不扣成负数。升级、搬迁、换配方或受损之前先结算旧状态，不能把新产率倒算到过去。

家园给稳定基础收益，搜打撤给更高净收益与稀缺输入。首轮目标是：同阶段一次正常离线积累足够一项看得见的小投入；一次失败后仍有基础修复与下一次低风险出航的路。生产、银币、油弹和真实补员成本一起调，不先写一组脱离现有经济的漂亮大数。

## 5. 防御：海上交战、滩头阻滞、纵深反击

**海上**：驻防舰真实起锚、由AI迎击。进攻方争夺制海权后组织投送，军舰仍按完整海战逻辑作战。

**滩头**：机枪保护反甲炮，反甲炮用高单发、小范围、有限射界和装填威胁车辆；孤炮能被分散步兵侧袭清剿。普通艇需要合法卸载面，重艇展开更慢，两栖不能爬崖，空突会面对防空。

**纵深**：山地、树林、战壕、厂区、道路和预备队形成包抄空间。驻军使用真实连队和身体车辆，同一连不能同时出征和驻防。炮兵身体只自卫，坦克不会因伴随步兵全灭而失去控制。

舰炮和航空保持有力量的支援，但受平台、观察/标定、射程和油弹约束。核心夺控、搜集和装载仍需要登陆，不能远海炸完就凭空获得全部物资。升级加强专长，保留设施弱点；不做同时反甲、反步兵、反空的万能塔。

## 6. 入侵、恢复与演习

首版仍先做本地人机岛、玩家主动开始的防御战和自家无损攻防演习。入侵分有限掠夺、设施破袭、核心夺控，战前用三个图标说明本次目标。只有登记为暴露的岛上库存承担有限风险；元词、已到账钱包银币、角色/协议所有权、等级与建筑等级受保护。

失守后保留建筑等级与研究，按实际状态停产、维修；身体恢复和修车分别结算。保留不依赖完整工厂的低门槛恢复来源。演习复制双方布局和部队，只产生报告，不扣真实油弹体力、不损坏设施、不发经济奖励。录像绑定开战快照与规则，观看不再发奖。

## 7. 前15分钟怎么教

1. 拖图找到指挥所，只出现当前一条短指令。
2. 拖仓库到路边，先取消，再合法确认；让玩家亲眼看到取消不扣费。
3. 建回收/能源，统一收取首批产物；工坊选一份任务，再交一次港口订单。
4. 拖机枪堡并旋转射界，再放反甲炮，用弱步兵和单车分别展示作用。
5. 把034一个连拖入防区，另一个连留作预备，进行一场无损演习。
6. 战报标出真实被突破的方向，让玩家亲手调一次防线，之后自由经营。

这是体验预算，不靠漫长工期凑15分钟。每步只认真实行为，读完对白不算建好或战胜。
