# v3 步坦协同：安全与射界的取舍

本设计只适用新 `island-war-v3`，不改历史、已发布 v2 或旧航次。022 仍是每连一辆独立坦克和六名原有步枪身体，坦克零乘员座位；103 为每连一辆两栖车和八名原有步枪身体，八个座位只供这些身体真实上下车。087 自行炮保持远距支援，手枪护卫不套用前压协同。视觉放大不修改三米车体碰撞半径、0.45 米身体半径、武器射程或海图真实比例。

玩家拖动整连后，应看见坦克或两栖车压在前面、已下车步兵利用车后推进。躲在车后能让敌人的直射先碰上实际车体，但自己的枪也不能穿车。至多两名身体向车侧探出取得射界，有限射击后退回；受真实伤害的身体优先回掩护。侧翼包抄和范围炮火因此仍是反制手段，而非给整连加一个永久防御数字。

## 有限参数与行动

威胁方向只读取本席可见目标。在距离不超过 2200 米的局部交战中，坦克或两栖车尝试保持约 480 米交战距离。022 六名步兵在其后方约 10 至 19 米寻找合法点；103 八名已下车身体采用相同逐人间距，最末位置约 22.6 米。左右微错开保留真实独立占位。两名探头者使用约十秒一个周期、两秒暴露窗口；侧位在车体半径之外再留约七米，不让全连同时冲到炮口前。

真实 HP 减少触发至少两秒回掩护。若没有合法位置，保留实际位置并继续既有寻路，不能传送穿车。所有移动仍由逐身体碰撞和每 tick 扫掠裁决。退出托管、手动停止、撤收或车体毁损后，协同不能覆盖玩家的实际命令。103 上车后，原身体不再作为地面实体行走、射击或执行掩护；再次下车仍是相同 ID、HP、弹匣、备弹及装填时钟，不把两栖车当八个身体的替身。具体最终时序以原核导出为准；本表是有限设计目标，不是已实测声明。

## 车体遮挡

遮挡以存活活动地面车辆的实际圆形足迹与射手至目标的线段相交判定。己方车体挡住本次直射就不能穿车开枪；敌方车体位于中间时，攻击拦截到真实载具，按该武器对装甲的倍率和载具防护裁决。目标车辆自身不误挡自己的目标点，空中车辆也不在地面上投出无条件挡弹墙。

范围与高弹道武器继续按真实落点、距离和既有目标类别生效，不因为步兵正在车后就免伤。不添加额外车后承伤倍率。`covered` 是当前行动描述，表示身体正在执行车后掩护；来自侧面的攻击是否被挡仍逐射线判定。

## 最小验收

1. 022 一连始终只有原有六个身体 ID 和一辆独立坦克；103 则为八个身体 ID 和一辆独立两栖车。实际路径不重叠、不穿车、不凭空出现驾驶员或乘员。
2. 实际推进出现车后位置和最多两名侧翼目标；受击后实际身体回撤，HP、枪弹、连射和换弹状态不重置。
3. 正面直射由车体拦截，侧翼同种子对照能伤到身体；己方在车后不能穿车射击，探头后有真实发射和有限弹消耗。
4. 范围炮火仍能伤及车后身体，坦克毁损/手动停止/撤收不会留下幽灵掩护命令。
5. 公共状态导出实际 `cover_vehicle_id`、`tactical_state`、`tactical_goal`；保存/读取及 native/WASM 重演一致。
6. 陆图视觉放大另由 GPU 同框核验中心、锚点和选择投影；美术大小不作为碰撞或真实阻挡证据。
7. 103 实际下车后核验车后移动与侧向真实射击；重新上车后隐藏原地面身体、停止地面枪火和掩护命令，仍保留原身份、HP 和有限枪械状态。087 不因本次扩展跑到坦克交战距离。

机器可读目标在 [tactical-v3-armor-infantry.json](tactical-v3-armor-infantry.json)。本轮采用圆形足迹，尚不代表现实装甲分区、穿深或高度逐面遮挡模拟；是否已满足上述行为，应查最终候选的实际测试与战报。
