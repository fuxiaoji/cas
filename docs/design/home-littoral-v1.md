# 归航：家园与两栖协同设计

本轮先梳理并实装。用户最新设定覆盖旧文档中“舰体与单一人形关系尚待选择”的候选项；原始docx/PDF保持只读。历史战役继续原规则。以下为独立原创模式的世界、玩法和美术准则。

## 想要玩家记住的体验

舰队把伙伴送上岸，再把她们接回家。海军炮火撕开岸防、运输艇冲滩、直升机掠过烟雾、地面小队取回核心，再回到自己逐渐建成的小岛。家园为出航提供理由，陆军为海军创造新目标，舰炮与制海权决定陆军能否安全归来。

循环：家园生产与整备 → 选择舰队/弹药/运输负担 → 海上接敌并压制岸防 → 登陆、夺点、搜索 → 撤收/回航 → 建设与缓慢恢复。不能让陆军变成与海军无关的另一个小游戏，也不能让付费抽卡成为首个通关门槛。

## 世界观补充：很多身体，一个她

MCP在本世界是Mass Cognition Protocol，群体认知协议的旧文明代号。协议是可生产身体的受限授权、战术记忆和独一人格核心，不是现代软件工具的安装包。旧文明遗迹散落大量沉睡机器人大军；有效协议持有者可以在相容设施中制造其身体，但复制制造蓝图不能复制一个新人格，也不能绕过核心的带宽上限。

每一支战术部队都是一名有自己名字、感受和历史的女性人格。步兵、车辆驾驶体、机载终端都是她的并行肢体。战斗数量由核心可维持的实体预算限制，失联/重伤使部分身体停机；核心尚存就不会因为兵损永远失去角色，但回收、校准与重制缓慢且需要设施和材料。稀有的是有效人格协议与核心，不是廉价无限生成的机器人。

2026-11-13用户明确补充：单一MCP能同时维持的机器人身体上限为1000–6000。二十人格各有固定编制上限，见tactical-units-v1.json的personnel_cap。云隼2200、礁刃4800、冬鸢6000、汐锚1600、铁潮1200；这表示全编制带宽上限，不能因抽到一张协议就自动发放几千具身体。战舰、车辆、直升机不是另一性别的人格，均由她的女性化人形操作。

当前cas-littoral-v1选择先遣小队规模：每支2–4名真人格身体与至多2台车辆/1架飞机。玩家按编制下令，画面逐实体表现真实身体与装备；全局仍最多32个己方身体、64敌人、256弹体。它们是本次从大编制派出的少数成员，不是把一人冒充一千人，部队详情明确区分。全编制逐身体生产、储备库存和大规模战争经济尚未实现，不把设定上限当现成后备补员。现有整备损失和缓慢医疗恢复继续真实结算。

本人SD采用两头身十二姿态图集，头发/眼睛/制服/携具严格绑定本人立绘；真实位置、开火、HP和部队阶段决定行走、射击、受击与倒地。回收登船、未部署、恢复旧快照不触发假战败。战败用失衡过渡到仰躺/侧卧、白眼/吐舌或小型卡通白泡沫，不含血腥和衣物破损。

舰娘采用同样的一体意识解释：舰体、舵手人形、炮手人形、水手人形和用于交流的前台都是同一个她。人形可同时出现，但受到舰内线路、短程链路与算力限制；不能凭数量凭空增加舰炮、弹药、装甲或历史命中率。她们说“我在舰桥，也在炮塔里”，不把水手写成被替代的独立人格。核心保护、修复材料和通信受限继续沿用原设定。

技术断层下，舰炮依旧是可维护的大规模火力，直升机和军团协议是稀有维护链支持的局部遗产，不能以它们反向改写历史CAS想定。主角只能在近距、对方回应或维护通道授权时建立链接，不能凭血统无线接管所有军团。

## 家园：返航灯岛

以一座动漫程序海岛为主画面，浅水、沙岸、林地、废墟和码头有明确层次。资源生产、仓储、医疗、核心站和岸防可点选建设/摆放/升级；少量资源常驻，详细数值点开建筑再看。建筑使用有辨识的物件素材，避免把主页面做成卡片报表。资源为浮材、合金、能源，与银币/元词分账；离线产出有时长与仓储上限，不要求玩家定时上线避免全损。

守岛舰队从真实拥有身份中编成，先停泊起锚，再由AI迎击入侵舰队。入侵先做可保存的人机岛与对自己防线的演练，明确标人机；未来玩家互袭采用岛屿防御快照、服务器结算与冷却，本轮不伪造联网。有限掠夺只影响家园可掠库存，永久设施、角色、原仓库实物和主钱包不被删除。

参考学习《海岛奇兵》的海岸分层、登岛路径、岸防交叉火力与舰上支援；学习《皇室战争》的明确目标、有限部署预算和短局可读性。原创角色、建筑、地图与音乐，不复制参考游戏资产。

## 双尺度作战

海军大图负责航路、舰艇相对位置、留守舰起锚、炮战、支援射界与运输舰存活。陆战小图聚焦同一岛屿的真实区域，切图不跳时间、不重置敌人、不暂停另一个尺度。海上舰艇失去弹药、被击毁或不在射程内，陆地舰炮按钮必须显示对应原因并拒绝开火。

地面操作采用少量战术队、自动索敌射击和点地集结；玩家主要决定从哪上岸、先压哪座设施、把舰炮/直升机用在哪里、什么时候撤。避免逐个机器人微操。预计单局6–10分钟以内完成一条抢滩/迂回/撤收路线，具体时长以实测登记，不以等待拖长。支援有有限弹药、冷却、落点延迟和清晰预警；防空克制空输，反甲克制重装，工兵擅长破障和回收。护航舰队可先摧毁防空，给机降开窗。

搜打撤增加独立“两栖打捞”入口与规则版本，生成有大块陆地的海域。出航前明确战斗/均衡/运输预设的载弹与运力取舍：运输舰容量较大，普通舰可少装弹换运力。收益必须来自实际地面搜索并撤回，失败/中止不能直接把地上物资入库。旧搜打撤航次不静默升级。

## 教学叙事：一座可以回来的岛

独立支线接在主角与第五驱逐小队建立信任之后，不重写原三章进度。残存中继站发来“还有未撤收单位”的旧频求救；主角和弗莱彻在半淹仓库找到礁刃。她没有立即认主，而是要求先救回停机的登陆机体。玩家先学海上定位和近岸舰炮，再登陆、避开防御、取回协议校准件并撤收。

救下的流民原先维护返航灯岛的淡水站。教团掠夺者切断补给后，他们无力再守。上层舰娘以“护航线维护委托”给主角驻岛权，既掩护其来历，也为战帮提供中继港。岛不是凭空送的王国：主角承诺恢复淡水、救护和返航信标，居民保有生活区域。

教学分为遗迹会面、真实海陆协同救援、驻岛委托、生产/建设、守岛警报、返航灯点亮。旁白交代环境，角色通过具体分歧说话；MCP统一人格用“同一刻她的另一个声音从艇上响起”展示，不在开场堆说明书。奖励与岛屿解锁在真实通关后一次性授予，跳过对白不能绕过实战。

## 音画与交付边界

原创音乐共用返航动机，但港口、家园、探索、登陆、激战和结算有独立编曲/配器，留下语音空间。转场保留全屏动漫遮盖与约三名随机本人SD，蹦跳时真实横向行进，各有相位和速度；减少动态时保留可读切换。

角色美术采用原创军武动漫语言：成年女性、可辨军种装备与不同轮廓、每人独立配色、姿势、服装剪裁与适量军种携具；参考少女前线的战术人物表达，不复制现有角色。家园和战场仍程序生成，CG只用于剧情和卡池，不用整张固定岛图冒充可生成海面。

验收必须包含真实海战/起锚/登陆/舰炮/机降/防空/撤收胜败、生产消耗与恢复/抽卡保存、防重复结算、完整关闭恢复、native/WASM与旧规则冻结、Godot真实窗口及可编辑场景、音乐循环与转场实位移。未完成项如实列入交付，不以设计文档冒充程序。

## 2026-11-13 最新美术纠正

战术部队的每一个机器人身体均为女性化人形，拥有与本人一致的发色、脸型与识别物；不是一名女性指挥无脸金属大兵。车辆、直升机是她们操作的装备，不替代女性化身体。本人立绘参考少女前线的轻盈人物与战术服装结合：约6–6.5头身的小巧成年女性，窄肩、纤细自然体态、柔和清楚的动漫脸，枪械、耳机、少量弹匣袋和护膝保留专业性。避免厚重机械肩甲、巨型外骨骼、浮空炮塔、肌肉硬派脸和满屏装备。不同军种用服装剪裁、配色、携具与武器区分，不只换色。此前厚重候选不作为正式美术。
