# 冒险体验与入口美术调整

本轮直接落实用户六项反馈，采用“历史战役保真、原创冒险重可玩”的模式边界。操作应尽量在画面上理解：物资用形状表达占位，怪物用攻击区域表达威胁，标题用场景和字形表达世界；精确参数在选中或详情里查看。

## 标题方向

参考 [DREDGE 官方视觉](https://www.dredge.game/) 的场景主体与简短菜单，以及 [GRIS 官方视觉](https://nomada.studio/gris-game/) 对构图和留白的重视。具体菜单图片另做了网上目视研究；此处是设计归纳，不复制它们的标志、背景或界面资源。新作图是沉城灯塔、晨光和驶归的小舰，标题采用思源宋体的轻重笔画与航海刻度构成独立字标区域；主要行动改为文字导航和聚焦细线。装饰潮光缓慢运动，减少动态设置会停止。背景仅用于标题CG，战场海域仍全程序生成。

## 物资整理

物件表和格子均可直接拿起，拖动保持拿起的那一格，R旋转保持抓点。轮廓完整显示，绿色✓或红色×配合短理由，颜色不是唯一反馈。放到非法位置或窗口外不执行交易、不弃置。双击只找首个合法空位，不替玩家重排；原单击选中后点格子保持。货舱内的变更都走原核原子命令，结算只接收实际装入并成功撤离的货物。

## 冒险边界

`cas-adventure-v1` 仅新剧情和普通打捞远征显式选择。航行10倍与加速度提升独立于秒钟，炮火装填、天气、搜索与怪物蓄力仍以游戏秒推进。怪物只在本席实际发现后展示血量与招式；精确数据面板以选中或真实威胁为条件。圆形爆发和线性扑击采用不同预警形状，告诉玩家应如何应对。历史战役和旧保存不补字段、不换规则。

## 可编辑交付

标题、AI方案卡、怪物情报均为Godot真实场景/节点，可在编辑器改布局和文案；没有把整套界面烘焙为图片。战场实体和地形参数由原核公开观察驱动，不能仅改画面后宣称改变碰撞或规则。验证结果见开发回执。
