# 搜打撤行动系统 v2

2026-11-12，依用户追加要求实施。设计目标是让每次出航都有“多做一件，还是带着现有收获离开”的判断，同时保留舰队航行、雷击和格形货舱的特色。历史战役不采用这些原创冒险规则。

## 研究与改编

参考 PlayStation 的[《绝地潜兵2》实机介绍](https://blog.playstation.com/2024/02/02/helldivers-2-hands-on-report-chaotic-co-op-and-empowering-stratagems/)。官方介绍的程序地形会同时改变据点、次要目标与撤离路径，战前装备则帮助适应任务与环境。以下是对 CAS 的设计判断，不宣称复制该游戏的具体数值、AI或素材。

- **地图改变决策**：地貌、天气、世界场景分开选择。五场景为溺城街区、拜教中继、风暴船冢、热泉裂谷、流民堤道；地图仍由种子生成，建筑与环境物件是局部表现，不使用固定照片作战场。
- **次要目标产生局内效果**：每航次抽取三项临时任务，可接取和放弃。中继、测绘、救援、信标与密藏分别影响警戒/奖励箱/撤离等待/额外撤离点等。完成任务产生的物资仍经过搜索、装载和真实撤离，不能在菜单点击直接变成账户奖励。
- **压力应当可读且有限**：Boss 先预告后入场，每航次最多一次。玩家可以挑战，也可以绕行撤离。敌舰按照本次部署舰队分数预算加入，不向弱小舰队固定投放同一重型阵容。
- **补给产生取舍**：均衡、穿甲、高爆三类炮弹；标准、疾行、重型三类鱼雷。备雷0–2轮，每轮占2格；20秒装填，重型30秒。卸下鱼雷的舰与本来没有雷装的舰不能获得免费备雷。
- **战利品具有世界意义**：16种实物包括净水滤芯、旧世相机、医疗箱、记忆匣、拜教芯片、潮能电池等。形状、重量和价值不同；普通收藏品兑换银币，明确标记的舰装箱/水手档案才拆包。

## 自动指挥

自动指挥默认关闭。谨慎、均衡、大胆三种策略读取本席公开信息，评估血量、炮弹、鱼雷、载重、可见威胁和Boss风险，再选择航行、搜索、摆放货物、作战或撤离。AI下达与玩家相同的合法命令，不读取未发现的实体或凭空获取物资。玩家手动下令即接管。

这是帮助玩家执行已经理解的舰队操作，而非后台挂机发奖。实际自动指挥状态及原因在行动面板可见，错误和不可行航路必须保留反馈；退出/恢复/重放须保存同一状态。

## 视觉与界面

怪物统一90度俯视，朝向、比例和六种姿态保持一致。游动、蓄势、攻击、受伤和死亡由真实公开状态触发，不用侧面角色立绘悬在海上。敌舰使用俯视舰体与尾迹。

战场常驻只增加“行动”“自动打捞”入口，以及自动执行/重大威胁时的一行提示；不常驻钱包、任务全文或数值表。任务面板有接取、定位、交互和放弃；定位只移动镜头，不能冒充航行或完成任务。弹药在航前配置，战斗详情读取实际装填与备雷状态。

## 版本与验收

新搜打撤显式使用 `cas-adventure-v2`；剧情保持 `cas-adventure-v1`，旧航次和历史不自动升级。独立新模块的物资目录、任务、配置、AI状态均随原核保存与重演。只将已真实验证的航次、窗口、原生/WASM和旧冻结对照写入交付记录；后续平衡意见不冒充已完成机制。
