# 搜打撤 v4：从航行等待改成路线、交战与装载的取舍

2026-11-12，独立游戏设计与实际表现交付。此设计用于新建的 `salvage-v4` 架空 PvE；历史 CAS、章节目标和已保存 v1–v3 不随菜单升级。

## 想让玩家感到什么

核心体验是：在漂亮、可读的海域中发现旧世界遗产，判断是否值得停船，带着自己挑中的收获回来。主张力只有一条——继续深入的收益，与已装上船的价值和风险之间的取舍。

现有问题不靠增加数字解决。航速低造成的空等，用更合理的首个搜索点和前方撤离区改善；不同水平的玩家，用三档风险分开；搜完自动加一条资源，用可见物件、重量和实际占格替代；战斗反馈散落在日志，用少量情境提示和发生位置上的短反馈替代。

| 时间尺度 | 玩家动作 | 反馈与下一次选择 |
|---|---|---|
| 一次接敌 | 看威胁、下航路、选目标、避开已公开的冲击区 | 命中短环、受损/鱼雷提示；决定继续输出或机动 |
| 一处残骸 | 靠近、减速、开始搜索；受损时重新评估 | 真实搜索进度、逐件揭示物资，选择入舱、旋转、移动或放弃 |
| 一次远征 | 选择风险/地貌/起航天气 → 编队与装载 → 搜索/战斗 → 撤离 | 只有实际带出物件进入仓库；卖出、拆解、养成，准备下一次航行 |
| 多次游玩 | 试不同舰队、运输舰、轻装DD和地貌；逐步挑战更危险海域 | 组合与路线变化，保留舰娘既有的小幅成长上限 |

## 三档风险的首版落地

界面只展示一张风景图、玩法定位、风险、收益类别。精确参数在此登记，战斗里不常驻刷表。

| 项目 | 近海巡航 `calm` | 交锋航路 `standard` | 深渊禁区 `hazard` |
|---|---|---|---|
| 适用 | 初次搜索与撤离 | 熟悉基础指挥后 | 做好整备、愿意承受多源威胁 |
| 体力 | 8 | 14 | 20 |
| 初始海怪数 | 3 | 7 | 11 |
| 敌压构成 | 2拾骸兽、1骨帆水母；无渊喉 | 既有7只生态，远侧有渊喉 | 标准生态追加守卫、水母、拾骸兽、渊喉；近侧也有威胁 |
| 首个遗迹距领舰 | 750米 | 1000米 | 1450米 |
| 搜索时长 | 8模拟秒 | 12模拟秒 | 16模拟秒 |
| 每处揭示 | 4物件 | 5物件 | 6物件 |
| 单物件标价系数 | 1.0 | 1.4 | 1.9 |

数量和标价分开处理：1.4/1.9不是整局收益倍数。收益还取决于具体类别、舱位、负重以及实际带出数量。不同难度不凭空发空舱奖励。带出封存物件拆包时调用既有三档表，品质下限分别为制式、改良、精良；最高品质概率继续沿用既有抽表，不随难度加倍，不突破舰装/水手既定增益上限。

三档各有前向首撤离区，靠近第一处遗迹，避免为完成一次基础循环必须掉头长航。标准/深渊的额外价值来自更危险海域和更深路线的选择；不能借此调整历史舰艇速度、射程、命中或伤害。

## 地貌与天气由玩家独立选择

四种地貌都使用种子化的权威陆地多边形，再以程序水面、岛岸、云和地标表现。菜单的三张原画只负责介绍氛围，不作为战场底图或碰撞面。

| 地貌 | 导航性格 | 玩家应考虑的问题 |
|---|---|---|
| 珊瑚环礁 | 分段环形岛、开口与泻湖 | 通过开口接近目标，保持转向余地 |
| 碎裂群岛 | 主岛与散碎礁石簇 | 选择可航缺口，避免让多编队挤在同一处 |
| 峡湾水道 | 岸体与错位岬角形成水道 | 提前设航点，别把受损舰留在狭窄方向 |
| 淹没都市 | 高地、建筑基底与真实水道 | 结合地标辨认航路，选择搜索与绕行方向 |

起航天气为自动、晴空、阵雨或海雾；选择的是初始天气，后续仍由原核时间线变化。云雨雾的动画不独立改判可见性；天气规则与存取/重演继续由原核负责。难度和环境不相互强绑，喜欢晴天画面的玩家也能选高风险。

## 货舱是出航决策的一部分

本轮由原核与货舱专线实现吨位、指挥官等级、运输舰、炮弹和鱼雷装载形成的空间预算，并严格验证边界、重叠和载重。设计层要求：

1. 出航前展示选择造成的空间变化；减少弹药、移除DD鱼雷必须真实减少本航次携带的战斗资源。
2. 搜索等待只走原核模拟时间。搜索时不能暂停模拟；近距离、低速和受损中断形成停留风险。
3. 搜完不等于入舱。未入舱物件需在遗迹附近装载；旋转、移动和取舍都应可操作，不用文本列表冒充空间整理。
4. 整理单机货舱时记住进入前的运行状态并暂停；关闭后恢复，降低“摆积木时看不见遭袭”的不公平。
5. 可一键紧凑整理，但不自动替玩家挑走全部物品；弃置不可恢复，失败不得结算带出物资。

## 战场信息与反馈

原航路、炮雷、雷达、射程、选择与战术抽屉保留。新反馈位于独立 Godot 场景，只读取本席已经知道的事件和本舰状态。

| 信号 | 表现 | 优先级与边界 |
|---|---|---|
| 鱼雷预警 | 顶部单条“鱼雷来袭 · 改变航向”与图标；已知位置短环 | 最高优先级，替换普通命中反馈；不显示未发现的鱼雷 |
| 严重受损 | 仅首次越过35%本舰耐久阈值时提醒 | 不是每帧重复播报；阈值是表现提醒，未改伤害裁决 |
| 海怪冲击 | “海怪冲击预警 · 离开标记” | 仅公开事件；现有权威冲击范围和倒计时继续负责准确预警 |
| 普通受损 | “舰体受损 · 保持机动” | 不展示数字弹幕 |
| 命中 | 已知命中位置的短环和四条短射线；“命中确认” | 低优先级，不盖住危险 |
| 搜索/拾取 | “发现物资 · 可选择装载”/“搜索完成 · 选择带走的物资”/“物资已入舱” | 对应真实 `cargo_revealed` / `cargo_search_complete` / `cargo_stowed`，整理和弃置不当作新收益 |

默认短环0.75秒、通知3.2秒、最多5个位置标记；相近同类短环合并。搜索完工与最后一件物资同秒出现时，完工提示覆盖部分揭示，且不受刚显示部分揭示的同类限流阻挡；真正危险仍优先。恢复存档、时间回退和重演不补播旧事件。没有全屏闪、连续镜头抖动、假命中、假拾取或人为停顿权威时钟。既有战场语音入口保留，避免重复叠音。

## 官方参考与采用的部分

- [明日方舟官方集成战略更新](https://www.arknights.global/news/1695)明确区分挑战难度并说明已有进度对应的起点。这里采用“先让玩家选择风险”的组织方式；三档数值、海怪和资源成本均是CAS自有设计。
- [原神官方Luna I更新的Tutorials调整](https://genshin.hoyoverse.com/en/news/detail/159349)说明未阅读教学在再次遇到对应机制时重新提示，并优先列出附近教学。这里采用情境出现的短提示，与剧情专线的逐关引导配合，不把全部教学常驻战场。
- [DREDGE官方介绍](https://www.dredge.game/)展示搜集深海物件、装入货舱获利、出售与升级船只的循环。由此推导本项目的“搜索—空间取舍—撤离—养成”循环；不是照搬其战斗或经济数值。
- [Windward开发商资料](https://www.tasharen.com/presskit/sheet.php?p=windward)说明程序海域、休闲贸易与危险海域，以及更高难度对应更好回报。这里采用独立的环境/风险选择，保持相同种子可重演与玩家AI同规则。

## 可编辑交付与本线验收

- `godot/scenes/ui/expedition_select.tscn`：完整风险/环境/天气页面。
- `godot/scenes/ui/expedition_card.tscn`：复用风险插画卡。
- `godot/data/expedition-design.tres`：三档文案、原画路径与环境/天气选项，可在Inspector修改。
- `godot/scenes/ui/battle_feedback.tscn`：可在编辑器预览的独立反馈层；时长、数量上限为导出参数。
- `godot/tests/expedition_feedback_review.gd`：实际鼠标选项与账户保存/重载、层级返回、原生夜战真实命中/受损/鱼雷事件、权威存档不变；单独标注的表现层边界夹具不冒充真实战斗。

本线GPU验收42/42，包括初始键盘焦点、精确体力预览和同tick搜索完工的表现层边界。原生夜战种子6106在348秒出现真实命中、354秒本舰受损、1080秒发现来袭鱼雷；新反馈层实际显示这些事件。重复刷新前后序列化权威存档相同。截图与报告在 `artifacts/godot/expedition-feedback-v4/`。货舱实战、三个风险档的真实搜索/入舱/撤离，以及native/WASM重演由原核专线另附验收，不能用本线夜战报告代替。

## 后续平衡观察点

以下是下一轮要用真实游玩统计判断的调整方向，不登记为本轮已完成内容：首个搜索前等待时间、各风险的带出率、单位体力净收益、第一次货舱满载时间、危机提示的阅读率。特别检查“深渊只拿首遗迹立即撤离”是否挤掉标准难度：若存在，优先把稀缺价值分配到更深的残骸，保持近端安全退出，不通过惩罚新手、提高舰娘成长上限或加长空等解决。
