# 出征经济与十五分钟海岛攻防重构方案

日期：2026-11-16。状态：**设计草案与后续实施依据，未实施、未完成平衡验收**。本轮只整理文档和交接，不修改运行代码、核心、账户、原始PDF或参考工程。

来源：已逐轮阅读聊天 `01a1df6a-9178-7d21-9eac-5942d533f11c`，共六轮，无剩余分页；结合当前聊天的操作、速度、卸载和载具反馈。保留旧计划 `island-economy-defense-plan-20261115.md`；本文对出征支出、仓储、战斗时长和实施顺序作更新。本文具体数值均为建议，不等于用户已经确认或游戏已经采用。

## 1. 先确定游戏要让玩家决定什么

核心体验：在有限补给和军事预算下，用侦察选择投送路线，用步兵打开缺口，用装甲或航空扩大战果，用舰炮支援关键突破，并决定何时带着收益撤回。

三个长期取舍：

1. 同一块沿海平地，建港口/工厂获得收入，还是保留给炮位、军营和机动道路。
2. 此次远征多带战斗力量、多带运输空间，还是压低成本接受较小收益。
3. 防御预算用于岸防、纵深火力、核心驻军或机动舰队。由玩家决定重点，不强制固定三道防线。

装甲保持强火力和防护；限制它的是有限的合法投送口、道路、侧后反甲、昂贵运输和对任务的局限，不能靠给坦克统一减血解决所有问题。装甲自带步兵能清除孤立火点，但不足以同时完成多路占领、清壕、护送和搜索。

历史CAS战役、历史舰卡、原表射程/航速及已有航次继续冻结。新的经济和原创攻防规则必须显式版本化；先检查版本名是否占用，不能直接把旧v4或旧coastal存档改成新规则。

## 2. 经济闭环与收费时点

基本循环：家园生产 → 整备与编成 → 出征报价 → 实际战斗/搜索/装载 → 撤离结算 → 修复、养成或扩建。

首版玩家主要看到五类：燃油、弹药补给、粮食、通用建材、银币；体力独立显示。元词/抽卡券仍属于既有征募经济，不充当日常炮弹或基础维修的必需品。

| 对象 | 出征时 | 战斗中 | 返港后 |
| --- | --- | --- | --- |
| 舰娘 | 消耗一次体力，预留燃油；不足的弹药在整备时补充 | 实际炮弹/鱼雷/航空库存减少，燃油按同一燃油系统结算 | 按真实损伤维修，按缺额补弹，不再次收取整船出征费用 |
| 战术部队 | 按**实际选中的连队**支付固定燃油、弹药包、粮食 | 使用本次装入的有限弹药/投掷物，不能开枪再扣同一笔钱包弹药 | 轻损用时间与后勤恢复；重损和车辆维修需要建材 |
| 无损家园演习/基础教学 | 0体力、0永久支出 | 独立临时库存 | 不扣真实资源、不改变真实整备、不发可刷的经济奖励 |
| 掠夺岛屿 | 与远征同一收费链 | 抢到资源仍需占领/装运/撤收 | 按真实带回物结算；不因点过仓库就立即入账 |

必须避免重复收费：舰队补弹在装入实体库存时收费，实际开火仅减少该库存；陆军固定弹药包已经覆盖本次装载，不能再按射击逐次扣同一钱包。陆军首版固定包用剩不退，换取明确报价；以后如改退未用弹药，必须新增版本并封堵反复装卸套利。

建议常规行动体力12，体力上限150，每6分钟恢复1；新手恢复行动可为3，演习为0。是调参起点，不额外叠加每连体力。先复用现有体力服务，不创建第二套体力。

燃油与修复的初始报价基准，按15分钟常规远征：

| 舰型 | 建议燃油预留基准 | 满损维修建材基准 |
| --- | ---: | ---: |
| DD | 20 | 40 |
| CL | 30 | 60 |
| CA | 40 | 85 |
| BB | 75 | 160 |
| CV | 90 | 180 |
| APV/运输船 | 25 | 50 |
| 架空LHA | 60 | 130 |

这些是**经济报价**，不修改CAS吨位、航速或历史舰卡。实施时用真实吨位/动力类型在舰型基准附近插值，不把所有DD收费完全相同。已有燃油按航程消耗时，使用“预留→实际耗用→释放余量”，不能把上表固定费用与旧逐航程费用叠收。战斗内切换地图、暂停、8倍速或读取存档不得增加一次出征收费。

陆军每连固定费用见配套CSV。全额修复成本按真实损伤比例计，不按开过几次界面计费。建议身体损失率前20%主要消耗后勤与恢复时间，超过20%的重损部分连续增加建材需求；不要采用跨过阈值就突然收取全部身体费用。可用 `重损建材=ceil(每体基准×编制身体数×max(0,损失比例-0.20))` 试算，每体基准普通12、重装20；独立车辆按实际损伤另计，坦克满修150、两栖车90、自行炮120、武直140。最终须用新号/中期/满级三档损失模拟调参。

机体、身体损失可恢复，人物身份、等级、已解锁外观和编制不会因战败永久删除。粮食作为部队后勤包计账，服务随军人类和仿生体维护，不在本轮擅自重写机器人生理设定。

## 3. 生产、仓储和掠夺

| 设施 | 主要产物/功能 | 土地和军事取舍 |
| --- | --- | --- |
| 农田/水培场 | 粮食 | 连续低坡土地，不能同时铺满壕沟与炮位 |
| 回收工厂 | 通用建材 | 要求平地、港口/道路连接；换产强化料时不再满额产建材 |
| 油料设施/贸易码头 | 燃油来源之一 | 易燃、临海通道有风险；不要求每个岛都凭空有油井 |
| 商港 | 银币和贸易订单 | 占可利用岸线，需要运输通道；可兼顾驻防舰出动 |
| 训练场/研究站 | 经验、突破/专精材料 | 同时只能处理选定生产任务，高阶需要远征原料 |
| 弹药工坊 | 弹药补给 | 消耗建材/银币，和建设争产能 |
| 岛屿仓库 | 生产缓冲和可掠夺库存 | 集中省地但风险集中，分散增加保护难度 |

**溢出定义**：设施自带小缓冲；缓冲满后自动转入有空间的岛屿仓库，不要求逐个点农田。全岛仓库也满时，停止新增产出，显示“仓储已满”，不悄悄销毁已有库存。建议设施缓冲2小时、总离线结算上限24小时作为原型；这些与旧版8小时上限分别留档比较。

基地长期仓库、岛上暴露库存、当前远征编队货舱是不同位置的同类物资，转运守恒，不能三处复制。保留一份不能掠夺的基础储备和低门槛恢复来源；基础修复不能依赖已经停产、却修不起的工厂。

建议单次可带走上限为 `min(暴露库存×20%, 对应岛级掠夺上限, 实际运载能力)`；保护储备不进入“暴露库存”。已有建筑等级不掉级，损伤主要导致暂时停产及维修。入侵目标采用防御快照，不能离线期间同时出现两次独立战斗各取走同一份库存。NPC库存重置/补货需有明确规则和稳定行动ID。

收支校准目标：普通成功行动毛收益约为固定出征成本的2.0–2.8倍资源价值；中度战损后仍有净收益，高风险搜打撤高于安全资源关。严重失败可亏，但合理被动产出与恢复任务应在一次正常离线周期内提供重新出征的底线。以上是测试目标，不保证每次随机箱子都回本。

旧资源迁移须单列映射：`home.resources.credits`是旧岛屿补给，`wallet.credits`是银币，不得因同名覆盖。旧scrap/alloy/energy保留原数量和来源；“通用建材”先确定是复用现有材料的显示/配方还是新增版本账本，再迁移，不能把旧材料随手合并或消失。所有生产在升级/换配方前先按旧状态结算，小数余量保留。

## 4. 有限防御预算和地形建设

军事预算是长期容量，建造资源是一次投资，两者同时存在；花钱更多不能绕过容量。驻防部队、舰队和工事都占预算，防止“少建塔、无限驻军”绕过限制。

| 岛屿HQ等级 | 建议军事预算 | 建议可改造陆地比例上限 |
| --- | ---: | ---: |
| 1 | 60 | 10% |
| 2 | 100 | 12% |
| 3 | 150 | 15% |
| 4 | 220 | 20% |
| 5 | 300 | 25% |

防御部队按CSV连队点数占预算；驻防舰按其既有CAS部署分折算预算（建议 `ceil(CAS分/100)` 作为起点），不改原CAS分值。军营只提供集结/整备和预备队管理，不生成免费无限士兵。预算分配面板常驻“已用/上限”，其余详细费用在选择时显示。

**攻守比较采用同一个总容量口径**：攻击行动容量包含舰队、实际选中连队和另购的支援；运输船按舰计，连队固定自带艇/车/机已经计入连队点数，不能重复收容量。航母按舰计，舰载机按实际编制和库存，不另外凭空获得无限航空。首轮HQ3测试守方上限150点，攻方总容量180点，三种阵容都在这180点内换配；其中约90–110点用于陆军只是例子，不是额外额度。先以1.2:1作为静态工事优势的试验补偿，再根据胜负和战损调整至1.0–1.25，而非让100点攻击300点满防。三张测试岛都用相同守方上限和驻防快照，防御点数不能同时复用成多批无限增援。

| --- | ---: | --- | --- |
| 机枪阵地 | 6 | 压制暴露人员、守路口 | 对重甲弱；侧后接近、烟幕和曲射 |

| 重岸炮/海防导弹 | 34 | 高级岛的海上拒止 | 显著预算与土地代价，可被断侦察/陆军破坏 |

| 军营/预备队集结点 | 5+实际驻军点数 | 有限增援、换防、反击 | 佯攻可牵制，不能无限刷新 |
| 战壕/墙/地雷 | 每段1/2/每组2 | 定向掩护、隔离路线、有限消耗 | 空壕可被占，墙可破坏，雷可侦查/排除 |

升级增加预算占用：如基础×1、专精×1.5、高阶×2；分支选择穿甲/周转/射界等方向，不能最后每种塔都变成全目标万能塔。首轮8–10种基本设施可先实现，余下明确后续；不要为了数量做只有换皮的塔。

地形改造在备战阶段完成，战斗中冻结。以局部削坡、填坑、修路、有限工事为主，首轮建议每次高程变化≤2米、累计人工改造≤8米；不能凭空封死所有合法登陆口和通向目标的可破坏通路。造山自然少了可建厂平地、可能挡自己射界，不额外塞一个不透明全岛产量惩罚。已有道路、设施基础、岸线通行、海陆寻路和画面使用同一地理快照与哈希。

## 5. 海陆攻防如何互相制约

典型选择是：在岸炮射界外等待陆军开口，还是冒险让舰队进入支援位置；从主滩强攻，还是用轻装/空突绕侧面；摧毁炮位，还是突击观察站削弱其协同。

岸炮不是“陆军没点按钮，所以舰炮禁用”的硬锁。舰船始终受真实射程、炮位、装填和有限弹药约束；在原创模式里另明确对岸观察、距离散布、飞行时间和地形遮挡。远距离轰击仍可作为昂贵且较慢的选择，不能凭空给炮台无敌罩。岸炮对近岸支援舰有威胁，突击其侧后方应成为更划算的解决办法。

普通艇只能在合法岸段逐人卸载，然后走向内陆目标；不能按拖拽终点在内陆生成身体。两栖车能利用部分窄滩/浅滩，但不能爬所有悬崖；武直和伞降能做纵深任务，但有航程、容量、防空和降落窗口。不得默认全体轻步兵都能攀崖。

反坦克炮对装甲有高威胁且爆炸小，海军陆战队依靠人数、多路、烟幕、压制和近距离清剿处理炮位。装甲的随行身体要实际下车和承担风险，车内身体不能同时开枪/占点/搜索。炮兵身体持手枪近距自卫，不能随自行炮攻击指令冲锋。

## 6. 十五分钟节奏和地图尺度

时长定义：**从行动开始到胜负/撤离结算，正常1倍速的主动游玩时间**，排除编成界面、暂停和剧情阅读；标准对局目标12–18分钟，中心约15分钟。教学3–6分钟，熟练的快速掠夺可8–12分钟，难度/目标不同不强行相同。900秒可为标准争夺的结束节点，但不以强制等待900秒制造时长。

| 大致阶段 | 时间预算 | 玩家正在决定什么 |
| --- | --- | --- |
| 侦察与制海 | 0–2分钟 | 判断岸炮/驻防舰、选择滩头、海军接敌或牵制 |
| 建立登陆条件 | 2–5分钟 | 首批步兵清点、烟幕/工兵、有限航空投送、开运输出口 |
| 主攻与机动反击 | 5–10分钟 | 装甲突破、炮兵转移、切断观察站，守方调真实预备队 |
| 争夺与收尾 | 10–15分钟 | 深入争HQ，或装运仓储并撤收；守军反扑/争取保产 |

阶段可以并行、提前、跳过，不规定每座岛有三层防线。首轮用三张同预算测试岛：偏滩头火力、偏工业纵深、偏机动驻军。分别保留多种成立的攻击路线。

当前720×720米样区是美术/首轮可玩样区，不能把坐标整体拉伸冒充大岛。标准攻防建议新生成约1.2×1.6公里真实陆地，主要目标路线400–700米；保持人车楼和道路真实尺度，沿用获批Demo的材质/光照/海水语言。先让720m样区的速度/卸载正确，再新增地理版本验证较大岛，不能同时重写所有场景而无可比基准。

基础步速建议重装1.5–1.7、普通1.8–2.0、轻装/侦察2.2–2.4米/秒；短冲刺×1.25、约5秒、不持续精确开火。不得把70m/s字段显示成2m/s，也不能只把屏幕插值拖慢。陆上车辆5–9、水中两栖2.6–4.4、重艇4、普通艇6、快艇9、运输旋翼25–32、武直28–35、投送飞机50–60米/秒，按类型校准；固定步长下测试加速和刹停。海军不得继承旧搜打撤10倍速，历史模式真实节数不改。

暴露步兵在有效距离1v1典型TTK建议12–25秒，集中火力可以明显缩短；整连对整连15–35秒出现关键损失、约30–60秒形成局部胜负。反坦克炮正面击破代表坦克约3–5次有效命中，留出6–10秒装填窗口；针对真实护甲矩阵计算，不能把表上伤害当已经减伤后的值再减一次。弱教学不应让首次正确卸载的整连在2秒内消失。

爆炸面积必须统一米制。起始建议：坦克HE半径4.5m、自行炮7m、火箭3m、手雷3m、机炮1m、工兵爆破2m；舰炮127mm约5.08m、406mm约16.24m仅作本原创模式基准。伤害、散布、击退、范围指示、身体圆和建筑真实占地一起核对，不能保留隐含+10/+20m身体或+60m建筑命中垫边。穿甲弹单目标、低溅射，HE反人员/轻结构；不要让机炮带数十米AOE。

武器模型仍按各本人区分。同类武器可以沿用不同型号/精度/弹匣/射速，统一的是单位和射击状态机。步枪/冲锋枪/射手步枪的近远精度曲线继续不同；射速、短连发间隔和换弹独立。舰炮弹数按真实炮管，步兵一发、载具一发、消耗一发、产生一条实际弹道。

大岛仅指陆地，外围海图须按原舰炮/岸炮真实射程、舰队航行和支援距离扩展。不能因为陆图只有1.6km，就把海军也塞进1.6km方框或给海军整体提速。首个15分钟样板可以从舰队抵达任务海域的合理接敌部署开始，不增加无事可做的远洋航渡；长距离海上机动由真实海图、任务起点和目标布置共同验证。

弹药续航单列验算：每型号至少测2–3段30–60秒间歇交火后的剩余弹量，区分火箭手、普通身体和机体库存。总携弹量先保留CSV旧值作对照，确定阵容是否能完成一次标准任务，再通过真实装载和报价调整；不能全员无限弹，也不能让116技能凭空补弹。默认火力纪律不持续打已失去视线/无有效伤害的目标；玩家可切目标优先级。移动判定阈值应随新步速同步校正（建议0.15m/s及停步约0.3秒恢复稳定瞄准），否则旧2m/s阈值会误把普通行走当静止射击。

有效节奏验收：首个可操作目标在30秒内、首次有效接敌通常在90秒内；累计无选择的赶路/等待占比目标低于20%，没有任务分配机会的单段等待原则上少于20秒。远路可以部署其他连队、安排海战或处理货舱；不能仅把行走改慢、拉大地图就称15分钟完成。战斗保留0.5×/1×/2×可读倍率，首次默认1×；倍率改变的是模拟推进速度，状态、计费和存读仍依模拟时间一致处理。

## 8. AI、界面和教学

进攻AI：侦察当前公开威胁 → 选合法滩头 → 步兵/工兵抢占与清障 → 装甲沿可达路线推进 → 看条件请求有限舰炮/航空 → 分配搜索/装运 → 评估弹药、人员和收益 → 撤收。每一步均有超时、失败原因和备用目标。不能搜完一个点就停，也不能把“自动部署”叫全程托管。

防守AI：初始真实驻军和舰队；舰队先起锚，再航行接敌；岸炮优先有价值海军目标，反甲炮优先车辆，机枪优先人员，防空优先在空威胁。预备队决定支援滩头还是保工厂；可以后退换防，不无限刷兵、不知道对方隐藏命令。

装甲内置AI不依赖总托管：步兵随车后掩护、侧探、回掩护，车辆与身体独立生命/弹药/命令；步兵全灭后坦克还能移动、索敌、开火和撤回。炮兵保持距离、身体自卫；武直避开已知防空并有实际卸载点。手动命令应有短期优先权，AI不得立即覆盖。

接管边界：总托管负责全局任务分配，连队内置AI负责执行和自保。玩家手动指定后，该连队标记“手动任务”，一直执行至完成/取消/明确失败；接到立即致命预警可短暂躲避并提示，随后继续或请求新目标，不能后台改派去搜另一个点。长按/按钮可明确“交回托管”。界面只显示当前任务和下一步短句，例如“清除反甲炮 → 护送运输车”；主动技能应显示可干预窗口，自动使用不覆盖正在拖拽的预览。

界面保持海陆主图/小图切换和拖动：拖部队到地面移动、到敌人攻击、到遗迹搜索；拖载具默认移动，拖敌人攻击，炮向作为明确可选命令。点击所选连队只展开一行情境操作，步兵/载具切换、技能、上下车，更多里放待命/撤收。点击技能后点地图与直接拖技能均可，目标范围/预览/取消/失败原因一致。

主HUD仅常驻时间/倍率/暂停、当前目标、海陆切换和简洁部队状态。血量条和敌方攻击预告在需要时可读，非历史模式不隐藏必要敌人信息。伤害、装填、射程等数字放选择详情，避免全屏钱包和表格。建造、资源报价、数量一律滑块/预设档，不让玩家填数字。

逐关真实教学：①无火力岸卸载与移动；②步兵对孤立反甲炮；③机枪阵地需要烟幕/侧袭；④工兵清障与步坦协同；⑤岸炮迫使舰队等待，陆军破坏后请求炮援；⑥防空与伞降/空突；⑦打仓库、装运、止盈撤收；⑧有限预算布防及自家无损演习。每步只给一条主要指令，按原核动作完成，不靠点“下一步”直接通关。教程允许退出/重看。
