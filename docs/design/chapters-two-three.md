# 二、三章：从被救起的人，到自己选择回答的人

本轮为原创水世界剧情，不改 CAS 历史想定。每章14节点、3场原核实战；对白与演出不提供通关开关。主线让玩家反复做同一个选择：靠近危险取得线索，还是先把同伴带回去。主角的异常只带来线索，不替全队免伤，也不等于控制憎恶的权限。

## 第二章《无名者的航线》

堤道是由退役船壳组成的生活区。淡水交接把“搜集物资”变成具体的人际关系：玩家先保护航线，再看到弗莱彻和德雷顿把人拉过断桥。中段在沉钟交换站回收维护记录，发现教团删去了“拒绝同步”的注释。末段击败被改接信号的采掘守门体，旧金山承认她知道部分旧信标历史，仍不交出完整答案。

| 节点 | 主要行动或演出 |
| --- | --- |
| 01–03 | 堤道场景、借用“指挥官”的称呼、扑击线教学 |
| 04 | `c2-convoy`：抵达信标，五舰全部生还撤离 |
| 05–07 | 双人救援CG、修理师与教团的差别、搜索前的减速教学 |

## 第三章《门后的潮声》

风暴灯塔留下“不要把识别当作忠诚”的纸条。控制中枢被教团称为神殿，但档案揭示重启不会使已经消失的人回来。旧金山和潮痕把选择权留给主角；主角暂时拒绝强制记忆接入。最终切断潮门前的受控巨兽，得到“重启曾被人为中断”的局部证据。交接纸的作者、主角的身份与灾变原因继续保留。

## 演出和可读性

- 场景、角色和阅读器跨对白保留；只在换场景时进行短交叉淡出。旁白的有限文字回声自行停止。
- 弗莱彻、德雷顿、旧金山、潮痕各有6个本人参考表情。说话根据真实文字揭示播放嘴型，闭眼帧定期短暂出现；呼吸移动小于两个虚拟像素。减少动态效果时恢复静止。
- 战场只常驻小血条与真实危险区。实体教学和自动情报避免重复；玩家主动展开详细情报时，教学暂时让出焦点。
- 情报数字只取显式公开的 `contact.intelligence` 与 `health/max_health`，包括航速、伤害、距离、冷却、装甲和弱点。实际历史观察不携带扩展，详情不开放。
- 海怪保持90度俯视；6个动作状态增加0.16秒混合及连续尾肢网格游动。确认死亡只使用原核公开死亡记录，失联不是死亡。
- 所有战斗海面、岸线、云和天气仍由程序与真实公开环境驱动。8张新CG只用于章节封面、路线和剧情演出。
