# 家园建造、经济与防御审计提案

日期：2026-11-16。用途：供本轮家园大纲及建筑风格板选用。本文是设计建议和代码只读审计，不代表新经济、设施或战斗规则已经上线。

## 1. 核心体验

把避难的小港口经营成可以养活居民、整备舰队、守住战利品的海上据点。家园的一次完整循环是：回港整理战利品，选择生产或建设，安排有限驻军，出海带回短缺物资，再用真实战报调整防线。

最重要的取舍是**把好地段用于生产、运输，还是留给工事和机动**。增加十种需要手动领取的资源不会自动带来深度；港口与炮位争夺海岸、仓库与工厂争夺平地、驻军和远征争夺同一连队，才会让布局有意义。

三条准则：岛上直接拖动，点中后再显示详情；成长优先解锁布局与协同选项；被击败仍能恢复并再出击。建造界面和战斗界面共享同一地形、设施ID与真实位置。

## 2. 当前账本事实与最小资源方案

只读核查 `godot/scripts/home_service.gd` 与 `home_development.gd`：目前家园资源是浮材、合金、能源、协议片、岛屿补给。`home.resources.credits` 的显示名是**岛屿补给**，`wallet.credits` 才是**银币**。现有战术训练、突破、补员和建筑升级真实消费岛屿补给，不能把字段同名当作可以合并的证据。

| 玩家要理解的东西 | 用途与边界 | 首版处理 |
| --- | --- | --- |
| 浮材 | 回收、基础建造、工事与维修 | 复用现有家园资源 |
| 合金 | 坚固结构、装甲维修、进阶建设 | 复用现有资源，不把所有低级动作都设高额合金费 |
| 能源 | 加工、协议恢复和训练 | 复用现有资源；不做首版逐秒电网和离线欠费 |
| 银币 | 贸易订单、既有通用养成消费及后续明确登记的建设货币部分 | 真实进入通用钱包；不创建第二种银币 |
| 岛屿补给 | 现有训练、补员和升级消费者 | 原值原语义保留，详情内展示。新配方可为其建立有界来源；是否长期保留独立货币另作一次性迁移方案 |
| 协议片及养成物品 | 突破、专精、明确配方 | 藏于对应操作页；使用已有合法物品，不堆常驻顶栏 |
| 元词、招募券 | 既有抽卡与兑换 | 不用家园无限被动生产，已有PVE/PVP/充值来源不变 |
| 燃油、弹药、体力 | 出航与战斗既有实际成本 | 不拿能源替代燃油，不另造第二套体力 |

家园常驻资源条先只显示浮材、合金、能源及一个钱包入口。需要支付银币或岛屿补给时，操作面板明确显示各自图标与余额，不能因追求简洁隐藏真实费用。

农产、打捞商品、维修件优先作为已有仓库实物或少量明确配方输入，不立即升级为额外全局货币。新养成产物没有实际消费者时不开放生产。生产站的“预计满仓”和统一收取要比十几个小气泡更优先。

## 3. 四步经济闭环

1. **稳定生产**：回收站产浮材，能源站产能源，农场产贸易原料。工坊占用一个配方位，将指定输入加工成合金或实际可用的维修/训练物资。
2. **风险采购**：搜打撤提供高收益商品、稀缺原料和协议线索；部队登陆可完成岸上仓库、遗迹和设施回收任务。所得必须真正装载并带离。
3. **港口贸易**：交付订单把可出售物品变成银币，定向后勤订单可提供岛屿补给。贸易价与拆解收益不形成循环套利；商品售出和原料扣除同一次提交。
4. **投入与防守**：建造、升级、训练、维修、装填构成消费；未转运实物和公开的岛上库存承担有限风险。新增防御占用资金与土地，驻守连队不再同时出征。

原型先保留现有最多8小时产出为对照，比较12小时或24小时候选。最终目标是每天一至两次自然回家也能经营，不能把“避免满仓”变成强迫登录。具体时长和产率均未定稿。

调参目标先用行为而非大数：同阶段一次正常离线积累应当够做一项看得见的小投入；一次同预算普通远征的净收益应明显高于挂机，但失败不至于断掉下一次基础出航。正式数值必须同时核银币、补员、油弹与修车成本。

## 4. 建筑目录与外观识别

下列16个目录项用于第一版大纲。港区、军营和整备包含明确区分的子设施；合并展示入口不意味着合并真实容量、占地、库存或旧ID。战壕、雷区、道路和坡道归“工程”，不挤入建筑清单。

| 项 | 建筑/目录 | 玩家做什么 | 建筑形态与配色 | 必须保留的取舍 |
| --- | --- | --- | --- | --- |
| 01 | 联络中枢 | 管理岛权、岛级、警戒 | 暖白两层港务小楼、红瓦、钟/旗杆、低矮天线 | 是目标与管理节点，不提供全图无条件增伤 |
| 02 | 港务区 | 商港贸易；军用船坞驻舰 | 木石码头、起重臂、青绿棚顶、小仓棚、真实泊位 | 商业和军事泊位分别计量，不能一座建筑无限驻舰 |
| 03 | 浮材回收站 | 收集洋流物资 | 拦漂栅、栈桥、卷扬机、分拣台 | 需要合适岸段，与靠泊/岸炮位置竞争 |
| 04 | 制造工坊 | 合金精炼、后勤配方 | 砖石基座、红褐锯齿顶或小烟囱、外露工作台 | 单一配方位选择产物；不同时满速制造一切 |
| 05 | 潮汐能源站 | 产能源、储能 | 低矮白色机房、海绿管道、潮渠、水轮/小太阳板 | 以空间和资源付出成本，不造首版复杂电网 |
| 06 | 梯田农场 | 农产、民生贸易 | 小水渠、整齐不僵硬的菜畦、矮棚、果树 | 成片缓坡，占地大；机器人不被写成需要吃饭 |
| 07 | 综合仓库 | 容量、保护额度、批量整理 | 长条暖墙仓房、青绿大门、编号、装卸台 | 集中便于管理，分散降低单点风险 |
| 08 | 军营与训练区 | 分连驻军、预备队、定向训练 | 红瓦低层宿舍、沙土训练场、器械棚、集合旗 | 军营不是无限刷兵器，训练与驻防使用真实库存 |
| 09 | 整备中心 | 身体恢复、车辆修理、有限战地整备 | 浅墙医疗小楼/开放修车棚；医疗和机械子设施轮廓不同 | 不把旧medical和repair_tower静默合成无限治疗塔 |
| 10 | 遗迹研究室 | 加工突破原料、解锁设施专精 | 小型玻璃采光窗、黄铜/青绿终端、旧文明外壳 | 稀缺输入来自行动，不能无限复制MCP协议 |
| 11 | 通用岸防炮 | 对近岸水面与登记合法目标作战 | 低矮混凝土/石砌炮座、海军炮盾、弹药间 | 旧turret明确保留，不能偷偷解释成所有反甲功能 |
| 12 | 反坦克炮位 | 处理登陆装甲 | 长炮管、低炮盾、沙袋、偏扇形掩体 | 高单发、小杀伤面、慢转向/装填；怕侧袭清剿 |
| 13 | 近防机枪堡 | 反步兵、保护炮位 | 低轮廓沙袋/混凝土堡、窄射孔 | 怕装甲与远程压制，有真实朝向 |
| 14 | 迫击阵地 | 处理集结与遮挡后目标 | 开放式环形炮坑、箱具、遮雨网 | 有近距盲区、散布、有限弹药 |
| 15 | 防空阵地 | 对航空和下降伞兵 | 可辨旋转炮组/发射器、独立雷达小棚 | 地面火力弱或无，防空不能兼任最强地面炮 |
| 16 | 海防导弹阵地 | 拦截大型舰艇威胁 | 矮掩体、倾斜双联/四联发射器、窄服务道 | 昂贵且专向海上，有限弹药，怕岸上突入 |

首轮实际做能互相区分的12项即可：01–09、12、13、15。其他目录先保留设计和旧功能入口，不宣称已获得新模型或新规则。用于图板的样板优先联络中枢、仓库、工坊、农场、码头、军营、反甲炮、机枪堡。

## 5. 建筑风格的统一与差异

**共同语言**：延续已批准Demo的碧青浅海、偏暖干沙、苔绿草木、浅米墙体、陶土红瓦、少量海绿金属和黄铜点缀。斜俯视下屋顶与功能设备清楚，立面有窗框、檐口、落水管、护栏、装卸区和接地阴影。旧文明的残旧感来自局部补丁、盐蚀和拼接，而不是全景灰黑滤镜。

**按功能改变轮廓**：住用/指挥设施可用红瓦；工业采用更高的采光顶、烟道和堆场；港口突出码头和起重；防御低矮、粗实、朝向明确。不要给所有类型套同一栋小屋再改屋顶颜色，也不要把防御都做成童话圆塔。

**真实比例**：大设施按院区约30–80米级占地登记，内部楼体、通路、炮座、堆场各有独立尺寸。不能把一张建筑图放满旧120米格。主路与支路需分层；下轮米制占地合同确定后再给具体模型宽高，不能单凭SD展示高倒推真实楼高。

**二维与三维边界**：女性身体/步兵使用本人2D动作，建筑、树石、登陆艇、战斗载具和旋翼机使用真3D。炮塔、舱门、旋翼需要独立可动节点；人物脚底与实体中心一致。远景用符号/LOD降低开销，近景保留真实体积。手机以模型数量、材质、透明面积和LOD共同控载。

**图板顺序**：先一张同角度八建筑小样，第二张港区实景组合，第三张沙滩—道路—机枪/反甲—军营的防线小场景。标明“概念图”或“运行截图”，不互相冒充。功能名由排版叠字，建筑本体不画大段说明。

## 6. 岛级与土地成长

建议采用同种子稳定的大岛，随HQ等级与任务解锁可经营区域、道路修复和新的合法作业岸段。已建地块不因升级换岛形、挪位置或缩小设施；远处未开发地区仍可作为景观和后续战术空间。

| 阶段 | 开放的选择 | 战术空间的变化 |
| --- | --- | --- |
| HQ1 安身港 | 基础港区、回收、能源、仓库，1个简单防区 | 一处宽滩和一条清楚通路，安全教学 |
| HQ2 稳定后勤 | 工坊、农场、军营、两种基础火力 | 两条地面接近路线与一处高低差 |
| HQ3 分区经营 | 商业/工业专精、反甲、迫击、防空、研究 | 多个合法滩头、港区与后方路线、空输落点取舍 |
| HQ4 纵深防守 | 预备队、有限整备、高地工事、道路工程 | 至少可组织侧翼/纵深，不用大平地铺塔替代 |
| HQ5 完整据点 | 多区协同、蓝图、完整攻防 | 保留大岛真实纵深，近景分块运行，概览显示功能区 |

这描述的是经营/控制范围增长，不是每升一级凭空长出陆地。若最终要literal填海扩岛，作为独立后续工程，只有权威海岸、导航和登陆合法性同步更新后才开放。当前发布v4满级岛约8×10km，不能用几百米美术样区替代正式岛尺寸。

普通艇仅到合法岸段卸载，登陆后步行到拖动目标；重型艇需要更宽的卸载空间；两栖车水慢陆快且只能走实际可上岸坡面；空输须有航程、落点和防空风险。普通岛先试2–3个主滩头，不强制每个种子数量相同。施工不能封死最后的登陆—目标—撤离路。

## 7. 防御的可玩结构

1. **海上层**：驻防舰接警后真实起锚，沿合法海路迎击。港口、海防火力和进攻舰队形成制海权竞争；保留原海战完整操作，不另做假想“一键减血”海战。
2. **滩头层**：机枪压步兵，反甲炮威胁车辆，地雷/障碍拖延有准备的进攻。地雷与水雷属于有成本、可侦察/触发/清除的工程物，不无限免费补回。
3. **纵深层**：地形、高地、战壕、厂区和预备队创造侧袭与反击；迫击支援密集敌人，防空保护关键路线。道路既让己方调动快，也可能帮敌人接近。

玩家可重岸防、重核心、重机动或重生产，没有固定三道线要求。舰炮/航空保持强力，但受真实平台、观察、射程、油弹与调用窗口限制；不通过全体建筑“免疫舰炮”来强行保塔防。

反甲炮+机枪+驻兵比孤炮更难清。孤立反甲炮可被合理分散、侧翼推进的步兵处理，不能因“是炮”就全方向瞬杀一连。022/103伴随步兵仍有用，专业陆战队的额外人数与分组优势体现在同时夺点、清战壕和保持任务速度。

## 8. 驻防、入侵与恢复

按稳定company_id安排守区、巡逻和预备队，同人格可分连驻防和远征，但同一连队/身体/车辆不能复制。军营只管理有限兵力，预备队从真实位置增援；步兵全灭不使独立坦克失去选择与指挥资格。

进攻提供三类任务：有限掠夺、设施破袭、核心夺控。开战前用图标标出本场要拿什么、货舱是否够、何时可撤。部分掠夺可带回实际装载物，但不等同攻陷全岛。首版对手仅本地NPC，防守仅玩家明确启动的本地模拟；不能宣传成其他在线玩家偷袭。

只允许登记的可掠库存承担风险，已进入通用钱包的银币、元词、角色、协议所有权、养成进度和建筑等级受保护。当前仓储保护已有“受保护+暴露上限”结构，继续从该结构发展；具体比例不在大纲中擅自定稿。进攻收入与守方损失绑定同一凭证，不从炸毁建筑凭空发一份库存。

被击败后保留设施等级和研究，按真实状态停产/维修；身体恢复与车辆维修分开结算。保留不依赖完整工厂的基础恢复来源，必要时允许撤低风险资源点；不把失败变成必须充值才能重新出海。未来联网之前才设计离线保护与匹配，现在先测本地战斗与恢复闭环。

自家攻防演习复制岛、两方部队与库存，只写演习报告，不扣真实体力、油弹、整备，不损坏建筑，不产生掠夺奖励。录像只读且绑定规则/布局/快照，观看不重复发奖或恢复生产。

## 9. 前15分钟拖动教学

时间是体验预算，不通过加长等待制造时长。教学配置允许短施工和借用资源，奖励来自真实教学动作，不能读对白自动通过。

| 大约时间 | 单一动作 | 真实通过条件 |
| --- | --- | --- |
| 0–2分 | 缩放/拖图，点击联络中枢 | 玩家真实移动镜头并选中目标；只出现一条短提示 |
| 2–4分 | 拖仓库到路边，预览、取消、重放并确认 | 取消零扣费；落成一次且道路/占地合法 |
| 4–6分 | 放回收站/能源，统一收取首批物资 | 收取真到账；再点一次不重复领取 |
| 6–8分 | 工坊选择一个配方，港口交一次贸易订单 | 输入扣除、产物/银币到账有可理解反馈 |
| 8–10分 | 拖机枪堡旋转射界，再放一门反甲炮 | 看到目标差异，不能把“绿色”当唯一合法标志 |
| 10–12分 | 把034一个连拖入防区，另一个连留预备 | 同人格分连而非锁全人格；实际出动和返回 |
| 12–15分 | 一场无损小演习，故意暴露侧路后重布一次 | 弱敌先步兵后单辆装甲；真实战报指出突破方向；不扣真实库存 |

只在当前动作需要时显示相应覆盖层：建造显示占地和道路，布防显示射界，投送显示合法滩头，库存显示保护范围。底栏3–5张图卡，点开单设施最多3个常用动作，批量/配方/详细数值放二级抽屉；数量输入全部滑块。

## 10. 首批交付验收

| A 风格 | 同镜头比较人、车、楼、树、道路，沙滩与高差接地自然；屋型/轮廓可辨用途 | 概念图不能替代运行截图，RTX帧率不证明中端手机 |
| B 建造 | 拖入、旋转、取消、确认、存读；完整占地、坡度、道路、最后通路校验 | 中心点在陆地不等于完整可建 |
| C 经济 | 实际生产完成一项建设、一次训练、一次维修；容量/余量/改配方/重复提交守恒 | 改资源显示数或免费测试账号不等于闭环 |
| D 防守 | 相同预算四种布局：贸易农业、工业纵深、岸防要塞、机动驻军，各有可突破方案 | 同人数不等于同成本，纯装甲不应全图占优 |
| E 状态 | 受损停产、有限库存被带离、维修恢复；演习和回放无真实经济副作用 | 仅看成功弹窗不算验证扣费与持久化 |
| F 回归 | 新显式规则与旧档边界；原生/WASM重演，Godot真实拖动与浏览器验收 | 旧v4测试不能替代新经济/几何/规则验证 |

先做四件最小循环：港口、工坊/农场、仓库、两种互补工事，打通再扩大目录。建筑数不是完成度，真实可经营和可攻防才是。

## 11. 最需要防住的设计失败

| 风险 | 早期信号 | 最小修正 |
| --- | --- | --- |
| 全部经济建筑塞角落，岸边塔无限堆 | 同预算总有固定无脑布局 | 真实占地、射界/运输路线、有限预备队与建设总投入一起压测 |
| 岸防卡口无解 | 同预算混合队也无法上岸 | 先改投送容量、压制窗口、合法替代路线，不能只给新手加血 |
| 强舰炮从海上清完所有目标 | 不需要登陆就能拿满所有奖励 | 保留舰炮力量；任务要求实际夺控/搜索/装载，并检查真实油弹与支援消耗 |
| 累计数值吞掉兵种价值 | 高等级万能塔同时反甲反步兵反空 | 升级拓展专精且保留弱点，不全维加乘 |
| 养成与建造争同种材料导致死锁 | 失败后收入不足以修任何产线 | 基础安全来源、保护库存、一次小投入可负担，先看三档收支 |
| 钱包/补给混账 | 升级后银币或旧补给消失 | 独立字段、映射说明、一次性迁移凭证及旧档副本校验 |
| 界面又变运营面板 | 常驻数字、角标和按钮不断新增 | 当前动作只一层覆盖，图卡辨识、批量收取、数值按需出现 |
| 3D景观改变既有战斗地理 | 漂亮沙滩落点却判悬崖 | 权威岸线/高差同源；装饰只读，不能自行创造可通行路线 |

- 离线积累最终8/12/24小时，按每天自然回港频率及容量测定。
