# 海陆空拖动指挥 v4

日期：2026-11-14。目标是让原海战成为可操作的基础，再把登陆、航空和搜打撤连接到同一艘实际载舰。原战役、旧版存档、原PDF与参考项目保持原有定义。

本轮过程中用户补充了斜俯视密集城镇参考，并否定平面草地贴片效果。最终美术改向明亮沿海街区：真实道路网、低层楼房、红瓦浅墙、蓝绿门窗、道路植被和可见楼体高度。保留程序生成，不能把参考截图作为地图背景。陆图使用可逆等距投影，海军大图保留原海战投影；所有选择、路径、武器与拖点均投回原世界坐标。

后续追加真实岛屿纵深与战术高差：新版岛屿扩大实际岸线/地图范围，留出多连展开与侧翼空间。高地、低地与坡道由原核登记分区，至少影响实际陆战射程或掩护；表现读取同一数据，不以镜头缩放或纯阴影冒充战术地形。历史与旧规则航次仍保持原地理。

用户随后明确要求真实比例尺，该要求覆盖中间盲目放大方案。最终采用公里级真实岛屿、几十米级建筑与十几米级道路；海图不能假缩岸线，陆图通过局部镜头显示街区。远景设施转成小型可交互标记，街区近景才显示按真实占地缩放的素材。战术空间由原核多路径地形保证，不由巨大建筑或虚大海岛制造。

## 玩家的一次行动

出航时选舰与战术人格，看到载舰、人数与运输方式。海军沿用原编队、航路、舰速、火炮、鱼雷、雷达与射程操作。下方增加陆军军牌，拖到陆地即预览并下达投送命令；海陆大小图可以交换。空中中队同样拖到目标，显示真实飞机数、状态、航程与返航条件。每一次投送、开火、返航与任务奖励都由实际状态驱动。

拖动不是传送。越界、载舰沉没、舱位不足和不合格载舰应明确给出原因。普通舰不能因为选择直升机图片而取得航空资格。失败预览不扣资源；同一连队不能拆给几艘不合格船凑舱位。

军牌上方的 X / XX / III / II 表示人格绑定的旅 / 师 / 团 / 营身份，不用本次6–10个身体推导编制。倒下身体留在本航次地面，按单位身份与固定种子选姿势；正常回收不生成尸体。离开本航次才清理。

## 航空的实现边界

企业和翔鹤的舰体与火炮依据原CAS舰卡录入；返航灯LHA与潮桥APV明确为原创。新舰仅用于本版架空海陆空及新版搜打撤，不写入历史战役兵力。舰载航空先实现有限飞机、挂载、甲板串行、飞向目标、返航、整备和损失。完整CAS高度层、机动率、甲板事故、风向合成与航空攻击表尚待后续实现，不能称为原规则航空完成。逐页证据见[来源记录](../rules/littoral-v4-source-notes.md)。

旧RTS航母参考采用官方0.6.3（2017）说明：中队选取和目标下达、替代双键操作与手动攻击，转成当前项目的单指拖动、目标预览和明确返航，而非采用后来版本的单机追尾视角。[官方0.6.3说明](https://worldofwarships.com/en/content/update-notes-main/release-notes-063/)

## 程序化地形

实际阅读开源代码与项目文档（检索于2026-11-14）：

- [Terrain3D](https://github.com/TokisanGames/Terrain3D)：约4.8k星；阅读 `src/terrain_3d_mesher.cpp` 的clipmap分层缓存与移动阈值更新。采用缓存和远近细节思想；本项目未安装其3D地形插件。
- [Godot HeightMap](https://github.com/Zylann/godot_heightmap_plugin)：约2.3k星；阅读 `hterrain.gd` 与 `hterrain_mesher.gd` 的脏区、分块与LOD网格复用。当前2D岛屿采用按种子与真实岸线缓存纹理。
- [Waterways](https://github.com/Arnklit/Waterways)：约1.4k星；阅读项目说明的流向图、岸边距离与泡沫关系，用于组织动态海面与岸线分层。未声称复用了它的完整shader。
- [Godot FastNoiseLite](https://docs.godotengine.org/en/stable/classes/class_fastnoiselite.html)：独立高度与湿度噪声产生沙滩、草地、干地和坡地；全部由真实多边形限制。

采用程序海岸、分区地表与模块化城镇素材，不使用地图照片。原多边形仍是唯一海陆边界；画面不能额外长出阻挡舰船的假岛。城市建筑由原核登记footprint，显示与寻路共用同一轮廓；道路保留真实通行走廊，街树、路灯和车辆为非实体景物，人物和交互标记显示在其上方。高度/湿度/岸距纹理只在种子或地形改变时生成，绘制复用缓存，远景降低装饰细节。泡沫与海面按时间连续运动。

原创新增十二类楼房与十二类道路道具，单独透明图集，建筑包括住宅、公寓、商店、仓库、诊所、工坊、港务楼及毁损建筑。它们是可重组模块，地图仍由道路、建筑位置、楼层与真实碰撞数据生成。素材与提示记录在 `docs/art/combined-arms-v4-20261114/`，没有把整张生成城市图贴入战场。

## 搜打撤的陆军循环

在原搜索、拼格背包、燃油和撤离经济上扩展 `cas-adventure-v3`。带陆军才安排对应陆地遗迹/协议任务；控制陆地点后生成真实物资接驳箱，须搜索装包并撤离才能获得。敌人包括锈甲蟹、前文明女性哨兵、孢甲猎犬与迫击无人机组，各有读得懂的预警和反制。时间越晚威胁提升，但刷怪有预算，避免无限堆积造成卡顿。

自动指挥应完成：合法载舰选择 → 近岸/航程检查 → 投送 → 多任务 → 回收 → 海上搜索 → 评估血量弹药燃油 → 撤离。仅派出第一支部队不能算闭环。存档保留实际位置、载具与身体、任务、奖励箱和已消耗资源。

## 验收

分别验证资格拒绝不扣资源、近岸后出艇、空中半径、真实World海战命令、有限中队往返、身份正确的长留尸体、跨存读、多个陆地任务和真实撤离结算。另做旧版本原生/WASM重演与Godot交互验收，旧输出不能被新数据静默改写。新美术保留原始生成结果、提示词与SHA256。
