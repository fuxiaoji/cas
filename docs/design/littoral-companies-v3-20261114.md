# 两栖连队 v3：拖动、速度与协同

目标是让玩家看懂“谁在运送、何时上岸、谁在掩护、何时撤收”，并让指令尽快产生可见结果。海陆仍用同一个拖动动作：部队卡拖岛登陆，拖空地移动，拖目标攻击或搜索，撤收卡拖回本人。海图与陆图随时交换主图、小图，同一场战斗持续推进。

新行动显式采用 `cas-littoral-v3`。旧v1/v2在其原规则下恢复，历史战役舰表、距离、航速与裁决保持原样。

## 时间和规模

新行动出动2–5连，各连6–10真实女性机器人身体，最大50名友方。一个编制对应一个人格；身体都是她的不同实例，车辆是她们操控的装备。世界观1000–6000的完整协议上限仍与本次出动数量分开。

1/2/4/8倍速改变实际模拟时钟推进，暂停可停止；不伪造位移或炮弹。独立v3的地面基础移动为前版2.5倍、普通地面装填间隔除以1.8，使登陆后能快速推进。舰炮仍实际转向、装填、扣弹。倍速下保留未消费时间，不能少算伤亡、跳过冷却或取消在途炮弹。

## 运输取舍

登陆艇多运身体，速度慢；两栖战车运输人数少一些，装甲和耐久更好；旋翼机投送快、人数少且脆弱，适合抢点和任务。出航按实际人数和舱位检查运力，不能只在界面扣预算。载具受损、被击毁和乘员损失由原核裁决，返程不凭空补耐久或弹药。

二十支部队各有一款专属默认载具，包括双跳板重载艇、气垫侦察艇、抢修吊臂艇、电子战艇、医疗救护艇、导弹艇、火箭支援艇、装甲补给艇、低噪潜入艇、河口巡逻艇、破障艇、指挥艇、轮式两栖车、履带两栖战车、轻型突击直升机、倾转旋翼机、武装直升机和搜救直升机。型号和数值以原核导出的 `tactical-profiles-v3.json` 为准。

MCP-027使用赤隼武装直升机：运输阶段也有真实有限武器，12发、1.2秒装填、1400米目标距离；返程保留剩余弹药，耗尽停火。她不是纯装饰性的运输图标。其他编制的武器、支援专长和装备仍按本人档案使用。

## 美术与稳定动画

每支部队的默认载具使用自己独有的俯视图，两帧对应完整、展开投送。四张5×2透明图集共40帧；通用3×3艇/车/直升机图集用于更换运输家族后的备用方案，始终带本人军牌与名称，不冒用另一部队的专属载具。旋翼、水迹、烟雾以程序表现接实际状态。程序海面、云、岛岸和建筑散件保留，不用固定整岛照片。

人物实体保持实例与渲染槽位；同一tick刷新、窗口投影变化、海陆换主图不能重新播放受击或重新创建全部人物。不同Atlas姿态通过脚点元数据对齐，视觉插值和震动不改变命令坐标。暂停、存取和倒带各有明确边界。

## 三课教学

1. **制海权**：拖动战舰进入交战距离，观察真实交战，击沉守舰，驶入返航圈撤离。
2. **登陆与炮援**：拖陆战队卡到滩头，等待载舰靠近和运输；交换主图，移动、攻击；海图指向岸上，陆图拖舰炮卡清除威胁；搜索、撤收、返航。
3. **协同作战**：陆战队搭艇、空突连搭旋翼机分别投送；实际炮弹命中岸防后，两连共同推进，完成遗迹搜索，再逐连撤收。装甲连也作为可指挥训练借用编制提供，可尝试不同组合。

每课只有一条当前提示、来源与目的地聚光和循环手势。可以收起，随时重学。没有点“下一步”假完成，也不因为关闭或完成帮助就发奖励。三课借用身份、舰艇与弹药显式登记，训练不改本人伤势/库存，重复训练不重复发奖。首次正常成功仍沿授岛、陆战队协议和十券的一次性流程。

## 家园和招募

战术驻防与舰艇驻防分开保存，选择已拥有且可用的2–5连，防御演练冻结这份选择。家园本人小人沿可行走路径蹦跳、相遇互动，点击可进入本人信息，不制造生产收益。已具本人SD的使用本人SD，其余本人肖像兵牌，不借用他人。

返回先退一层；弹窗也有可达返回和母港按钮。直返母港取消未确认建设，不扣费；真实在途行动先保存。

战术招募先完成真实事务，再播放寻频、握手、头部近景和全身身份揭示。跳过显示五列两行结果；单次、十次、下一位、回看、减少动态和中途返港都不再扣费，结果留在上次同步。

## 验收边界

测试应使用隔离普通账户与明确标注的规模夹具。实际鼠标/触摸验证导航、拖放、运输差异、三课真终局、暂停和倍速墙钟、五连50身体性能、招募去重与保存恢复。原核变更须检查Rust、native/WASM、新旧版本字节冻结及历史浏览器兼容。Windows输入注入通过不等同手机实机或联网攻防。
