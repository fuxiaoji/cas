每首有两个独立写出的四小节动机句：A确立角色，A′改变轮廓及织体，B调整音区、反旋律和九音和弦，回归收束。拨弦/钟琴琶音、弦乐和声、低音、主旋律、应答及鼓组分层；不同场景有不同速度、调式、主旋律和鼓法，非单一正弦或同一循环改名。音色为柔和的合成室内乐/动漫游戏电子编制，并非真人管弦乐录音。

`*.score.json` 保存每个音符的音高、拍点、时值、力度、声部和声像；`*.mid` 为标准Type-1 MIDI、多轨和速度信息，可导入DAW或打谱软件。MIDI的GM Program只是可编辑音色建议，OGG的声音来自生成脚本自身。`analysis-all.json` 记录时长、文件SHA和响度。

重建：在项目根执行 `python scripts/compose-cas-score.py`，只重建一首用 `--only harbor_day`。依赖Python+NumPy和FFmpeg（脚本顶部路径可配置）。之后运行 `python scripts/analyze-cas-score.py` 检查解码、响度、真峰、循环接缝和曲谱，并生成A/B选段试听合集。原始临时PCM渲染文件在编码后删除，完整可编辑生成来源保留。

混音约-22 LUFS，44.1kHz立体声Vorbis q5。循环曲的乐段位于各自score的sections；A段首播一次，后续从第8小节A′起循环主体，`loop_start_bar`及audio.json的秒偏移为实际解码器设置，非只写标签。末50ms进行本曲局部尾响接缝处理；胜负曲单次播放，末尾渐弱。音量与原有用户设置兼容。旧MP4条目只保留在audio.json的legacy_music，不作为任何默认曲目。
