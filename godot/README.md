# CAS Godot 原生客户端

Godot 4.7.2 是新的 Windows 单人试玩客户端，使用现有 Rust CAS 原核裁决。这个目录与旧网页客户端并存，原始 PDF 和参考项目不进入迁移清理范围。

## 启动

双击项目根目录的 `CAS-Godot.cmd` 即可启动最新版。

母港的「竞技」在「出航」正下方。「返航灯岛」可直接点设施查看升级/维修，拖动岛屿平移、滚轮或双指缩放；建设先选设施、预览落位，再确认扣费，取消不花材料。返回先关闭当前建设层，母港按钮直接回港。全屏动漫转场为三名随机小人向右连续三次短跳。

海岛现用9套精细设施及7类透明环境散件，继续按程序岸线拼装。五支开放战术人格各有12姿态本人SD，真实陆战驱动行走/开火/受击/搜索/躺倒；正常登船不会误判战败。Godot中打开`scenes/ui/tactical_sprite_preview.tscn`按F6可用滑块查看全部姿态。二十人格1000–6000是全编制协议上限，本版实际部署仍为先遣小队。[本轮验收及编辑说明](../docs/development/mobile-home-20261113.md)。

双击入口会自动准备战斗核心和Godot资源，不改变系统执行策略。首次启动会准备资源，日志保存在 `artifacts/godot-launch-build.log` 和 `godot-launch-import.log`。编辑工程时，在Godot项目管理器中导入本目录的 `project.godot`，进入编辑器后按F5运行。

以下PowerShell脚本方式只适用于已允许运行本地脚本的环境；当前电脑直接用上述双击入口。

```powershell
.\scripts\start-godot.ps1
```

默认使用本机 `D:\downloads\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`，构建 Rust 本地战斗进程，导入 Godot 素材，再打开游戏。Godot 路径变化时传入 `-GodotPath`。该路径上一级虽然以 `.exe` 结尾，实际是存放两个程序的文件夹。

```powershell
# 打开项目编辑器
.\scripts\start-godot.ps1 -Editor

# 导入和独立经济音频检查，不打开游戏窗口
.\scripts\start-godot.ps1 -RunTests -NoLaunch

# 已有当前构建与素材缓存时快速运行
.\scripts\start-godot.ps1 -SkipBuild -SkipImport
```

首次构建需要 Rust 工具链。导入与构建日志写在根目录 `artifacts`，启动器不会下载或发布资产。战斗进程通过标准输入输出与 Godot 通信；构建程序与运行程序隔离，通过 `godot/bin/core-current.json` 指向按哈希保存的运行副本，因此旧窗口未关也能准备新版本。`CAS_SIM_PATH` 可显式选择已验证的本地程序；没有清单时兼容旧 `target/release/cas-sim.exe` 和 `godot/bin/cas-sim.exe`。

## 单人流程与存档

启动先显示“CAS / 归航”标题页；“开始游戏”进入母港，有未完成航次时可直接“继续航次”。各级页面分别提供「返回」和直接「母港」，战斗菜单的直达母港先保存同一行动。母港“剧情章节”先显示深色竖幅章节封面，再进入章内分页航线；三章各六场真实实战，均有可收起的操作引导。

母港顶栏「返航灯岛」进入家园教学；真实救援后开放生产/建设/驻防、协议招募和海陆空协同。首批五支可实战战术人格、二十名原创本人立绘，三个本地人机岛；左海图/右陆图共用世界，真实搭载、舰炮、机降和撤收。[完整入口与可编辑资源](../docs/development/home-littoral-20261113.md)。有旧航次时先正常完成或保存继续，不覆盖旧档。新BGM为十一首原创合成乐曲，源乐谱与MIDI位于项目的 `music/original-v1/`。

母港“出航”→“打捞远征”选择三档风险、五个行动场景、地貌和天气，再编成舰队。“装载与货舱”可少带炮弹或卸下鱼雷；“弹种与备雷”选择均衡/穿甲/高爆炮弹、标准/疾行/重型鱼雷，以及0–2轮备雷。备雷每轮占2格，灰色交叉格不可装货；鱼雷使用有限备弹自动装填，标准/疾行20秒，重型30秒。容量还受指挥官等级、舰船吨位预算及部署运输角色影响。

靠近残骸减速搜索，逐件揭示后直接拖入格子，拖动中R旋转；绿色✓可放、红色×不能放，拖到外面或按Esc取消。双击物件可找首个空位，也保留选择后点击格子的方式。装入且实际撤离成功才可带回；结算“整理带回物资”直接打开格库，仓库“打捞货物”可再次进入拆包或兑换。16种旧世物资有独立物件图、不同占格/重量/银币价，舰装箱与水手档案才拆包。

战场左下“行动”接取三项临时任务、定位并查看收益。接取后靠近650米、降至8节以下，再开始交互；受伤会中断。任务可放弃，Boss先预告后入场，可战也可撤。敌方包括七种有六姿态俯视素材的原创海怪和按出航分数预算加入的遥控巡逻舰。新打捞默认启动均衡自动指挥并开始航行，会接可承受任务、实际搜索装货、评估挑战与撤离；低血、缺弹、低油、满舱或敌情越线时优先带货撤离，不保证完成所有可选任务。「接管 · 自动中」可切换谨慎/均衡/大胆或关闭；玩家手动下令也会接管。保存暂离后继续沿用已保存的自动授权，手动关闭过的航次不会强制重开。

新的剧情实战使用 `cas-adventure-v1`，新打捞远征使用 `cas-adventure-v2`：航行实际提速10倍、加速更快，怪物有公开血条、蓄力和反制提示，建议使用1×时间倍率观察。旧航次不会途中改规则；历史战役、资源副本和天梯不启用这套冒险改编。军需处“舰队战术”展示原作六名AI角色及对应方案，原有解锁和交易保持不变。[本轮验证与编辑入口](../docs/development/adventure-polish-receipt.md)。

母港底部进入「舰娘」「编队」「仓库」「军需」「征募」；活动在顶栏，邮件单独位于右上。点击秘书舰附近的「更换 / 调整」可换已拥有舰娘、调整立绘大小及水平/垂直位置，点击「保存展示」后重启也会保留。母港有「一键整备」，舰娘页还可分别维修、补弹；先显示费用，确认后统一结算。

「出航」直接展示打捞、资源海域、天梯、剧情与战役。编队页可新建、改名或移除保存的舰队，用「管理成员」自由增删成员，没有原三舰槽限制；左侧勾选本次出航的多个编队，同一舰娘不能重复部署。计划弹药与体力够用时可出航。基础借用打捞仍可用于资源不足的账户恢复。

旧 `salvage-v3` 航次仍按原版本恢复：保留四类种子地图、旧搜索与撤离流程及4×时钟选项。已有旧航次不会途中升级；结束后新出航才启用新版行动系统。

剧情三章为《返航灯》《无名者的航线》《门后的潮声》，从失忆获救、第五驱逐小队突围、返港听证，到调查教团线索、旧设施和潮痕的过错。新增日常、分歧与调查，通过具体行动建立角色关系。101节点、1877页正文、每章六场真实行动；最短必读正文约2.2万汉字，按每分钟400字加实际战斗预算分别约64/62/65分钟，尚非真人常速计时。关键CG、多人同框、眨眼、25处人工表情转折及少量轻动作保留。空格/Enter先显示完整对白再推进；可自动、回顾或跳过当前对白段，实战仍须真正胜利。旧完章档能回看新片段、重玩新增关卡，完成状态保留，回访不重发首通资源或经验。旧序章教学留在章节目录内。[长篇剧情与真实验收](../docs/development/story-longform-receipt.md)。

页面切换默认全屏动漫PPT式遮盖与揭幕，包括云浪横推、圆形开合、纸帆斜切；三名放大小人独立跳动，相邻转场优先避开上一组，从已登记素材库随机展示，不改变角色所有权。设置可关闭动效。已登记210名角色使用177张生成SD与33张参考SD；海伦娜按CAS本人棕发立绘重做小人，不再绑定碧蓝航线蓝发同名角色。无身份登记的历史舰保留舰体与中性图标，原舰影仍可切回。

母港顶栏「竞技」进入人机排位或3v3。排位从保存的编队中选1–4组，总计不超过10000分；同一身份不能跨组重复。3v3玩家席预算3400分，两名AI队友各3300分，对面三名AI总计10000分。原核按种子生成阵容和24个候选人机ID；AI队友可查看但独立指挥。15分钟模拟时间或一方全灭后按实际击沉CAS点数结算，记录积分/最高分/胜败，七档段位奖励各模式分别领取一次。认输会扣分且不解锁初始奖励，重复结算和领奖不会重复发奖。此入口全部为本地人机，没有真人联网匹配。

秘书舰「更换 / 调整」的水平范围扩大至±1200、垂直范围扩大至向上900/向下700设计像素，使用滑块即时预览；「保存展示」保留位置与大小，重启后继续生效，「重置位置」可随时找回默认位置。已有保存位置不会自动改变。

战斗自动进入显示器全屏，返港恢复此前窗口模式。海图滚轮缩放，右键平移，点击预览多航点再确认；点击本舰、接触、残骸或撤离圈出现对应操作。默认收起详细面板，右上「战术」展开编队、舰况、战术 AI 和战情。炮雷按住、锁定、微调与取消沿用原操作。选中舰艇即显示炮击、鱼雷和实际雷达等范围，左下「射程」可直接开关。Esc 优先取消当前瞄准或航路，其次打开暂停菜单；「菜单」中的「保存暂离」保留本航次，结束行动会明确提示未撤出损失。「视图」可调整网格和投影，设置页也可切换小人与原舰影。

主炮齐射按实际发射管数显示独立炮弹，三联装实际三管开火即显示三发；多座同秒开火显示本次实际合计管数，不虚构炮座归属。主炮有金色弹头、随口径变化的尾迹、抛物弹道与落水波纹；副炮的每次真实发射使用较细、较短、低弧线的浅青弹道，包含未命中射击。副炮的飞行是视觉表现，原核的装填、即时裁决与伤害时序保持原样。大口径开火更重、小口径更轻快，己方受击有短促反馈；HUD固定，海图震动不改指令落点。在设置或战斗「视图」中用「战斗震动」滑块调节，滑到最左关闭镜头震动。

标题和母港跟随机器现实本地时间，每10秒刷新：05–08晨曦、08–16:30日间、16:30–19黄昏、19–05星夜。既有原创底画配合独立天空/海水/岸壁材质、日月星点、灯塔与码头亮灯生成四套光景，角色和界面不被整页染暗；不是四张固定新CG。剧情、搜打撤和活动的水波、云、岩岸、高地与植被全部程序生成，采用2.5D投影，没有云岛照片依赖。新航次每240模拟秒进入天气阶段，提前45秒过渡预报，晴、多云、阴、雨与雾会变化；暂停冻结天气进度，水纹仍有动画。雨雾按已实现规则降低能见度，历史战役仍保留原定环境。

历史战役按最新要求恢复旧卫星底图：萨沃岛、埃斯佩兰斯角、塔萨法隆加复用原地图与原地理配准，随缩放和平移贴合世界坐标。视图菜单可切到战术海图；旧版未登记卫星地图的历史海域仍用平面战术海图。剧情、搜打撤和活动继续使用程序动漫海域。底图不改变原有岸线裁决、阵位、距离、探测或炮雷计算。

军需可采购补给、礼包和指定舰娘，元词可兑换征募券/物资，银币用于日常维修训练；体力上限120，每8分钟恢复1点。舰娘详情有原始CAS舰表、成长、舰装和四类水手页。新自有舰PvE的满级增益约5%，满熟练度让基础命中率相对提升10%，舰装约1%，舵手/火炮/损管/指挥组有主副词条且总提升约1%。资源海域可定向刷取，打捞综合收益更高；天梯支持3000对4500等预算，每周前3次胜利提供元词，之后仍可重复挑战。剧情与战役也有幂等资源奖励。战役编成的「自有舰战役演练」仅故事难度和自有舰使用成长，不计历史星数；历史借用出航保留原参数。充值与PvP暂无实际服务。

剧情独立全屏，无母港钱包和导航；对白可回顾、自动播放或跳过本段，选择、教学与奖励不会被跳过。UP征募保留海上信号、高清特写、完整立绘和清册，抽取结果在演出前已保存。

剧情、活动对白和旧序章采用宽银幕半身近景，人物头肩比例统一，下缘渐隐融入对白；长对白扩展阅读区，人物不会为躲避文本而缩成小图。取景使用原生Atlas资源，不改变立绘源图片；眨眼与同表情换句沿用稳定的人物实例。

网站同名参考SD、生成SD与CAS外观候选分别登记，准确身份与覆盖数量以角色素材台账为准。本轮重新生成海伦娜本人SD，并为帷幄、夜潮、铁幕、绯刃、逐浪、缚潮六个进阶AI生成独立肖像；旧原图保留，来源、提示词、SHA和透明通道记录在 `docs/art/generated-arena-ai-helena-v1.json`。军需九个现用战术方案均解析为各自画像。

活动航次期间港口只允许查看，交易与编队修改由账户服务锁定。保存暂离后从大厅继续同一航次；明确结束行动按失败结算。账户保存于 Godot 的用户数据目录，通常为 `%APPDATA%/Godot/app_userdata/CAS · 归航/`。账户主档为 `cas_port_v1.json`，旁边的 `.bak` 为上一份备份。原核快照以原始 JSON 字符串保存，避免64位随机状态被界面数值解析改写。

## 当前交付边界

当前是本机 Windows 原生试玩。Rust 标准输入输出桥接依赖可启动的 Windows 进程；本次没有交付 Godot Android APK。原有 `android/` 是迁移前客户端的构建路线，不代表本次 Godot 版已支持 Android。后续手机版本需要 Android 可用的原核绑定、触屏与性能验收。新增排位和3v3仅使用本地账户与人机，没有启用线上账户或真人匹配。

不把此目录直接当作公开发行包。音乐、战场录音与部分角色图像仅有本地试玩使用记录，其来源与适用范围分别见 `data/audio.json`、角色素材台账和项目素材记录。界面音为 Kenney CC0。`export_presets.cfg` 仅提供排除这些私人试玩素材的 Windows 配置草案；尚未生成独立导出包，也未安装/核验本机 Godot 导出模板。正式打包还需要将原核进程作为外部依赖放置、验证导出后路径，并完成素材授权及整包测试。

细节及凭证见 [迁移计划](../docs/development/godot-migration-plan.md)、[经济音频验收](../docs/development/godot-economy-audio-receipt.md)、[UI 重构验收](../docs/development/ui-redesign-receipt.md)。
