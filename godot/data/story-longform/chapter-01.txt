# rescue
旁白|你醒来的时候，一只鞋里还盛着水。甲板在脸颊下面晃，铁锈刮得皮肤发疼。有人正把一条湿透的绳子从你胸口抽出来，动作很慢，怕碰断了什么。
drayton|能听见吗？别急着坐。你刚才吐了好多水。
你|……我的船呢？
drayton|我们没看见船。只有一块门板，还有你。
旁白|她把你的手放到栏杆上。手指会握紧，也知道怎样随着船身起伏卸力。身体似乎来过这里，可你叫不出海的名字，更叫不出自己的。
fletcher|德雷顿，毯子给他。帕金斯，后面那道烟还跟着吗？
perkins|跟着。一直在我们出水的位置转圈。它不像在搜残骸。
你|我是不是……给你们惹麻烦了？
drayton|麻烦从昨晚就跟着了。你只赶上了后半场。
旁白|她想笑一下，嘴唇却被冻得发白。你看见她虎口一道新口子，血被盐水冲成了淡粉色。她注意到你的目光，把手缩进袖口。
fletcher|我是弗莱彻。我们是第五驱逐小队。先记住这个，想不起别的也没关系。
你|第五……还有别的人吗？
fletcher|有。莫里在前面探路，拉姆森拖着我们的补给艇。现在加上你，都要回去。
perkins|队长，主航道封了。灯号喊三遍，没一盏回。
旁白|那句话让甲板上突然安静。德雷顿替你掖住毯子的手也停了一瞬。远处传来两声低响，听上去不像雷；第二声之后，她们一起看向海面。
你|你们救我的时候……我说过什么吗？
drayton|说了。你一直让我别回头。
你|你回头了？
drayton|不然怎么把你拉上来。好啦，别替刚认识的人担心。先告诉我，你还记得什么？

# waking
旁白|海图铺在一个倒扣的木箱上，边角压着扳手。图上有两条铅笔线，一条划穿黑色的礁区，一条消失在昨夜留下的水渍里。
perkins|红线是原航道，现在走不了。西边这片没测完，拉姆森的舵又受了伤，急弯她跟不上。
你|这里为什么画着两层岸线？
perkins|下面是旧城，上面是露出水面的东西。海会涨，楼不会自己走。画一条线容易，信它才会死人。
旁白|你伸手碰到纸边。没有完整的回忆回来，只有一些很细碎的感觉：铅笔在指腹上的阻力，手表秒针的声音，以及一句听不清是谁说的“后面的也算上”。
你|如果先从这边出去……不，等一下。补给艇会被留在转弯外面。
fletcher|你看得懂队形？
你|我不知道。只是觉得，不能把线画得这么紧。
perkins|很多人会觉得。我们现在需要的是哪边、什么时候转、谁先走。
旁白|帕金斯没有把图收回去。她把扳手移开，给你腾出一块能落笔的地方。你看了看弗莱彻；她只问了一件事。
fletcher|假如走错，你还会留在这里吗？
你|我连能去哪儿都不知道。
fletcher|那就先和我们一起。你说航路，我盯着后面。
drayton|别被她吓着。她每次出航前都问，不过通常问的是发动机。
perkins|右边的响声近了。先把路线看完，我们会稳住队形。报清楚往哪边走，比急着喊一句有用。
旁白|你把第一段线画得很短，留出一个随时能回头的弯。德雷顿把木箱扶稳了。三个人都没有再问你的名字。
你|先确认落在后面的那艘。我们得知道大家都能走多快。
fletcher|拉姆森，回话。接下来跟我们的航路走，转不过来就喊，别自己硬扛。
lamson|收到了。我还没慢到要你们替我数浪。
旁白|无线电里轻轻笑了一声。你握着那截铅笔，第一次觉得自己不是一件刚被捞上来的东西。前面有雾，后面有人在等你的下一句话。

# silence
perkins|刚才那段记录别覆盖。把它单独存一份。
旁白|她指着海图上的交叉点。炮口从你们前方转过去，落点却出现在另一侧。那不是你能解释的事，你甚至不敢肯定自己真的看清了。
drayton|我以为它要开火了。已经准备把你按下去了。
你|它有没有……停了一下？
fletcher|有。但我们先别替它决定原因。
perkins|它没停下追其他人。我能确认的只有这个。别把一次空当当成护身符。
旁白|德雷顿把耳机拿下来，耳廓被压出一道红痕。她好像还有一句话要问，最后只是把水壶递给了你。
你|如果它们真的不会攻击我，是不是应该让我在后面——
fletcher|不应该。
你|我还没说完。
fletcher|我知道你想说什么。我们不知道它不打你的条件，连是不是“不打你”都不知道。拿你试一次，失败就没有第二份记录了。
旁白|她说得有点急，自己也听出来了。她把铅笔放回桌上，重新理平了纸角。纸已经湿过一次，怎么抚都还是卷着。
fletcher|刚才你帮我们带出了补给艇。这件事是真的。其他的，等有证据再说。
drayton|而且你还欠我一条毯子。上面全是油，得自己洗。
你|我以为那是你们给我的。
drayton|借你的。借东西的人总得回来嘛。
旁白|港口的灯从雾里浮出来。一盏接一盏，并不明亮，像有人沿着岸把很小的火捂在手心。拉姆森的回报终于传来：补给艇还在，绳也没有断。
perkins|我们回去以后，先去医务室，再做接触笔录。顺序不要倒。有人会趁你说不清话，把别人的话填进你的嘴里。
你|你在提醒我，还是在教我应付盘问？
perkins|都有。你现在看起来，两样都用得上。

# return
旁白|港口不是地图上那种完整的岸。浮桥、旧船壳和焊在一起的铁板围成一条窄街。有人把盆栽吊在起重臂上，叶子被风吹得一直碰铃铛。
drayton|过这块板小心。它每次都说自己修好了，然后专挑新来的晃。
你|这里的人都住在船上？
drayton|有人住船，有人住还没淹的楼。住楼的羡慕船能搬，住船的羡慕楼不会漏。都不肯真换。
旁白|一个拎着空桶的孩子从你们身边跑过，忽然折回来，向弗莱彻伸出手。她从口袋里找出一小块玻璃，擦干净，郑重地放到他掌心。
你|那是什么？
fletcher|答应替他找的窗玻璃。他们家那扇窗一直拿布挡着。
drayton|她昨晚差点连自己都带不回来，还护着这块玻璃。你以后就知道了，别轻易让她答应事情。
旁白|你想起海图上那句“后面的也算上”，却想不起声音。一个穿围裙的女人递来热水，问你是不是第五队新补的人。德雷顿替你接了杯子，没有替你回答。
你|我……暂时跟着她们。
女人|暂时也得吃饭。碗放那边，用完别往海里扔，上次来的人就干过这事。
fletcher|我们得去登记。你可以先坐，德雷顿留下陪你。
你|我能一起吗？如果有人问我的事，总不能全让你们说。
旁白|弗莱彻看了你一会儿，把自己的外套搭到你肩上。港风从衣服破口里穿过去，仍然很冷，不过那块烧焦的布至少是干的。
fletcher|可以。但不知道的就说不知道，不用为了让我省事编答案。
perkins|医务室给的单子拿着。你今天真晕过去了，他们就得先停下来。
drayton|最好别真晕。我背人下楼，比把人从海里拉上来难多了。
旁白|登记处的灯是白的。门外晾着三件还在滴水的救生衣，你认不出哪一件曾穿在自己身上。你跟着她们跨进门，没有人让你走在最后。

# hearing
登记员|打捞位置、遇险原因、原属船只。先从能确认的说。
你|打捞位置她们有记录。后面两个，我想不起来。
登记员|一个都想不起来？
旁白|他把笔悬在表格上方，没落下。桌上有一只缺了耳朵的搪瓷杯，杯底压着几张寻人启事。最上面那张边已经翻毛了。
fletcher|落水后失忆，医务室检查过。第五队提交了出航和返航记录。
登记员|我看过。记录里还有一段解释不了的接触。你们在有憎恶的海区捞起一个没有舰历的人，申请临时通行，这需要担保。
你|我能留在检查区。如果需要观察，别扣住她们的船。
perkins|我们没有被扣船。别先替人把更重的话说出来。
旁白|门在这时候开了。旧金山没带随从，手里夹着一份折过的维修单。她先把单子递给登记员，才转过来看你。
sanfrancisco|他的临时身份挂第五队，担保人填我。需要补充的资料，明早送到我办公室。
登记员|这份单子是航道维修，不是身份审查。
sanfrancisco|维修申请我也签了。第五队那艘补给艇要是再搁浅，我们还得去捞第二次。你可以把两件事分别记，不必替我省纸。
旁白|登记员看着她，终于放下了笔。他在两份表格上分别盖章，没有再追问。旧金山却没有马上离开，等他把你名字那一栏画了横线。
你|你认识我？
sanfrancisco|不认识。
你|那为什么——
sanfrancisco|因为今早这几个人回来了。你在她们的船上，她们愿意替你作证。我不想让你们站在这里，把还没暖好的水放凉。
旁白|她的回答很平常。可你看见她合上文件时，拇指挡住了封面一个旧印记。那个形状使你胸口短暂地发闷，像吞下一口太冷的水。
sanfrancisco|你可以在港里走动，出航跟第五队。夜间不要靠近旧信标。我明天会找你，今天先睡。
你|你是不是还有什么没说？
sanfrancisco|有。等你能听完一件事，不再用“我来试试”回答每一个问题，我们再谈。
旁白|走出门以后，弗莱彻才长长呼出一口气。你想向她道歉，她摆了摆手，先问德雷顿医务室还有没有剩下的热汤。

# supplies
旁白|第二天，你在桌上发现一套干衣服、一截新铅笔和一张没有写抬头的餐票。餐票背面写着：锅在右边，别掀左边的盖子，那是颜料。
drayton|你昨晚睡着了吗？我听见你在走廊走。
你|一闭眼就觉得地板要沉。走一走好一点。
drayton|头几天都这样。可以开着灯，我睡对门，不嫌亮。
旁白|你以为她会问你梦见了什么。她却把自己的碗推过来，问你能不能帮她挑出一片掉进去的漆。生活在这里总是有一点没法郑重的事。
lamson|早饭吃完来码头。我们丢了一箱净水膜，仓库给的替代品比你毯子还容易漏。
你|去昨天那片海？
lamson|去旧信标外侧的打捞点。不是送你回去，别那个表情。
fletcher|原本只做物资回收。昨晚维修班在那边听见断续信号，说有一份旧档案跟净水膜放在一起。旧金山希望我们顺手带回来。
perkins|她说“顺手”的时候通常不顺。我查过潮汐，退路有，但得在搜索前留出来。
你|我们能先看看原始记录吗？不是她整理过的那份。
旁白|帕金斯把耳机推过来。信号大部分时候只是噪声，中间有三次短促的敲击。你跟着敲了一遍，手指停在桌边，耳机里却多出第四声。
drayton|怎么了？
你|可能是回声。我不确定。
fletcher|那就把“不确定”也记上。今天还有别的事，别把自己全塞进一段杂音里。
旁白|码头边有人正在补网。渔网挂着几个旧瓶盖，颜色跟你们舰上的标记一样。你问拉姆森为什么，她说方便认自己人的东西，丢海里以后也一样。
lamson|能带回来的先带回来。带不下就记位置，别把船也赔进去。小队没有多余的第五条命给你算账。
你|不是有五个人吗？
lamson|所以你算数的时候，把自己也放进去。
旁白|你把这句话写在新铅笔的纸套上。纸太窄，最后一个字只好写到背面。德雷顿看见了，忍住笑，没替你把它说成什么伟大的约定。

# archive
旁白|档案箱离开水面时，锁扣已经酥了。拉姆森没有立刻撬开，她先把箱底的淤泥接到托盘里，从中捡出一截很细的红线。
lamson|封签有人重新缝过。原来的线是白的。你看，这边还有一段。
你|会不会只是维修？
lamson|会。所以先拍下来，别急着给别人定罪。手套拿过来，纸一碰就散。
旁白|箱子里没有你期待的姓名、照片或答案。只有几张维护表、一枚不再走的计时器，和一袋装得很仔细的净水膜。最不神秘的东西反而没有受潮。
drayton|他们把吃水的东西包了三层，把秘密只包一层。真是会过日子的人。
perkins|最后两页被拆走了。不是烂掉，孔边切得很整齐。
你|这里写着“拒绝同步”。后面为什么空了？
旁白|你把那四个字念出来。无线电里原本的静噪声忽然变得很低，像有谁在隔壁按了一下琴键。弗莱彻伸手关了主扬声器，房间里只剩水从箱角滴下的声音。
fletcher|先别在开放频道读。旧金山知道这份东西从哪儿来的，我们当面问。
你|如果她就是不想让我们知道的人呢？
perkins|那更要留下原件、照片和我们见过什么的记录。不是把整箱扔回水里，然后靠怀疑撑过明天。
旁白|你低头看计时器。表针停在一个没有意义的刻度，却让你想起有人从背后盖住过你的手。你不愿再去想那只手是为了阻止，还是为了帮忙。
drayton|你脸色不太好。我们先把净水膜送到仓库？
你|我想把档案也带着。
fletcher|可以。箱子我提，记录你拿。中途要是想歇，直接说。
旁白|回码头的路上，德雷顿开始数新换的路灯。她数错了一次，你提醒她，她又从头数。你知道她不是不会数，只是想让你把目光从那截红线上移开。
drayton|给旧金山看之前，你想先告诉谁？这个回答我不会替你选。

# message
旁白|祈祷从没有接线的旧收音机里传出来。没人碰它，调频旋钮却自己颤了一下。仓库管理员退到门边，手里还拿着没盖上的印泥盒。
herald|第五队，下午好。你们带回来的那只箱子，是我们遗失的东西。
fletcher|报身份和频道。这里是民用仓库。
herald|我们在寻找一位走散的客人。你们已经找到他，却还在给他披不合身的衣服。
你|你在说我？
旁白|收音机沉默了一会儿。你听见底噪里有一声呼吸，随后又想起这不该是能传声音的设备。帕金斯已经拔下天线，声音没有变化。
herald|你还记得门吗？门后的海很安静。你曾经希望所有人都能听见。
你|我记不得。你说得再具体一点。
herald|他们让你失去了名字。我们可以还给你。
drayton|真要还东西就留个领取地址。躲在收音机后面，连自己叫什么都不肯说？
旁白|她把收音机转了个面，露出后盖一张褪色标签。标签上不是神的名字，是一个维修班组号，旁边贴着半张尚未兑付的食堂券。
herald|不是每个人都愿意听见真相。你的朋友尤其如此。
fletcher|你不知道我的朋友愿意听什么。把你控制的东西从仓库退出去，这里有平民。
perkins|外海接触在变。它们绕过巡逻灯，朝打捞区来了。
你|这些东西是你带来的？
herald|我们只替它们清掉妨碍它们聆听的噪声。
旁白|弗莱彻压低声音，让仓库管理员先带人离开。她没有继续和收音机争辩。你忽然明白，让对方一直说话也是在给远处争时间，而你们已经没有多少。
fletcher|箱子留下封存，净水膜先运走。第五队去外堤，我们不在住人的地方接这一仗。
你|如果他说的名字是真的——
fletcher|回来再听。你今天不用拿港口换一个答案。
旁白|收音机里又响起四次敲击。这次你把每一下都记住，没有跟着敲。德雷顿拽住你的袖子，拉你离开了那张桌子。

# afterboss
旁白|最后一阵浪推上外堤，卷走了半个浮标。它不动了以后，比活着的时候更像一件被人丢弃的机器：接缝开裂，线缆露在外面，还在往水里放很小的电火花。
perkins|没有新的攻击征兆。别靠太近，先让损管班确认。
你|刚才它是要来找我吗？
fletcher|它攻击的是外堤。我们现在能确认的就这些。
drayton|不管它想找谁，都把拉姆森的工具箱砸了。她等会儿会很生气，你最好帮我想个说法。
旁白|拉姆森正蹲在甲板上，把湿螺帽一颗颗摆开。她听见了，没有抬头，只向德雷顿伸出手。德雷顿叹气，把自己偷偷拿走的小扳手放回她掌心。
lamson|东西少了还能补，人少了没地方领。先点名。
fletcher|弗莱彻。
drayton|德雷顿。鞋丢一只，人没有。
perkins|帕金斯。
lamson|拉姆森。莫里在回航线上，已经确认。
旁白|轮到你的时候，你张了张嘴。没有名字可报这件事，第一次显得比海上的炮声更难应付。弗莱彻却没催，等你把那口气慢慢吐出来。
你|我在。
fletcher|收到了。
旁白|你以为那两个字需要一个真正的名字才能成立，她却在名单最后画了一个小小的勾。帕金斯把接触记录交给你，最后一行保留着你当时说过的“不确定”。
perkins|没改。以后有新的证据，往下面添，不往上面擦。
你|也包括它没打我的那一次？
perkins|包括。如果下一次不一样，也一样记。
旁白|收音机彻底没了声音。远处的民居开始重新亮灯，没有人知道刚才有人承诺过一个能解释一切的名字。你一时觉得庆幸，一时又觉得自己还在听。

# promise
旁白|夜里下起很细的雨。德雷顿在船尾晾那条你借过的毯子，晾了半天，发现越晾越湿，只好连衣架一起搬回走廊。
你|我来吧。说好了我洗。
drayton|明天。今天它已经比你先累了。
旁白|她给你留出旁边的位置。港口的灯倒在水里，常常被船经过的尾浪搅碎，过一会儿又自己拼起来。你盯着看，终于不再觉得每一块黑水下面都有东西等着。
你|我今天有一瞬间想跟那个声音走。
drayton|我猜到了。
你|你不生气？
drayton|有点。我把人从海里捞回来，他转头就想自己跳回去，总得让我有点意见吧。
旁白|她说完偏过脸，像是在给你留出反驳的机会。你没反驳。那一点坦白的生气，比一句“我相信你”更容易接住。
你|下次我会先告诉你们。
drayton|下次我们也可能不同意。你得听完再做决定。
你|好。
旁白|弗莱彻抱着维修图经过，见你们都坐在门口，把原本要说的事停了一下。她最后只把一串钥匙放到你手边。钥匙新磨过，边上还有一点铁屑。
fletcher|房间的。里面柜子没锁，不是防你，是锁坏了。想放东西的话，明天我找人来修。
你|我没有什么东西。
fletcher|会有的。
旁白|她没有把这句话说得很郑重，像在说迟早会补上缺的螺丝。你把钥匙攥了一会儿，掌心留下两道浅浅的印子，终于有了一样能放进口袋的东西。
drayton|明早还是那个点。左锅汤，右锅颜料——哎，等一下，我刚才是不是说反了？
你|我会先闻。
旁白|她笑出声。有人从走廊另一端喊你们小声一点。你们都压低了声音，却谁也没马上起身，像再坐一会儿，就能让这一天完整地过去。

# ending
旁白|旧金山的办公室还亮着灯。她把原档案放进铁柜，留在桌上的只是那张维修单。纸张翻过来，背面有一个和计时器一样的旧印记。
sanfrancisco|这次不是重发的旧信号。有人在现场看着他们。
潮痕|他也听见了？
sanfrancisco|他说记不起来。我相信他。
旁白|潮痕站在窗边，没有去碰桌上的灯。雨从玻璃外面流下来，把港口切成许多相近又不同的碎片。
tideborn|你相信他不记得，还是相信他不会做以前做过的事？
sanfrancisco|我没说后面那句。
tideborn|那你为什么签字？
sanfrancisco|因为我知道一个人醒来时什么都不记得是什么样。你也知道。
旁白|潮痕垂下眼。她手里那只旧表没有表针，表面却擦得很干净。旧金山看见了，没再说下去，先把窗缝塞住。
tideborn|如果那道门真的还认得他，你藏不住太久。
sanfrancisco|我知道。我至少要让他在被人问“你是谁”之前，有机会知道自己愿意做谁。
旁白|灯下的纸压住一小截红线。旧金山最终没有把它一起锁进柜子，而是装进一个新的证物袋，在背面写下今天的日期。
tideborn|下一份记录呢？
sanfrancisco|沉钟交换站。第五队会经过那条航路。
tideborn|你打算告诉她们多少？
sanfrancisco|先告诉她们航路上住着人。至于我欠的话，不能再用任务简报代替。
旁白|走廊外有人轻轻敲门，说医务室的名单已经齐了。旧金山应了一声，把“来历不明”那张表移到一边，先去确认每个人有没有领到干净的床单。
